    Mathematical Symbols

    This document specifies the recommended notation for mathematical symbols in OI Wiki, with some application examples.

    This document was revised referencing GB/T 3102.11-1993, ISO 80000-2:2019 and the symbol tables from "Concrete Mathematics", so it is basically compatible with the symbol systems used in textbooks and the conventional symbol systems in OI scenarios.

    For the LaTeX notation of symbols, please refer to the source code of this document

    Mathematical Logic

    No.Symbol, ExpressionMeaning, Equivalent ExpressionNotes and Examples
    n1.1𝑝 ∧𝑞p∧qconjunction of 𝑝p and 𝑞q𝑝p and 𝑞q.
    n1.2𝑝 ∨𝑞p∨qdisjunction of 𝑝p and 𝑞q𝑝p or 𝑞q;
    the "or" here is inclusive, i.e., if either 𝑝p or 𝑞q is true, then 𝑝 ∨𝑞p∨q is true.
    n1.3¬𝑝¬pnegation of 𝑝pnot 𝑝p.
    n1.4𝑝 ⟹ 𝑞p⟹q𝑝p implies 𝑞q;
    if 𝑝p is true, then 𝑞q is true    		𝑞 ⟸ 𝑝q⟸p and 𝑝 ⟹ 𝑞p⟹q are equivalent.
    n1.5𝑝 ⟺ 𝑞p⟺q𝑝p is equivalent to 𝑞q(𝑝 ⟹ 𝑞) ∧(𝑞 ⟹ 𝑝)(p⟹q)∧(q⟹p) and 𝑝 ⟺ 𝑞p⟺q are equivalent.
    n1.6(∀ 𝑥 ∈𝐴)  𝑝(𝑥)(∀ x∈A)  p(x)for all 𝑥x in 𝐴A, proposition 𝑝(𝑥)p(x) is trueIf the set 𝐴A being considered can be inferred from the context, one can use (∀ 𝑥)  𝑝(𝑥)(∀ x)  p(x).
    ∀∀ is called the universal quantifier.
    See n2.1 for the meaning of 𝑥 ∈𝐴x∈A.
    n1.7(∃ 𝑥 ∈𝐴)  𝑝(𝑥)(∃ x∈A)  p(x)there exists an 𝑥x in 𝐴A such that 𝑝(𝑥)p(x) is trueIf the set 𝐴A being considered can be inferred from the context, one can use (∃ 𝑥)  𝑝(𝑥)(∃ x)  p(x).

    ∃!∃! can also be written as ∃1∃1.
