## Vertex Coloring

(Discussion assumes undirected graphs without self-loops)

Vertex coloring of an undirected graph requires that adjacent vertices have different colors. If G is $k$-colorable but not $(k-1)$-colorable, then $k$ is called the chromatic number of G, denoted $\chi(G)$.

For any graph G, $\chi(G) \leq \Delta(G) + 1$, where $\Delta(G)$ is the maximum degree.

### Brooks' Theorem

If a connected graph is neither a complete graph nor an odd cycle, then $\chi(G) \leq \Delta(G)$.

#### Proof

???+ note "Proof"
    Let $|V(G)|=n$ and use mathematical induction.
    
    First, the statement is obviously true when $n\leq 3$.
    
    Now assume the statement holds for $n-1$. We will strengthen the proposition step by step.
    
    We only need to consider $\Delta(G)$-regular graphs, because non-regular graphs can be viewed as regular graphs with some edges removed, and this process does not affect the conclusion.
    
    For any regular graph G that is neither a complete graph nor an odd cycle, pick a vertex $v$ and consider the subgraph $H:=G-v$. By the induction hypothesis, $\chi(H)\leq\Delta(H)=\Delta(G)$. Now we only need to prove that inserting $v$ back does not affect the conclusion.
    
    Let $\Delta:=\Delta(G)$. Let the $\Delta$ colors used in H be $c_1,c_2,\dots,c_{\Delta}$, and let $v$'s $\Delta$ adjacent vertices be $v_1,v_1,\dots,v_{\Delta}$. Without loss of generality, assume all of $v$'s adjacent vertices have different colors; otherwise, the proposition is proved.
    
    Next, let $H_{i,j}$ be the subgraph of H consisting of all vertices colored $c_i$ or $c_j$ and all edges between them. Assume that any two distinct vertices $v_i$, $v_j$ are always in the same connected component of $H_{i,j}$. If they were in different connected components, we could swap the colors in one component, making $v_i$ and $v_j$ have the same color.
    
    > Here, "swapping colors" means: if there are only two colors a and b in the graph, then all vertices originally colored a are changed to b, and all vertices originally colored b are changed to a.
    
    Let this connected component be $C_{i,j}$. Then $C_{i,j}$ can only be a path from $v_i$ to $v_j$. Because $v_i$ has degree $\Delta-1$ in H, all its adjacent vertices in H must have different colors; otherwise, we could recolor $v_i$ with another color, making it share a color with another adjacent vertex of $v$. So $v_i$ has exactly one adjacent vertex in $C_{i,j}$, and similarly for $v_j$. Then we take a path $P$ from $v_i$ to $v_j$ in $C_{i,j}$. If $C_{i,j}\ne P$, then along $P$, we encounter the first vertex $u$ with degree greater than 2. Note that $u$'s adjacent vertices use at most $\Delta-2$ colors, so $u$ can be recolored, making $v_i$ and $v_j$ disconnected.
    
    Then it's not hard to see that for any three distinct vertices $v_i$, $v_j$, $v_k$, we have $V(C_{i,j})\cap V(C_{j,k})=\{v_j\}$.
    
    At this point, the work of strengthening the proposition is complete.
    
    Now it becomes simple. First, if $v$'s adjacent vertices are pairwise adjacent, the proposition is proved. Without loss of generality, let $v_1$, $v_2$ be non-adjacent. Take a neighbor $w$ of $v_1$ in $C_{1,2}$ and swap colors in $C_{1,3}$. In the new graph, $w\in V(C_{1,2})\cap V(C_{2,3})$, a contradiction.
    
    The proposition is thus proved.

### Welsh–Powell Algorithm

The Welsh–Powell algorithm is a greedy algorithm for finding a coloring when the maximum number of colors is not limited.

For an undirected graph G without self-loops, let $V(G):=\{v_1,v_2,\dots,v_n\}$ satisfy

$\deg(v_i)\geq\deg(v_{i+1}),~\forall 1\leq i\leq n-1$

The number of colors used by Welsh–Powell algorithm is at most $\max_{i=1}^n\min\{\deg(v_i)+1,i\}$, and the time complexity is $O\left(n\max_{i=1}^n\min\{\deg(v_i)+1,i\}\right)=O(n^2)$.

#### Procedure

1.  Sort the currently uncolored vertices in descending order of degree.
2.  Color the first vertex with an unused color.
3.  Sequentially traverse the remaining vertices. If the current vertex is not adjacent to all vertices that have the **same** color as the first vertex, color it with the same color as the first vertex.
4.  If there are still uncolored vertices, return to step 1; otherwise, end.

#### Proof

???+ note "Proof"
    For an undirected graph G without self-loops, let $V(G):=\{v_1,v_2,\dots,v_n\}$ satisfy
    
    $\deg(v_i)\geq\deg(v_{i+1}),~\forall 1\leq i\leq n-1$
    
    Let $V_0=\varnothing$. We take a subset $V_m$ from $V(G)\setminus\bigcup_{i=0}^{m-1} V_i$, where elements satisfy
    
    1.  $v_{k_m}\in V_m$, where $k_m=\min\{k:v_k\notin\bigcup_{i=0}^{m-1} V_i\}$
    2.  If
    
        $\{v_{i_{m,1}},v_{i_{m,2}},\dots,v_{i_{m,l_m}}\}\subset V_m,~i_{m,1}<i_{m,2}<\dots<i_{m,l_m}$
    
        then $v_j\in V_m$ if and only if
    
        1.  $j>i_{m,l_m}$
        2.  $v_j$ is not adjacent to $v_{i_{m,1}},v_{i_{m,2}},\dots,v_{i_{m,l_m}}$
    
    Obviously, if we color vertices in $V_i$ with color $i$, this coloring scheme is exactly what the Welsh–Powell algorithm gives. Clearly we have
    
    -   $V_1\neq\varnothing$
    -   $V_i\cap V_j=\varnothing\iff i\neq j$
    -   $\exists \alpha(G)\in\Bbb{N}^*,\forall i>\alpha(G),~s.t.~ V_i=\varnothing$
    
    We only need to prove:
    
    $\bigcup_{i=1}^{\alpha(G)} V_i=V(G)$
    
    where
    
    $\chi(G)\leq\alpha(G)\leq\max_{i=1}^n\min\{\deg(v_i)+1,i\}$
    
    The left inequality obviously holds. We consider the right one.
    
    First, it's not hard to derive:
    
    If $v\notin\bigcup_{i=1}^mV_i$, then $v$ is adjacent to at least one vertex in each of $V_1,V_2,\dots,V_m$, so $\deg(v)\geq m$.
    
    Therefore,
    
    $v_j\in\bigcup_{i=1}^{\deg(v_j)+1}V_i$
    
    On the other hand, based on the construction of $\{V_i\}$,
    
    $v_j\in\bigcup_{i=1}^j V_i$
    
    Combining the two gives the result.

## Edge Coloring

Edge coloring of an undirected graph requires that adjacent edges have different colors. If G is $k$-edge-colorable but not $(k-1)$-edge-colorable, then $k$ is called the edge chromatic number of G, denoted $\chi'(G)$.

### Vizing's Theorem

For a simple graph G, $\Delta(G) \leq \chi'(G) \leq \Delta(G) + 1$

If G is a bipartite graph, then $\chi'(G)=\Delta(G)$

When $n$ is odd ($n \neq 1$), $\chi'(K_n)=n$; when $n$ is even, $\chi'(K_n)=n-1$

### Constructive Proof of Vizing's Theorem for Bipartite Graphs

???+ note "Proof"
    We add edges to the bipartite graph sequentially.
    
    When trying to add edge $(x,y)$, we find the smallest unused color numbers for $x$ and $y$, denoted $l_x$ and $l_y$ respectively.
    
    If $l_x=l_y$, we can directly set this edge's color to $l_x$.
    
    Otherwise, assume $l_x<l_y$. We try to change the color of the edge incident to $y$ with color $l_x$ to $l_y$.
    
    This modification process can be approximated as a finite alternating augmenting path starting from $y$, alternating between edges of color $l_x$ and $l_y$.
    
    Since the augmenting path is finite, we can reverse the colors of all edges on the path: edges originally colored $l_x$ become $l_y$, and edges originally colored $l_y$ become $l_x$.
    
    By the properties of bipartite graphs, node $x$ cannot be a node on the augmenting path; otherwise, it would contradict $l_x$ being the smallest unused color.
    
    Therefore, after augmentation, we can directly set the edge connecting $x$ and $y$ to color $l_x$.
    
    The total construction time complexity is $O(nm)$.

## Chromatic Polynomial

$P(G,k)$ denotes the total number of different $k$-colorings of G.

$P(K_n, k) = k(k-1)\cdots(k-n+1)$

$P(N_n, k) = k^n$

In an undirected acyclic graph G,

1.  $e=(v_i, v_j) \notin E(G)$, then $P(G, k) = P(G \cup e, k)+P(G\setminus e, k)$
2.  $e=(v_i, v_j) \in E(G)$, then $P(G,k)=P(G-e,k)-P(G\setminus e,k)$

Theorem: Let $V_1$ be a vertex cut set of G, and $G[V_1]$ be a complete subgraph of G of order $|V_1|$. If $G-V_1$ has $p(p \geq 2)$ connected components, then:

$P(G,k)=\frac{\Pi_{i=1}^{p}{(P(H_i, k))}}{P(G[V_1], k)^{p-1}}$

where $H_i=G[V_1 \cup V(G_i)]$
