This chapter introduces dynamic programming (DP), the kinds of problems it solves, algorithms designed with it, and common optimizations.

Dynamic programming is a method for solving complex problems by decomposing the original problem into relatively simple subproblems.

Because dynamic programming is not one specific algorithm, but a way to solve certain classes of problems, it appears across many data structures and problem types. Related problems are therefore quite diverse.

In OI, recurrence-based solutions for non-optimization problems such as counting are also often informally called DP. This chapter includes them as well. In practice, dynamic programming and other kinds of recurrences share many similarities, so it is useful to compare their commonalities and differences while learning.
