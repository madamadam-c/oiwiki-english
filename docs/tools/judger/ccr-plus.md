## CCR Plus

**CCR Plus** is an open-source cross-platform judging environment suitable for NOI series competitions, written using Qt, and currently supports Windows and Linux.

Source code is hosted at [sxyzccr/CCR-Plus](https://github.com/sxyzccr/CCR-Plus).
