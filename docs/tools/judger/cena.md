## Cena

**Cena** is an open-source judging tool written by Liu Qishuai and Li Zixing in Pascal language, and is the most widely used local judging tool. Cena was originally open-sourced on the Google Code platform. Due to unknown reasons, Google deleted the Cena project. Currently, you can find Cena's official website on [Web Archive](https://web.archive.org/web/20131023112258/http://code.google.com/p/cena/).

Cena's permission restrictions are not very clear; during testing, you can read test points as AC.

Cena's source code is hosted at [oi-archive/cena](https://github.com/oi-archive/cena).
