## Introduction

The **15-puzzle** (also known as the Gem Puzzle, Boss Puzzle, Game of 15, Mystic Square, N-puzzle, etc.) is a sliding puzzle game. The sliding board has size $4\times 4$, with 15 positions occupied by numbered tiles in a shuffled order and one position empty. Tiles in the same row or column as the empty space can be moved by sliding horizontally or vertically. The goal of the puzzle is to arrange the tiles in numeric order.

The 15-puzzle is commonly also called the **n-puzzle**, where the number $n$ refers to the total number of tiles on the board. Variants of different sizes use similar names; for example, the $8$-puzzle refers to $8$ tiles placed on a $3\times3$ board. But the $15$-puzzle can also be called the $16$-puzzle, where 16 refers to the board capacity. Its extended problems sometimes also include $n \times m$ sliding boards.

The 15-puzzle is a classic problem involving [heuristic algorithm](../search/heuristic.md) modeling. Common forms of this problem use [Manhattan distance](../geometry/distance.md#曼哈顿距离) and the number of misplaced tiles. Both are admissible heuristics, meaning they never overestimate the number of remaining moves, which ensures optimality for certain search algorithms such as the [A \* algorithm](../search/astar.md).

???+ note "Note"
    **Sliding puzzles** are puzzle games in which tiles slide on a plane to form a specified arrangement. Common sliding puzzles include number puzzles, Klotski, and Rush Hour. Among them, the 15-puzzle is the oldest sliding puzzle, invented by Noyes Chapman, and it became popular in the 1880s. Unlike other tour-type puzzles, sliding puzzles forbid any tile from leaving the board, which distinguishes them from rearrangement puzzles.

## Definition

Given a $4 \times 4$ board with $15$ tiles arranged arbitrarily, we need to arrange them in numeric order as shown below. The move rule is that each move can only swap the empty tile with one adjacent tile. Common questions include finding the minimum number of steps to solve the puzzle, computing the number of misplaced tiles, or determining whether the final ordered arrangement can be reached.

## Solvability Proof

Johnson & Story (1879) proved that if both $m$ and $n$ are at least $2$, the converse applies to boards of size $m\times n$: by induction on $m$ and $n$ starting from $m=n=2$, all even permutations are solvable. Archer (1999) gave another proof based on equivalence classes defined by Hamiltonian paths.

## Algorithms

Finding one solution to a number sliding puzzle is relatively easy, but finding an **optimal solution** is an **NP-hard** problem. An optimal solution to the 15-puzzle has at most 80 moves; an optimal solution to the 8-puzzle has at most 31 moves.

N-puzzle supports common graph-based search algorithms such as breadth-first search and depth-first search. We can also use the [A \* search](../search/astar.md) algorithm to find an optimal solution. The heuristic function $h(n)$ can be

-   The number of misplaced tiles.
-   The sum of Euclidean distances from all misplaced tiles to their target positions.
-   The sum of Manhattan distances from all misplaced tiles to their target positions.

### Group Theory

Because configurations of the 15-tile number sliding puzzle can be generated by "3-cycles", it can be proved that the 15-tile number sliding puzzle can be represented by the alternating group $A_{15}$. In fact, any number sliding puzzle using $2\times k-1$ square tiles of equal area can be represented by the alternating group $A_{2k-1}$.
