This document specifies the recommended notation for mathematical symbols in **OI Wiki**, with some application examples.

This document was revised referencing [GB/T 3102.11-1993](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=3DE79450D562E62D41CB6E79FF411054), [ISO 80000-2:2019](https://www.iso.org/standard/64973.html) and the symbol tables from "Concrete Mathematics", so it is basically compatible with the symbol systems used in textbooks and the conventional symbol systems in OI scenarios.

For the LaTeX notation of symbols, please refer to [the source code of this document](https://github.com/OI-wiki/OI-wiki/blob/master/docs/intro/symbol.md?plain=1)

## Mathematical Logic

| No.                   | Symbol, Expression                    | Meaning, Equivalent Expression                          | Notes and Examples                                                                                                                                                                                               |
| --------------------- | ------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="n1.1"></a>n1.1 | $p \land q$               | conjunction of $p$ and $q$                    | $p$ and $q$.                                                                                                                                                                                          |
| <a id="n1.2"></a>n1.2 | $p \lor q$                | disjunction of $p$ and $q$                    | $p$ or $q$;<br>the "or" here is inclusive, i.e., if either $p$ or $q$ is true, then $p \lor q$ is true.                                                                                                                                     |
| <a id="n1.3"></a>n1.3 | $\lnot p$                 | negation of $p$                          | not $p$.                                                                                                                                                                                              |
| <a id="n1.4"></a>n1.4 | $p \implies q$            | $p$ implies $q$;<br>if $p$ is true, then $q$ is true | $q \impliedby p$ and $p \implies q$ are equivalent.                                                                                                                                                               |
| <a id="n1.5"></a>n1.5 | $p \iff q$                | $p$ is equivalent to $q$                      | $(p \implies q) \land (q \implies p)$ and $p \iff q$ are equivalent.                                                                                                                                              |
| <a id="n1.6"></a>n1.6 | $(\forall~x \in A)~~p(x)$ | for all $x$ in $A$, proposition $p(x)$ is true    | If the set $A$ being considered can be inferred from the context, one can use $(\forall~x)~~p(x)$.<br>$\forall$ is called the universal quantifier.<br>See [n2.1](#n2.1) for the meaning of $x \in A$.                                                                                          |
| <a id="n1.7"></a>n1.7 | $(\exists~x \in A)~~p(x)$ | there exists an $x$ in $A$ such that $p(x)$ is true    | If the set $A$ being considered can be inferred from the context, one can use $(\exists~x)~~p(x)$.<br>$\exists$ is called the existential quantifier.<br>See [n2.1](#n2.1) for the meaning of $x \in A$.<br>$(\exists!~x)~~p(x)$ (unique quantifier) indicates there is exactly one $x$ such that $p(x)$ is true.<br>$\exists!$ can also be written as $\exists^1$. |

## Set Theory

| No.                      | Symbol, Expression                                                | Meaning, Equivalent Expression                         | Notes and Examples                                                                                                                                                                                                                                                                                                                                 |
| ----------------------- | ----------------------------------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="n2.1"></a>n2.1   | $x \in A$                                             | $x$ belongs to $A$, $x$ is an element of set $A$     | $A \ni x$ and $x \in A$ are equivalent.                                                                                                                                                                                                                                                                                                             |
| <a id="n2.2"></a>n2.2   | $y \notin A$                                          | $y$ does not belong to $A$, $y$ is not an element of $A$   |                                                                                                                                                                                                                                                                                                                                       |
| <a id="n2.3"></a>n2.3   | $\{x_1, x_2, \dots, x_n\}$                            | set containing elements $x_1, x_2, \dots, x_n$  | Can also be written as $\{x_i ~\vert~ i \in I\}$, where $I$ is the index set.                                                                                                                                                                                                                                                                                         |
| <a id="n2.4"></a>n2.4   | $\{x \in A ~\vert~ p(x)\}$                            | set of all elements in $A$ for which proposition $p(x)$ is true    | For example $\{x \in \textbf{R} ~\vert~ x \geq 5\}$;<br>if the set $A$ being considered can be inferred from the context, one can use $\{x ~\vert~ p(x)\}$ (e.g., $\{x ~\vert~ x \geq 5\}$ when only considering real numbers)<br>$\vert$ can also be replaced with a colon, like $\{x \in A : p(x)\}$.                                                                                                                                                |
| <a id="n2.5"></a>n2.5   | $\operatorname{card} A$;<br>$\vert A\vert$;<br>$\# A$ | number of elements in $A$, cardinality of $A$              |                                                                                                                                                                                                                                                                                                                                       |
| <a id="n2.6"></a>n2.6   | $\varnothing$                                         | empty set                              | $\emptyset$ should not be used.                                                                                                                                                                                                                                                                                                                     |
| <a id="n2.7"></a>n2.7   | $B \subseteq A$                                       | $B$ is contained in $A$, $B$ is a subset of $A$     | Every element of $B$ belongs to $A$.<br>$\subset$ can also be used for this meaning, but see the note in [n2.8](#n2.8).<br>$A \supseteq B$ and $B \subseteq A$ are equivalent.                                                                                                                                                                                                                               |
| <a id="n2.8"></a>n2.8   | $B \subset A$                                         | $B$ is strictly contained in $A$, $B$ is a proper subset of $A$   | Every element of $B$ belongs to $A$, and $A$ has at least one element not in $B$.<br>If $\subset$ has the meaning of [n2.7](#n2.7), then the symbol for [n2.8](#n2.8) should use $\subsetneq$.<br>$A \supset B$ and $B \subset A$ are equivalent.                                                                                                                                                                               |
| <a id="n2.9"></a>n2.9   | $A \cup B$                                            | union of $A$ and $B$                   | $A \cup B := \{x ~\vert~ x \in A \lor x \in B\}$;<br>see [n4.3](#n4.3) for the definition of $:=$                                                                                                                                                                                                                                                         |
| <a id="n2.10"></a>n2.10 | $A \cap B$                                            | intersection of $A$ and $B$                   | $A \cap B := \{x ~\vert~ x \in A \land x \in B\}$;<br>see [n4.3](#n4.3) for the definition of $:=$                                                                                                                                                                                                                                                        |
| <a id="n2.11"></a>n2.11 | $\displaystyle \bigcup\limits_{i=1}^n A_i$            | union of sets $A_1, A_2, \dots, A_n$   | $\displaystyle \bigcup\limits_{i=1}^n A_i=A_1\cup A_2\cup \dots \cup A_n$;<br>can also use $\displaystyle \bigcup\nolimits_{i=1}^n$，$\displaystyle \bigcup\limits_{i\in I}$，$\displaystyle \bigcup\nolimits_{i\in I}$, where $I$ is the index set；<br>further, if $P(i)$ is a proposition related to $i$, one can use $\displaystyle \bigcup_{P(i)} A_i$ to denote the union of all $A_i$ for which $P(i)$ is true |
| <a id="n2.12"></a>n2.12 | $\displaystyle \bigcap\limits_{i=1}^n A_i$            | intersection of sets $A_1, A_2, \dots, A_n$   | $\displaystyle \bigcap\limits_{i=1}^n A_i=A_1\cap A_2\cap \dots \cap A_n$;<br>can also use $\displaystyle \bigcap\nolimits_{i=1}^n$，$\displaystyle \bigcap\limits_{i\in I}$，$\displaystyle \bigcap\nolimits_{i\in I}$, where $I$ is the index set；<br>further, if $P(i)$ is a proposition related to $i$, one can use $\displaystyle \bigcap_{P(i)} A_i$ to denote the intersection of all $A_i$ for which $P(i)$ is true |
| <a id="n2.13"></a>n2.13 | $A \setminus B$                                       | set difference of $A$ and $B$                   | $A \setminus B = \{x ~\vert~ x \in A \land x \notin B\}$;<br>$A - B$ should not be used；<br>when $B$ is a subset of $A$, one can also use $\complement_A B$, and $A$ can be omitted if the set $A$ being considered can be inferred from the context.<br>When no ambiguity arises, $\overline{B}$ can also be used to denote the complement of set $B$.                                                                                                                               |
| <a id="n2.14"></a>n2.14 | $(a, b)$                                              | ordered pair $a$, $b$    | $(a, b) = (c, d)$ if and only if $a = c$ and $b = d$.                                                                                                                                                                                                                                                                                             |
| <a id="n2.15"></a>n2.15 | $(a_1, a_2, \dots, a_n)$                              | ordered $n$-tuple                       | See [n2.14](#n2.14).                                                                                                                                                                                                                                                                                                                   |
| <a id="n2.16"></a>n2.16 | $A \times B$                                          | Cartesian product of sets $A$ and $B$              | $A \times B = \{(x, y) ~\vert~ x \in A \land y \in B\}$.                                                                                                                                                                                                                                                                              |
| <a id="n2.17"></a>n2.17 | $\displaystyle \prod\limits_{i=1}^{n} A_i$            | Cartesian product of sets $A_1, A_2, \dots, A_n$ | $\displaystyle \prod\limits_{i=1}^{n} A_i=\{(x_1, x_2, \dots, x_n) ~\vert~ x_1 \in A_1, x_2 \in A_2, \dots, x_n \in A_n\}$;<br>$A \times A \times \dots \times A$ is denoted as $A^n$, where $n$ is the number of factors；<br>see [n6.8](#n6.8) for another usage of this symbol                                                                                                             |
| <a id="n2.18"></a>n2.18 | $\mathrm{id}_A$                                       | diagonal of $A\times A$                | $\mathrm{id}_A=\{(x, x)~\vert~x\in A\}$;<br>if the set $A$ being considered can be inferred from the context, $A$ can be omitted．                                                                                                                                                                                                                                                      |
| <a id="n2.19"></a>n2.19 | $\mathbf{1}_A$                                        | indicator function                            | $\mathbf{1}_A(a)=[a\in A]$, see [n6.24](#n6.24) for the definition of $[\cdot]$．                                                                                                                                                                                                                                                                           |
| <a id="n2.20"></a>n2.20 | $\mathcal{P}(A)$;<br>$2^A$                            | power set                              | $\mathcal{P}(A)=\{S:S\subseteq A\}$                                                                                                                                                                                                                                                                                                   |

## Standard Number Sets and Intervals

| No.                      | Symbol, Expression       | Meaning, Equivalent Expression           | Notes and Examples                                                                                                                                                                                       |
| ----------------------- | ------------ | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="n3.1"></a>n3.1   | $\mathbf{N}$ | set of natural numbers              | $\mathbf{N} = \{0, 1, 2, 3, \dots\}$;<br>$\mathbf{N}^* = \mathbf{N}_+ = \{1, 2, 3, \dots\}$;<br>other restrictions can be added as: $\mathbf{N}_{> 5} = \{n \in \mathbf{N} ~\vert~ n > 5\}$;<br>can also use $\mathbb{N}$. |
| <a id="n3.2"></a>n3.2   | $\mathbf{Z}$ | set of integers               | $\mathbf{Z}^* = \mathbf{Z}_+ = \{n \in \mathbf{Z} ~\vert~ n \ne 0\}$;<br>other restrictions can be added as: $\mathbf{Z}_{> -3} = \{n \in \mathbf{Z} ~\vert~ n > -3\}$;<br>can also use $\mathbb{Z}$.                      |
| <a id="n3.3"></a>n3.3   | $\mathbf{Q}$ | set of rational numbers              | $\mathbf{Q}^* = \mathbf{Q}_+ = \{r \in \mathbf{Q} ~\vert~ r \ne 0\}$;<br>other restrictions can be added as: $\mathbf{Q}_{< 0} = \{r \in \mathbf{Q} ~\vert~ r < 0\}$;<br>can also use $\mathbb{Q}$.                        |
| <a id="n3.4"></a>n3.4   | $\mathbf{R}$ | set of real numbers               | $\mathbf{R}^* = \mathbf{R}_+ = \{x \in \mathbf{R} ~\vert~ x \ne 0\}$;<br>other restrictions can be added as: $\mathbf{R}_{> 0} = \{x \in \mathbf{R} ~\vert~ x > 0\}$;<br>can also use $\mathbb{R}$.                        |
| <a id="n3.5"></a>n3.5   | $\mathbf{C}$ | set of complex numbers               | $\mathbf{C}^* = \mathbf{C}_+ = \{z \in \mathbf{C} ~\vert~ z \ne 0\}$;<br>can also use $\mathbb{C}$.                                                                                                 |
| <a id="n3.6"></a>n3.6   | $\mathbf{P}$ | set of (positive) prime numbers            | $\mathbf{P} = \{2, 3, 5, 7, 11, 13, 17, \dots\}$;<br>can also use $\mathbb{P}$.                                                                                                                     |
| <a id="n3.7"></a>n3.7   | $[a, b]$     | closed interval from $a$ to $b$    | $[a, b] = \{x \in \mathbf{R} ~\vert~ a \leq x \leq b\}$.                                                                                                                                    |
| <a id="n3.8"></a>n3.8   | $(a, b]$     | left-open right-closed interval from $a$ to $b$ | $(a, b] = \{x \in \mathbf{R} ~\vert~ a < x \leq b\}$;<br>$(-\infty, b] = \{x \in \mathbf{R} ~\vert~ x \leq b\}$.                                                                            |
| <a id="n3.9"></a>n3.9   | $[a, b)$     | left-closed right-open interval from $a$ to $b$ | $[a, b) = \{x \in \mathbf{R} ~\vert~ a \leq x < b\}$;<br>$[a, +\infty) = \{x \in \mathbf{R} ~\vert~ a \leq x\}$.                                                                            |
| <a id="n3.10"></a>n3.10 | $(a, b)$     | open interval from $a$ to $b$    | $(a, b) = \{x \in \mathbf{R} ~\vert~ a < x < b\}$;<br>$(-\infty, b) = \{x \in \mathbf{R} ~\vert~ x < b\}$;<br>$(a, +\infty) = \{x \in \mathbf{R} ~\vert~ a < x\}$.                          |

## Relations

| ----------------------- | -------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------- |

| <a id="n4.8"></a>n4.8   | $a < b$              | $a$ is less than $b$         |                                                                                                               |
| <a id="n4.9"></a>n4.9   | $b > a$              | $b$ is greater than $a$         |                                                                                                               |
| <a id="n4.10"></a>n4.10 | $a \leq b$           | $a$ is less than or equal to $b$       |                                                                                                               |
| <a id="n4.11"></a>n4.11 | $b \geq a$           | $b$ is greater than or equal to $a$       |                                                                                                               |
| <a id="n4.12"></a>n4.12 | $a \ll b$            | $a$ is much less than $b$        |                                                                                                               |
| <a id="n4.13"></a>n4.13 | $b \gg a$            | $b$ is much greater than $a$        |                                                                                                               |
| <a id="n4.14"></a>n4.14 | $\infty$             | infinity                | this symbol is **not** a number.<br>can also use $+\infty$，$-\infty$.                                                                  |
| <a id="n4.15"></a>n4.15 | $x \to a$            | $x$ approaches $a$        | usually appears in limit expressions.<br>$a$ can also be $\infty$，$+\infty$，$-\infty$.                                                        |
| <a id="n4.16"></a>n4.16 | $m \mid n$           | $m$ divides $n$         | for integers $m$, $n$:<br>$(\exists~k \in \mathbf{Z})~~m\cdot k = n$.                                                   |
| <a id="n4.17"></a>n4.17 | $m \perp n$          | $m$ is coprime to $n$       | for integers $m$, $n$:<br>$(\nexists~k \in \mathbf{Z}_{>1})~~(k \mid m) \land (k \mid n)$;<br>see [n5.2](#n5.2) for another usage of this symbol |
| <a id="n4.18"></a>n4.18 | $n \equiv k \pmod m$ | $n$ is congruent to $k$ modulo $m$ | for integers $n$, $k$, $m$:<br>$m \mid (n - k)$;<br>do not confuse with the meaning in [n4.1](#n4.1).                                           |
