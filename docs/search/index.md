Search means enumerating the state space, exhausting all possibilities to find the optimal solution or to count the number of valid solutions.

There are many ways to optimize search, such as reducing the state space, changing the search order, and pruning.

Search is the basis of some advanced algorithms. In OI, pure search is often also a way to obtain partial scores, but very few problems can be fully solved by pure search alone.
