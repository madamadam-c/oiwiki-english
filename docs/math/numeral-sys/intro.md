???+ warning "Warning"
    The discussion here is not about [number systems](https://en.wikipedia.org/wiki/Number#Classification). In mathematics, a number system refers to a class of sets, such as the set of integers $\mathbf{Z}$ or the set of complex numbers $\mathbf{C}$.

A **numeral system**, also called a **system of numeration**, is a writing system used to represent numbers, such as the [Hindu–Arabic numeral system](https://en.wikipedia.org/wiki/Hindu%E2%80%93Arabic_numeral_system), [Roman numerals](https://en.wikipedia.org/wiki/Roman_numerals), or [Suzhou numerals](https://en.wikipedia.org/wiki/Suzhou_numerals). Numeral systems are tools for encoding numbers.

Generally, in a numeral system, each numeral is a string of symbols, along with a set of rules that map this string to the corresponding number. For example, the Roman numeral $\text{XLII}$, the binary number $101010_{(2)}$, and the decimal number $42$ all correspond to the same number.

In competitive programming, we usually only focus on the conversion relationships between different numeral systems. See [Positional Notation](./base.md) for details.
