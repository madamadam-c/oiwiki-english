**Algorithm**, as the name suggests, refers to a method of computation. Algorithms are usually used to solve specific computational tasks, but unlike programs that can run directly on a computer, algorithms use mathematical descriptions and focus more on the underlying ideas, and can be regarded as abstract programs. The same algorithm can have many different implementations, and two different programs may also use the same algorithm.

This chapter introduces some fundamental algorithms. When a computational task is general enough to appear widely across various problems, the algorithm for solving that task is called by more algorithms, gaining considerable importance and fundamentality. At the same time, the more general an algorithm is, the simpler it usually is, resembling ideas rather than programs. The algorithms introduced in this chapter possess sufficient elegance and interest, and will often appear in subsequent advanced content.
