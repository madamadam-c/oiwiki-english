    Graph Matching

    Introduction

    A matching, or independent edge set, is a set of edges in a graph that share no common endpoints. Graph matching algorithms are commonly used in competitive programming and can be roughly divided into two categories: maximum matching and maximum weight matching. Since matching in a bipartite graph is equivalent to a network flow problem and has good properties, it is relatively easier to handle. Therefore, we will first introduce algorithms for bipartite graphs, then discuss algorithms for general graphs.

    Matching in Graphs

    Let 𝐺 =(𝑉,𝐸)G=(V,E) be an undirected graph, where 𝑉V is the set of vertices and 𝐸E is the set of edges. If a set of edges 𝑀 ⊆𝐸M⊆E contains no self-loops and no two edges share a common vertex, then 𝑀M is called a matching or independent edge set of graph 𝐺G. An edge 𝑒 ∈𝐸e∈E that appears in matching 𝑀M is called a matched edge, otherwise it is called an unmatched edge. Similarly, a vertex 𝑣 ∈𝑉v∈V is called a matched vertex if it is an endpoint of a matched edge, otherwise it is called an unmatched vertex.

    The size of a matching 𝑀M is the number of edges it contains. For (weighted) undirected graphs, the following concepts are often considered:

    • Maximal matching: A matching to which no more edges can be added. A maximal matching is not necessarily a maximum matching.

    • Maximum matching or maximum cardinality matching: A matching with the maximum number of edges. There may be more than one maximum matching, but the number of edges in a maximum matching is fixed and cannot exceed half the number of vertices in the graph.

    • Maximum weight matching: In a weighted graph, a matching with the maximum sum of edge weights.

    • Maximum weight maximum cardinality matching: Among all maximum matchings (those with the most edges), the one with the maximum sum of edge weights. That is, the maximum weight matching among all maximum cardinality matchings.

    • Perfect matching: A matching in which every vertex is a matched vertex. A perfect matching is always a maximum matching. Any complete graph with an even number of vertices necessarily has a perfect matching.

    • Near-perfect matching: A matching with exactly one unmatched vertex. This can only occur when the graph has an odd number of vertices. A near-perfect matching is always a maximum matching. Any complete graph with an odd number of vertices necessarily has a near-perfect matching.

    In competitive programming, graph matching problems primarily refer to finding maximum matchings or maximum weight matchings.

    Augmenting Paths

    In graph matching algorithms, augmenting paths are the core structures used to improve matchings.

    Definition

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E) and its matching 𝑀M, we can define the following two types of (simple) paths:

    • An alternating path is a path that alternates between matched edges and unmatched edges.
    • An augmenting path is an alternating path that starts and ends at unmatched vertices.

    Since an augmenting path has one more unmatched edge than matched edges, the number of edges in an augmenting path is always odd. If we flip the matched and unmatched edges along an augmenting path, it remains an alternating path, and the matching size increases by 1. The process of finding an augmenting path and flipping it to increase the matching size is called augmentation. In mathematical terms, augmentation corresponds to taking the symmetric difference of the matching 𝑀M and the augmenting path 𝑃P, obtaining a new matching 𝑀 ⊕𝑃M⊕P.

    Berge's Lemma

    Berge's lemma shows that improving a matching using augmenting paths is sufficient. That is, when no augmenting path can be found, we have already obtained a maximum matching.

    Berge's Lemma

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E) and its matching 𝑀M, the matching 𝑀M is maximum if and only if there exists no augmenting path relative to 𝑀M.

    Proof

    The forward direction was already shown above: when there exists an augmenting path 𝑃P, the matching 𝑀 ⊕𝑃M⊕P is larger than 𝑀M, so 𝑀M cannot be a maximum matching.

    Conversely, we need to show that if there exists a matching 𝑀′M′ that is larger than 𝑀M, then there must exist an augmenting path 𝑃P relative to 𝑀M. To show this, consider the symmetric difference 𝑀 ⊕𝑀′M⊕M′. In the graph (𝑉,𝑀 ⊕𝑀′(V,M⊕M′, each vertex has degree 0, 1, or 2; the connected components of such a graph must be paths, cycles, or isolated vertices. Moreover, the two edges adjacent to a vertex of degree 2 must come from different matchings, so the number of edges from 𝑀M and 𝑀′M′ in each cycle is equal. Since 𝑀′M′ is larger than 𝑀M, there exists at least one path in which the number of edges from 𝑀′M′ exceeds the number from 𝑀M; call this path 𝑃P. Then both endpoints of 𝑃P are unmatched vertices in 𝑀M, and 𝑃P is an alternating path relative to 𝑀M, so 𝑃P must be an augmenting path relative to 𝑀M. This completes the proof.

    From this theorem, we can derive the core approach for finding maximum matchings:

    • Enumerate all unmatched vertices, searching for augmenting paths, until no augmenting path can be found.

    In fact, after each augmentation operation, we don't need to re-enumerate all unmatched vertices. In the entire process of finding a maximum matching, each vertex only needs to be traversed once.

    Proof

    We only need to show that if, when enumeration reaches vertex 𝑣v, there is no augmenting path starting from 𝑣v, then even after several rounds of augmentation, there will still be no augmenting path starting from 𝑣v. This shows that even if augmentation changes the matching, we don't need to re-check previously enumerated unmatched vertices.

    Suppose otherwise. That is, suppose 𝑣v is an already-enumerated unmatched vertex, and after some round of augmentation along an augmenting path 𝑃P from 𝑢u to 𝑤w, a new augmenting path 𝑃′P′ starting from 𝑣v appears that didn't exist before. Then path 𝑃′P′ must share an edge with 𝑃P; otherwise, augmenting along 𝑃P wouldn't change the matching status of any edge in 𝑃′P′, so 𝑃′P′ wouldn't be a newly created augmenting path due to this augmentation.

    (In the figure, black edges represent unmatched edges, while red and blue edges represent different matching states.)

    Let 𝑥x be the first vertex of 𝑃P encountered when traversing along 𝑃′P′ starting from 𝑣v. Since there existed an alternating path from 𝑣v to 𝑥x before this augmentation, 𝑥x must be a matched vertex, and thus cannot be either vertex 𝑢u or vertex 𝑤w. Therefore, on the augmenting path 𝑃P, the two edges adjacent to 𝑥x have opposite matching status. This means that regardless of the matching status of the edge when arriving at vertex 𝑥x along an alternating path starting from 𝑣v, we can extend the alternating path along path 𝑃P to reach either 𝑢u or 𝑤w. This shows that before the augmentation, there already existed an augmenting path starting from 𝑣v, contradicting our assumption.

    Alternating Trees

    Another concept closely related to augmenting paths is the alternating tree. It is a tree generated during the process of searching for augmenting paths using DFS or BFS starting from an unmatched vertex.

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E) and its matching 𝑀M, if a subgraph 𝐻 ⊆𝐺H⊆G is a tree rooted at an unmatched vertex 𝑟r, and the path connecting 𝑟r and any 𝑣 ∈𝐻v∈H is an alternating path, then 𝐻H is called an alternating tree. Vertices at even depths in the tree are called even vertices, and vertices at odd depths are called odd vertices.

    Existence of Perfect Matchings

    In graph matching theory, there are two important existence theorems that can be used to determine whether a perfect matching exists in a bipartite graph or general graph.

    Hall's Theorem

    Assume 𝐺 =(𝑋,𝑌,𝐸)G=(X,Y,E) is a bipartite graph with |𝑋| ≤|𝑌||X|≤|Y|. For a matching 𝑀M of graph 𝐺G, if all vertices in 𝑋X are matched vertices, then 𝑀M is called an 𝑋X-perfect matching, sometimes simply called a (bipartite graph 𝐺G) perfect matching. This is the largest matching that can be achieved in a bipartite graph. Hall's theorem provides a necessary and sufficient condition for the existence of such a matching.

    Hall's theorem states that as long as for any subset of 𝑋X, there are enough vertices in 𝑌Y that can be matched with it, an 𝑋X-perfect matching must exist.

    Hall's Theorem

    Assume 𝐺 =(𝑋,𝑌,𝐸)G=(X,Y,E) is a bipartite graph with |𝑋| ≤|𝑌||X|≤|Y|. For any 𝑊 ⊆𝑋W⊆X, let 𝑁𝐺(𝑊)NG(W) be the set of all vertices in graph 𝐺G adjacent to vertices in 𝑊W. Then an 𝑋X-perfect matching exists if and only if |𝑊| ≤|𝑁𝐺(𝑊)||W|≤|NG(W)| holds for all 𝑊 ⊆𝑋W⊆X.

    Proof

    The condition is clearly necessary. Suppose an 𝑋X-perfect matching 𝑀M exists, then every vertex in 𝑋X is matched to a distinct vertex in 𝑌Y. The set 𝑁𝐺(𝑊)NG(W) includes at least the vertices matched with vertices in 𝑊W, so its size is at least |𝑊||W|.

    The condition is also sufficient. Suppose no 𝑋X-perfect matching exists, then there must be a maximum matching 𝑀M such that a vertex 𝑣 ∈𝑋v∈X remains unmatched. Let 𝑍Z be the set of all vertices reachable by alternating paths starting from 𝑣v, and let 𝑆 =𝑍 ∩𝑋S=Z∩X, 𝑇 =𝑍 ∩𝑌T=Z∩Y. The set 𝑆 ∖{𝑣}S∖{v} must all be matched vertices, otherwise there would be an odd cycle, contradicting that 𝐺G is a bipartite graph. The set 𝑇T must also all be matched vertices, otherwise there would be an augmenting path, contradicting that 𝑀M is a maximum matching by Berge's lemma. Since they are all matched vertices, and matching can only occur between 𝑋X and 𝑌Y, the vertices in 𝑆 ∖{𝑣}S∖{v} correspond one-to-one with vertices in 𝑇T, so |𝑇| =|𝑆| −1|T|=|S|−1. Since vertices in 𝑇T are already matched with vertices in 𝑆S, we have 𝑇 ⊆𝑁𝐺(𝑆)T⊆NG(S). However, there is no unmatched vertex in 𝑁𝐺(𝑆)NG(S), because if there were an unmatched vertex 𝑢u adjacent to some 𝑣′v′ in 𝑆S, we could extend the alternating path reaching 𝑣′v′ to reach 𝑢u. This shows 𝑇 =𝑁𝐺(𝑆)T=NG(S). These arguments show |𝑁𝐺(𝑆)| <|𝑆||NG(S)|<|S|, which contradicts the condition assumed in Hall's theorem. This proves that an 𝑋X-perfect matching exists.

    Corollary

    Every regular bipartite graph has a perfect matching.

    Proof

    In a regular bipartite graph, all vertices have the same degree, say 𝑘k. First verify that Hall's condition holds, i.e., for any 𝑊 ⊆𝑋W⊆X, we have |𝑁𝐺(𝑊)| ≥|𝑊||NG(W)|≥|W|. The number of edges adjacent to vertices in 𝑊W is 𝑘|𝑊|k|W|, and each vertex in 𝑁𝐺(𝑊)NG(W) can be adjacent to at most 𝑘k of these edges, so we must have 𝑘|𝑊| ≤𝑘|𝑁𝐺(𝑊)|k|W|≤k|NG(W)|, i.e., |𝑊| ≤|𝑁𝐺(𝑊)||W|≤|NG(W)|. In particular, we have |𝑋| ≤|𝑌||X|≤|Y|; since 𝑋X and 𝑌Y are symmetric, we have |𝑋| =|𝑌||X|=|Y|. This shows that in a regular bipartite graph, an 𝑋X-perfect matching is also a perfect matching. Since Hall's theorem guarantees the existence of an 𝑋X-perfect matching, a perfect matching must also exist.

    Tutte's Theorem

    Tutte's theorem provides a necessary and sufficient condition for the existence of perfect matchings in general graphs. This condition comes from a direct observation: a graph with an odd number of vertices cannot have a perfect matching.

    Tutte's Theorem

    A graph 𝐺 =(𝑉,𝐸)G=(V,E) has a perfect matching if and only if for every 𝑈 ⊆𝑉U⊆V, we have odd⁡(𝐺 −𝑈) ≤|𝑈|odd⁡(G−U)≤|U|, where 𝐺 −𝑈G−U denotes the subgraph obtained by deleting vertices in 𝑈U and all edges incident to them from graph 𝐺G, and odd⁡(𝐺 −𝑈)odd⁡(G−U) denotes the number of connected components of 𝐺 −𝑈G−U that have an odd number of vertices.

    Proof

    We only need to consider simple graphs, since multiple edges and self-loops do not affect Tutte's condition or the existence of perfect matchings.

    The necessity of the condition is relatively straightforward. Suppose a perfect matching 𝑀M exists. For any 𝑈 ⊆𝑉U⊆V, after removing vertices in 𝑈U from graph 𝐺G, each connected component with an odd number of vertices has at least one vertex that cannot be matched with vertices in the same connected component; these vertices must seek to be matched with vertices in 𝑈U. For such a matching to exist, we must have odd⁡(𝐺 −𝑈) ≤|𝑈|odd⁡(G−U)≤|U|. This is the Tutte condition.

    The sufficiency of the condition is more complex. Suppose 𝐺G satisfies the Tutte condition but has no perfect matching. Since adding any edge to 𝐺G would still satisfy the Tutte condition, we may assume 𝐺G is a maximal such graph; that is, 𝐺G has no perfect matching, but for any non-existent edge 𝑒e, 𝐺 +𝑒G+e has a perfect matching. Let 𝑈 ⊆𝑉U⊆V be the set of all vertices with degree |𝑉| −1|V|−1. It can be shown that each connected component of 𝐺 −𝑈G−U is a complete graph. From this, we can construct a perfect matching of 𝐺G: first take a maximum matching of each connected component of 𝐺 −𝑈G−U; only when a connected component has an odd number of vertices does one unmatched vertex appear; then match these unmatched vertices to vertices in 𝑈U; since 𝐺G has an even number of vertices (taking 𝑈 =∅U=∅ in the Tutte condition), the remaining unmatched vertices in 𝑈U are also even in number, so they can be paired up. This contradiction shows that there is no 𝐺G that satisfies the Tutte condition but has no perfect matching.

    The key is to prove that each connected component of 𝐺 −𝑈G−U is a complete graph. Suppose not. Let vertices 𝑥,𝑦,𝑧x,y,z belong to such a connected component with (𝑥,𝑦) ∈𝐸(x,y)∈E, (𝑦,𝑧) ∈𝐸(y,z)∈E, but (𝑥,𝑧) ∉𝐸(x,z)∉E. Moreover, since 𝑦 ∉𝑈y∉U, there exists 𝑤 ∈𝑉 ∖𝑈w∈V∖U such that (𝑦,𝑤) ∉𝐸(y,w)∉E. Due to the maximality of 𝐺G, graphs 𝐺 +(𝑥,𝑧)G+(x,z) and 𝐺 +(𝑦,𝑤)G+(y,w) each have perfect matchings 𝑀1M1 and 𝑀2M2 respectively. Consider their symmetric difference 𝑀1 ⊕𝑀2M1⊕M2. Since in the graph (𝑉,𝑀1 ⊕𝑀2)(V,M1⊕M2) all vertices have degree either 0 or 2, 𝑀1 ⊕𝑀2M1⊕M2 is actually a disjoint union of even cycles, where each even cycle consists of alternating matched edges from 𝑀1M1 and 𝑀2M2.

    As shown in the figure, there are two cases:

    • (𝑥,𝑧)(x,z) and (𝑦,𝑤)(y,w) are in different cycles (as shown on the left): let 𝐶C be the cycle containing (𝑦,𝑤)(y,w), then the edge set 𝑀2 ⊕𝐶M2⊕C is a perfect matching of 𝐺G.
    • (𝑥,𝑧)(x,z) and (𝑦,𝑤)(y,w) are in the same cycle (as shown on the right): by symmetry, assume the cycle goes through 𝑥,𝑦,𝑤,𝑧x,y,w,z in order; then take the path from 𝑦y through 𝑤w to 𝑧z along the cycle, call it 𝑃P, and let 𝐶 ={(𝑦,𝑧)} ∪𝑃C={(y,z)}∪P be the cycle; then the edge set 𝑀2 ⊕𝐶M2⊕C is also a perfect matching of 𝐺G.

    In either case, this contradicts the choice of 𝐺G. This contradiction shows that each connected component of 𝐺 −𝑈G−U is a complete graph.

    Corollary

    Every bridgeless 3-regular graph has a perfect matching.

    Proof

    To verify that the Tutte condition holds, for any 𝑈 ⊆𝑉U⊆V, we need to prove odd⁡(𝐺 −𝑈) ≤|𝑈|odd⁡(G−U)≤|U|. Let 𝐺1,⋯,𝐺𝑛G1,⋯,Gn be all connected components of 𝐺 −𝑈G−U with an odd number of vertices.     Common Algorithms

    A fundamental problem in combinatorial optimization is finding maximum matchings and maximum weight matchings in graphs.

    Maximum Matching in Bipartite Graphs

    See the Maximum Matching in Bipartite Graphs page.

    In an unweighted bipartite graph, the Kuhn algorithm can solve it in 𝑂(|𝑉||𝐸|)O(|V||E|) time, or the Hopcroft–Karp algorithm can solve it in 𝑂(|𝑉|1/2|𝐸|)O(|V|1/2|E|) time.

    Maximum Weight Matching in Bipartite Graphs

    See the Maximum Weight Matching in Bipartite Graphs page.

    In a weighted bipartite graph, the Hungarian algorithm can be used. If Bellman–Ford is used for shortest path finding, the time complexity is 𝑂(|𝑉|2|𝐸|)O(|V|2|E|); if Dijkstra's algorithm or Fibonacci heap is used, it can be solved in 𝑂(|𝑉|2log⁡|𝑉| +|𝑉||𝐸|)O(|V|2log⁡|V|+|V||E|) time.

    Maximum Matching in General Graphs

    See the Maximum Matching in General Graphs page.

    In an unweighted general graph, Edmonds' blossom algorithm can solve it in 𝑂(|𝑉|2|𝐸|)O(|V|2|E|) time.

    Maximum Weight Matching in General Graphs

    See the Maximum Weight Matching in General Graphs page.

    In a weighted general graph, Edmonds' blossom algorithm can solve it in 𝑂(|𝑉|2|𝐸|)O(|V|2|E|) time.

    Related Problems

    Maximum (weight) matchings are closely related to other graph theory problems. This section only discusses general graphs; the conclusions for bipartite graphs can be found on the Maximum Matching in Bipartite Graphs page.

    Maximum Weight Maximum Cardinality Matching

    The maximum weight maximum cardinality matching problem and the maximum weight matching problem can be reduced to each other. A notable difference between them is that maximum weight maximum cardinality matching may contain negative-weight edges, while maximum weight matching cannot.

    First, the maximum weight matching problem can be reduced to the maximum weight maximum cardinality matching problem. First, set the weights of all negative-weight edges in graph 𝐺G to 0; then, by connecting several edges with weight 0, expand the graph to a complete graph 𝐺′G′. Note that in a complete graph with non-negative edge weights, maximum weight maximum cardinality matching and maximum weight matching coincide. Therefore, we only need to compute the maximum weight maximum cardinality matching 𝑀′M′ of 𝐺′G′, and then delete all zero-weight edges from 𝑀′M′; the resulting edge set 𝑀M is the maximum weight matching of graph 𝐺G.1

    Conversely, the maximum weight maximum cardinality matching problem can also be reduced to the maximum weight matching problem. We only need to add a sufficiently large positive constant 𝐾K to the weight of all edges in graph 𝐺G to ensure that the maximum weight matching of the resulting graph 𝐺′G′ is also a maximum matching, and thus necessarily a maximum weight maximum cardinality matching. This is because computing the maximum weight matching of 𝐺′G′ is equivalent to maximizing

    𝐾|𝑀|+∑𝑒∈𝑀𝑤(𝑒)K|M|+∑e∈Mw(e)

    over all matchings in graph 𝐺G.

    When 𝐾K is sufficiently large, the gain 𝐾K from adding one more edge to the matching exceeds any possible change in the sum of edge weights. Therefore, the algorithm will first try to match as many edges as possible, then maximize the sum of edge weights of matched edges. The constant 𝐾K only needs to be strictly greater than the difference between two possible matchings. An obvious choice is

    𝐾=∑𝑒∈𝐸|𝑤(𝑒)|+1.K=∑e∈E|w(e)|+1.

    Minimum (Weight) Edge Cover

    Another problem closely related to maximum (weight) matchings is the minimum (weight) edge cover. The relationship between edge covers and matchings (also called edge independent sets) is similar to the relationship between vertex covers and independent sets.

    A set of edges 𝐶 ⊆𝐸C⊆E in a graph 𝐺 =(𝑉,𝐸)G=(V,E) is called an edge cover if every vertex 𝑣 ∈𝑉v∈V is an endpoint of some edge in 𝐶C. When discussing edge covers, we always assume that graph 𝐺G has no isolated vertices.

    For unweighted graphs, the minimum edge cover problem is almost equivalent to the maximum matching problem. For any maximum matching 𝑀M of graph 𝐺G, by adding one incident edge for each unmatched vertex, we can obtain a minimum edge cover 𝐶C. Denote the resulting graph as 𝐺′ =(𝑉′,𝐸′)G′=(V′,E′). If graph 𝐺G is a bipartite graph or a sparse graph, then graph 𝐺′G′ is also a bipartite graph or sparse graph respectively. Moreover, the minimum weight edge cover problem of graph 𝐺G is reduced to the minimum weight perfect matching problem of graph 𝐺′G′2: for the minimum weight perfect matching 𝑀′M′ of 𝐺′G′, by retaining edges in 𝐸E and replacing all matched edges (𝑣,𝑣′)(v,v′) with the minimum weight edge incident to 𝑣v in graph 𝐺G, we obtain a minimum weight edge cover of graph 𝐺G.
