    Random Walks on Graphs

    This page introduces random walk problems on graphs. We explore this topic from three perspectives: grid graphs, sparse graphs, and general graphs. Various methods for solving such problems are introduced, along with comparisons of their advantages and disadvantages.

    Definition

    Given a directed simple graph 𝐺 =(𝑉,𝐸)(𝑉 ={𝑣1,𝑣2,⋯,𝑣|𝑉|})G=(V,E)(V={v1,v2,⋯,v|V|}), a start node 𝑠 ∈𝑉s∈V, and an end node 𝑡 ∈𝑉t∈V, each edge 𝑒 =(𝑥,𝑦)e=(x,y) has a positive weight 𝑤𝑒we, satisfying ∀𝑥 ∈𝑉\{𝑡}∀x∈V\{t}, ∑(𝑥,𝑦)∈𝐸𝑤(𝑥,𝑦) =1∑(x,y)∈Ew(x,y)=1, and for any node 𝑥x there exists a path from 𝑥x to 𝑡t. A token starts at the start node. Each second, from the current node 𝑥x, it chooses edge (𝑥,𝑦)(x,y) with probability 𝑤(𝑥,𝑦)w(x,y) and moves to 𝑦y. The process stops when reaching the end node. Find the expected time.

    Actually, this problem can also be expressed in matrix form. Define matrix 𝑃P:

    𝑃𝑥,𝑦={𝑤(𝑥,𝑦)if (𝑥,𝑦)∈𝐸 and 𝑥≠𝑡0if (𝑥,𝑦)∉𝐸 or 𝑥=𝑡Px,y={w(x,y)if (x,y)∈E and x≠t0if (x,y)∉E or x=t

    The answer we want is:

    ∑𝑘≥0𝑘×(𝑃𝑘)𝑠,𝑡∑k≥0k×(Pk)s,t

    Here, (𝑃𝑘)𝑠,𝑡(Pk)s,t represents the probability of reaching the end node for the first time after exactly 𝑘k steps. When the graph is finite and all nodes can reach the end node, it can be proven from the definition of 𝑃P that all eigenvalues are less than 1, so the answer converges.

    For convenience, in this page, unless specified otherwise, 𝑛n denotes |𝑉||V| and 𝑚m denotes |𝐸||E|.

    Also in this page, a sparse graph refers to a graph where the number of edges is on the same order as the number of nodes.

    Grid Graphs

    Problem 1 Circles of Waiting

    A token starts at point (0,0)(0,0) in the Cartesian coordinate plane. Each second, the token moves randomly. If it is currently at (𝑥,𝑦)(x,y), it has probability 𝑝1p1 to move to (𝑥 −1,𝑦)(x−1,y), probability 𝑝2p2 to move to (𝑥,𝑦 −1)(x,y−1), probability 𝑝3p3 to move to (𝑥 +1,𝑦)(x+1,y), and probability 𝑝4p4 to move to (𝑥,𝑦 +1)(x,y+1). It is guaranteed that 𝑝1 +𝑝2 +𝑝3 +𝑝4 =1p1+p2+p3+p4=1. Find the expected time until the token moves to a position whose Euclidean distance from the origin exceeds 𝑅R. 0 ≤𝑅 ≤500≤R≤50, 𝑝1,𝑝2,𝑝3,𝑝4 >0p1,p2,p3,p4>0, answer modulo 109 +7109+7.

    Naive Approach

    Let 𝑓(𝑖,𝑗)f(i,j) be the expected time for the token to reach a position whose Euclidean distance from the origin exceeds 𝑅R when starting from (𝑖,𝑗)(i,j). The transition is:

    𝑓(𝑖,𝑗)={𝑝1𝑓(𝑖−1,𝑗)+𝑝2𝑓(𝑖,𝑗−1)+𝑝3𝑓(𝑖+1,𝑗)+𝑝4𝑓(𝑖,𝑗+1)+1𝑖2+𝑗2≤𝑅20𝑖2+𝑗2>𝑅2f(i,j)={p1f(i−1,j)+p2f(i,j−1)+p3f(i+1,j)+p4f(i,j+1)+1i2+j2≤R20i2+j2>R2

    Since the transitions do not follow a topological order, Gaussian elimination is needed. Time complexity is 𝑂(𝑅6)O(R6), which cannot pass this problem.

    Direct Elimination

    Notice that most coefficients in the equations to be eliminated are 0. We can reduce complexity by only computing for positions with non-zero values.

    Consider the elimination process, ordering equations from top to bottom in the coordinate plane, and within each row from left to right. Mark eliminated equations in yellow, cells adjacent to yellow cells in green, and the rest in black, as shown below:

    Now we eliminate the equation corresponding to the next green cell. In this equation, only the coefficients of variables corresponding to the green cell and the first black cell below it may be non-zero. Similarly, only in the equation of the first black cell below the green cell may the coefficient of the current cell's variable be non-zero.

    Notice that there are only 𝑂(𝑅)O(R) green cells, so the time complexity for eliminating a single equation is 𝑂(𝑅2)O(R2). There are 𝑂(𝑅2)O(R2) equations in total, so the time complexity is reduced to 𝑂(𝑅4)O(R4), which can pass this problem.

    Pivot Method

    There are 𝑂(𝑅2)O(R2) equations and variables. If we can reduce the scale to 𝑂(𝑅)O(R), naive Gaussian elimination will work.

    Set the first cell in each row as the pivot variable, giving 2𝑅 +12R+1 pivots. Express all other cell variables as linear functions of these pivots. Consider each column from left to right. For the current cell (𝑖,𝑗)(i,j), notice that 𝑓(𝑖,𝑗)f(i,j), 𝑓(𝑖 −1,𝑗)f(i−1,j), 𝑓(𝑖,𝑗 −1)f(i,j−1), and 𝑓(𝑖,𝑗 +1)f(i,j+1) are all known linear functions of the pivots. Rearranging the transition equation:

    𝑓(𝑖+1,𝑗)=𝑓(𝑖,𝑗)−𝑝1𝑓(𝑖−1,𝑗)−𝑝2𝑓(𝑖,𝑗−1)−𝑝4𝑓(𝑖,𝑗+1)−1𝑝3f(i+1,j)=f(i,j)−p1f(i−1,j)−p2f(i,j−1)−p4f(i,j+1)−1p3

    This gives us 𝑓(𝑖 +1,𝑗)f(i+1,j) as a linear function of the pivots. If (𝑖 +1,𝑗)(i+1,j) is already beyond Euclidean distance 𝑅R from the origin, we get an equation: 𝑓(𝑖 +1,𝑗) =0f(i+1,j)=0. Eventually, we get 2𝑅 +12R+1 equations, and Gaussian elimination on these gives the answer.

    During the propagation of linear functions of pivots, there are 𝑂(𝑅2)O(R2) variables, and propagating a single variable takes 𝑂(𝑅)O(R) time. Then the problem size is reduced to 𝑂(𝑅)O(R). Both parts have 𝑂(𝑅3)O(R3) complexity, so the total is 𝑂(𝑅3)O(R3), which can pass this problem.

    Comparison of the Two Approaches

    The following compares the two approaches from multiple perspectives:

    From time complexity perspective, the pivot method has worst-case complexity 𝑂(𝑛√𝑛)O(nn) on grid graphs (highest when both length and width are 𝑂(√𝑛)O(n)), while direct elimination has worst-case complexity 𝑂(𝑛2)O(n2), so the pivot method is better.

    From numerical precision perspective, for problems requiring real number calculations rather than modular arithmetic, direct elimination has better precision than the pivot method.

    From applicability perspective, the two methods suit different scenarios.

    When there are obstacles in the grid graph or some edges have probability 00, the pivot method requires adding a pivot for each obstacle or edge with probability 00. When the number of such obstacles or edges exceeds 𝑂(𝑅)O(R), the pivot method's complexity increases, while direct elimination's complexity remains unchanged.

    However, the pivot method can also handle elimination of transition equations similar to those on grid graphs, such as 𝑓(𝑖,𝑗) =𝑝1𝑓(𝑖 +1,𝑗) +𝑝2𝑓(𝑖,𝑗 +1) +𝑝3𝑓(pre⁡(𝑖,𝑗)) +1f(i,j)=p1f(i+1,j)+p2f(i,j+1)+p3f(pre⁡(i,j))+1, where pre⁡(𝑖,𝑗) =(𝑥,𝑦)(𝑥 ≤𝑖,𝑦 ≤𝑗)pre⁡(i,j)=(x,y)(x≤i,y≤j) is a given value, whereas the complexity analysis of direct elimination does not apply to this model.

    Additionally, computing the determinant of the adjacency matrix of a grid graph cannot use the pivot method; only direct elimination can optimize the time complexity.

    In summary, each method has its strengths, and the appropriate method should be chosen based on the specific problem.

    Sparse Graphs

    Problem 2 Expected Value

    Given a simple undirected connected sparse graph 𝐺 =(𝑉,𝐸)G=(V,E), a token starts at 𝑣1v1. Each second, the token randomly chooses one of the edges connected to the current node with equal probability and moves to the adjacent node. Find the expected time to reach 𝑣𝑛vn. 𝑛 ≤2000n≤2000, answer modulo 𝑝p, where 𝑝p is a prime randomly generated in the interval [109,1.01×109][109,1.01×109].

    Background

    Definition 4.1. A polynomial 𝑝(𝜆)p(λ) such that 𝑝(𝐴) =0p(A)=0 is called an annihilating polynomial of matrix 𝐴A.

    Definition 4.2. Let 𝐼𝑛In be the 𝑛 ×𝑛n×n identity matrix. The characteristic polynomial of an 𝑛 ×𝑛n×n matrix 𝐴A is defined as 𝑝(𝜆) =det⁡(𝜆𝐼𝑛−𝐴)p(λ)=det⁡(λIn−A), where detdet denotes the determinant of a matrix. It is easy to see that the characteristic polynomial of an 𝑛 ×𝑛n×n matrix has degree at most 𝑛n.

    Theorem 4.2. (Cayley-Hamilton Theorem) The characteristic polynomial of any matrix is its annihilating polynomial.

    Therefore, the minimal annihilating polynomial of an 𝑛 ×𝑛n×n matrix also has degree at most 𝑛n.

    Solving the Original Problem

    Notice that the expected time 𝐸(𝑡) =∑𝑖≥0Pr⁡[𝑡 >𝑖]E(t)=∑i≥0Pr⁡[t>i]. If we can find the probability of not having finished after 𝑖i steps, summing over all 𝑖 ≥0i≥0 gives the answer.

    Let 𝑓(𝑖,𝑗)f(i,j) be the probability that after 𝑖i steps, the token is at 𝑗j and has never visited 𝑛n. Then:

    𝑓(𝑖,𝑗)=∑(𝑘,𝑗)∈𝐸𝑓(𝑖−1,𝑘)deg𝑘(𝑗≠𝑛)f(i,j)=∑(k,j)∈Ef(i−1,k)degk(j≠n)

    Here, deg𝑘degk denotes the degree of 𝑘k.

    Notice that the transition of 𝑓f does not depend on 𝑖i. We can view one transition as multiplying by a matrix, i.e., 𝑓𝑖+1 =𝑓𝑖𝑀fi+1=fiM. Since the minimal annihilating polynomial of 𝑀M has degree at most 𝑛n, the shortest recurrence for 𝑓f also has length at most 𝑛n. Hence, the shortest recurrence for Pr⁡[𝑡 >𝑖] =∑𝑛−1𝑗=1𝑓(𝑖,𝑗)Pr⁡[t>i]=∑j=1n−1f(i,j) also has length at most 𝑛n. We can compute Pr⁡[𝑡 >0],Pr⁡[𝑡 >1],⋯,Pr⁡[𝑡 >3𝑛]Pr⁡[t>0],Pr⁡[t>1],⋯,Pr⁡[t>3n] in 𝑂(𝑛𝑚)O(nm) time, then use the Berlekamp-Massey algorithm to find the shortest recurrence for Pr⁡[𝑡 >𝑖]Pr⁡[t>i] in 𝑂(𝑛2)O(n2) time.
