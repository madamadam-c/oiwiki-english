    Graph Concepts

    This page provides an overview of some concepts in graph theory. Not all of these concepts are commonly seen in OI (Olympiad in Informatics). For OIers, it is sufficient to master the basic parts of this page. If you encounter concepts you don't understand while studying, you can refer back to this page.

    Warning

    Definitions of graph theory concepts may vary across different textbooks. Always interpret them based on context.

    Graph

    A graph 𝐺G is a pair 𝐺 =(𝑉(𝐺),𝐸(𝐺))G=(V(G),E(G)) where 𝑉(𝐺)V(G) is a non-empty set called the vertex set, and each element of 𝑉V is called a vertex or node, simply a point; 𝐸(𝐺)E(G) is the set of edges between nodes in 𝑉(𝐺)V(G), called the edge set.

    We commonly use 𝐺 =(𝑉,𝐸)G=(V,E) to denote a graph.

    When both 𝑉V and 𝐸E are finite sets, 𝐺G is called a finite graph.

    When 𝑉V or 𝐸E is an infinite set, 𝐺G is called an infinite graph.

    There are various types of graphs, including undirected graphs, directed graphs, mixed graphs, etc.

    If 𝐺G is an undirected graph, each element in 𝐸E is an unordered pair (𝑢,𝑣)(u,v), called an undirected edge or simply edge, where 𝑢,𝑣 ∈𝑉u,v∈V. For 𝑒 =(𝑢,𝑣)e=(u,v), 𝑢u and 𝑣v are called the endpoints of 𝑒e.

    If 𝐺G is a directed graph, each element in 𝐸E is an ordered pair (𝑢,𝑣)(u,v), sometimes written as 𝑢 →𝑣u→v, called a directed edge or arc. It can also be called an edge when there is no ambiguity. For 𝑒 =𝑢 →𝑣e=u→v, 𝑢u is called the tail of 𝑒e, and 𝑣v is called the head of 𝑒e. The tail and head are also called the endpoints of 𝑒e. We also say 𝑢u is a direct predecessor of 𝑣v, and 𝑣v is a direct successor of 𝑢u.

    Why is the starting point called 'tail' and the ending point 'head'?

    Edges are usually represented with arrows, and arrows point from the "tail" to the "head".

    If 𝐺G is a mixed graph, 𝐸E contains both directed edges and undirected edges.

    If each edge 𝑒𝑘 =(𝑢𝑘,𝑣𝑘)ek=(uk,vk) of 𝐺G is assigned a number as the weight of that edge, 𝐺G is called a weighted graph. If all weights are positive real numbers, 𝐺G is called a positively weighted graph.

    The number of vertices |𝑉(𝐺)||V(G)| in graph 𝐺G is also called the order of graph 𝐺G.

    In simple terms, a graph consists of several points and the edges connecting them.

    Adjacency

    In an undirected graph 𝐺 =(𝑉,𝐸)G=(V,E), if vertex 𝑣v is an endpoint of edge 𝑒e, then 𝑣v and 𝑒e are said to be incident or adjacent. For two vertices 𝑢u and 𝑣v, if edge (𝑢,𝑣)(u,v) exists, 𝑢u and 𝑣v are said to be adjacent.

    The neighborhood of a vertex 𝑣 ∈𝑉v∈V is the set of all vertices adjacent to it, denoted 𝑁(𝑣)N(v).

    The neighborhood of a vertex set 𝑆S is the set of all vertices adjacent to at least one vertex in 𝑆S, denoted 𝑁(𝑆)N(S), that is:

    𝑁(𝑆)=⋃𝑣∈𝑆𝑁(𝑣)N(S)=⋃v∈SN(v)

    Simple Graph

    Loop: For an edge 𝑒 =(𝑢,𝑣)e=(u,v) in 𝐸E, if 𝑢 =𝑣u=v, then 𝑒e is called a loop.

    Multiple edge (parallel edge): If there exist two identical elements (edges) 𝑒1,𝑒2e1,e2 in 𝐸E, they are called (a set of) multiple edges.

    Simple graph: A graph without loops or multiple edges is called a simple graph. In any simple undirected graph with at least two vertices, there must exist vertices with the same degree. (Pigeonhole principle)

    If a graph contains loops or multiple edges, it is called a multigraph.

    Warning

    In undirected graphs, (𝑢,𝑣)(u,v) and (𝑣,𝑢)(v,u) count as one set of multiple edges. In directed graphs, 𝑢 →𝑣u→v and 𝑣 →𝑢v→u are not multiple edges.

    Warning

    In problems, unless specified otherwise, loops and multiple edges are allowed. You need to consider them specially when solving problems.

    Degree

    The number of edges incident to a vertex 𝑣v is called the degree of that vertex, denoted 𝑑(𝑣)d(v). Specifically, for edge (𝑣,𝑣)(v,v), each such edge contributes 2 to 𝑑(𝑣)d(v).

    For an undirected simple graph, we have 𝑑(𝑣) =|𝑁(𝑣)|d(v)=|N(v)|.

    Handshaking lemma (also called the fundamental theorem of graph theory): For any undirected graph 𝐺 =(𝑉,𝐸)G=(V,E), we have ∑𝑣∈𝑉𝑑(𝑣) =2|𝐸|∑v∈Vd(v)=2|E|.

    Corollary: In any graph, the number of vertices with odd degree must be even.

    If 𝑑(𝑣) =0d(v)=0, then 𝑣v is called an isolated vertex.

    If 𝑑(𝑣) =1d(v)=1, then 𝑣v is called a leaf vertex or pendant vertex.

    If 2 ∣𝑑(𝑣)2∣d(v), then 𝑣v is called an even vertex.

    If 2 ∤𝑑(𝑣)2∤d(v), then 𝑣v is called an odd vertex. The number of odd vertices in a graph is even.

    If 𝑑(𝑣) =|𝑉| −1d(v)=|V|−1, then 𝑣v is called a universal vertex.

    For a graph, the minimum degree among all vertices is called the minimum degree of 𝐺G, denoted 𝛿(𝐺)δ(G); the maximum degree is called the maximum degree, denoted Δ(𝐺)Δ(G). That is: 𝛿(𝐺) =min𝑣∈𝐺𝑑(𝑣)δ(G)=minv∈Gd(v), Δ(𝐺) =max𝑣∈𝐺𝑑(𝑣)Δ(G)=maxv∈Gd(v).

    In a directed graph 𝐺 =(𝑉,𝐸)G=(V,E), the number of edges with vertex 𝑣v as the starting point is called the out-degree of that vertex, denoted 𝑑+(𝑣)d+(v). The number of edges with vertex 𝑣v as the ending point is called the in-degree of that vertex, denoted 𝑑−(𝑣)d−(v). Clearly, 𝑑+(𝑣) +𝑑−(𝑣) =𝑑(𝑣)d+(v)+d−(v)=d(v).

    For any directed graph 𝐺 =(𝑉,𝐸)G=(V,E), we have:

    ∑𝑣∈𝑉𝑑+(𝑣)=∑𝑣∈𝑉𝑑−(𝑣)=|𝐸|∑v∈Vd+(v)=∑v∈Vd−(v)=|E|

    If every vertex of an undirected graph 𝐺 =(𝑉,𝐸)G=(V,E) has the same degree 𝑘k, then 𝐺G is called a 𝑘k-regular graph.

    If a given sequence 𝑎a can be realized as the degree sequence of some graph 𝐺G, then 𝑎a is called graphical.

    If a given sequence 𝑎a can be realized as the degree sequence of some simple graph 𝐺G, then 𝑎a is called simple graphical.

    Path

    Walk: A walk is a sequence of edges connecting a sequence of vertices, which can be of finite or infinite length. Formally, a finite walk 𝑤w is a sequence of edges 𝑒1,𝑒2,…,𝑒𝑘e1,e2,…,ek, such that there exists a sequence of vertices 𝑣0,𝑣1,…,𝑣𝑘v0,v1,…,vk satisfying 𝑒𝑖 =(𝑣𝑖−1,𝑣𝑖)ei=(vi−1,vi), where 𝑖 ∈[1,𝑘]i∈[1,k]. Such a walk can be abbreviated as 𝑣0 →𝑣1 →𝑣2 →⋯ →𝑣𝑘v0→v1→v2→⋯→vk. Typically, the number of edges 𝑘k is called the length of this walk (if edges are weighted, length usually refers to the sum of edge weights on the walk, though problems may define it differently).

    Trail: For a walk 𝑤w, if 𝑒1,𝑒2,…,𝑒𝑘e1,e2,…,ek are all distinct, then 𝑤w is called a trail.

    Path (also called simple path): For a trail 𝑤w, if the vertex sequence has no repeated vertices, then 𝑤w is called a path.

    Circuit: For a trail 𝑤w, if 𝑣0 =𝑣𝑘v0=vk, then 𝑤w is called a circuit.

    Cycle (also called simple circuit): For a circuit 𝑤w, if 𝑣0 =𝑣𝑘v0=vk is the only pair of repeated vertices in the sequence, then 𝑤w is called a cycle.

    Warning

    Definitions of "path" may vary in different sources. For example, "path" might refer to "walk" in this article, and "cycle" might refer to "circuit". If you see similar terms in problems without special explanations like "simple path" or "non-simple path" (i.e., "walk" in this article), it's best to ask for clarification.

    Subgraph

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E), if there exists another graph 𝐻 =(𝑉′,𝐸′)H=(V′,E′) such that 𝑉′ ⊆𝑉V′⊆V and 𝐸′ ⊆𝐸E′⊆E, then 𝐻H is called a subgraph of 𝐺G, denoted 𝐻 ⊆𝐺H⊆G.

    If for 𝐻 ⊆𝐺H⊆G, for all ∀𝑢,𝑣 ∈𝑉′∀u,v∈V′, whenever (𝑢,𝑣) ∈𝐸(u,v)∈E, we also have (𝑢,𝑣) ∈𝐸′(u,v)∈E′, then 𝐻H is called an induced subgraph of 𝐺G.

    It is easy to see that the induced subgraph of a graph is determined solely by the vertex set. Therefore, the induced subgraph with vertex set 𝑉′V′ (𝑉′ ⊆𝑉V′⊆V) is denoted 𝐺[𝑉′]G[V′].

    If 𝐻 ⊆𝐺H⊆G satisfies 𝑉′ =𝑉V′=V, then 𝐻H is called a spanning subgraph of 𝐺G.

    Clearly, 𝐺G is itself a subgraph, spanning subgraph, and induced subgraph; the edgeless graph is a spanning subgraph of 𝐺G. The original graph 𝐺G and the edgeless graph are both trivial subgraphs of 𝐺G.

    If an undirected graph 𝐺G has a spanning subgraph 𝐹F that is 𝑘k-regular, then 𝐹F is called a 𝑘k-factor of 𝐺G.

    If a directed graph 𝐺 =(𝑉,𝐸)G=(V,E) has an induced subgraph 𝐻 =𝐺[𝑉∗]H=G[V∗] such that for all 𝑣 ∈𝑉∗v∈V∗, if (𝑣,𝑢) ∈𝐸(v,u)∈E, then 𝑢 ∈𝑉∗u∈V∗, then 𝐻H is called a closed subgraph of 𝐺G.

    Connectivity

    Undirected Graph

    For an undirected graph 𝐺 =(𝑉,𝐸)G=(V,E), for 𝑢,𝑣 ∈𝑉u,v∈V, if there exists a walk such that 𝑣0 =𝑢,𝑣𝑘 =𝑣v0=u,vk=v, then 𝑢u and 𝑣v are connected. By definition, any vertex is connected to itself, and the two endpoints of any edge are connected.

    If an undirected graph 𝐺 =(𝑉,𝐸)G=(V,E) satisfies that any two vertices are connected, then 𝐺G is called a connected graph. This property of 𝐺G is called connectivity.

    If 𝐻H is a connected subgraph of 𝐺G, and there exists no 𝐹F such that 𝐻 ⊊𝐹 ⊆𝐺H⊊F⊆G and 𝐹F is a connected graph, then 𝐻H is a connected component (maximally connected subgraph) of 𝐺G.

    Directed Graph

    For a directed graph 𝐺 =(𝑉,𝐸)G=(V,E), for 𝑢,𝑣 ∈𝑉u,v∈V, if there exists a walk such that 𝑣0 =𝑢,𝑣𝑘 =𝑣v0=u,vk=v, then 𝑢u reaches 𝑣v. By definition, any vertex can reach itself, and the tail of any edge can reach the head. (Connectivity in undirected graphs can be viewed as mutual reachability.)

    If a directed graph has vertices where every pair is mutually reachable, then the graph is strongly connected.

    If replacing all edges of a directed graph with undirected edges results in a connected graph, then the original directed graph is weakly connected.

    Similar to connected components, there are weakly connected components (maximal weakly connected subgraphs) and strongly connected components (maximal strongly connected subgraphs).

    For related algorithms, see Strongly Connected Components.

    Cuts

    For related algorithms, see Articulation Points and Bridges and Biconnected Components.

    In this section, "connectivity" for directed graphs generally refers to "strong connectivity".

    For a connected graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝑉′ ⊆𝑉V′⊆V and 𝐺[𝑉∖𝑉′]G[V∖V′] (i.e., removing vertices in 𝑉′V′ from 𝐺G) is not connected, then 𝑉′V′ is a vertex cut of 𝐺G. A vertex cut of size 1 is called a cut vertex.

    For a connected graph 𝐺 =(𝑉,𝐸)G=(V,E) and an integer 𝑘k, if |𝑉| ≥𝑘 +1|V|≥k+1 and 𝐺G has no vertex cut of size 𝑘 −1k−1, then 𝐺G is 𝑘k-vertex-connected. The largest such 𝑘k is called the vertex connectivity of 𝐺G, denoted 𝜅(𝐺)κ(G). (For non-complete graphs, vertex connectivity equals the size of the minimum vertex cut. For the complete graph 𝐾𝑛Kn, vertex connectivity is 𝑛 −1n−1.)

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E) and vertices 𝑢,𝑣 ∈𝑉u,v∈V with 𝑢 ≠𝑣u≠v, 𝑢u and 𝑣v are non-adjacent, and 𝑢u reaches 𝑣v. If 𝑉′ ⊆𝑉V′⊆V, 𝑢,𝑣 ∉𝑉′u,v∉V′, and in 𝐺[𝑉∖𝑉′]G[V∖V′] 𝑢u and 𝑣v are not connected, then 𝑉′V′ is called a vertex cut from 𝑢u to 𝑣v. The size of the minimum vertex cut from 𝑢u to 𝑣v is called the local connectivity from 𝑢u to 𝑣v, denoted 𝜅(𝑢,𝑣)κ(u,v).

    Similar definitions can be made for edges:

    For a connected graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝐸′ ⊆𝐸E′⊆E and 𝐺′ =(𝑉,𝐸 ∖𝐸′)G′=(V,E∖E′) (i.e., removing edges in 𝐸′E′ from 𝐺G) is not connected, then 𝐸′E′ is an edge cut of 𝐺G. An edge cut of size 1 is called a bridge.

    For a connected graph 𝐺 =(𝑉,𝐸)G=(V,E) and an integer 𝑘k, if 𝐺G has no edge cut of size 𝑘 −1k−1, then 𝐺G is 𝑘k-edge-connected. The largest such 𝑘k is called the edge connectivity of 𝐺G, denoted 𝜆(𝐺)λ(G). (For any graph, edge connectivity equals the size of the minimum edge cut.)

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E) and vertices 𝑢,𝑣 ∈𝑉u,v∈V with 𝑢 ≠𝑣u≠v, and 𝑢u reaches 𝑣v. If 𝐸′ ⊆𝐸E′⊆E, and in 𝐺′ =(𝑉,𝐸 ∖𝐸′)G′=(V,E∖E′) 𝑢u and 𝑣v are not connected, then 𝐸′E′ is called an edge cut from 𝑢u to 𝑣v. The size of the minimum edge cut from 𝑢u to 𝑣v is called the local edge-connectivity from 𝑢u to 𝑣v, denoted 𝜆(𝑢,𝑣)λ(u,v).

    Biconnected is almost identical to 22-vertex-connected, except for a graph consisting of two vertices connected by one edge, which is biconnected but not 22-vertex-connected. In other words, a connected graph without cut vertices is biconnected.

    22-edge-connected is identical to 22-edge-connected. In other words, a connected graph without bridges is 22-edge-connected.

    Similar to connected components, there are biconnected components (maximal biconnected subgraphs) and 22-edge-connected components (maximal 22-edge-connected subgraphs).

    Whitney's theorem: For any graph 𝐺G, we have 𝜅(𝐺) ≤𝜆(𝐺) ≤𝛿(𝐺)κ(G)≤λ(G)≤δ(G). (The three terms are vertex connectivity, edge connectivity, and minimum degree.)

    Sparse Graph / Dense Graph

    If a graph has far fewer edges than the square of its number of vertices, it is a sparse graph.

    If a graph has a number of edges close to the square of its number of vertices, it is a dense graph.

    These concepts do not have strict definitions. They are generally used when discussing efficiency differences between 𝑂(|𝑉|2)O(|V|2) and 𝑂(|𝐸|)O(|E|) algorithms (on dense graphs, these two algorithms have similar efficiency, while on sparse graphs, 𝑂(|𝐸|)O(|E|) algorithms are significantly more efficient).

    Complement Graph

    For an undirected simple graph 𝐺 =(𝑉,𝐸)G=(V,E), its complement graph is defined as follows: denoted ¯𝐺G¯, with 𝑉(¯𝐺) =𝑉(𝐺)V(G¯)=V(G), and for any pair of vertices (𝑢,𝑣)(u,v), (𝑢,𝑣) ∈𝐸(¯𝐺)(u,v)∈E(G¯) if and only if (𝑢,𝑣) ∉𝐸(𝐺)(u,v)∉E(G).

    Transpose Graph

    For a directed graph 𝐺 =(𝑉,𝐸)G=(V,E), its transpose graph has the same vertex set, with each edge reversed. That is, if the transpose of 𝐺G is 𝐺′ =(𝑉,𝐸′)G′=(V,E′), then 𝐸′ ={(𝑣,𝑢)|(𝑢,𝑣) ∈𝐸}E′={(v,u)|(u,v)∈E}.

    Special Graphs

    If an undirected simple graph 𝐺G has an edge between every pair of distinct vertices, then 𝐺G is called a complete graph. An 𝑛n-vertex complete graph is denoted 𝐾𝑛Kn. If a directed simple graph 𝐺G has two edges in opposite directions between every pair of distinct vertices, then 𝐺G is called a complete digraph.

    A graph with empty edge set is called an edgeless graph, empty graph, or null graph. An 𝑛n-vertex edgeless graph is denoted ――𝐾𝑛K―n or 𝑁𝑛Nn. 𝑁𝑛Nn and 𝐾𝑛Kn are complement graphs of each other.

    Warning

    Null graph can also refer to the order-zero graph 𝐾0K0, which has both vertex set and edge set empty.

    If a directed simple graph 𝐺G has exactly one edge (in one direction) between every pair of distinct vertices, then 𝐺G is called a tournament graph.

    If an undirected simple graph 𝐺 =(𝑉,𝐸)G=(V,E) has all its edges forming a cycle, then 𝐺G is called a cycle graph. An 𝑛n-vertex (𝑛 ≥3n≥3) cycle graph is denoted 𝐶𝑛Cn. It is easy to see that a graph is a cycle graph if and only if it is a 22-regular connected graph.

    If an undirected simple graph 𝐺 =(𝑉,𝐸)G=(V,E) has a vertex 𝑣v that is a universal vertex, and no edges between other vertices, then 𝐺G is called a star graph. An 𝑛 +1n+1-vertex (𝑛 ≥1n≥1) star graph is denoted 𝑆𝑛Sn.

    If an undirected simple graph 𝐺 =(𝑉,𝐸)G=(V,E) has a vertex 𝑣v that is a universal vertex, and other vertices form a cycle, then 𝐺G is called a wheel graph. An 𝑛 +1n+1-vertex (𝑛 ≥3n≥3) wheel graph is denoted 𝑊𝑛Wn.

    If an undirected simple graph 𝐺 =(𝑉,𝐸)G=(V,E) has all its edges forming a simple path, then 𝐺G is called a path graph. An 𝑛n-vertex path graph is denoted 𝑃𝑛Pn. It is easy to see that a path can be obtained by removing one edge from a cycle graph.

    If an undirected connected graph contains no cycles, it is called a tree. For more details, see Tree Basics.

    If an undirected connected graph contains exactly one cycle, it is called a pseudotree.

    If a directed weakly connected graph has in-degree 1 for every vertex, it is called an in-tree (or rooted out-tree).

    If a directed weakly connected graph has out-degree 1 for every vertex, it is called an out-tree (or rooted in-tree).

    Multiple trees can form a forest, multiple pseudotrees can form a pseudoforest, multiple in-trees can form an in-forest, and multiple out-trees can form an out-forest (also called a functional graph).

    If an undirected connected graph has each edge belonging to at most one cycle, it is called a cactus. Multiple cacti can form a desert.

    If the vertex set of a graph can be divided into two parts such that there are no edges within each part, then the graph is a bipartite graph. If in a bipartite graph every pair of vertices in different parts are connected by an edge, then the graph is a complete bipartite graph (or biclique). A complete bipartite graph with parts of size 𝑛n and 𝑚m is denoted 𝐾𝑛,𝑚Kn,m. For more details, see Bipartite Graph.

    If a graph can be drawn on a plane with no two edges crossing except at their endpoints, then the graph is a planar graph. A necessary and sufficient condition for a graph to be planar is that none of its subgraphs is 𝐾5K5 or 𝐾3,3K3,3. For a simple connected planar graph 𝐺 =(𝑉,𝐸)G=(V,E) with 𝑉 ≥3V≥3, we have |𝐸| ≤3|𝑉| −6|E|≤3|V|−6.

    Isomorphism

    Two graphs 𝐺G and 𝐻H, if there exists a bijection 𝑓 :𝑉(𝐺) →𝑉(𝐻)f:V(G)→V(H) such that (𝑢,𝑣) ∈𝐸(𝐺)(u,v)∈E(G) if and only if (𝑓(𝑢),𝑓(𝑣)) ∈𝐸(𝐻)(f(u),f(v))∈E(H), then we say 𝑓f is an isomorphism from 𝐺G to 𝐻H, and graphs 𝐺G and 𝐻H are isomorphic, denoted 𝐺 ≅𝐻G≅H.

    From the definition, if 𝐺 ≅𝐻G≅H, the following must hold:

    • |𝑉(𝐺)| =|𝑉(𝐻)|,|𝐸(𝐺)| =|𝐸(𝐻)||V(G)|=|V(H)|,|E(G)|=|E(H)|
    • The non-increasing sequences of vertex degrees in 𝐺G and 𝐻H are identical
    • 𝐺G and 𝐻H have isomorphic induced subgraphs

    Binary Operations on Undirected Simple Graphs

    For undirected simple graphs, we can define the following binary operations:

    Intersection: For graphs 𝐺 =(𝑉1,𝐸1),𝐻 =(𝑉2,𝐸2)G=(V1,E1),H=(V2,E2), the intersection is defined as 𝐺 ∩𝐻 =(𝑉1∩𝑉2,𝐸1∩𝐸2)G∩H=(V1∩V2,E1∩E2).

    It can easily be proven that the intersection of two undirected simple graphs is still an undirected simple graph.

    Union: For graphs 𝐺 =(𝑉1,𝐸1),𝐻 =(𝑉2,𝐸2)G=(V1,E1),H=(V2,E2), the union is defined as 𝐺 ∪𝐻 =(𝑉1∪𝑉2,𝐸1∪𝐸2)G∪H=(V1∪V2,E1∪E2).

    Sum/Direct Sum/Disjoint Union: For 𝐺 =(𝑉1,𝐸1),𝐻 =(𝑉2,𝐸2)G=(V1,E1),H=(V2,E2), construct 𝐻′ ≅𝐻H′≅H such that 𝑉(𝐻′) ∩𝑉1 =∅V(H′)∩V1=∅ (𝐻′H′ can equal 𝐻H). Any graph isomorphic to 𝐺 ∪𝐻′G∪H′ is called the sum/direct sum/disjoint union of 𝐺G and 𝐻H, denoted 𝐺 +𝐻G+H or 𝐺 ⊕𝐻G⊕H.

    If 𝐺G and 𝐻H have disjoint vertex sets, then 𝐺 ∪𝐻 =𝐺 +𝐻G∪H=G+H.

    For example, a forest can be defined as the sum of several trees.

    Difference between Union and Sum

    Think of it this way: "union" merges vertices and edges with the same names in the two graphs, while "sum" does not.

    Special Vertex Sets / Edge Sets

    Dominating Set

    For an undirected graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝑉′ ⊆𝑉V′⊆V and for every 𝑣 ∈(𝑉 ∖𝑉′)v∈(V∖V′) there exists an edge (𝑢,𝑣) ∈𝐸(u,v)∈E with 𝑢 ∈𝑉′u∈V′, then 𝑉′V′ is a dominating set of 𝐺G.

    The size of the minimum dominating set of undirected graph 𝐺G is denoted 𝛾(𝐺)γ(G). Finding the minimum dominating set of a graph is NP-hard.

    For a directed graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝑉′ ⊆𝑉V′⊆V and for every 𝑣 ∈(𝑉 ∖𝑉′)v∈(V∖V′) there exists an edge (𝑢,𝑣) ∈𝐸(u,v)∈E with 𝑢 ∈𝑉′u∈V′, then 𝑉′V′ is an out-dominating set of 𝐺G. Similarly, we can define the in-dominating set of a directed graph.

    The size of the minimum out-dominating set of directed graph 𝐺G is denoted 𝛾+(𝐺)γ+(G), and the size of the minimum in-dominating set is denoted 𝛾−(𝐺)γ−(G).

    Edge Dominating Set

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝐸′ ⊆𝐸E′⊆E and for every 𝑒 ∈(𝐸 ∖𝐸′)e∈(E∖E′) there exists an edge in 𝐸′E′ sharing an endpoint with 𝑒e, then 𝐸′E′ is an edge dominating set of 𝐺G.

    Finding the minimum edge dominating set of a graph is NP-hard.

    Independent Set

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝑉′ ⊆𝑉V′⊆V and no two vertices in 𝑉′V′ are adjacent, then 𝑉′V′ is an independent set of 𝐺G.

    The size of the maximum independent set of graph 𝐺G is denoted 𝛼(𝐺)α(G). Finding the maximum independent set of a graph is NP-hard.

    Matching

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝐸′ ⊆𝐸E′⊆E and no two distinct edges in 𝐸′E′ share a common endpoint, and no edge in 𝐸′E′ is a loop, then 𝐸′E′ is a matching of 𝐺G, also called an independent edge set. If a vertex is an endpoint of some edge in the matching, it is called matched or saturated; otherwise, it is called unmatched.

    A matching with the maximum number of edges is called a maximum-cardinality matching. The size of the maximum matching of graph 𝐺G is denoted 𝜈(𝐺)ν(G).

    If edges have weights, a matching with maximum total weight is called a maximum-weight matching.

    If a matching becomes non-matching when any edge is added to it, then this matching is a maximal matching. The largest maximal matching is the maximum matching, and every maximum matching is a maximal matching. A maximal matching is always an edge dominating set, but an edge dominating set is not necessarily a matching. The minimum maximal matching and minimum edge dominating set have the same size, but the minimum edge dominating set is not necessarily a matching. Finding the minimum maximal matching is NP-hard.

    If all vertices are matched in a matching, then this matching is a perfect matching. If exactly one vertex is unmatched in a matching, then this matching is a near-perfect matching.

    Finding the number of matchings or perfect matchings in a general graph or bipartite graph is #P-complete.

    For a matching 𝑀M, if a path starts at an unmatched vertex, and alternatingly contains edges in and not in the matching, then this path is called an alternating path. An alternating path that ends at an unmatched vertex is called an augmenting path.

    Tutte's theorem: An 𝑛n-vertex undirected graph 𝐺G has a perfect matching if and only if for any 𝑉′ ⊂𝑉(𝐺)V′⊂V(G), 𝑝odd(𝐺 −𝑉′) ≤|𝑉′|podd(G−V′)≤|V′|, where 𝑝oddpodd denotes the number of odd-order connected components.

    Tutte's theorem (corollary): Every bridgeless 3-regular graph has a perfect matching.

    Vertex Cover

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝑉′ ⊆𝑉V′⊆V and for every 𝑒 ∈𝐸e∈E, at least one endpoint of 𝑒e is in 𝑉′V′, then 𝑉′V′ is a vertex cover of 𝐺G.

    A vertex cover is necessarily a dominating set, but a minimal vertex cover is not necessarily a minimal dominating set.

    A vertex set is a vertex cover if and only if its complement is an independent set. Therefore, the complement of a minimum vertex cover is a maximum independent set. Finding the minimum vertex cover of a graph is NP-hard.

    The size of any matching in a graph is at most the size of any vertex cover. For a complete bipartite graph 𝐾𝑛,𝑚Kn,m, the maximum matching and minimum vertex cover both have size min(𝑛,𝑚)min(n,m).

    Edge Cover

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝐸′ ⊆𝐸E′⊆E and for every 𝑣 ∈𝑉v∈V, 𝑣v is adjacent to at least one edge in 𝐸′E′, then 𝐸′E′ is an edge cover of 𝐺G.

    The size of a minimum edge cover is denoted 𝜌(𝐺)ρ(G), which can be obtained greedily from a maximum matching: for all unmatched vertices, add one adjacent edge to the maximum matching to obtain a minimum edge cover.

    A maximum matching can also be obtained from a minimum edge cover: for each pair of edges in the minimum edge cover that share a common endpoint, delete one of them.

    The size of a minimum edge cover plus the size of a maximum matching equals the number of vertices: 𝜌(𝐺) +𝜈(𝐺) =|𝑉(𝐺)|ρ(G)+ν(G)=|V(G)|.

    The size of a maximum matching is at most the size of a minimum edge cover: 𝜈(𝐺) ≤𝜌(𝐺)ν(G)≤ρ(G). In particular, a perfect matching is always a minimum edge cover, which is the only case where the equality holds.

    The size of any independent set is at most the size of any edge cover. For a complete bipartite graph 𝐾𝑛,𝑚Kn,m, the maximum independent set and minimum edge cover both have size max(𝑛,𝑚)max(n,m).

    Clique

    For a graph 𝐺 =(𝑉,𝐸)G=(V,E), if 𝑉′ ⊆𝑉V′⊆V and every pair of distinct vertices in 𝑉′V′ are adjacent, then 𝑉′V′ is a clique of 𝐺G. The induced subgraph of a clique is a complete graph.

    If adding any vertex to a clique makes it no longer a clique, then this clique is a maximal clique.

    The size of the maximum clique of a graph is denoted 𝜔(𝐺)ω(G). The size of the maximum clique equals the size of the maximum independent set in the complement graph: 𝜔(𝐺) =𝛼(¯𝐺)ω(G)=α(G¯). Finding the maximum clique of a graph is NP-hard.
