    Slope Trick Optimization

    Introduction

    For a class of two-dimensional DP problems, if the value function 𝑓(𝑖,𝑥)f(i,x) is convex in 𝑥x for every fixed 𝑖i, then it is often useful to regard the whole function 𝑓(𝑖, ⋅)f(i,⋅) as the state at 𝑖i and maintain its difference, or slope,

    Δ𝑓(𝑖,𝑥)=𝑓(𝑖,𝑥+1)−𝑓(𝑖,𝑥)Δf(i,x)=f(i,x+1)−f(i,x)

    instead of the function values themselves. This DP optimization idea is called the Slope Trick.

    Slope

    In most problems the functions are only evaluated at integer points, so there is no essential difference between calling this quantity a difference and calling it a slope. This article follows the term Slope Trick and uses "slope" throughout.

    The exact way to maintain slopes depends on the problem. If the range of slope values is small, it is usually convenient to maintain the points where the slope changes, namely the breakpoints. If the domain is small, maintaining the slope sequence itself may be better. More complex problems may require maintaining both the slope value of each segment and its length. In all cases, the key observation is that the slope sequence changes only slightly under the transition.

    Convex Functions

    Before discussing examples, we review the basic properties of convex functions and how their slopes change under common transformations.

    Convex Functions On The Real Line

    The most general definition is on 𝐑R.

    Convex Functions On 𝐑R

    A function 𝑓 :𝐑 →𝐑 ∪{ ±∞}f:R→R∪{±∞} is convex if for all 𝑥,𝑦 ∈𝐑x,y∈R and 𝛼 ∈(0,1)α∈(0,1),

    𝑓(𝛼𝑥+(1−𝛼)𝑦)≤𝛼𝑓(𝑥)+(1−𝛼)𝑓(𝑦),f(αx+(1−α)y)≤αf(x)+(1−α)f(y),

    Arithmetic involving ±∞±∞ follows the usual extended-real convention: multiplying by a positive real or adding a real number keeps ±∞±∞, and −∞ <𝑥 < +∞−∞<x<+∞ for every real 𝑥x.

    Changing ≤≤ to ≥≥ gives concavity1. Since 𝑓f is concave iff −𝑓−f is convex, this article only discusses convex functions.

    Only Proper Convex Functions Are Considered

    To avoid issues such as ∞ −∞∞−∞, we assume a convex function never takes the value −∞−∞ and is not identically +∞+∞. Such functions are called proper convex functions, which is enough for competitive-programming applications.

    If 𝑓f is only defined on a subset of 𝐑R, extend it by

    ˜𝑓(𝑥)={𝑓(𝑥),𝑥∈dom⁡𝑓,+∞,𝑥∉dom⁡𝑓f~(x)={f(x),x∈dom⁡f,+∞,x∉dom⁡f

    Then 𝑓f is convex iff ˜𝑓f~ is convex. Thus, unless stated otherwise, convex functions are treated as functions on all of 𝐑R; their finite domain must be an interval.

    Simple Examples

    Common convex functions include:

    1. constant functions 𝑓(𝑥) =𝑐f(x)=c;
    2. affine functions 𝑓(𝑥) =𝑘𝑥 +𝑏f(x)=kx+b with 𝑘 ≠0k≠0;
    3. absolute-value functions 𝑓(𝑥) =|𝑥 −𝑎|f(x)=|x−a|;
    4. restrictions of convex functions to intervals, for example 0[𝑎,𝑏](𝑥)0[a,b](x), the indicator function of [𝑎,𝑏][a,b] in convex analysis.

    More complicated convex functions can be built from the convexity-preserving transformations below.

    Convex Functions On Discrete Sets

    In competitive programming, many functions are defined only on some integer points. Their domain is not convex, so the real-line definition cannot be applied directly. The usual approach is to linearly interpolate the function and then test convexity.

    Convex Functions On Discrete Sets

    Let 𝑆 ⊂𝐑S⊂R be discrete, meaning 𝑆 ∩[𝑎,𝑏]S∩[a,b] is finite for every closed interval [𝑎,𝑏][a,b]. For 𝑓 :𝑆 →𝐑 ∪{ ±∞}f:S→R∪{±∞}, define ˜𝑓 :𝐑 →𝐑 ∪{ ±∞}f~:R→R∪{±∞} by:

    • if 𝑥 ∈𝑆x∈S, then ˜𝑓(𝑥) =𝑓(𝑥)f~(x)=f(x);

    • if 𝑥 ∈(inf𝑆,sup𝑆) ∖𝑆x∈(infS,supS)∖S, let 𝑠− =max{𝑠 ∈𝑆 :𝑠 ≤𝑥}s−=max{s∈S:s≤x} and 𝑠+ =min{𝑠 ∈𝑆 :𝑠 ≥𝑥}s+=min{s∈S:s≥x}, and set

      ˜𝑓(𝑥)=𝑠+−𝑥𝑠+−𝑠−𝑓(𝑠−)+𝑥−𝑠−𝑠+−𝑠−𝑓(𝑠+),f~(x)=s+−xs+−s−f(s−)+x−s−s+−s−f(s+),

    • if 𝑥 ∉[inf𝑆,sup𝑆]x∉[infS,supS], then ˜𝑓(𝑥) = +∞f~(x)=+∞.

    If ˜𝑓f~ is convex on 𝐑R, then 𝑓f is called convex on 𝑆S.

    For 𝑆 =𝐙S=Z, there is a simpler equivalent condition.

    Equivalent Definition On 𝐙Z

    A function 𝑓 :𝐙 →𝐑 ∪{ ±∞}f:Z→R∪{±∞} is convex iff

    𝑓(𝑥)−𝑓(𝑥−1)≤𝑓(𝑥+1)−𝑓(𝑥)f(x)−f(x−1)≤f(x+1)−f(x)

    holds for all 𝑥 ∈𝐙x∈Z.

    Proof

    This is the slope characterization of convexity. If 𝑓f is convex, slopes are nondecreasing:

    Δ𝑓(𝑥−1,𝑥)≤Δ𝑓(𝑥−1,𝑥+1)≤Δ𝑓(𝑥,𝑥+1).Δf(x−1,x)≤Δf(x−1,x+1)≤Δf(x,x+1).

    Conversely, if first differences are nondecreasing, then for any 𝑥1 <𝑥2x1<x2,

    Δ𝑓(𝑥1,𝑥2)=1𝑥2−𝑥1𝑥2−1∑𝑖=𝑥1(𝑓(𝑖)−𝑓(𝑖−1)).Δf(x1,x2)=1x2−x1∑i=x1x2−1(f(i)−f(i−1)).

    This is the arithmetic mean of all differences with 𝑥1 ≤𝑖 <𝑥2x1≤i<x2. Moving the right endpoint right inserts a larger difference; moving the left endpoint right removes the smallest difference. Both operations increase the average, so all secant slopes are nondecreasing, which is convexity.

    Thus a nondecreasing difference sequence can be viewed as a convex function on 𝐙Z.

    Two Characterizations Of Convexity

    The slope characterization generalizes.

    Slope Characterization Of Convex Functions

    Let 𝑆S be 𝐑R or a discrete subset of it. A function 𝑓 :𝑆 →𝐑 ∪{ ±∞}f:S→R∪{±∞} is convex iff the slope

    Δ𝑓(𝑥1,𝑥2)=𝑓(𝑥2)−𝑓(𝑥1)𝑥2−𝑥1Δf(x1,x2)=f(x2)−f(x1)x2−x1

    is nondecreasing in both 𝑥1x1 and 𝑥2x2 for all 𝑥1 <𝑥2x1<x2 in 𝑆S.

    Proof

    For functions on 𝐑R, set 𝑥3 =𝛼𝑥1 +(1 −𝛼)𝑥2x3=αx1+(1−α)x2. The inequalities

    Δ𝑓(𝑥1,𝑥3)≤Δ𝑓(𝑥1,𝑥2)≤Δ𝑓(𝑥3,𝑥2)Δf(x1,x3)≤Δf(x1,x2)≤Δf(x3,x2)

    are equivalent to

    𝑓(𝑥3)−𝑓(𝑥1)1−𝛼≤𝑓(𝑥2)−𝑓(𝑥1)≤𝑓(𝑥2)−𝑓(𝑥3)𝛼.f(x3)−f(x1)1−α≤f(x2)−f(x1)≤f(x2)−f(x3)α.

    Both inequalities are equivalent to 𝑓(𝑥3) ≤𝛼𝑓(𝑥1) +(1 −𝛼)𝑓(𝑥2)f(x3)≤αf(x1)+(1−α)f(x2), namely convexity.

    For a function 𝑓f on a discrete subset 𝑆S of 𝐑R, necessity follows from convexity of ˜𝑓f~. For sufficiency, it is enough to prove that Δ˜𝑓(𝑥1,𝑥2)Δf~(x1,x2) is also nondecreasing. Let 𝑆 ={𝑠𝑖}S={si} with 𝑠𝑖si strictly increasing in 𝑖i, and suppose 𝑠𝑖1 ≤𝑥1 ≤𝑠𝑖1+1si1≤x1≤si1+1 and 𝑠𝑖2 ≤𝑥2 ≤𝑠𝑖2+1si2≤x2≤si2+1, so 𝑖1 ≤𝑖2i1≤i2. Let Δ𝑖 =Δ𝑓(𝑠𝑖,𝑠𝑖+1)Δi=Δf(si,si+1). If 𝑖1 =𝑖2i1=i2, then Δ𝑖1 =Δ˜𝑓(𝑥1,𝑥2) =Δ𝑖2Δi1=Δf~(x1,x2)=Δi2. Otherwise,

    Δ˜𝑓(𝑥1,𝑥2)=1𝑥2−𝑥1((𝑠𝑖1+1−𝑥1)Δ𝑖1+(𝑥2−𝑠𝑖2)Δ𝑖2+𝑖2−1∑𝑗=𝑖1+1(𝑠𝑗+1−𝑠𝑗)Δ𝑗).Δf~(x1,x2)=1x2−x1((si1+1−x1)Δi1+(x2−si2)Δi2+∑j=i1+1i2−1(sj+1−sj)Δj).

    Since the Δ𝑖Δi are nondecreasing, Δ𝑖1 ≤Δ˜𝑓(𝑥1,𝑥2) ≤Δ𝑖2Δi1≤Δf~(x1,x2)≤Δi2. Applying this to 𝑥1 <𝑥2x1<x2 and 𝑥3 =𝛼𝑥1 +(1 −𝛼)𝑥2x3=αx1+(1−α)x2, with 𝑠𝑖3 ≤𝑥3 ≤𝑠𝑖3+1si3≤x3≤si3+1, gives

    Δ˜𝑓(𝑥1,𝑥3)≤Δ𝑖3≤Δ˜𝑓(𝑥3,𝑥2).Δf~(x1,x3)≤Δi3≤Δf~(x3,x2).

    Substituting the expression for 𝑥3x3 gives convexity of ˜𝑓f~.

    Because slopes of convex functions are monotone, data structures such as heaps and balanced binary search trees are often used to maintain them.

    Another useful characterization uses the epigraph

    epi⁡𝑓={(𝑥,𝑦)∈𝐑2:𝑦≥𝑓(𝑥)}.epi⁡f={(x,y)∈R2:y≥f(x)}.
    Epigraph Characterization Of Convex Functions

    A function 𝑓 :𝐑 →𝐑 ∪{ ±∞}f:R→R∪{±∞} is convex iff epi⁡𝑓epi⁡f is a convex subset of 𝐑2R2.

    Proof

    If 𝑓f is convex, then for (𝑥1,𝑦1),(𝑥2,𝑦2) ∈epi⁡𝑓(x1,y1),(x2,y2)∈epi⁡f and any 𝛼 ∈(0,1)α∈(0,1),

    𝛼𝑦1+(1−𝛼)𝑦2≥𝛼𝑓(𝑥1)+(1−𝛼)𝑓(𝑥2)≥𝑓(𝛼𝑥1+(1−𝛼)𝑥2).αy1+(1−α)y2≥αf(x1)+(1−α)f(x2)≥f(αx1+(1−α)x2).

    Hence 𝛼(𝑥1,𝑦1) +(1 −𝛼)(𝑥2,𝑦2) ∈epi⁡𝑓α(x1,y1)+(1−α)(x2,y2)∈epi⁡f.

    Conversely, if epi⁡𝑓epi⁡f is convex, then for any 𝑥1 <𝑥2x1<x2 and 𝛼 ∈(0,1)α∈(0,1),

    𝛼(𝑥1,𝑓(𝑥1))+(1−𝛼)(𝑥2,𝑓(𝑥2))∈epi⁡𝑓.α(x1,f(x1))+(1−α)(x2,f(x2))∈epi⁡f.

    This is equivalent to 𝛼𝑓(𝑥1) +(1 −𝛼)𝑓(𝑥2) ≥𝑓(𝛼𝑥1+(1−𝛼)𝑥2)αf(x1)+(1−α)f(x2)≥f(αx1+(1−α)x2), which is convexity of 𝑓f.

    This viewpoint connects infimal convolution of convex functions with Minkowski sums of convex sets.

    Transformations Of Convex Functions

    Nonnegative Linear Combinations

    If 𝑓f and 𝑔g are convex and 𝛼,𝛽 ≥0α,β≥0, then 𝛼𝑓 +𝛽𝑔αf+βg is convex, and

    Δ(𝛼𝑓+𝛽𝑔)=𝛼Δ𝑓+𝛽Δ𝑔.Δ(αf+βg)=αΔf+βΔg.

    When maintaining slopes, compute the combined slope segment by segment. If one function has a simple form, lazy tags often reduce the update cost. When maintaining breakpoints, the breakpoints of 𝑓 +𝑔f+g are obtained by merging the breakpoint lists.

    Infimal Convolution (Minkowski Sum)

    For functions 𝑓f and 𝑔g,

    ℎ(𝑥)=inf𝑦∈𝐑𝑓(𝑦)+𝑔(𝑥−𝑦)h(x)=infy∈Rf(y)+g(x−y)

    is called their infimal convolution2. If both are convex, so is ℎh.

    Interpreting The Figure

    To compute ℎh, move the graph of 𝑔g along the graph of 𝑓f and take the lower envelope. Each slope segment of ℎh is a slope segment of either 𝑓f or 𝑔g, reordered by slope. Geometrically, epi⁡ℎepi⁡h is the Minkowski sum of epi⁡𝑓epi⁡f and epi⁡𝑔epi⁡g.

    Proof

    For 𝑥1 <𝑥2x1<x2 and 𝛼 ∈(0,1)α∈(0,1), choose near-optimal decompositions 𝑥𝑖 =𝑦𝑖 +𝑧𝑖xi=yi+zi such that

    ℎ(𝑥𝑖)+𝜀>𝑓(𝑦𝑖)+𝑔(𝑧𝑖).h(xi)+ε>f(yi)+g(zi).

    Convexity of 𝑓f and 𝑔g gives

    𝛼ℎ(𝑥1)+(1−𝛼)ℎ(𝑥2)+𝜀>𝛼𝑓(𝑦1)+(1−𝛼)𝑓(𝑦2)+𝛼𝑔(𝑧1)+(1−𝛼)𝑔(𝑧2)≥𝑓(𝛼𝑦1+(1−𝛼)𝑦2)+𝑔(𝛼𝑧1+(1−𝛼)𝑧2)≥ℎ(𝛼𝑥1+(1−𝛼)𝑥2).αh(x1)+(1−α)h(x2)+ε>αf(y1)+(1−α)f(y2)+αg(z1)+(1−α)g(z2)≥f(αy1+(1−α)y2)+g(αz1+(1−α)z2)≥h(αx1+(1−α)x2).

    Since 𝜀 >0ε>0 is arbitrary,

    𝛼ℎ(𝑥1)+(1−𝛼)ℎ(𝑥2)≥ℎ(𝛼𝑥1+(1−𝛼)𝑥2).αh(x1)+(1−α)h(x2)≥h(αx1+(1−α)x2).

    This proves convexity. The epigraph relation is

    epi⁡𝑓+epi⁡𝑔⊆epi⁡ℎ⊆cl⁡(epi⁡𝑓+epi⁡𝑔).epi⁡f+epi⁡g⊆epi⁡h⊆cl⁡(epi⁡f+epi⁡g).

    For any (𝑥,𝑦) ∈epi⁡𝑓 +epi⁡𝑔(x,y)∈epi⁡f+epi⁡g, there are (𝑥1,𝑦1) ∈epi⁡𝑓(x1,y1)∈epi⁡f and (𝑥2,𝑦2) ∈epi⁡𝑔(x2,y2)∈epi⁡g such that 𝑥 =𝑥1 +𝑥2x=x1+x2 and

    𝑦=𝑦1+𝑦2≥𝑓(𝑥1)+𝑔(𝑥2)≥ℎ(𝑥1+𝑥2)=ℎ(𝑥).y=y1+y2≥f(x1)+g(x2)≥h(x1+x2)=h(x).

    Hence (𝑥,𝑦) ∈epi⁡ℎ(x,y)∈epi⁡h. Conversely, if (𝑥,𝑦) ∈epi⁡ℎ(x,y)∈epi⁡h, then 𝑦 ≥ℎ(𝑥)y≥h(x). For any 𝜀 >0ε>0, there exist 𝑥1 +𝑥2 =𝑥x1+x2=x such that

    𝑦+𝜀>𝑓(𝑥1)+𝑔(𝑥2).y+ε>f(x1)+g(x2).

    Taking 𝜀 →0ε→0 gives the inclusion into the closure. Thus equality holds when the sum is closed, as in the usual piecewise-linear cases.

    If one function has few slope segments, insert them into the larger structure directly; otherwise use DSU on tree, mergeable heaps, or another problem-specific merging strategy.

    Min And Max Operations

    The maximum of two convex functions is convex, but the minimum of two convex functions need not be convex.

    Many useful minimum operations can be rewritten as infimal convolution.

    Examples

    • 𝑓(𝑥) =min𝑦∈[𝑥+𝑎,𝑥+𝑏]𝑔(𝑦)f(x)=miny∈[x+a,x+b]g(y) is convex because

      𝑓(𝑥)=min𝑦∈𝐑𝑔(𝑦)+0[−𝑏,−𝑎](𝑥−𝑦).f(x)=miny∈Rg(y)+0[−b,−a](x−y).

    • 𝑓(𝑥) =min{𝑔(𝑥 −𝑎𝑖) +𝑏𝑖}f(x)=min{g(x−ai)+bi} is convex on 𝐙Z if 𝑔g is convex on 𝐙Z and ℎ :𝑎𝑖 ↦𝑏𝑖h:ai↦bi is convex on the finite set {𝑎𝑖}{ai}, because the interpolated function can be written as the infimal convolution

      ˜𝑓(𝑥)=min𝑦∈𝐑˜ℎ(𝑦)+˜𝑔(𝑥−𝑦).f~(x)=miny∈Rh~(y)+g~(x−y).

      Therefore the original function 𝑓(𝑥)f(x) is also convex.

    Counterexample

    If 𝑔(𝑥)g(x) is convex, 𝑓(𝑥) =min{𝑔(𝑥 −1) +𝑘𝑥,𝑔(𝑥)}f(x)=min{g(x−1)+kx,g(x)} is not necessarily convex.

    Some DP transitions are minima of convex functions that cannot easily be expressed as infimal convolutions, but convexity still holds. In practice, tables and pattern-spotting are often used to discover the correct slope transition.

    Maintaining Breakpoints

    This type of problem often appears when minimizing sums of absolute values. Because slopes change by small integer amounts, maintaining breakpoints is convenient.

    Maintaining breakpoints means storing the points where the slope of a piecewise-linear function changes. If the breakpoint multiset is 𝜉−𝑠 ≤⋯ ≤𝜉−1 ≤𝜉1 ≤⋯ ≤𝜉𝑡ξ−s≤⋯≤ξ−1≤ξ1≤⋯≤ξt, then the slope is 00 on [𝜉−1,𝜉1][ξ−1,ξ1], decreases by one when passing a breakpoint to the left, and increases by one when passing a breakpoint to the right. Formally,

    𝑓(𝑥)=𝑓(𝜉1)+−1∑𝑖=−𝑠max{𝜉𝑖−𝑥,0}+ℓ∑𝑖=1max{𝑥−𝜉𝑖,0}.f(x)=f(ξ1)+∑i=−s−1max{ξi−x,0}+∑i=1ℓmax{x−ξi,0}.

    The minimum value is 𝑓(𝜉−1) =𝑓(𝜉1)f(ξ−1)=f(ξ1) and is attained anywhere in [𝜉−1,𝜉1][ξ−1,ξ1].

    Example: Minimum-Cost Increasing Sequence

    [BalticOI 2004] Sequence

    Given a sequence {𝑎𝑖}{ai} of length 𝑛n, find a strictly increasing sequence {𝑏𝑖}{bi} minimizing ∑𝑖|𝑎𝑖 −𝑏𝑖|∑i|ai−bi|, and output the minimum value and any optimal sequence.

    Solution

    Strictly increasing {𝑏𝑖}{bi} is equivalent to nondecreasing 𝑏′𝑖 =𝑏𝑖 −𝑖bi′=bi−i. Let 𝑎′𝑖 =𝑎𝑖 −𝑖ai′=ai−i. Define 𝑓𝑖(𝑥)fi(x) as the minimum cost after choosing the first 𝑖i values of 𝑏′b′ with 𝑏′𝑖 ≤𝑥bi′≤x:

    𝑓𝑖(𝑥)=min𝑖∑𝑗=1|𝑎′𝑗−𝑏′𝑗| s.t. 𝑏′1≤𝑏′2≤⋯≤𝑏′𝑖≤𝑥.fi(x)=min∑j=1i|aj′−bj′| s.t. b1′≤b2′≤⋯≤bi′≤x.

    The transition is

    𝑓𝑖(𝑥)=min𝑦≤𝑥𝑓𝑖−1(𝑦)+|𝑎′𝑖−𝑦|.fi(x)=miny≤xfi−1(y)+|ai′−y|.

    Add two breakpoints at 𝑎′𝑖ai′, then delete all positive-slope breakpoints. Since after every step there are no positive-slope breakpoints, a max-heap of breakpoints suffices: insert 𝑎′𝑖ai′ twice and pop the heap top.

    The minimum value must also be maintained. If the heap top before an operation is 𝜉−1ξ−1, the new minimum is the function value at the heap top before it is popped, namely

    𝑓𝑖−1(max{𝑎′𝑖,𝜉−1})+|max{𝑎′𝑖,𝜉−1}−𝑎′𝑖|=𝑓𝑖−1(𝜉−1)+max{0,𝜉−1−𝑎′𝑖}.fi−1(max{ai′,ξ−1})+|max{ai′,ξ−1}−ai′|=fi−1(ξ−1)+max{0,ξ−1−ai′}.

    Thus add max{0,𝜉−1 −𝑎′𝑖}max{0,ξ−1−ai′} to the answer each step. To reconstruct a solution, record the current minimizer and go backward, taking prefix minima.

    The complexity is 𝑂(𝑛log⁡𝑛)O(nlog⁡n).

    Example: Transitions With Constraints

    [NOISG 2018 Finals] Safety

    Given a sequence {𝑎𝑖}{ai}, find a sequence {𝑏𝑖}{bi} satisfying |𝑏𝑖 −𝑏𝑖−1| ≤ℎ|bi−bi−1|≤h for all 1 <𝑖 ≤𝑛1<i≤n and minimizing ∑𝑖|𝑎𝑖 −𝑏𝑖|∑i|ai−bi|.

    Solution

    Let 𝑓𝑖(𝑥)fi(x) be the minimum cost when 𝑏𝑖 =𝑥bi=x:

    𝑓𝑖(𝑥)=min𝑖∑𝑗=1|𝑎𝑗−𝑏𝑗| s.t. |𝑏𝑗−1−𝑏𝑗|≤ℎ,∀1<𝑗≤𝑖, 𝑏𝑖=𝑥.fi(x)=min∑j=1i|aj−bj| s.t. |bj−1−bj|≤h,∀1<j≤i, bi=x.

    Then

    𝑓𝑖(𝑥)=|𝑎𝑖−𝑥|+min|𝑦−𝑥|≤ℎ𝑓𝑖−1(𝑦).fi(x)=|ai−x|+min|y−x|≤hfi−1(y).

    The first operation is infimal convolution with 0[−ℎ,ℎ]0[−h,h], which shifts all negative-slope breakpoints left by ℎh and all positive-slope breakpoints right by ℎh. Then add two breakpoints at 𝑎𝑖ai. Use two heaps, a max-heap and a min-heap, to maintain negative and positive breakpoints, with lazy offsets. If the heap tops cross, swap them and add their distance to the minimum value.

    Specifically, if 𝜉−1 >𝜉1ξ−1>ξ1, then swapping the heap tops changes the local expression from

    max{0,𝑥−𝜉−1}+max{0,𝑥−𝜉1}max{0,x−ξ−1}+max{0,x−ξ1}

    to

    max{0,𝑥−𝜉1}+max{0,𝑥−𝜉−1}.max{0,x−ξ1}+max{0,x−ξ−1}.

    The shape is unchanged, only shifted downward by |𝜉−1 −𝜉1||ξ−1−ξ1|, so add this distance to the minimum value to keep the function unchanged. Each step swaps at most once, so the complexity is 𝑂(𝑛log⁡𝑛)O(nlog⁡n).

#include <queue>
#include <vector>

int main() {
  int n;
  long long h;
  std::cin >> n >> h;
  std::priority_queue<long long> max_heap;
  std::priority_queue<long long, std::vector<long long>, std::greater<>>
      min_heap;
  long long lt = 0, rt = 0;
  long long res = 0;
  for (; n; --n) {
    long long x;
    std::cin >> x;
    lt += h;
    rt += h;
    max_heap.emplace(x + lt);
    min_heap.emplace(x - rt);
    auto l = max_heap.top() - lt;
    auto r = min_heap.top() + rt;
    while (l > r) {
      max_heap.pop();
      min_heap.pop();
      res += l - r;
      max_heap.emplace(r + lt);
      min_heap.emplace(l - rt);
      l = max_heap.top() - lt;
      r = min_heap.top() + rt;
    }
  }
  std::cout << res << std::endl;
  return 0;
}

    Maintaining Slopes

    In some problems, maintaining slopes directly is more convenient. Such problems are often also solvable by undoable greedy methods or by simulating min-cost flow. In a min-cost-flow model, the minimum cost is often a convex function of the flow value, which provides the basis for Slope Trick.

    Example: Stock Trading

    Codeforces 865 D. Buy Low Sell High

    Given stock prices {𝑝𝑖}{pi} for 𝑛n days, initially holding no stock, each day you may buy one share, sell one share, or do nothing. Find the maximum profit after 𝑛n days.

    Solution

    Let 𝑓𝑖(𝑥)fi(x) be the maximum profit after day 𝑖i while holding 𝑥 ≥0x≥0 shares:

    𝑓𝑖(𝑥)=max{𝑓𝑖−1(𝑥−1)−𝑝𝑖,𝑓𝑖−1(𝑥),𝑓𝑖−1(𝑥+1)+𝑝𝑖}.fi(x)=max{fi−1(x−1)−pi,fi−1(x),fi−1(x+1)+pi}.

    Start with 𝑓0(0) =0f0(0)=0 and 𝑓0(𝑥) = −∞f0(x)=−∞ for 𝑥 ≠0x≠0; the answer is 𝑓𝑛(0)fn(0). The transition first performs supremal convolution with the piecewise-linear extension of

    ℎ𝑖(𝑥)=⎧{ {⎨{ {⎩𝑝𝑖,𝑥=−1,0,𝑥=0,−𝑝𝑖,𝑥=1hi(x)={pi,x=−1,0,x=0,−pi,x=1

    Example: Moving Soil And Stone

    [USACO16OPEN] Landscaping P

    Given sequences {𝑎𝑖}{ai} and {𝑏𝑖}{bi}, where garden 𝑖i currently has 𝑎𝑖ai units of soil and needs exactly 𝑏𝑖bi, buying one unit costs 𝑋X, discarding one unit costs 𝑌Y, and moving one unit from garden 𝑖i to garden 𝑗j costs 𝑍|𝑖 −𝑗|Z|i−j|. Find the minimum cost. Here 𝑎𝑖,𝑏𝑖 ≤10ai,bi≤10.
