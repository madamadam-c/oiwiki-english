    Suffix Array Overview

    Some Conventions

    For definitions related to strings, refer to String Basics.

    String indices start from 11.

    The length of string 𝑠s is 𝑛n.

    "Suffix 𝑖i" refers to the suffix starting at the 𝑖i-th character. When storing, we use 𝑖i to represent the suffix 𝑠[𝑖…𝑛]s[i…n] of string 𝑠s.

    What is a Suffix Array?

    The Suffix Array mainly involves two arrays: 𝑠𝑎sa and 𝑟𝑘rk.

    Here, 𝑠𝑎[𝑖]sa[i] represents the index of the 𝑖i-th smallest suffix after sorting all suffixes, which is what we call the suffix array, also referred to as the index array 𝑠𝑎sa in later sections;

    𝑟𝑘[𝑖]rk[i] represents the rank of suffix 𝑖i, which is an important auxiliary array, also referred to as the rank array 𝑟𝑘rk in later sections.

    These two arrays satisfy the property: 𝑠𝑎[𝑟𝑘[𝑖]] =𝑟𝑘[𝑠𝑎[𝑖]] =𝑖sa[rk[i]]=rk[sa[i]]=i.

    How to Compute a Suffix Array?

    O(n^2logn) Approach

    I believe this approach can be figured out by anyone: sort the array containing all suffix strings using sort. Since the sorting performs 𝑂(𝑛log⁡𝑛)O(nlog⁡n) string comparisons, and each string comparison requires 𝑂(𝑛)O(n) character comparisons, this sorting has a time complexity of 𝑂(𝑛2log⁡𝑛)O(n2log⁡n).

    O(nlog^2n) Approach

    This approach uses the doubling technique.

    First, sort all substrings of length 11 of string 𝑠s, i.e., each character, to obtain the sorted index array 𝑠𝑎1sa1 and rank array 𝑟𝑘1rk1.

    Doubling process:

    1. Using the ranks of two substrings of length 11, i.e., 𝑟𝑘1[𝑖]rk1[i] and 𝑟𝑘1[𝑖 +1]rk1[i+1], as the first and second sort keys, we can sort all substrings of length 22 of string 𝑠s: {𝑠[𝑖…min(𝑖 +1,𝑛)] | 𝑖 ∈[1, 𝑛]}{s[i…min(i+1,n)] | i∈[1, n]} to obtain 𝑠𝑎2sa2 and 𝑟𝑘2rk2;

    2. Then, using the ranks of two substrings of length 22, i.e., 𝑟𝑘2[𝑖]rk2[i] and 𝑟𝑘2[𝑖 +2]rk2[i+2], as the first and second sort keys, we can sort all substrings of length 44 of string 𝑠s: {𝑠[𝑖…min(𝑖 +3,𝑛)] | 𝑖 ∈[1, 𝑛]}{s[i…min(i+3,n)] | i∈[1, n]} to obtain 𝑠𝑎4sa4 and 𝑟𝑘4rk4;

    3. Continue this doubling: using the ranks of substrings of length 𝑤/2w/2, i.e., 𝑟𝑘𝑤/2[𝑖]rkw/2[i] and 𝑟𝑘𝑤/2[𝑖 +𝑤/2]rkw/2[i+w/2], as the first and second sort keys, we can sort all substrings of length 𝑤w of string 𝑠s: 𝑠[𝑖…min(𝑖 +𝑤 −1, 𝑛)]s[i…min(i+w−1, n)] to obtain 𝑠𝑎𝑤saw and 𝑟𝑘𝑤rkw. Here, similar to alphabetical order sorting, when 𝑖 +𝑤 >𝑛i+w>n, 𝑟𝑘𝑤[𝑖 +𝑤]rkw[i+w] is treated as negative infinity;

    4. 𝑟𝑘𝑤[𝑖]rkw[i] is the rank of substring 𝑠[𝑖…𝑖 +𝑤 −1]s[i…i+w−1]. When 𝑤 ⩾𝑛w⩾n, the resulting index array 𝑠𝑎𝑤saw is the suffix array we need.

    Process

    Doubling sorting diagram:

    Obviously, the doubling process is 𝑂(log⁡𝑛)O(log⁡n), and each doubling uses sort to sort substrings in 𝑂(𝑛log⁡𝑛)O(nlog⁡n), with each substring comparison requiring 2 character comparisons;

    Additionally, after each sort sorting in doubling, there are extra 𝑂(𝑛)O(n) operations to update 𝑟𝑘rk, but they are negligible compared to 𝑂(𝑛log⁡𝑛)O(nlog⁡n);

    Therefore, the time complexity of this algorithm is 𝑂(𝑛log2⁡𝑛)O(nlog2⁡n).

    #include <algorithm>
#include <cstdio>
#include <cstring>
#include <iostream>

using namespace std;

constexpr int N = 1000010;

char s[N];
int n, w, sa[N], rk[N << 1], oldrk[N << 1];

// To prevent array out-of-bounds when accessing rk[i+w], allocate double-sized array.
// Of course, we can also check for bounds before accessing, but directly allocating double-sized array is more convenient.

int main() {
  int i, p;

  scanf("%s", s + 1);
  n = strlen(s + 1);
  for (i = 1; i <= n; ++i) sa[i] = i, rk[i] = s[i];

  for (w = 1; w < n; w <<= 1) {
    sort(sa + 1, sa + n + 1, [](int x, int y) {
      return rk[x] == rk[y] ? rk[x + w] < rk[y + w] : rk[x] < rk[y];
    });  // Using lambda here
    memcpy(oldrk, rk, sizeof(rk));
    // Since the original rk will be overwritten when computing rk, we need to copy it first.
    // If two substrings are identical, their corresponding rk should also be the same, so we need to deduplicate.
    for (p = 0, i = 1; i <= n; ++i) {
      if (oldrk[sa[i]] == oldrk[sa[i - 1]] &&
          oldrk[sa[i] + w] == oldrk[sa[i - 1] + w]) {
        rk[sa[i]] = p;
      } else {
        rk[sa[i]] = ++p;
      }
    }
  }

  for (i = 1; i <= n; ++i) printf("%d ", sa[i]);

  return 0;
}

    O(nlogn) Approach

    In the previous 𝑂(𝑛log2⁡𝑛)O(nlog2⁡n) approach, single sorting is 𝑂(𝑛log⁡𝑛)O(nlog⁡n). If we can sort in 𝑂(𝑛)O(n), we can compute the suffix array in 𝑂(𝑛log⁡𝑛)O(nlog⁡n).

    Prerequisites: Counting Sort, Radix Sort.

    Since the sort keys during suffix array computation are ranks with a value range of 𝑂(𝑛)O(n), and it's a double-key sort, we can use radix sort to optimize to 𝑂(𝑛)O(n).

    #include <algorithm>
#include <cstdio>
#include <cstring>
#include <iostream>

using namespace std;

constexpr int N = 1000010;

char s[N];
int n, sa[N], rk[N << 1], oldrk[N << 1], id[N], cnt[N];

int main() {
  int i, m, p, w;

  scanf("%s", s + 1);
  n = strlen(s + 1);
  m = 127;
  for (i = 1; i <= n; ++i) ++cnt[rk[i] = s[i]];
  for (i = 1; i <= m; ++i) cnt[i] += cnt[i - 1];
  for (i = n; i >= 1; --i) sa[cnt[rk[i]]--] = i;
  memcpy(oldrk + 1, rk + 1, n * sizeof(int));
  for (p = 0, i = 1; i <= n; ++i) {
    if (oldrk[sa[i]] == oldrk[sa[i - 1]]) {
      rk[sa[i]] = p;
    } else {
      rk[sa[i]] = ++p;
    }
  }

  for (w = 1; w < n; w <<= 1, m = n) {
    // For second key: id[i] + w, use counting sort
    memset(cnt, 0, sizeof(cnt));
    memcpy(id + 1, sa + 1,
           n * sizeof(int));  // id stores a copy of sa, essentially equivalent to oldsa
    for (i = 1; i <= n; ++i) ++cnt[rk[id[i] + w]];
    for (i = 1; i <= m; ++i) cnt[i] += cnt[i - 1];
    for (i = n; i >= 1; --i) sa[cnt[rk[id[i] + w]]--] = id[i];

    // For first key: id[i], use counting sort
    memset(cnt, 0, sizeof(cnt));
    memcpy(id + 1, sa + 1, n * sizeof(int));
    for (i = 1; i <= n; ++i) ++cnt[rk[id[i]]];
    for (i = 1; i <= m; ++i) cnt[i] += cnt[i - 1];
    for (i = n; i >= 1; --i) sa[cnt[rk[id[i]]]--] = id[i];

    memcpy(oldrk + 1, rk + 1, n * sizeof(int));
    for (p = 0, i = 1; i <= n; ++i) {
      if (oldrk[sa[i]] == oldrk[sa[i - 1]] &&
          oldrk[sa[i] + w] == oldrk[sa[i - 1] + w]) {
        rk[sa[i]] = p;
      } else {
        rk[sa[i]] = ++p;
      }
    }
  }

  for (i = 1; i <= n; ++i) printf("%d ", sa[i]);

  return 0;
}

  n = strlen(s + 1);
  m = 128;

  for (int i = 1; i <= n; i++) cnt[rk[i] = s[i]]++;
  for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
  for (int i = n; i >= 1; i--) sa[cnt[rk[i]]--] = i;

  for (int w = 1;; w <<= 1, m = p) {  // m = p is the value range optimization
    int cur = 0;
    for (int i = n - w + 1; i <= n; i++) id[++cur] = i;
    for (int i = 1; i <= n; i++)

    memset(cnt, 0, sizeof(cnt));
    for (int i = 1; i <= n; i++) cnt[rk[i]]++;
    for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; i--) sa[cnt[rk[id[i]]]--] = id[i];

    p = 0;
    memcpy(oldrk, rk, sizeof(oldrk));
    for (int i = 1; i <= n; i++) {
      if (oldrk[sa[i]] == oldrk[sa[i - 1]] &&
          oldrk[sa[i] + w] == oldrk[sa[i - 1] + w])

      else

    }

    if (p == n) break;  // When p = n, no further sorting is needed

    O(n) Approach

    In typical problems, the doubling method with small constants for computing suffix arrays is fully sufficient. The parts other than computing the suffix array often also have 𝑂(𝑛log⁡𝑛)O(nlog⁡n) complexity, so doubling for suffix array does not become a bottleneck.

    However, if encountering special problems, time-critical problems, or if you want to pursue shorter execution time, you need to learn the 𝑂(𝑛)O(n) method for computing suffix arrays.

    Finding Substrings in a String

    The task is to online find pattern string 𝑆S in main string 𝑇T. "Online" means we already know main string 𝑇T in advance, but we only know pattern string 𝑆S when queried. We can first construct the suffix array of 𝑇T, then search for substring 𝑆S. If substring 𝑆S appears in 𝑇T, it must be a prefix of some suffixes of 𝑇T. Since we have sorted all suffixes, we can implement this by binary searching 𝑆S in the 𝑠𝑎sa array. Comparing substring 𝑆S with the current suffix takes 𝑂(|𝑆|)O(|S|) time, so the time complexity of finding a substring is 𝑂(|𝑆|log⁡|𝑇|)O(|S|log⁡|T|). Note that if the substring appears multiple times in 𝑇T, each occurrence is adjacent in the 𝑠𝑎sa array. Therefore, the number of occurrences can be found by another binary search, and outputting each occurrence position is also easy.

    Height Array

    LCP (Longest Common Prefix)

    The LCP of two strings 𝑆S and 𝑇T is the largest 𝑥x (𝑥 ≤min(|𝑆|,|𝑇|)x≤min(|S|,|T|)) such that 𝑆𝑖 =𝑇𝑖 (∀ 1 ≤𝑖 ≤𝑥)Si=Ti (∀ 1≤i≤x).

    In the following text, we use 𝑙𝑐𝑝(𝑖,𝑗)lcp(i,j) to denote the longest common prefix (length) of suffix 𝑖i and suffix 𝑗j.

    Definition of Height Array

    ℎ𝑒𝑖𝑔ℎ𝑡[𝑖] =𝑙𝑐𝑝(𝑠𝑎[𝑖],𝑠𝑎[𝑖 −1])height[i]=lcp(sa[i],sa[i−1]), i.e., the longest common prefix between the suffix at rank 𝑖i and the suffix at rank 𝑖 −1i−1.

    ℎ𝑒𝑖𝑔ℎ𝑡[1]height[1] can be considered as 00.

    A Lemma for Computing Height Array in O(n)

    ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖]] ≥ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]] −1height[rk[i]]≥height[rk[i−1]]−1

    Proof

    When ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]] ≤1height[rk[i−1]]≤1, the inequality obviously holds (right side is ≤0≤0).

    When ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]] >1height[rk[i−1]]>1:

    According to the definition of ℎ𝑒𝑖𝑔ℎ𝑡height, we have 𝑙𝑐𝑝(𝑠𝑎[𝑟𝑘[𝑖 −1]],𝑠𝑎[𝑟𝑘[𝑖 −1] −1]) =ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]] >1lcp(sa[rk[i−1]],sa[rk[i−1]−1])=height[rk[i−1]]>1.

    Since suffix 𝑖 −1i−1 and suffix 𝑠𝑎[𝑟𝑘[𝑖 −1] −1]sa[rk[i−1]−1] have a longest common prefix of length ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]]height[rk[i−1]],

    let's denote this longest common prefix as 𝑎𝐴aA (where 𝑎a is a character, and 𝐴A is a non-empty string of length ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]] −1height[rk[i−1]]−1).

    Then suffix 𝑖 −1i−1 can be expressed as 𝑎𝐴𝐷aAD, and suffix 𝑠𝑎[𝑟𝑘[𝑖 −1] −1]sa[rk[i−1]−1] can be expressed as 𝑎𝐴𝐵aAB (𝐵 <𝐷B<D, 𝐵B may be empty, 𝐷D is non-empty).

    Furthermore, suffix 𝑖i can be expressed as 𝐴𝐷AD, and there exists suffix (𝑠𝑎[𝑟𝑘[𝑖 −1] −1] +1sa[rk[i−1]−1]+1) 𝐴𝐵AB.

    Since suffix 𝑠𝑎[𝑟𝑘[𝑖] −1]sa[rk[i]−1] is only one rank below suffix 𝑠𝑎[𝑟𝑘[𝑖]]sa[rk[i]] (i.e., suffix 𝑖i) in the ranking, and 𝐴𝐵 <𝐴𝐷AB<AD.

    Therefore, 𝐴𝐵 ≤AB≤ suffix 𝑠𝑎[𝑟𝑘[𝑖] −1] <𝐴𝐷sa[rk[i]−1]<AD. Obviously, suffix 𝑖i and suffix 𝑠𝑎[𝑟𝑘[𝑖] −1]sa[rk[i]−1] share prefix 𝐴A.

    Thus we can conclude that 𝑙𝑐𝑝(𝑖,𝑠𝑎[𝑟𝑘[𝑖] −1])lcp(i,sa[rk[i]−1]) is at least ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]] −1height[rk[i−1]]−1, i.e., ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖]] ≥ℎ𝑒𝑖𝑔ℎ𝑡[𝑟𝑘[𝑖 −1]] −1height[rk[i]]≥height[rk[i−1]]−1.

    Longest Common Prefix of Two Substrings

    𝑙𝑐𝑝(𝑠𝑎[𝑖],𝑠𝑎[𝑗]) =min{ℎ𝑒𝑖𝑔ℎ𝑡[𝑖 +1..𝑗]}lcp(sa[i],sa[j])=min{height[i+1..j]}

    For a rigorous proof, refer to [2004] Suffix Array by. Xu Zhilei.

    With this theorem, computing the longest common prefix of two substrings reduces to an RMQ Problem.

    Comparing the Size Relationship of Two Substrings of a String

    Assume we need to compare 𝐴 =𝑆[𝑎..𝑏]A=S[a..b] and 𝐵 =𝑆[𝑐..𝑑]B=S[c..d].

    Otherwise, 𝐴 <𝐵 ⟺ 𝑟𝑘[𝑎] <𝑟𝑘[𝑐]A<B⟺rk[a]<rk[c].

    Number of Distinct Substrings

    A substring is a prefix of a suffix. So we can enumerate each suffix, calculate the total number of prefixes, then subtract duplicates.

    The "total number of prefixes" is actually the number of substrings, which is 𝑛(𝑛 +1)/2n(n+1)/2.

    If we enumerate suffixes in the order of sorted suffixes, the new substrings added each time are the prefixes remaining after subtracting the LCP with the previous suffix. These prefixes must be new; otherwise, it would violate the property 𝑙𝑐𝑝(𝑠𝑎[𝑖],𝑠𝑎[𝑗]) =min{ℎ𝑒𝑖𝑔ℎ𝑡[𝑖 +1..𝑗]}lcp(sa[i],sa[j])=min{height[i+1..j]}. Only these prefixes are new because the LCP part was counted when enumerating the previous prefix.

    Therefore, the answer is:

    Whether a Certain String Appears at Least Twice Non-overlappingly in the Text String

    We can binary search the length |𝑠||s| of the target string, divide the ℎh array into several consecutive segments where LCP is greater than or equal to |𝑠||s|. Use RMQ to find the maximum and minimum indices among the numbers appearing in each segment. If the distance between these two indices satisfies the condition, then there must be a string of length |𝑠||s| appearing twice non-overlappingly.

    Consecutive Identical Substrings

    We can enumerate the length |𝑠||s| of the consecutive string, divide the entire string into blocks according to |𝑠||s|, and perform LCP and LCS queries on the block headers of adjacent blocks. For details, see [2009] Suffix Array — A Powerful Tool for String Processing.

    Example problem: 「NOI2016」Excellent Splitting.

    Combined with Disjoint Set Union (DSU)

    Some problems require dividing the suffix array into several consecutive segments where LCP length is greater than or equal to a certain value, i.e., dividing the ℎh array into several consecutive segments where the minimum value is greater than or equal to a certain value, and counting the answer for each segment. If there are multiple queries, we can process them offline. Observe that when the given value decreases monotonically, the number of satisfying intervals always decreases, and new intervals are formed by connecting two or more original intervals. Moreover, in new intervals, the ℎh values of parts not included in the original intervals are all equal to this decreased value. We only need to maintain a DSU, merging adjacent intervals each time and maintaining statistical information.

    Classic problem: 「NOI2015」Banquet

    Combined with Segment Tree

    Some problems ask to find the first several numbers satisfying the condition, and these numbers lie in an interval in the suffix sorting. At this time, we can use the property of merge sort to merge information from two nodes, and use a segment tree to maintain and query interval answers.

  for (i = 1; i <= n; ++i) ++cnt[rk[i] = s[i]];
  for (i = 1; i <= m; ++i) cnt[i] += cnt[i - 1];
  for (i = n; i >= 1; --i) sa[cnt[rk[i]]--] = i;

  for (w = 1; w < n; w <<= 1, m = p) {
    for (p = 0, i = n; i > n - w; --i) id[++p] = i;
    for (i = 1; i <= n; ++i)
      if (sa[i] > w) id[++p] = sa[i] - w;
    memset(cnt, 0, sizeof(cnt));
    for (i = 1; i <= n; ++i) ++cnt[px[i] = rk[id[i]]];
    for (i = 1; i <= m; ++i) cnt[i] += cnt[i - 1];
    for (i = n; i >= 1; --i) sa[cnt[px[i]]--] = id[i];
    memcpy(oldrk, rk, sizeof(rk));
    for (p = 0, i = 1; i <= n; ++i)
      rk[sa[i]] = cmp(sa[i], sa[i - 1], w) ? p : ++p;
  }
  // 求 height
  for (i = 1, k = 0; i <= n; ++i) {
    if (k) --k;
    while (s[i + k] == s[sa[rk[i] - 1] + k]) ++k;
    ht[rk[i]] = k;
  }
  // 维护单调栈
  for (i = 1; i <= n; ++i) {
    while (ht[sta[top]] > ht[i]) --top;  // top类似于一个指针
    l[i] = i - sta[top];
    sta[++top] = i;
  }
  // 最后利用单调栈算 ans
  sta[++top] = n + 1;
  ht[n + 1] = -1;
  for (i = n; i >= 1; --i) {
    while (ht[sta[top]] >= ht[i]) --top;
    ans -= 2ll * ht[i] * l[i] * (sta[top] - i);
    sta[++top] = i;
  }

  cout << ans;

  return 0;
}
