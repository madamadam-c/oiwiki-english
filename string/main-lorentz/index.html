    Main-Lorentz Algorithm

    Tandem Repetitions

    Definition

    Given a string 𝑠s of length 𝑛n.

    We call the new string obtained by writing a string consecutively twice a tandem repetition. In the following text, for precise wording, we call the string being repeated the original string. In other words, a tandem repetition is equivalent to a pair of indices (𝑖,𝑗)(i,j) such that 𝑠[𝑖…𝑗]s[i…j] is formed by concatenating two identical strings.

    Your goal is to find all tandem repetitions in the given string 𝑠s. Or, solve a simpler problem: find any tandem repetition in 𝑠s, or the longest one.

    The algorithm below was proposed by Michael Main and Richard J. Lorentz in 1982.

    Convention

    All string indices in the following text start from 00.

    In the following text, let ――𝑠s― denote the reverse of 𝑠s. For example, ―――𝚊𝚋𝚌 =𝚌𝚋𝚊abc―=cba.

    Explanation

    Consider the string 𝚊𝚌𝚊𝚋𝚊𝚋𝚊𝚎𝚎acababaee, which contains three tandem repetitions:

    • 𝑠[2…5] =𝚊𝚋𝚊𝚋s[2…5]=abab
    • 𝑠[3…6] =𝚋𝚊𝚋𝚊s[3…6]=baba
    • 𝑠[7…8] =𝚎𝚎s[7…8]=ee

    Here is another example, consider the string 𝚊𝚋𝚊𝚊𝚋𝚊abaaba, which has only two tandem repetitions:

    • 𝑠[0…5] =𝚊𝚋𝚊𝚊𝚋𝚊s[0…5]=abaaba
    • 𝑠[2…3] =𝚊𝚊s[2…3]=aa

    Number of Tandem Repetitions

    A string of length 𝑛n can have up to 𝑂(𝑛2)O(n2) tandem repetitions. An obvious example is a string where all 𝑛n characters are the same; in this case, any substring with even length is a tandem repetition. In most cases, a periodic string with a small period will have many tandem repetitions.

    However, this does not prevent us from computing the number of tandem repetitions in 𝑂(𝑛log⁡𝑛)O(nlog⁡n) time. This is because the algorithm represents tandem repetitions in some compressed form, allowing us to compress multiple tandem repetitions into one.

    Here are some interesting facts about the number of tandem repetitions:

    • If the original string of a tandem repetition is not itself a tandem repetition, we call this a primitive repetition. It can be proven that there are at most 𝑂(𝑛log⁡𝑛)O(nlog⁡n) primitive repetitions.
    • If we compress a tandem repetition using a Crochemore triple (𝑖,𝑝,𝑟)(i,p,r), where 𝑖i is the starting position of the tandem repetition, 𝑝p is the length of one period of this repetition (note: not the length of the original string!), and 𝑟r is the number of times this period repeats. Then all tandem repetitions of a string can be represented by 𝑂(𝑛log⁡𝑛)O(nlog⁡n) Crochemore triples.
    • Fibonacci strings are defined as follows:
    𝑡0=𝑎,𝑡1=𝑏,𝑡𝑖=𝑡𝑖−1+𝑡𝑖−2,t0=a,t1=b,ti=ti−1+ti−2,

    It can be observed that Fibonacci strings have high periodicity. For a Fibonacci string 𝑡𝑖ti of length 𝑓𝑖fi, even when compressed with Crochemore triples, there are 𝑂(𝑓𝑖log⁡𝑓𝑖)O(filog⁡fi) triples. The number of primitive repetitions is also 𝑂(𝑓𝑖log⁡𝑓𝑖)O(filog⁡fi).

    Main–Lorentz Algorithm

    Explanation

    The core idea of the Main–Lorentz algorithm is divide and conquer.

    This algorithm divides the string into left and right parts, first computes the number of tandem repetitions that are entirely in the left part (or right part), then computes the number of tandem repetitions that start in the left part and end in the right part. (In the following text, we call such tandem repetitions crossing tandem repetitions)

    Computing the number of crossing tandem repetitions is the key point of the Main–Lorentz algorithm, which we will discuss in detail below.

    Process

    Finding Crossing Tandem Repetitions

    Let the left part of a string be 𝑢u and the right part be 𝑣v. Then 𝑠 =𝑢 +𝑣s=u+v, and the lengths of 𝑢u and 𝑣v are approximately half the length of 𝑠s.

    For any tandem repetition, consider its middle character. Here we call the first character of the right half of a tandem repetition its middle character. In other words, if 𝑠[𝑖...𝑗]s[i...j] is a tandem repetition, then its middle character is 𝑠[(𝑖 +𝑗 +1)/2]s[(i+j+1)/2]. If a tandem repetition's middle character is in 𝑢u, we call it left-biased, otherwise right-biased.

    Next, we will explore how to find all left-biased tandem repetitions.

    Let the length of a left-biased tandem repetition be 2𝑙2l. Consider its first character that falls into 𝑣v (i.e., 𝑠[|𝑢|]s[|u|]), this character must be identical to some character 𝑢[𝑐𝑛𝑡𝑟]u[cntr] in 𝑢u.

    We consider fixing 𝑐𝑛𝑡𝑟cntr and finding all qualifying tandem repetitions. For example: for the string 𝚌 𝚊𝑐𝑛𝑡𝑟 𝚌 | 𝚊 𝚍 𝚊cacntrc|ada (the || is used to distinguish the two parts), fixing 𝑐𝑛𝑡𝑟 =1cntr=1, we can find the tandem repetition 𝚌𝚊𝚌𝚊caca satisfies the condition.

    Obviously, once we fix 𝑐𝑛𝑡𝑟cntr, we also fix the value of 𝑙l. Once we know how to find all tandem repetitions, we can enumerate 𝑐𝑛𝑡𝑟cntr from 00 to |𝑢| −1|u|−1 and find all qualifying tandem repetitions.

    Determining Left-biased Tandem Repetitions

    Even after fixing 𝑐𝑛𝑡𝑟cntr, there may still be multiple qualifying tandem repetitions. How do we find all of them?

    Let's give another example: for the tandem repetition in string 𝚊𝚋𝚌𝚊𝚋𝚌𝚊𝚌abcabcac, 𝑙1⏞𝚊𝑙2⏞𝚋𝑐𝑛𝑡𝑟𝚌𝑙1⏞𝚊 | 𝑙2⏞𝚋𝚌a⏞l1bcntrc⏞l2a⏞l1|bc⏞l2, we denote 𝑙1l1 as the length of the substring from the first character of this tandem repetition to 𝑠[𝑐𝑛𝑡𝑟 −1]s[cntr−1], and 𝑙2l2 as the length of the substring from 𝑠[𝑐𝑛𝑡𝑟]s[cntr] to the last character of the left original string of this tandem repetition.

    Thus, we can give a necessary and sufficient condition for a substring of length 2𝑙 =2(𝑙1 +𝑙2) =2(|𝑢| −𝑐𝑛𝑡𝑟)2l=2(l1+l2)=2(|u|−cntr) to be a tandem repetition:

    Let 𝑘1k1 be the maximum integer satisfying 𝑢[𝑐𝑛𝑡𝑟 −𝑘1…𝑐𝑛𝑡𝑟 −1] =𝑢[|𝑢| −𝑘1…|𝑢| −1]u[cntr−k1…cntr−1]=u[|u|−k1…|u|−1], and let 𝑘2k2 be the maximum integer satisfying 𝑢[𝑐𝑛𝑡𝑟…𝑐𝑛𝑡𝑟 +𝑘2 −1] =𝑣[0…𝑘2 −1]u[cntr…cntr+k2−1]=v[0…k2−1]. Then for any pair (𝑙1,𝑙2)(l1,l2) satisfying 𝑙1 ≤𝑘1l1≤k1 and 𝑙2 ≤𝑘2l2≤k2, we can find exactly one corresponding tandem repetition.

    Summarizing:

    • Fix a 𝑐𝑛𝑡𝑟cntr.
    • Then the length of all tandem repetitions we need to find is 2𝑙 =2(|𝑢| −𝑐𝑛𝑡𝑟)2l=2(|u|−cntr). There may still be multiple qualifying tandem repetitions, depending on the values of 𝑙1l1 and 𝑙2l2.
    • Compute the 𝑘1k1, 𝑘2k2 mentioned above.
    • Then all qualifying tandem repetitions satisfy:
    𝑙1+𝑙2=𝑙=|𝑢|−𝑐𝑛𝑡𝑟𝑙1≤𝑘1,𝑙2≤𝑘2.l1+l2=l=|u|−cntrl1≤k1,l2≤k2.

    Next, we only need to consider how to quickly compute 𝑘1k1 and 𝑘2k2. Using the Z-function, we can compute them in 𝑂(1)O(1):

    • To compute 𝑘1k1: just compute the Z-function of ――𝑢u―.
    • To compute 𝑘2k2: just compute the Z-function of 𝑣 +# +𝑢v+#+u, where ## is a character that does not appear in either 𝑢u or 𝑣v.

    Right-biased Tandem Repetitions

    The method for computing right-biased tandem repetitions is almost the same as for left-biased ones. Consider its first character that falls into 𝑢u (i.e., 𝑠[|𝑢| −1]s[|u|−1]), it must be identical to some character in 𝑣v. Let the position of this character in 𝑣v be 𝑐𝑛𝑡𝑟cntr.

    Let 𝑘1k1 be the maximum integer satisfying 𝑣[𝑐𝑛𝑡𝑟 −𝑘1 +1…𝑐𝑛𝑡𝑟] =𝑢[|𝑢| −𝑘1…|𝑢| −1]v[cntr−k1+1…cntr]=u[|u|−k1…|u|−1], and 𝑘2k2 be the maximum integer satisfying 𝑣[𝑐𝑛𝑡𝑟 +1…𝑐𝑛𝑡𝑟 +𝑘2] =𝑣[0…𝑘2 −1]v[cntr+1…cntr+k2]=v[0…k2−1]. Then we can obtain 𝑘1k1 and 𝑘2k2 by computing the Z-functions of ――𝑢 +# +――𝑣u―+#+v― and 𝑣v respectively.

    Enumerate 𝑐𝑛𝑡𝑟cntr and use a similar method to find right-biased tandem repetitions.

    Implementation

    The Main–Lorentz algorithm outputs all tandem repetitions in the form of quadruples (𝑐𝑛𝑡𝑟,𝑙,𝑘1,𝑘2)(cntr,l,k1,k2). If you only need to count the number of tandem repetitions, or only need to find the longest one, the information provided by these quadruples is sufficient. By the Master Theorem, the time complexity of the Main–Lorentz algorithm is 𝑂(𝑛log⁡𝑛)O(nlog⁡n).

    Note that if you want to find all starting and ending positions of tandem repetitions from these quadruples, the worst-case time complexity will reach 𝑂(𝑛2)O(n2). We have implemented this in the program below, storing all starting and ending positions of tandem repetitions in repetitions.

    vector<int> z_function(string const& s) {
  int n = s.size();
  vector<int> z(n);
  for (int i = 1, l = 0, r = 0; i < n; i++) {
    if (i <= r) z[i] = min(r - i + 1, z[i - l]);
    while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
    if (i + z[i] - 1 > r) {
      l = i;
      r = i + z[i] - 1;
    }
  }
  return z;
}

int get_z(vector<int> const& z, int i) {
  if (0 <= i && i < (int)z.size())
    return z[i];
  else
    return 0;
}

vector<pair<int, int>> repetitions;

void convert_to_repetitions(int shift, bool left, int cntr, int l, int k1,
                            int k2) {
  for (int l1 = max(1, l - k2); l1 <= min(l, k1); l1++) {
    if (left && l1 == l) break;
    int l2 = l - l1;
    int pos = shift + (left ? cntr - l1 : cntr - l - l1 + 1);
    repetitions.emplace_back(pos, pos + 2 * l - 1);
  }
}

void find_repetitions(string s, int shift = 0) {
  int n = s.size();
  if (n == 1) return;

  int nu = n / 2;
  int nv = n - nu;
  string u = s.substr(0, nu);
  string v = s.substr(nu);
  string ru(u.rbegin(), u.rend());
  string rv(v.rbegin(), v.rend());

  find_repetitions(u, shift);
  find_repetitions(v, shift + nu);

  vector<int> z1 = z_function(ru);
  vector<int> z2 = z_function(v + '#' + u);
  vector<int> z3 = z_function(ru + '#' + rv);
  vector<int> z4 = z_function(v);

  for (int cntr = 0; cntr < n; cntr++) {
    int l, k1, k2;
    if (cntr < nu) {
      l = nu - cntr;
      k1 = get_z(z1, nu - cntr);
      k2 = get_z(z2, nv + 1 + cntr);
    } else {
      l = cntr - nu + 1;
      k1 = get_z(z3, nu + 1 + nv - 1 - (cntr - nu));
      k2 = get_z(z4, (cntr - nu) + 1);
    }
    if (k1 + k2 >= l) convert_to_repetitions(shift, cntr < nu, cntr, l, k1, k2);
  }
}
