    Permutations and Combinations

    Introduction

    Permutations and combinations are the foundation of combinatorics. Permutations refer to selecting a certain number of elements from a given number of elements and arranging them; combinations refer to selecting a certain number of elements from a given number of elements without considering the order. The central problem of permutations and combinations is to study the total number of possible permutations and combinations that satisfy given requirements. Permutations and combinations are closely related to classical probability theory.

    In high school elementary mathematics, permutations and combinations are mostly solved using methods such as listing and enumeration.

    Addition & Multiplication Principles

    Addition Principle

    Completing a task can be done in 𝑛n categories of methods, where 𝑎𝑖(1 ≤𝑖 ≤𝑛)ai(1≤i≤n) represents the number of methods in the 𝑖i-th category. Then there are 𝑆 =𝑎1 +𝑎2 +⋯ +𝑎𝑛S=a1+a2+⋯+an different methods to complete the task.

    Multiplication Principle

    Completing a task requires 𝑛n steps, where 𝑎𝑖(1 ≤𝑖 ≤𝑛)ai(1≤i≤n) represents the number of different methods for the 𝑖i-th step. Then there are 𝑆 =𝑎1 ×𝑎2 ×⋯ ×𝑎𝑛S=a1×a2×⋯×an different methods to complete the task.

    Basics of Permutations and Combinations

    Permutation Number

    From 𝑛n different elements, select 𝑚m elements (𝑚 ≤𝑛m≤n, 𝑚m and 𝑛n are natural numbers) and arrange them in a certain order. This is called a permutation of 𝑚m elements from 𝑛n different elements. The number of all such permutations of 𝑚m elements from 𝑛n different elements is called the permutation number, denoted as A𝑚𝑛Anm (or P𝑚𝑛Pnm).

    The formula for permutations is:

    A𝑚𝑛=𝑛(𝑛−1)(𝑛−2)⋯(𝑛−𝑚+1)=𝑛!(𝑛−𝑚)!Anm=n(n−1)(n−2)⋯(n−m+1)=n!(n−m)!

    𝑛!n! represents the factorial of 𝑛n, i.e., 6! =1 ×2 ×3 ×4 ×5 ×66!=1×2×3×4×5×6.

    The formula can be understood as: 𝑛n people, select 𝑚m to form a line (𝑚 ≤𝑛m≤n). The first position can have 𝑛n choices, the second position can have 𝑛 −1n−1 choices, and so on. The 𝑚m-th (last) position can have 𝑛 −𝑚 +1n−m+1 choices. We get:

    A𝑚𝑛=𝑛(𝑛−1)(𝑛−2)⋯(𝑛−𝑚+1)=𝑛!(𝑛−𝑚)!Anm=n(n−1)(n−2)⋯(n−m+1)=n!(n−m)!

    Full permutation: 𝑛n people all form a line of length 𝑛n. The first position can have 𝑛n choices, the second position can have 𝑛 −1n−1 choices, and so on. We get:

    A𝑛𝑛=𝑛(𝑛−1)(𝑛−2)⋯3×2×1=𝑛!Ann=n(n−1)(n−2)⋯3×2×1=n!

    Full permutation is a special case of permutation numbers.

    Combination Number

    From 𝑛n different elements, select 𝑚 ≤𝑛m≤n elements to form a set. This is called a combination of 𝑚m elements from 𝑛n different elements. The number of all such combinations of 𝑚m elements from 𝑛n different elements is called the combination number, denoted as (𝑛𝑚)(nm), read as "𝑛n choose 𝑚m".

    The combination number formula:

    (𝑛𝑚)=A𝑚𝑛𝑚!=𝑛!𝑚!(𝑛−𝑚)!(nm)=Anmm!=n!m!(n−m)!

    How to understand this formula? Consider selecting 𝑚m out of 𝑛n people (𝑚 ≤𝑛m≤n), without lining up, order doesn't matter. If order matters, it's A𝑚𝑛Anm; if order doesn't matter, we need to divide out the duplicates. How many duplicates are there? The 𝑚m selected people also need to be "fully arranged", which takes 𝑚!m!. So we get:

    (𝑛𝑚)×𝑚!=A𝑚𝑛(𝑛𝑚)=A𝑚𝑛𝑚!=𝑛!𝑚!(𝑛−𝑚)!(nm)×m!=Anm(nm)=Anmm!=n!m!(n−m)!

    Combination numbers are also often denoted as C𝑚𝑛Cnm, i.e., C𝑚𝑛 =(𝑛𝑚)Cnm=(nm). The notation (𝑛𝑚)(nm) is now more commonly used in mathematics rather than C𝑚𝑛Cnm.

    Combination numbers are also called "binomial coefficients", and the connection will be explained in the binomial theorem below.

    In particular, when 𝑚 >𝑛m>n, we define A𝑚𝑛 =(𝑛𝑚) =0Anm=(nm)=0.

    Stars and Bars

    Stars and bars (Stars and bars) is a technique used to find the number of ways to divide identical elements into groups, and can also be used to find the number of solutions to a class of linear Diophantine equations.

    Number of Compositions into Positive Integers

    Problem 1: We have 𝑛n completely identical elements. We need to divide them into 𝑘k groups, ensuring each group has at least one element. How many ways are there?

    Consider using 𝑘 −1k−1 boards to insert into the 𝑛 −1n−1 gaps formed by the 𝑛n elements.

    Since the elements are identical, the answer is (𝑛−1𝑘−1)(n−1k−1).

    The essence is finding the number of positive integer solutions to 𝑥1 +𝑥2 +⋯ +𝑥𝑘 =𝑛x1+x2+⋯+xk=n.

    Number of Compositions into Non-negative Integers

    Problem 2: What if each group is allowed to be empty?

    Obviously, we can't directly use stars and bars at this point, because it's possible that many boards are inserted into the same gap, which is very difficult to calculate.

    We consider creating conditions to transform it into the restricted Problem 1. First borrow 𝑘k elements. With 𝑛 +𝑘n+k elements, insert boards into the 𝑛 +𝑘 −1n+k−1 gaps. The answer is:

    (𝑛+𝑘−1𝑘−1)=(𝑛+𝑘−1𝑛)(n+k−1k−1)=(n+k−1n)

    Although this is not directly the original problem, this formula is the answer to the original problem. This can be understood as:

    Initially, we borrowed 𝑘k elements to ensure each group has at least one element. After inserting the boards, we remove these 𝑘k borrowed elements from the 𝑘k groups. Since the elements are identical, the transformed case and the case before transformation can be one-to-one correspond, so the answers are equal.

    From this, we can derive the formula for stars and bars: (𝑛+𝑘−1𝑛)(n+k−1n).

    The essence is finding the number of non-negative integer solutions to 𝑥1 +𝑥2 +⋯ +𝑥𝑘 =𝑛x1+x2+⋯+xk=n (i.e., requiring 𝑥𝑖 ≥0xi≥0).

    Number of Compositions with Different Lower Bounds

    Problem 3: If we go one step further, requiring that group 𝑖i receives at least 𝑎𝑖ai elements, where ∑𝑎𝑖 ≤𝑛∑ai≤n?

    The essence is finding the number of solutions to 𝑥1 +𝑥2 +⋯ +𝑥𝑘 =𝑛x1+x2+⋯+xk=n where 𝑥𝑖 ≥𝑎𝑖xi≥ai.

    By analogy with the unrestricted case, we borrow ∑𝑎𝑖∑ai elements to ensure group 𝑖i can receive at least 𝑎𝑖ai elements. That is, let:

    𝑥′𝑖=𝑥𝑖−𝑎𝑖xi′=xi−ai

    We get the new equation:

    (𝑥′1+𝑎1)+(𝑥′2+𝑎2)+⋯+(𝑥′𝑘+𝑎𝑘)=𝑛𝑥′1+𝑥′2+⋯+𝑥′𝑘=𝑛−𝑎1−𝑎2−⋯−𝑎𝑘𝑥′1+𝑥′2+⋯+𝑥′𝑘=𝑛−∑𝑎𝑖(x1′+a1)+(x2′+a2)+⋯+(xk′+ak)=nx1′+x2′+⋯+xk′=n−a1−a2−⋯−akx1′+x2′+⋯+xk′=n−∑ai

    where

    𝑥′𝑖≥0xi′≥0

    Then Problem 3 transforms into Problem 2. Using the stars and bars formula, the answer is:

    (𝑛−∑𝑎𝑖+𝑘−1𝑛−∑𝑎𝑖)(n−∑ai+k−1n−∑ai)

    Non-adjacent Permutations

    Among the 𝑛n natural numbers 1 ∼𝑛1∼n, select 𝑘k numbers such that no two selected numbers are adjacent. There are (𝑛−𝑘+1𝑘)(n−k+1k) ways.

    Binomial Theorem

    Before entering the advanced topics of permutations and combinations, we introduce a theorem closely related to combination numbers—the binomial theorem.

    The binomial theorem states the coefficients of an expansion:

    (𝑎+𝑏)𝑛=𝑛∑𝑖=0(𝑛𝑖)𝑎𝑛−𝑖𝑏𝑖(a+b)n=∑i=0n(ni)an−ibi

    The proof can be done using mathematical induction, using (𝑛𝑘) +(𝑛𝑘−1) =(𝑛+1𝑘)(nk)+(nk−1)=(n+1k) for induction.

    The binomial theorem can be easily extended to the multinomial form:

    Let 𝑛n be a positive integer, 𝑥𝑖xi be real numbers:

    (𝑥1+𝑥2+⋯+𝑥𝑡)𝑛=∑non-negative integer solutions 𝑛1+⋯+𝑛𝑡=𝑛(𝑛𝑛1,𝑛2,⋯,𝑛𝑡)𝑥𝑛11𝑥𝑛22⋯𝑥𝑛𝑡𝑡(x1+x2+⋯+xt)n=∑non-negative integer solutions n1+⋯+nt=n(nn1,n2,⋯,nt)x1n1x2n2⋯xtnt

    Here, (𝑛𝑛1,𝑛2,⋯,𝑛𝑡)(nn1,n2,⋯,nt) is the multinomial coefficient, which has similar properties:

    ∑(𝑛𝑛1,𝑛2,⋯,𝑛𝑡)=𝑡𝑛∑(nn1,n2,⋯,nt)=tn

    Advanced Permutations and Combinations

    Now we introduce some variants of permutations and combinations.

    Permutation Number of Multisets | Multiset Coefficient

    Be sure to distinguish multiset coefficient from permutation number of multisets! They are completely different concepts!

    A multiset is a generalized set containing repeated elements. Let 𝑆 ={𝑛1 ⋅𝑎1,𝑛2 ⋅𝑎2,⋯,𝑛𝑘 ⋅𝑎𝑘}S={n1⋅a1,n2⋅a2,⋯,nk⋅ak} represent a multiset consisting of 𝑛1n1 copies of 𝑎1a1, 𝑛2n2 copies of 𝑎2a2, ..., 𝑛𝑘nk copies of 𝑎𝑘ak. The number of all permutations of 𝑆S is:

    𝑛!∏𝑘𝑖=1𝑛𝑖!=𝑛!𝑛1!𝑛2!⋯𝑛𝑘!n!∏i=1kni!=n!n1!n2!⋯nk!

    This is equivalent to dividing out the permutations of identical elements. Specifically, you can think of having 𝑘k different types of balls, with each type having 𝑛1,𝑛2,⋯,𝑛𝑘n1,n2,⋯,nk balls respectively, and 𝑛 =𝑛1 +𝑛2 +… +𝑛𝑘n=n1+n2+…+nk. The number of all permutations of these 𝑛n balls is the permutation number of multisets. It is often called the multiset coefficient.
