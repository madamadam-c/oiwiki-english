    Polya Counting

    Introduction

    The Pólya enumeration theorem is typically used to solve counting problems involving "essentially different" configurations.

    This article may involve related content from group theory

    This article may involve content from group theory. This article will provide simple explanations of the relevant group theory concepts to help readers unfamiliar with this content understand and apply the Pólya enumeration theorem. For rigorous definitions and discussions of group theory, please refer to chapters such as Basic Concepts of Abstract Algebra and Group Theory.

    "Space Symmetry Group", "Symmetric Group", and "Permutation Group"

    This article will inevitably use these three types of group names simultaneously. Although this may easily cause confusion, they indeed refer to different concepts. Given a geometric structure, a symmetry operation on it refers to a geometric transformation that makes it coincide with itself, and the space symmetry group is the set of all such symmetry operations. The symmetric group is the set of all permutations on a given set. A permutation group is a subgroup of the symmetric group, i.e., a group formed by some (not necessarily all) permutations. Later, we will explain how to represent the space symmetry group of a given geometric structure as a permutation group for counting problems.

    Burnside's Lemma

    Further reading: Burnside's Lemma

    The Pólya enumeration theorem is an application and generalization of Burnside's lemma. Before introducing the Pólya enumeration theorem, we need to briefly review Burnside's lemma.

    To derive the general pattern, let's first consider a simple example.

    Necklace Coloring

    Consider a necklace with 4 beads, where each bead can be colored either red or blue. How many essentially different colorings are there? (If two colorings can be made identical by rotating the necklace, they are considered the same.)

    Solution and Analysis

    This problem is simple enough to be solved by enumeration. There are 4 beads, each with 2 possible colors, so there are 24 =1624=16 possible colorings in total. Grouping those that can be transformed into each other by rotation yields 6 groups, as shown in the figure. (Here, each coloring is encoded by the colors of beads starting from the bottom-left bead and going clockwise; B represents blue, R represents red; colorings in the same group have the same background color.)

    From this example, we can see that to calculate the number of essentially different colorings, the key is to know how many different colorings correspond to each essentially identical coloring. In other words, we need to determine the size of each group in the figure above.

    Colorings that can be grouped together are those that can be transformed into each other by rotation. There are 4 possible rotations, namely

    𝐺={𝑟0,𝑟1,𝑟2,𝑟3},G={r0,r1,r2,r3},

    representing rotations by 0, 1, 2, and 3 positions respectively. Rotation by 0 positions means staying in place.

    First, consider the group containing the coloring 𝑅𝑅𝐵𝐵RRBB. Applying these four operations yields

    𝑅𝑅𝐵𝐵,𝑅𝐵𝐵𝑅,𝐵𝐵𝑅𝑅,𝐵𝑅𝑅𝐵.RRBB,RBBR,BBRR,BRRB.

    These four colorings are all different, so this group has 4 elements.

    Now consider the group containing the coloring 𝐵𝑅𝐵𝑅BRBR. Applying these four operations yields

    𝐵𝑅𝐵𝑅,𝑅𝐵𝑅𝐵,𝐵𝑅𝐵𝑅,𝑅𝐵𝑅𝐵.BRBR,RBRB,BRBR,RBRB.

    Here, the result of rotation by 2 positions is the same as no rotation, and the result of rotation by 3 positions is the same as rotation by 1 position. So this group has 2 elements.

    If we look at the groups containing 𝐵𝐵𝐵𝐵BBBB and 𝑅𝑅𝑅𝑅RRRR, applying the four operations yields only themselves. Therefore, each group has only 1 element.

    Let 𝑥x represent a coloring, and 𝐺𝑥Gx represent the set of color encodings obtainable by applying operations to 𝑥x. From the above example, we can summarize a pattern: the effect of operations in 𝐺G on 𝑥x exhibits some kind of "periodicity".

    Let |𝐺||G| represent the total number of operations. This "periodicity" means that if there are 𝑚m different operations in 𝐺G that map 𝑥x to itself, then the results of 𝑥x under these operations will repeat 𝑚m times. Therefore, under these operations, there are |𝐺|/𝑚|G|/m different results for 𝑥x, which is exactly the size of the group containing 𝑥x.

    In this example, only rotation by 0 positions (𝑟0r0) can map 𝑅𝑅𝐵𝐵RRBB to itself, so its group size is 4/1 =44/1=4. Both rotation by 0 positions (𝑟0r0) and rotation by 2 positions (𝑟2r2) can map 𝐵𝑅𝐵𝑅BRBR to itself, so its group size is 4/2 =24/2=2. No matter how many positions we rotate, 𝐵𝐵𝐵𝐵BBBB maps to itself, so its group size is 4/4 =14/4=1.

    In the following, let 𝐺𝑥Gx represent the number of operations that map 𝑥x to itself, so |𝐺𝑥||Gx| is 𝑚m from above. Then the group size of 𝑋X is |𝐺|/|𝐺𝑥||G|/|Gx|. To calculate the number of groups of colorings, we only need to enumerate all possible colorings 𝑥 ∈𝑋x∈X, and for colorings with group size |𝐺𝑥||Gx|, assign weight 1/|𝐺𝑥|1/|Gx|. This allows us to express the number of groups as

    |𝑋/𝐺|=∑𝑥∈𝑋1|𝐺𝑥|=∑𝑥∈𝑋|𝐺𝑥||𝐺|.|X/G|=∑x∈X1|Gx|=∑x∈X|Gx||G|.

    The current form of this formula is not convenient for application. Let 𝑔𝑥gx be the result of applying operation 𝑔 ∈𝐺g∈G to the coloring 𝑥 ∈𝑋x∈X. Then the set 𝐺𝑥Gx described above is {𝑔 ∈𝐺 :𝑔𝑥 =𝑥}{g∈G:gx=x}. Changing the order of summation gives

    ∑𝑥∈𝑋|𝐺𝑥|=∑𝑥∈𝑋|{𝑔∈𝐺:𝑔𝑥=𝑥}|=∑𝑥∈𝑋∑𝑔∈𝐺[𝑔𝑥=𝑥]=∑𝑔∈𝐺∑𝑥∈𝑋[𝑔𝑥=𝑥]=∑𝑔∈𝐺|{𝑥∈𝑋:𝑔𝑥=𝑥}|=∑𝑔∈𝐺|𝑋𝑔|.∑x∈X|Gx|=∑x∈X|{g∈G:gx=x}|=∑x∈X∑g∈G[gx=x]=∑g∈G∑x∈X[gx=x]=∑g∈G|{x∈X:gx=x}|=∑g∈G|Xg|.

    Here, [ ⋅][⋅] is the Iverson bracket. In the result after changing the order of summation, 𝑋𝑔 ={𝑥 ∈𝑋 :𝑔𝑥 =𝑥}Xg={x∈X:gx=x} is the set of colorings 𝑥x that remain unchanged under operation 𝑔g. In other words, it consists of the fixed points of operation 𝑔g.

    After these discussions, the number of groups can now be written as

    |𝑋/𝐺|=1|𝐺|∑𝑔∈𝐺|𝑋𝑔|.|X/G|=1|G|∑g∈G|Xg|.

    That is, the number of groups equals the average number of fixed points of all rotation operations.

    As an application of this result, let's recalculate the number of essentially different colorings for the necklace. The fixed points of these rotation operations are listed below.

    OperationFixed Points
    𝑟0r0𝑋X
    𝑟1r1{𝐵𝐵𝐵𝐵,𝑅𝑅𝑅𝑅}{BBBB,RRRR}
    𝑟2r2{𝐵𝐵𝐵𝐵,𝐵𝑅𝐵𝑅,𝑅𝐵𝑅𝐵,𝑅𝑅𝑅𝑅}{BBBB,BRBR,RBRB,RRRR}
    𝑟3r3{𝐵𝐵𝐵𝐵,𝑅𝑅𝑅𝑅}{BBBB,RRRR}

    Therefore, the number of groups equals

    16+2+4+24=6.16+2+4+24=6.

    This matches our earlier result.

    From this example, we can derive a general result for solving such counting problems. For the sake of discussion, we consider the scenario of coloring problems in this article, though it can also be applied to other scenarios, with examples provided at the end.

    A coloring problem is: given some structure, coloring each of its vertices yields different coloring schemes. This structure has some symmetry such that seemingly different colorings can be transformed into each other through a series of symmetry operations. These mutually transformable colorings are called essentially identical. The problem asks for the number of essentially different colorings.

    Based on the analysis in the example, to solve this problem, we first need to determine what symmetry operations the given structure has. The set of these symmetry operations 𝐺G is called the space symmetry group of the given structure. In practical applications, most of the time we don't need to understand the definition of groups; we only need to be able to discuss all space symmetry operations without omission. Later in this article, we analyze several common space symmetry group structures, where the definition of groups is explained.

    The set of all colorings is denoted 𝑋X, and an individual coloring is denoted 𝑥x. The result of applying operation 𝑔 ∈𝐺g∈G to coloring 𝑥 ∈𝑋x∈X is 𝑔𝑥gx. Then all results obtainable by applying some operation to coloring 𝑥x is 𝐺𝑥 ={𝑔𝑥 :𝑔 ∈𝐺}Gx={gx:g∈G}, which is called the orbit of 𝑥x under group 𝐺G. Different colorings in the same orbit are what this problem calls "essentially identical". Therefore, the number of essentially different colorings is equivalent to the number of distinct orbits.

    The analysis in the example can be generalized to general cases.

    Burnside's Lemma

    Given a group 𝐺G acting on a set 𝑋X, the number of distinct orbits is

    |𝑋/𝐺|=1|𝐺|∑𝑔∈𝐺|𝑋𝑔|.|X/G|=1|G|∑g∈G|Xg|.

    Here, 𝑋𝑔 ={𝑥 ∈𝑋 :𝑔𝑥 =𝑥}Xg={x∈X:gx=x} is the set of fixed points under the action of 𝑔 ∈𝐺g∈G.

    The proof is essentially a direct application of the analysis in the example above. However, the example used an observation: the results of the action of group 𝐺G on a single element 𝑥x have some kind of "periodicity", so the number of such period repetitions equals the number of operations that map 𝑥x to itself. This observation is correct in general cases, but because the structure of group 𝐺G may be complex, its "periodicity" may not be as straightforward as in the example. To state this observation rigorously, we need to use the orbit-stabilizer theorem from group theory.

    In applications, as long as we can enumerate all symmetry operations and provide the number of fixed points for each symmetry operation, we can solve the corresponding counting problem. Below is a slightly more complex application.

    Cube Coloring

    Color a cube using three colors. How many essentially different colorings are there? (Two colorings that become the same after spatial rotation are considered the same.)

    Solution

    Since the cube has 6 faces, each with 3 coloring methods, there are 3636 possible colorings in total, i.e., |𝑋| =36|X|=36. Let the space symmetry group of the cube be 𝐺G.

    Next, we need to analyze all operations in 𝐺G. They can be divided into the following categories (for convenience, we call the six faces: front, back, top, bottom, left, right):

    • Identity: since all direct coloring schemes remain unchanged under the identity transformation, it has |𝑋𝑔| =36|Xg|=36;
    • 90∘90∘ rotation about the axis through the centers of two opposite faces: there are 3 choices for the pair of opposite faces, and 2 choices for rotation direction, so there are 6 permutations in total. If we choose the axis through the centers of the front and back faces, then to remain unchanged after rotation, the top, bottom, left, and right faces must all have the same color. At this point, there are 3 independently colorable regions, so |𝑋𝑔| =33|Xg|=33;
    • 180∘180∘ rotation about the axis through the centers of two opposite faces: there are 3 choices for the pair of opposite faces, and the rotation direction doesn't matter, so there are 3 permutations in total. If we choose the axis through the centers of the front and back faces, then to remain unchanged after rotation, the top and bottom faces must have the same color, and the left and right faces must have the same color. At this point, there are 4 independently colorable regions, so |𝑋𝑔| =34|Xg|=34;
    • 180∘180∘ rotation about the axis through the midpoints of two opposite edges: there are 6 choices for the pair of opposite edges, and the rotation direction still doesn't matter, so there are 6 permutations in total. If we choose the edge between the front and top faces and the edge between the back and bottom faces as the pair of opposite edges, then to remain unchanged after rotation, the front and top faces must have the same color, the back and bottom faces must have the same color, and the left and right faces must have the same color. At this point, there are 3 independently colorable regions, so |𝑋𝑔| =33|Xg|=33;

    Pólya Enumeration Theorem

    In the statement of Burnside's lemma, the property that 𝑋X is the set of all colorings of some structure is not used. Actually, the application scope of Burnside's lemma is not limited to coloring counting problems. For coloring counting problems, the Pólya enumeration theorem provides a more precise calculation method. It can be seen as the application of the general Burnside's lemma to coloring counting problems.

    Compared to Burnside's lemma, the improvement of the Pólya enumeration theorem is that it provides a specific calculation method for the size of the fixed point set |𝑋𝑔||Xg| in coloring counting problems.

    This can be intuitively seen from the cube coloring example above. For various symmetry operations of the cube, the size of the fixed point set is always in the form 𝑚𝑐(𝑔)mc(g), where 𝑚m is the number of colors, and 𝑐(𝑔)c(g) is the number of independently colorable regions under operation 𝑔g. This observation also holds in general cases, but we need to further clarify how to calculate 𝑐(𝑔)c(g) for a given 𝑔g.

    Choosing a coloring scheme for a structure, mathematically, means choosing a mapping 𝑓 :𝑋 →𝐶f:X→C from the set of colorable objects of this structure (such as beads in a necklace, faces of a cube, etc.) 𝑋X to the set of colors 𝐶C. Therefore, the set of coloring schemes is 𝐶𝑋CX. The space symmetry group 𝐺G of the structure acts on the structure, and naturally also acts on the set 𝑋X. This symmetry operation always corresponds to a bijection on set 𝑋X, i.e., a permutation.

    Now let's analyze the structure of the fixed point set (𝐶𝑋)𝑔(CX)g. Given 𝑔g, treated as a permutation on 𝑋X, following the analysis in the example, if a position 𝑥x in 𝑋X can move to position 𝑦y after finitely many repeated applications of 𝑔g, then as a fixed point 𝑓 ∈(𝐶𝑋)𝑔f∈(CX)g, it must satisfy 𝑓(𝑥) =𝑓(𝑦)f(x)=f(y). In the language of orbits from the previous section, since positions 𝑥x and 𝑦y are in the same orbit under the action of 𝑔g, they must be colored the same. In the language of permutations, in the cycle decomposition of 𝑔g, positions 𝑥x and 𝑦y are in the same cycle, so they need to be colored the same. Different cycles in the cycle decomposition can be colored differently and independently, so the number of independently colorable regions is 𝑐(𝑔)c(g), i.e., the number of cycles in the cycle decomposition of 𝑔g.

    Thus, the number of fixed points of operation 𝑔g is |𝐶|𝑐(𝑔)|C|c(g). Substituting this into Burnside's lemma gives the unweighted version of the Pólya enumeration theorem.

    Pólya Enumeration Theorem (Unweighted Version)

    Given a group 𝐺G acting on a set 𝑋X and a set of colors 𝐶C, the number of distinct colorings is

    |𝐶𝑋/𝐺|=1|𝐺|∑𝑔∈𝐺𝑚𝑐(𝑔),|CX/G|=1|G|∑g∈Gmc(g),

    where 𝑚m is the number of colors, and 𝑐(𝑔)c(g) is the number of cycles in the cycle decomposition of the permutation representation of 𝑔 ∈𝐺g∈G.

    About the meaning of group 𝐺G

    There is some abuse of notation here. If group 𝐺G acts on 𝑋X, then the group action on the coloring scheme set 𝐶𝑋CX needs to be redefined, which is not distinguished here.

    Weighted Version Extension

    The unweighted version of the Pólya enumeration theorem can only give the count of all essentially different coloring problems, but it cannot handle more refined problems. For example, if in the above coloring problem, we are given the number of each color that can be used, we cannot directly apply the Pólya enumeration formula above. To actually solve such problems, we need to derive again using Burnside's lemma; and summarizing these results in the form of generating functions gives the weighted version of the Pólya enumeration theorem.

    Necklace Coloring (with Restrictions)

    Consider a necklace with 4 beads, each bead can be either red or blue. We have exactly 2 red beads and 2 blue beads available. How many essentially different colorings are there? (If two colorings can be made identical by rotating the necklace, they are considered the same.)

    Solution and Analysis

    Consider using Burnside's lemma. There are 2 red beads and 2 blue beads, totaling (42) =6(42)=6 coloring schemes. The space symmetry group 𝐺 ={𝑟0,𝑟1,𝑟2,𝑟3}G={r0,r1,r2,r3} corresponds to rotations 0~3 respectively. Their fixed point sets are analyzed as follows:

    • Rotation by 0 positions 𝑟0 =(1)r0=(1), all 6 coloring schemes are fixed points;
    • Rotation by 1 position 𝑟1 =(1234)r1=(1234), fixed points require all beads to have the same color, so there are no fixed points;
    • Rotation by 2 positions 𝑟2 =(13)(24)r2=(13)(24), there are 2 independently colorable regions, each of size 2. They need to be colored with one red and one blue respectively, so the fixed point set has size 2;
    • Rotation by 3 positions 𝑟3 =(1432)r3=(1432), same as rotation by 1 position, there are no fixed points.

    Therefore, according to Burnside's lemma, the number of essentially different colorings is

    6+0+2+04=2.6+0+2+04=2.

    From this example, we can derive the following calculation method. For problems with restrictions on the number of different colors, we also need to color the cycles of each permutation in the space symmetry group, but we need to ensure that the number of colors used exactly equals the given number of colors. Such combinatorial problems usually don't have explicit solutions. Except for special cases that can be calculated using combinatorics methods, they need to be treated as knapsack problems.

    This counting problem can be answered using generating functions. Given a permutation 𝑔g, if its type is 1𝛼12𝛼2⋯𝑛𝛼𝑛1α12α2⋯nαn, i.e., it has 𝛼𝑘αk cycles of length 𝑘k, and for each cycle, it can be colored with one of 𝑚m colors, then in the generating function

    𝑛∏𝑘=1(𝑚∑𝑖=1𝑥𝑘𝑖)𝛼𝑘,∏k=1n(∑i=1mxik)αk,

    the coefficient of the monomial 𝑥𝛽11𝑥𝛽22⋯𝑥𝛽𝑚𝑚x1β1x2β2⋯xmβm is the count where color 𝑖i is used 𝛽𝑖βi times. The expression in parentheses, ∑𝑚𝑖=1𝑥𝑘𝑖∑i=1mxik, has the combinatorial meaning: for a cycle of length 𝑘k, if color 𝑖i is used 𝑘k times, the counting method is 1; for other cases, the count is 0; this precisely describes the requirement that positions in the same cycle have consistent coloring.

    Applying Burnside's lemma to each monomial in the generating function for counting colorings under a given permutation gives the essentially different counts for various color combinations. Since the generating function is linear for each monomial, the generating function for the count of essentially different coloring schemes is

    1|𝐺|∑𝑔∈𝐺𝑛∏𝑘=1(𝑚∑𝑖=1𝑥𝑘𝑖)𝛼𝑘.1|G|∑g∈G∏k=1n(∑i=1mxik)αk.

    Expanding this expression, the coefficient of each monomial gives the count of essentially different colorings for the given color combination.

    In the above process, the generating function ∑𝑚𝑖=1𝑥𝑘𝑖∑i=1mxik for coloring each cycle has nothing special and can be replaced by other generating functions. Therefore, there is a general version of the Pólya enumeration theorem.

    Cycle Index of a Permutation Group

    Given a permutation group 𝐺G, the cycle index of group 𝐺G, denoted 𝑍𝐺(𝑡1,𝑡2,⋯,𝑡𝑛)ZG(t1,t2,⋯,tn), is defined as

    Pólya Enumeration Theorem (Weighted Version)

    Applications

    The weighted version of the Pólya enumeration theorem plays an important role in combinatorial counting problems. Here we briefly discuss its applications, and for more general discussions, refer to Formal Methods for Combinatorial Problems.

    Common Space Symmetry Groups

    One of the difficulties in problems related to Pólya enumeration is analyzing the structure of permutation groups. Here, we briefly discuss the structures of common space symmetry groups and describe them using their cycle indices. It should be noted that for the same structure's space symmetry group, if the set of objects being acted upon is different, the corresponding group action is also different, and thus their permutation representations are different. For example, the space symmetry group of a cube acting on its vertices, edges, and faces respectively correspond to the vertex permutation group, edge permutation group, and face permutation group of the cube. The numbers of vertices, edges, and faces are different, so these permutation groups and their corresponding cycle indices are naturally different. Therefore, in solving specific problems, we cannot ignore the specification of the object of the group action.

    Relationship between Space Symmetry Groups and Permutation Groups

    Although the two concepts are very similar, they are not the same object. In the language of group theory, given a space symmetry group 𝐺G and its action on a set 𝑋X, the permutation representation of the group action provides a homomorphism 𝜑φ from group 𝐺G to the symmetric group 𝑆𝑋SX. Moreover, this permutation representation is often faithful in the context of combinatorial counting, i.e., ker⁡𝜑 ={𝑒}ker⁡φ={e}, so homomorphism 𝜑φ is actually an embedding of group 𝐺G into group 𝑆𝑋SX. The permutation group in the text is precisely the image of this embedding, i.e., 𝜑(𝐺)φ(G), which is isomorphic to the original space symmetry group 𝐺G. Therefore, for the same structure's space symmetry group 𝐺G, different choices of group action will be isomorphic to different permutation groups 𝜑(𝐺)φ(G), and consequently have different cycle indices (isomorphic permutation groups do not necessarily have the same cycle indices).

    Given a structure, its space symmetry group is the set of all operations that can map it to itself. It must satisfy the following conditions:

    • Applying two symmetry operations in succession to a given structure can be regarded as applying another symmetry operation, i.e., the set of symmetry operations is closed under composition;
    • The composition of symmetry operations satisfies the associative law;
    • There exists an identity symmetry operation, i.e., the given structure remaining unchanged itself is also considered an operation;
    • Every operation has its inverse operation, which can undo the effect of the given operation.

    A group is an abstraction of all concepts satisfying these conditions. The discussion of group structures is the main content of group theory. Our analysis here focuses on space symmetry groups, and the discussion of their structures mainly uses geometric perspectives. Here we provide common examples, and readers should derive common approaches to analyzing such problems from these.

    Cyclic Group

    For a regular 𝑛n-gon, all its rotation operations form a space symmetry group called the cyclic group, denoted 𝐶𝑛Cn. Let the counterclockwise rotation by (360/𝑛)∘(360/n)∘ be denoted as 𝑟r, then the elements of group 𝐶𝑛Cn can be written as

    𝐶𝑛={𝑒,𝑟,𝑟2,⋯,𝑟𝑛−1}.Cn={e,r,r2,⋯,rn−1}.

    Here, 𝑟𝑘rk refers to applying operation 𝑟r 𝑘k times, i.e., counterclockwise rotation by (360𝑘/𝑛)∘(360k/n)∘, and 𝑒 =𝑟0e=r0 refers to the identity transformation.

    Whether considering the action of the cyclic group on all vertices or all edges of a regular 𝑛n-gon, its permutation representation is the same. Let's analyze the permutation representation of the group action by taking the set of all vertices as an example. Its cycle index is

    𝑍(𝐶𝑛)=1𝑛∑𝑑∣𝑛𝜑(𝑑)𝑡𝑛/𝑑𝑑.Z(Cn)=1n∑d∣nφ(d)tdn/d.

    Here, 𝜑( ⋅)φ(⋅) is the Euler's totient function from number theory.

    Considering only rotation operations, the space symmetry group of a necklace of length 𝑛n is 𝐶𝑛Cn.

    Analysis

    Let the set of vertices be labeled in counterclockwise order as {0,1,⋯,𝑛 −1}{0,1,⋯,n−1}, then 𝑟𝑘(𝑖) =𝑖 +𝑘(mod𝑛)rk(i)=i+k(modn). The set of vertices in the cycle containing vertex 𝑖i is

    {𝑖+ℓ𝑘(mod𝑛):ℓ∈𝐙}.{i+ℓk(modn):ℓ∈Z}.

    Obviously, 𝑖 ≡𝑖 +ℓ𝑘(mod𝑛)i≡i+ℓk(modn) if and only if

    𝑛gcd(𝑘,𝑛)∣ℓ.ngcd(k,n)∣ℓ.

    This means that any vertex 𝑖i lies in a cycle of length 𝑛gcd(𝑘,𝑛)ngcd(k,n). Therefore, permutation 𝑟𝑘rk has gcd(𝑘,𝑛)gcd(k,n) cycles of equal length. Considering merging like terms in the expression of the cycle index, for a given 𝑑 ∣𝑛d∣n, there are 𝜑(𝑑)φ(d) values of 𝑘k satisfying gcd(𝑘,𝑛) =𝑛/𝑑gcd(k,n)=n/d, and their corresponding monomials are all of the form 𝑡𝑛/𝑑𝑑tdn/d. From this, we can derive the above cycle index expression.

    Dihedral Group

    For a regular 𝑛n-gon, all its rotation operations and reflections about symmetry axes also form a space symmetry group, called the dihedral group, denoted 𝐷2𝑛D2n. Let the counterclockwise rotation by (360/𝑛)∘(360/n)∘ be denoted as 𝑟r, and let the reflection about a given symmetry axis (such as the line through the center and a vertex) be denoted as 𝑠s. Then the operations of group 𝐷2𝑛D2n can be written as

    𝐷2𝑛={𝑒,𝑟,⋯,𝑟𝑛−1,𝑠,𝑠𝑟,⋯,𝑠𝑟𝑛−1}.D2n={e,r,⋯,rn−1,s,sr,⋯,srn−1}.

    Here, 𝑟𝑘rk is still a rotation operation, and although 𝑠𝑟𝑘srk means first rotating 𝑘k times and then reflecting about the given symmetry axis, it can equivalently be regarded as reflecting about another symmetry axis. Therefore, group 𝐷2𝑛D2n contains 1 identity transformation, (𝑛 −1)(n−1) rotation operations, and 𝑛n reflection operations. Its group actions on the vertex set and edge set also have the same permutation representation. Its cycle index is

    𝑍(𝐷2𝑛)=12𝑍(𝐶𝑛)+{12𝑡1𝑡𝑘2,𝑛=2𝑘+1,14(𝑡21𝑡𝑘−12+𝑡𝑘2),𝑛=2𝑘.Z(D2n)=12Z(Cn)+{12t1t2k,n=2k+1,14(t12t2k−1+t2k),n=2k.
    Analysis

    The analysis of rotation operations 𝑟𝑘rk in group 𝐷2𝑛D2n (including the identity transformation) is exactly the same as that for cyclic group 𝐶𝑛Cn. The key lies in the analysis of reflection operations. At this point, we need to classify according to the parity of the number of vertices 𝑛n.

    When 𝑛 =2𝑘 +1n=2k+1, all reflection axes are lines connecting a vertex to the midpoint of the opposite edge, totaling 𝑛n such axes. After each reflection, the vertex on the axis remains fixed, while other vertices are swapped in pairs. Therefore, there is 1 fixed point (1-cycle) and 𝑘k 2-cycles.

    When 𝑛 =2𝑘n=2k, there are two types of symmetry axes. Half of them are axes connecting opposite vertices; reflecting about such an axis keeps the two vertices on the axis fixed while swapping the remaining vertices in pairs, so there are 2 fixed points (1-cycles) and (𝑘 −1)(k−1) 2-cycles. The other half are axes connecting the midpoints of opposite edges; reflecting about such an axis swaps all vertices in pairs, so there are 𝑘k 2-cycles.

    Based on this analysis, we can write the above cycle index expression.

    Symmetric Group

    For a set of 𝑛n elements, all permutations on it form a group, called the symmetric group of degree 𝑛n, denoted 𝑆𝑛Sn. It describes all the symmetry these 𝑛n vertices can have. It is also the permutation representation of these symmetry operations acting on the vertex set.

    𝑍(𝑆𝑛)=∑𝛼1+2𝛼2+⋯+𝑛𝛼𝑛=𝑛𝑡𝛼11𝑡𝛼22⋯𝑡𝛼𝑛𝑛1𝛼12𝛼2⋯𝑛𝛼𝑛𝛼1!𝛼2!⋯𝛼𝑛!.Z(Sn)=∑α1+2α2+⋯+nαn=nt1α1t2α2⋯tnαn1α12α2⋯nαnα1!α2!⋯αn!.

    Here, the number of permutations with type 1𝛼12𝛼2⋯𝑛𝛼𝑛1α12α2⋯nαn is

    𝑛!1𝛼12𝛼2⋯𝑛𝛼𝑛𝛼1!𝛼2!⋯𝛼𝑛!.n!1α12α2⋯nαnα1!α2!⋯αn!.

    It satisfies the recurrence relation

    𝑍(𝑆𝑛)=1𝑛𝑛∑𝑘=1𝑡𝑘𝑍(𝑆𝑛−𝑘),Z(Sn)=1n∑k=1ntkZ(Sn−k),

    with initial condition 𝑍(𝑆0) =1Z(S0)=1. The combinatorial meaning of this recurrence relation is: to construct a permutation of length 𝑛n, first choose the length 𝑘k of the cycle containing point 𝑛n, then construct the set of remaining (𝑛 −𝑘)(n−k) vertices.

    Given a complete graph with 𝑛n vertices, its space symmetry group is exactly 𝑆𝑛Sn. The cycle index of its action on the set of all vertices is given by 𝑍(𝑆𝑛)Z(Sn) above. However, its permutation representation on the set of all edges is not the same. For example, the size of the set is different; the number of edges is 𝑛(𝑛 −1)/2n(n−1)/2. For the case of edges, additional analysis is needed. Here we give a simple example; for general cases, refer to the exercises.

    Undirected Simple Graph Counting

    Count the number of undirected simple graphs with 4 vertices up to isomorphism.

    Solution

    This is equivalent to coloring the complete graph with 4 vertices with two colors, requiring the number of essentially different colorings. The space symmetry group is 𝑆4S4. Now let's analyze the cycle index of its edge permutation group 𝑆(2)4S4(2).

    • Identity transformation (1 type): edges also remain fixed, so the corresponding monomial is 𝑡61t16;
    • Swapping two vertices (6 types): suppose we swap 𝑎a and 𝑏b, then edges 1 and 3 remain fixed, while edges 2 and 5 swap, and edges 4 and 6 swap, so the corresponding monomial is 6𝑡21𝑡226t12t22;

    Polyhedral Groups

    A polyhedral group is the space symmetry group of a regular polyhedron. There are only five regular polyhedra: regular tetrahedron, cube, regular octahedron, regular dodecahedron, and regular icosahedron. If we keep the adjacency relations between vertices, edges, and faces but swap vertices and faces, we obtain the dual regular polyhedron. The regular tetrahedron is self-dual, the cube and octahedron are dual to each other, and the dodecahedron and icosahedron are dual to each other. Using the dual relationship, we can simplify the discussion of their space symmetry groups.

    Considering only rotation operations in three-dimensional space, there are only three types of space symmetry groups.

    • Tetrahedral group, i.e., the space symmetry group of the regular tetrahedron:

      • Identity transformation;
      • Rotation by 120∘120∘ and 240∘240∘ about the axis through a vertex and the center of the opposite face;
      • Rotation by 180∘180∘ about the axis through the midpoints of opposite edges.

      There are 1 +2 ×4 +1 ×3 =121+2×4+1×3=12 symmetry operations in total.

      The cycle indices of the corresponding permutation groups are as follows.

      • Vertex permutation group and face permutation group: 112(𝑡41 +8𝑡1𝑡3 +3𝑡22)112(t14+8t1t3+3t22);
      • Edge permutation group: 112(𝑡61 +8𝑡23 +3𝑡21𝑡22)112(t16+8t32+3t12t22).

    • Octahedral group, i.e., the space symmetry group of the cube (and regular octahedron):

      • Identity transformation;
      • Rotation by 120∘120∘ and 240∘240∘ about the axis through opposite vertices;
      • Rotation by 180∘180∘ about the axis through the midpoints of opposite edges;
      • Rotation by 90∘90∘, 180∘180∘, and 270∘270∘ about the axis through the centers of opposite faces.

      There are 1 +2 ×4 +1 ×6 +3 ×3 =241+2×4+1×6+3×3=24 symmetry operations in total.

      The cycle indices of the corresponding cube's permutation groups are as follows.

      • Vertex permutation group: 124(𝑡81 +8𝑡21𝑡23 +9𝑡42 +6𝑡24)124(t18+8t12t32+9t24+6t42);
      • Edge permutation group: 124(𝑡121 +8𝑡43 +6𝑡21𝑡52 +6𝑡34 +3𝑡62)124(t112+8t34+6t12t25+6t43+3t26);
      • Face permutation group: 124(𝑡61 +8𝑡23 +6𝑡32 +6𝑡21𝑡4 +3𝑡21𝑡22)124(t16+8t32+6t23+6t12t4+3t12t22).

      The permutation group of the regular octahedron is similar, just swapping the roles of vertices and faces.

    • Icosahedral group, i.e., the space symmetry group of the regular dodecahedron (and regular icosahedron):

      • Identity transformation;
      • Rotation by 120∘120∘ and 240∘240∘ about the axis through opposite vertices;
      • Rotation by 180∘180∘ about the axis through the midpoints of opposite edges;
      • Rotation by 72∘72∘, 144∘144∘, 216∘216∘, and 288∘288∘ about the axis through the centers of opposite faces.

      There are 1 +2 ×10 +1 ×15 +6 ×4 =601+2×10+1×15+6×4=60 symmetry operations in total.

      The cycle indices of the corresponding regular dodecahedron's permutation groups are as follows.

      • Vertex permutation group: 160(𝑡201 +20𝑡21𝑡63 +15𝑡102 +24𝑡45)160(t120+20t12t36+15t210+24t54);
      • Edge permutation group: 160(𝑡301 +20𝑡103 +15𝑡21𝑡142 +24𝑡65)160(t130+20t310+15t12t214+24t56);
      • Face permutation group: 160(𝑡121 +20𝑡43 +15𝑡62 +24𝑡21𝑡25)160(t112+20t34+15t26+24t12t52).

      The permutation group of the regular icosahedron is similar, just swapping the roles of vertices and faces.

    All of these are cycle indices of permutation groups acting separately on objects like vertices, edges, and faces. If we need to color different objects simultaneously, we need to write a combined cycle index.
