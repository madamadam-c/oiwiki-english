    Inclusion-Exclusion Principle

    Introduction

    Introductory Example

    Suppose there are 10 students who like math, 15 students who like Chinese, and 21 students who like programming in a class. How many students like at least one subject?

    Is it 10 +15 +21 =4610+15+21=46 students? No, because some students may like both math and Chinese, or both Chinese and programming, or even all three.

    For convenience, let's denote the sets of students who like Chinese, math, and programming as 𝐴,𝐵,𝐶A,B,C respectively. Then the total number of students equals |𝐴 ∪𝐵 ∪𝐶||A∪B∪C|. As explained, if we directly add the sizes of these three sets |𝐴|,|𝐵|,|𝐶||A|,|B|,|C|, some elements will be counted multiple times, so we need to subtract |𝐴 ∩𝐵|,|𝐵 ∩𝐶|,|𝐶 ∩𝐴||A∩B|,|B∩C|,|C∩A|, but then we will have subtracted a small part too much, so we need to add back |𝐴 ∩𝐵 ∩𝐶||A∩B∩C|. That is:

    |𝐴∪𝐵∪𝐶|=|𝐴|+|𝐵|+|𝐶|−|𝐴∩𝐵|−|𝐵∩𝐶|−|𝐶∩𝐴|+|𝐴∩𝐵∩𝐶||A∪B∪C|=|A|+|B|+|C|−|A∩B|−|B∩C|−|C∩A|+|A∩B∩C|

    Generalizing the above problem to a general case is what we know as the inclusion-exclusion principle.

    Definition

    Let there be 𝑛n different properties for elements in universal set 𝑈U, and the 𝑖i-th property is called 𝑃𝑖Pi. Elements having property 𝑃𝑖Pi form set 𝑆𝑖Si. Then:

    ∣𝑛⋃𝑖=1𝑆𝑖∣=∑𝑖|𝑆𝑖|−∑𝑖<𝑗|𝑆𝑖∩𝑆𝑗|+∑𝑖<𝑗<𝑘|𝑆𝑖∩𝑆𝑗∩𝑆𝑘|−⋯+(−1)𝑚−1∑𝑎𝑖<𝑎𝑖+1∣𝑚⋂𝑖=1𝑆𝑎𝑖∣+⋯+(−1)𝑛−1|𝑆1∩⋯∩𝑆𝑛||⋃i=1nSi|=∑i|Si|−∑i<j|Si∩Sj|+∑i<j<k|Si∩Sj∩Sk|−⋯+(−1)m−1∑ai<ai+1|⋂i=1mSai|+⋯+(−1)n−1|S1∩⋯∩Sn|

    That is:

    ∣𝑛⋃𝑖=1𝑆𝑖∣=𝑛∑𝑚=1(−1)𝑚−1∑𝑎𝑖<𝑎𝑖+1∣𝑚⋂𝑖=1𝑆𝑎𝑖∣|⋃i=1nSi|=∑m=1n(−1)m−1∑ai<ai+1|⋂i=1mSai|

    Proof

    Use the binomial theorem to calculate the number of occurrences for each element. For element 𝑥x, suppose it appears in sets 𝑇1,𝑇2,⋯,𝑇𝑚T1,T2,⋯,Tm. Then its number of occurrences is:

    𝐶𝑛𝑡=|{𝑇𝑖}|−|{𝑇𝑖∩𝑇𝑗|𝑖<𝑗}|+⋯+(−1)𝑘−1∣{𝑘⋂𝑖=1𝑇𝑎𝑖|𝑎𝑖<𝑎𝑖+1}∣+⋯+(−1)𝑚−1|{𝑇1∩⋯∩𝑇𝑚}|=(𝑚1)−(𝑚2)+⋯+(−1)𝑚−1(𝑚𝑚)=(𝑚0)−𝑚∑𝑖=0(−1)𝑖(𝑚𝑖)=1−(1−1)𝑚=1Cnt=|{Ti}|−|{Ti∩Tj|i<j}|+⋯+(−1)k−1|{⋂i=1kTai|ai<ai+1}|+⋯+(−1)m−1|{T1∩⋯∩Tm}|=(m1)−(m2)+⋯+(−1)m−1(mm)=(m0)−∑i=0m(−1)i(mi)=1−(1−1)m=1

    Since each element appears exactly once, combining them gives the union. Q.E.D.

    Complement

    For the union of sets under universal set 𝑈U, we can use the inclusion-exclusion principle, and for the intersection of sets, we find it by subtracting the union of complements:

    ∣𝑛⋂𝑖=1𝑆𝑖∣=|𝑈|−∣𝑛⋃𝑖=1――𝑆𝑖∣|⋂i=1nSi|=|U|−|⋃i=1nSi―|

    The right side uses inclusion-exclusion.

    Readers familiar with inclusion-exclusion will know the above, but what they care more about is the application of inclusion-exclusion.

    So next, we provide 3 example problems at different levels to demonstrate the application of the inclusion-exclusion principle.

    Counting Non-negative Integer Solutions of Diophantine Equations

    Counting non-negative integer solutions of Diophantine equations

    Given a Diophantine equation ∑𝑛𝑖=1𝑥𝑖 =𝑚∑i=1nxi=m and 𝑛n constraints 𝑥𝑖 ≤𝑏𝑖xi≤bi, where 𝑚,𝑏𝑖 ∈ℕm,bi∈N. Find the number of non-negative integer solutions.

    Without constraints

    If there are no constraints 𝑥𝑖 ≤𝑏𝑖xi≤bi, the number of non-negative integer solutions to ∑𝑛𝑖=1𝑥𝑖 =𝑚∑i=1nxi=m is (𝑚+𝑛−1𝑛−1)(m+n−1n−1).

    Brief proof: Stars and bars.

    This is equivalent to distributing 𝑚m balls into 𝑛n boxes, where some boxes may be empty. This problem cannot be directly solved using binomial coefficients.

    So we add 𝑛 −1n−1 more balls. The problem becomes: in a sequence of 𝑚 +𝑛 −1m+n−1 balls, choose 𝑛 −1n−1 balls, and these 𝑛 −1n−1 balls separate the sequence into 𝑛n parts, which can correspond to 𝑛n boxes. The number of ways to choose 𝑛 −1n−1 balls from 𝑚 +𝑛 −1m+n−1 balls is (𝑚+𝑛−1𝑛−1)(m+n−1n−1).

    Inclusion-exclusion model

    Now we try to abstract the model of the inclusion-exclusion principle:

    1. Universal set 𝑈U: Non-negative integer solutions to ∑𝑛𝑖=1𝑥𝑖 =𝑚∑i=1nxi=m
    2. Elements: Variables 𝑥𝑖xi
    3. Properties: The condition that 𝑥𝑖xi satisfies, i.e., the condition 𝑥𝑖 ≤𝑏𝑖xi≤bi

    Goal: The size of the set when all variables satisfy their corresponding properties, i.e., |⋂𝑛𝑖=1𝑆𝑖||⋂i=1nSi|.

    This can be solved using |⋂𝑛𝑖=1𝑆𝑖| =|𝑈| −∣⋃𝑛𝑖=1――𝑆𝑖∣|⋂i=1nSi|=|U|−|⋃i=1nSi―|. |𝑈||U| can be calculated using binomial coefficients, and the latter part naturally uses inclusion-exclusion.

    So the problem becomes, for some ―――𝑆𝑎𝑖Sai― intersections, find the size. Consider the meaning of ―――𝑆𝑎𝑖Sai―, which represents the number of solutions where 𝑥𝑎𝑖 ≥𝑏𝑎𝑖 +1xai≥bai+1. The intersection represents simultaneously satisfying these conditions. So in this intersection's Diophantine equation, some variables have lower bound constraints, while some have no constraints.

    Can we eliminate these lower bound constraints? Since we need non-negative integer solutions, and some variables have lower bounds greater than 0, we can directly subtract this lower bound to make the lower bound of these variables become 0, i.e., no lower bound. Therefore, for:

    ∣1≤𝑖≤𝑘⋂𝑎𝑖<𝑎𝑖+1𝑆𝑎𝑖∣|⋂ai<ai+11≤i≤kSai|

    the Diophantine equation form is:

    𝑛∑𝑖=1𝑥𝑖=𝑚−𝑘∑𝑖=1(𝑏𝑎𝑖+1)∑i=1nxi=m−∑i=1k(bai+1)

    This can also be calculated using binomial coefficients. This array of length 𝑘k, 𝑎a, is equivalent to enumerating subsets.

    HAOI2008 Coin Shopping

    HAOI2008 Coin Shopping

    There are 4 types of coins, with the 𝑖i-th type having value 𝐶𝑖Ci. There are 𝑛n queries, each query gives the quantity 𝐷𝑖Di of each type of coin and a price 𝑆S. Find the number of payment methods.

    𝑛 ≤103,𝑆 ≤105n≤103,S≤105.

    If we use knapsack, the complexity is 𝑂(4𝑛𝑆)O(4nS), which is unbearable. The most obvious characteristic of this problem is that there are only 4 types of coins. Abstract the model, which is essentially to find the number of non-negative integer solutions to ∑4𝑖=1𝐶𝑖𝑥𝑖 =𝑆,𝑥𝑖 ≤𝐷𝑖∑i=14Cixi=S,xi≤Di.

    Using the same inclusion-exclusion method, the property of 𝑥𝑖xi is 𝑥𝑖 ≤𝐷𝑖xi≤Di. Applying the inclusion-exclusion formula, finally we need to solve:

    4∑𝑖=1𝐶𝑖𝑥𝑖=𝑆−𝑘∑𝑖=1𝐶𝑎𝑖(𝐷𝑎𝑖+1)∑i=14Cixi=S−∑i=1kCai(Dai+1)

    That is an unbounded knapsack problem. This can be preprocessed, and including the queries, the total complexity is 𝑂(4𝑆 +24𝑛)O(4S+24n).

    #include <iostream>
using namespace std;
constexpr long long S = 1e5 + 5;
long long c[5], d[5], n, s;
long long f[S];

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> c[1] >> c[2] >> c[3] >> c[4] >> n;
  f[0] = 1;
  for (long long j = 1; j <= 4; j++)
    for (long long i = 1; i < S; i++)
      if (i >= c[j]) f[i] += f[i - c[j]];  // f[i]: number of coin combinations with price i
  for (long long k = 1; k <= n; k++) {
    cin >> d[1] >> d[2] >> d[3] >> d[4] >> s;
    long long ans = 0;
    for (long long i = 1; i < 16;
         i++) {  // Inclusion-exclusion over 4 item types, so loop from 1 to 2^4-1=15
      long long m = s, bit = 0;
      for (long long j = 1; j <= 4; j++) {
        if ((i >> (j - 1)) % 2 == 1) {
          m -= (d[j] + 1) * c[j];
          bit++;
        }
      }
      if (m >= 0) ans += (bit % 2 * 2 - 1) * f[m];
    }
    cout << f[s] - ans << '\n';
  }

    Complete Graph Subgraph Coloring Problem

    The previous three problems are forward applications of the inclusion-exclusion principle. This problem requires reverse analysis using the inclusion-exclusion principle.

    Complete graph subgraph coloring problem

    A and B like to color graphs (not necessarily connected), with the rule that adjacent nodes must be colored with the same color. Today A and B play a game. For an 𝑛n-order complete graph 𝐺 =(𝑉,𝐸)G=(V,E). They define an evaluation function 𝐹(𝑆)F(S), where 𝑆S is an edge set, 𝑆 ⊆𝐸S⊆E. The value of 𝐹(𝑆)F(S) is the total number of colorings of graph 𝐺′ =(𝑉,𝑆)G′=(V,S) using 𝑚m colors. Their another rule is that if |𝑆||S| is odd, then A's score increases by 𝐹(𝑆)F(S), otherwise B's score increases by 𝐹(𝑆)F(S). Find the difference in scores between A and B.

    Mathematical form

    The trend of this problem is not obvious, so for a tricky problem, first abstract the mathematical form. The score difference is the parity symmetric difference, which can use −1−1 raised to a power as the coefficient. We are looking for:

    𝐴𝑛𝑠=∑𝑆⊆𝐸(−1)|𝑆|−1𝐹(𝑆)Ans=∑S⊆E(−1)|S|−1F(S)

    Inclusion-exclusion model

    We take "adjacent nodes must be colored with the same color" as the property. Here we first don't follow the coloring rules, and directly color the graph using 𝑚m colors. For graph 𝐺′ =(𝑉,𝑆)G′=(V,S), we treat it as elements. The property 𝑥𝑖 =𝑥𝑗xi=xj means nodes 𝑖,𝑗i,j have the same color (note: we don't require 𝑖,𝑗i,j to have an edge between them).

    And the set corresponding to property 𝑥𝑖 =𝑥𝑗xi=xj is defined as 𝑄𝑖,𝑗Qi,j, which means the number of coloring schemes of graph 𝐺′G′ satisfying this property. The elements in the set are essentially colored graphs of graph 𝐺′G′ satisfying this property.

    Back to the problem, "adjacent nodes must be colored with the same color" can be understood as the intersection of several 𝑄Q sets. So we can write:

    𝐹(𝑆)=∣⋂(𝑖,𝑗)∈𝑆𝑄𝑖,𝑗∣F(S)=|⋂(i,j)∈SQi,j|

    Doesn't it smell like inclusion-exclusion? Since the inclusion-exclusion principle doesn't have a form for pairs, we map all edges (𝑖,𝑗)(i,j) to 𝑇 =𝑛(𝑛+1)2T=n(n+1)2 integers, assuming (𝑖,𝑗)(i,j) is mapped to 𝑘,1 ≤𝑘 ≤𝑇k,1≤k≤T, and 𝑄𝑖,𝑗Qi,j is mapped to 𝑄𝑘Qk.     And 𝐸E corresponds to set 𝑀 ={1,2,⋯,𝑛(𝑛+1)2}M={1,2,⋯,n(n+1)2}. So:

    𝐹(𝑆)⟺𝐹({𝑘𝑖})=∣⋂𝑘𝑖𝑄𝑘𝑖∣F(S)⟺F({ki})=|⋂kiQki|

    Reverse analysis

    Then expand the required formula:

    𝐴𝑛𝑠=∑𝐾⊆𝑀(−1)|𝐾|−1∣⋂𝑘𝑖∈𝐾𝑄𝑘𝑖∣=∑𝑖|𝑄𝑖|−∑𝑖<𝑗|𝑄𝑖∩𝑄𝑗|+∑𝑖<𝑗<𝑘|𝑄𝑖∩𝑄𝑗∩𝑄𝑘|−⋯+(−1)𝑇−1∣𝑇⋂𝑖=1𝑄𝑖∣Ans=∑K⊆M(−1)|K|−1|⋂ki∈KQki|=∑i|Qi|−∑i<j|Qi∩Qj|+∑i<j<k|Qi∩Qj∩Qk|−⋯+(−1)T−1|⋂i=1TQi|

    𝐴𝑛𝑠=∣𝑇⋃𝑖=1𝑄𝑖∣Ans=|⋃i=1TQi|

    Now consider the meaning of the right side: as long as any condition from 1 ∼𝑇1∼T is satisfied, i.e., there exists a pair of nodes with the same color (not necessarily adjacent).
