    Du Jiao Sieve

    Du's Sieve is used to handle prefix sum problems of arithmetic functions. For an arithmetic function 𝑓f, Du's Sieve can compute 𝑆(𝑛) =∑𝑛𝑖=1𝑓(𝑖)S(n)=∑i=1nf(i) with a time complexity better than linear.

    Algorithm Idea

    We try to construct a recurrence formula for 𝑆(𝑛)S(n) in terms of 𝑆(⌊𝑛𝑖⌋)S(⌊ni⌋).

    For any arithmetic function 𝑔g:

    𝑛∑𝑖=1(𝑓∗𝑔)(𝑖)=𝑛∑𝑖=1∑𝑑∣𝑖𝑔(𝑑)𝑓(𝑖𝑑)=𝑛∑𝑖=1𝑔(𝑖)𝑆(⌊𝑛𝑖⌋)∑i=1n(f∗g)(i)=∑i=1n∑d∣ig(d)f(id)=∑i=1ng(i)S(⌊ni⌋)

    Where 𝑓 ∗𝑔f∗g is the Dirichlet convolution of arithmetic functions 𝑓f and 𝑔g.

    Brief Proof

    𝑔(𝑑)𝑓(𝑖𝑑)g(d)f(id) contributes to all 𝑖 ≤𝑛i≤n. So change the order of summation, let 𝑑d, 𝑖𝑑id be the new 𝑖,𝑗i,j:

    𝑛∑𝑖=1∑𝑑∣𝑖𝑔(𝑑)𝑓(𝑖𝑑)=𝑛∑𝑖=1⌊𝑛/𝑖⌋∑𝑗=1𝑔(𝑖)𝑓(𝑗)=𝑛∑𝑖=1𝑔(𝑖)⌊𝑛/𝑖⌋∑𝑗=1𝑓(𝑗)=𝑛∑𝑖=1𝑔(𝑖)𝑆(⌊𝑛𝑖⌋)∑i=1n∑d∣ig(d)f(id)=∑i=1n∑j=1⌊n/i⌋g(i)f(j)=∑i=1ng(i)∑j=1⌊n/i⌋f(j)=∑i=1ng(i)S(⌊ni⌋)

    Then we can get the recurrence formula:

    𝑔(1)𝑆(𝑛)=𝑛∑𝑖=1𝑔(𝑖)𝑆(⌊𝑛𝑖⌋)−𝑛∑𝑖=2𝑔(𝑖)𝑆(⌊𝑛𝑖⌋)=𝑛∑𝑖=1(𝑓∗𝑔)(𝑖)−𝑛∑𝑖=2𝑔(𝑖)𝑆(⌊𝑛𝑖⌋)g(1)S(n)=∑i=1ng(i)S(⌊ni⌋)−∑i=2ng(i)S(⌊ni⌋)=∑i=1n(f∗g)(i)−∑i=2ng(i)S(⌊ni⌋)

    If we can construct an appropriate arithmetic function 𝑔g such that:

    1. ∑𝑛𝑖=1(𝑓 ∗𝑔)(𝑖)∑i=1n(f∗g)(i) can be computed quickly;
    2. The prefix sum of 𝑔g can be computed quickly, so that ∑𝑛𝑖=2𝑔(𝑖)𝑆(⌊𝑛𝑖⌋)∑i=2ng(i)S(⌊ni⌋) can be solved by number theoretic division.

    Then we can compute 𝑔(1)𝑆(𝑛)g(1)S(n) in a relatively short time.

    Note

    Regardless of whether the arithmetic function 𝑓f is a multiplicative function, as long as an appropriate arithmetic function 𝑔g can be constructed, Du's Sieve can be used to compute the prefix sum of 𝑓f.

    For example, considering 𝑓(𝑛) =i𝜑(𝑛)f(n)=iφ(n), obviously 𝑓f is not a multiplicative function, but we can take 𝑔(𝑛) =1g(n)=1, thus:

    𝑛∑𝑘=1(𝑓∗𝑔)(𝑘)=i𝑛(𝑛+1)2∑k=1n(f∗g)(k)=in(n+1)2

    The time complexity of computing ∑𝑘≤𝑚(𝑓 ∗𝑔)(𝑘)∑k≤m(f∗g)(k) and ∑𝑘≤𝑚𝑔(𝑘)∑k≤mg(k) are both 𝑂(1)O(1), so Du's Sieve can be considered.

    Time Complexity

    Let 𝑅(𝑛) ={⌊𝑛𝑘⌋:𝑘=2,3,…,𝑛}R(n)={⌊nk⌋:k=2,3,…,n}. Using the property of number theoretic division, for any 𝑚 ∈𝑅(𝑛)m∈R(n), we have 𝑅(𝑚) ⊆𝑅(𝑛)R(m)⊆R(n). That is, after using memoization, we only need to compute 𝑆(𝑘)S(k) once for all 𝑘 ∈𝑅(𝑛)k∈R(n) to get the values of 𝑅(𝑛)R(n). The number of these points is |𝑅(𝑛)| =𝑂(√𝑛)|R(n)|=O(n).

    Let the time complexity of computing ∑𝑛𝑖=1(𝑓 ∗𝑔)(𝑖)∑i=1n(f∗g)(i) and ∑𝑛𝑖=1𝑔(𝑖)∑i=1ng(i) be both 𝑂(1)O(1). Let the time complexity of computing 𝑆(𝑛)S(n) be 𝑇(𝑛)T(n). Then:

    𝑇(𝑛)=∑𝑘∈𝑅(𝑛)𝑇(𝑘)=Θ(√𝑛)+⌊√𝑛⌋∑𝑘=1𝑂(√𝑘)+⌊√𝑛⌋∑𝑘=2𝑂(√𝑛𝑘)=𝑂(∫√𝑛0(√𝑥+√𝑛𝑥)d𝑥)=𝑂(𝑛3/4).T(n)=∑k∈R(n)T(k)=Θ(n)+∑k=1⌊n⌋O(k)+∑k=2⌊n⌋O(nk)=O(∫0n(x+nx)dx)=O(n3/4).

    If we can precompute some of 𝑆(𝑘)S(k) for 𝑘 =1,2,…,𝑚k=1,2,…,m, where 𝑚 ≥⌊√𝑛⌋m≥⌊n⌋. Let the preprocessing time complexity be 𝑇0(𝑚)T0(m). Then 𝑇(𝑛)T(n) at this time is:

    𝑇(𝑛)=𝑇0(𝑚)+∑𝑘∈𝑅(𝑛);𝑘>𝑚𝑇(𝑘)=𝑇0(𝑚)+⌊𝑛/𝑚⌋∑𝑘=1𝑂(√𝑛𝑘)=𝑂(𝑇0(𝑚)+∫𝑛/𝑚0√𝑛𝑥d𝑥)=𝑂(𝑇0(𝑚)+𝑛√𝑚).T(n)=T0(m)+∑k∈R(n);k>mT(k)=T0(m)+∑k=1⌊n/m⌋O(nk)=O(T0(m)+∫0n/mnxdx)=O(T0(m)+nm).

    If 𝑇0(𝑚) =𝑂(𝑚)T0(m)=O(m) (such as linear sieve), by the AM-GM inequality: when 𝑚 =Θ(𝑛2/3)m=Θ(n2/3), 𝑇(𝑛)T(n) attains its minimum value 𝑂(𝑛2/3)O(n2/3).

    A False Proof Example

    Let the complexity of computing 𝑆(𝑛)S(n) be 𝑇(𝑛)T(n). Then:

    𝑇(𝑛)=Θ(√𝑛)+𝑂⎛⎜ ⎜⎝⌊√𝑛⌋∑𝑖=2𝑇(⌊𝑛𝑖⌋)⎞⎟ ⎟⎠T(n)=Θ(n)+O(∑i=2⌊n⌋T(⌊ni⌋)) 𝑇(⌊𝑛𝑖⌋)=Θ(√𝑛𝑖)+𝑂⎛⎜ ⎜ ⎜⎝⌊√𝑛/𝑖⌋∑𝑗=2𝑇(⌊𝑛𝑖𝑗⌋)⎞⎟ ⎟ ⎟⎠=𝑂(√𝑛𝑖)T(⌊ni⌋)=Θ(ni)+O(∑j=2⌊n/i⌋T(⌊nij⌋))=O(ni)

    Here, 𝑂(∑⌊√𝑛/𝑖⌋𝑗=2𝑇(⌊𝑛𝑖𝑗⌋))O(∑j=2⌊n/i⌋T(⌊nij⌋)) is treated as higher-order infinitesimal, so it can be discarded. Therefore:

    𝑇(𝑛)=Θ(√𝑛)+𝑂⎛⎜ ⎜⎝⌊√𝑛⌋∑𝑖=2√𝑛𝑖⎞⎟ ⎟⎠=𝑂⎛⎜ ⎜⎝⌊√𝑛⌋∑𝑖=1√𝑛𝑖⎞⎟ ⎟⎠=𝑂(∫√𝑛0√𝑛𝑥d𝑥)=𝑂(𝑛3/4)T(n)=Θ(n)+O(∑i=2⌊n⌋ni)=O(∑i=1⌊n⌋ni)=O(∫0nnxdx)=O(n3/4)
    Bug

    The problem is in "treating as higher-order infinitesimal and discarding". We substitute 𝑇(⌊𝑛𝑖⌋)T(⌊ni⌋) into the formula for 𝑇(𝑛)T(n):

    #include <cstring>
#include <iostream>
#include <map>
using namespace std;
constexpr int MAXN = 2000010;
long long T, n, pri[MAXN], cur, mu[MAXN], sum_mu[MAXN];
bool vis[MAXN];
map<long long, long long> mp_mu;

long long S_mu(long long x) {  // Compute the prefix sum of mu
  if (x < MAXN) return sum_mu[x];
  if (mp_mu[x]) return mp_mu[x];  // Return directly if this mu value already exists in the map
  long long ret = (long long)1;
  for (long long i = 2, j; i <= x; i = j + 1) {
    j = x / (x / i);
    ret -= S_mu(x / i) * (j - i + 1);
  }
  return mp_mu[x] = ret;  // Path compression for the next computation
}

long long S_phi(long long x) {  // Compute the prefix sum of phi
  long long ret = (long long)0;
  long long j;
  for (long long i = 1; i <= x; i = j + 1) {
    j = x / (x / i);
    ret += (S_mu(j) - S_mu(i - 1)) * (x / i) * (x / i);
  }
  return (ret - 1) / 2 + 1;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> T;
  mu[1] = 1;
  for (int i = 2; i < MAXN; i++) {  // Linear sieve to preprocess the mu array
    if (!vis[i]) {
      pri[++cur] = i;
      mu[i] = -1;
    }
    for (int j = 1; j <= cur && i * pri[j] < MAXN; j++) {
      vis[i * pri[j]] = true;
      if (i % pri[j])
        mu[i * pri[j]] = -mu[i];
      else {
        mu[i * pri[j]] = 0;
        break;
      }
    }
  }
  for (int i = 1; i < MAXN; i++)
    sum_mu[i] = sum_mu[i - 1] + mu[i];  // Compute prefix sums of the mu array
  while (T--) {
    cin >> n;
    cout << S_phi(n) << ' ' << S_mu(n) << '\n';
  }
  return 0;
}

    // Do not shrink the arrays just to save memory; that gets stuck at 80 points.
#include <cmath>
#include <iostream>
#include <map>
using namespace std;
constexpr int N = 5e6, NP = 5e6, SZ = N;
long long n, P, inv2, inv6, s[N];
int phi[N], p[NP], cnt, pn;
bool bp[N];
map<long long, long long> s_map;

long long ksm(long long a, long long m) {  // Used to compute inverses
  long long res = 1;
  while (m) {
    if (m & 1) res = res * a % P;
    a = a * a % P, m >>= 1;
  }
  return res;
}

void prime_work(int k) {  // Linear sieve for phi and s
  bp[0] = bp[1] = true, phi[1] = 1;
  for (int i = 2; i <= k; i++) {
    if (!bp[i]) p[++cnt] = i, phi[i] = i - 1;
    for (int j = 1; j <= cnt && i * p[j] <= k; j++) {
      bp[i * p[j]] = true;
      if (i % p[j] == 0) {
        phi[i * p[j]] = phi[i] * p[j];
        break;
      } else
        phi[i * p[j]] = phi[i] * phi[p[j]];
    }
  }
  for (int i = 1; i <= k; i++)
    s[i] = (1ll * i * i % P * phi[i] % P + s[i - 1]) % P;
}

long long s3(long long k) {  // Sum of cubes
  return k %= P, (k * (k + 1) / 2) % P * ((k * (k + 1) / 2) % P) % P;
}

long long s2(long long k) {  // Sum of squares
  return k %= P, k * (k + 1) % P * (k * 2 + 1) % P * inv6 % P;
}

long long calc(long long k) {  // Compute S(k)
  if (k <= pn) return s[k];
  if (s_map[k]) return s_map[k];  // Use map-based sparse storage for values over pn
  long long res = s3(k), pre = 1, cur;
  for (long long i = 2, j; i <= k; i = j + 1)
    j = k / (k / i), cur = s2(j),
    res = (res - calc(k / i) * (cur - pre) % P) % P, pre = cur;
  return s_map[k] = (res + P) % P;
}

long long solve() {
  long long res = 0, pre = 0, cur;
  for (long long i = 1, j; i <= n; i = j + 1) {
    j = n / (n / i);
    cur = calc(j);
    res = (res + (s3(n / i) * (cur - pre)) % P) % P;
    pre = cur;
  }
  return (res + P) % P;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> P >> n;
  inv2 = ksm(2, P - 2), inv6 = ksm(6, P - 2);
  pn = (long long)pow(n, 0.666667);  // n^(2/3)
  prime_work(pn);
  cout << solve();
  return 0;
}
