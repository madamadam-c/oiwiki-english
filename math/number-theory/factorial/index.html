    Factorials Modulo a Number

    Introduction

    This article discusses relevant conclusions about factorial computation under a certain modulus, and provides a method whose time complexity is linearly related to the size of the modulus. Therefore, this method is primarily applicable when the modulus is not too large (∼106∼106). Besides the methods introduced in this article, according to different scenarios, polynomial techniques can also be applied for fast computation.

    According to the Chinese Remainder Theorem, the factorial modulo problem can be transformed into the case where the modulus is a prime power 𝑝𝛼pα. When handling such problems, we often extract all factors 𝑝p from the factorial 𝑛!n! to obtain the decomposition:

    𝑛!=𝑝𝜈𝑝(𝑛!)(𝑛!)𝑝.n!=pνp(n!)(n!)p.

    Here, 𝜈𝑝(𝑛!)νp(n!) represents the exponent of 𝑝p in the prime factorization of the factorial 𝑛!n!, and (𝑛!)𝑝(n!)p represents the integer obtained after removing all powers of 𝑝p from the result of the factorial 𝑛!n!. This article will discuss the specific computation methods for the remainder (𝑛!)𝑝(n!)p modulo a prime (power) and the exponent 𝜈𝑝(𝑛!)νp(n!).

    This decomposition is particularly useful when factorials appear in both the numerator and denominator of the expression to be solved, such as computing binomial coefficients modulo a certain modulus. For such problems, the exponents of 𝑝p in the numerator and denominator can be directly subtracted, and the part (𝑛!)𝑝(n!)p coprime with 𝑝p can be computed using multiplicative inverses.

    This article also introduces Wilson's theorem and its generalization, Legendre's formula, and Kummer's theorem, which are related to the above problems.

    Wilson's Theorem

    Wilson's theorem gives a necessary and sufficient condition to determine whether a natural number is a prime.

    Wilson's Theorem

    For a natural number 𝑛 >1n>1, 𝑛n is a prime if and only if (𝑛 −1)! ≡ −1(mod𝑛)(n−1)!≡−1(modn).

    Proof

    First, prove for a prime 𝑝p: (𝑝 −1)! ≡ −1(mod𝑝)(p−1)!≡−1(modp). For this, there are two concise proofs using either congruence equations or primitive roots, which are omitted here. A proof with fewer prerequisites is provided below:

    When 𝑝 =2p=2, the proposition obviously holds. Below, let 𝑝 ≥3p≥3. Then to prove that the product of all non-zero elements (i.e., congruence classes) in 𝐙𝑝Zp is ―――−1−1―. Because all non-zero elements ――𝑎a― in 𝐙𝑝Zp have inverses ――𝑎−1a―−1, the product of mutually inverse elements in 𝐙𝑝Zp is ――11―. But note that ――𝑎a― and ――𝑎−1a―−1 might be equal: ――𝑎 =――𝑎−1a―=a―−1, which holds if and only if 𝑎2 ≡1(mod𝑝)a2≡1(modp), i.e.,

    0≡𝑎2−1≡(𝑎+1)(𝑎−1),(mod𝑝)0≡a2−1≡(a+1)(a−1),(modp)

    Thus, 𝑎 ≡1(mod𝑝)a≡1(modp) or 𝑎 ≡ −1(mod𝑝)a≡−1(modp). This shows that the product of all elements in 𝐙𝑝 ∖{――0,――1,―――−1}Zp∖{0―,1―,−1―} is ――11―. Furthermore, the product of all non-zero elements in 𝐙𝑝Zp is ―――−1−1―.

    Conversely, for a composite number 𝑛n, proving that (𝑛 −1)! ≢ −1(mod𝑛)(n−1)!≢−1(modn). Using proof by contradiction, suppose (𝑛 −1)! ≡ −1(mod𝑛)(n−1)!≡−1(modn), i.e., there exists an integer 𝑘k such that (𝑛 −1)! =𝑘𝑛 −1(n−1)!=kn−1 holds. Since 𝑛n is composite, there necessarily exists a prime 𝑝 <𝑛p<n such that 𝑛 =𝑝𝑚n=pm, so (𝑛 −1)! =𝑘𝑝𝑚 −1 ≡ −1(mod𝑝)(n−1)!=kpm−1≡−1(modp). However, 𝑝p necessarily appears in the product (𝑛 −1)!(n−1)!, so (𝑛 −1)! ≡0(mod𝑝)(n−1)!≡0(modp). This contradiction shows that (𝑛 −1)! ≢ −1(mod𝑛)(n−1)!≢−1(modn).

    Using the notation in this article, Wilson's theorem can be written as (𝑝!)𝑝 ≡ −1(mod𝑝)(p!)p≡−1(modp).

    Generalization

    Wilson's theorem can be generalized to the case of general moduli.

    Theorem (Gauss)

    For a natural number 𝑚 >1m>1, we have:

    ∏1≤𝑘<𝑚, 𝑘⟂𝑚𝑘≡±1(mod𝑚).∏1≤k<m, k⟂mk≡±1(modm).

    Moreover, the ±1±1 in the remainder is −1−1 if and only if a primitive root exists modulo 𝑚m, i.e., 𝑚 =2,4,𝑝𝛼,2𝑝𝛼m=2,4,pα,2pα, where 𝑝p is an odd prime and 𝛼α is a positive integer.

    Proof

    This theorem can be easily proven using the structure of the multiplicative group of integers modulo 𝑛n. The proof provided here has similar ideas but is more elementary.

    For 𝑚 =2m=2, we have 1! =1 ≡ −1(mod2)1!=1≡−1(mod2). For other cases where primitive roots exist, let the primitive root be 𝑔g.     ∏1≤𝑘<𝑚, 𝑘⟂𝑚𝑘≡𝜑(𝑚)−1∏𝑖=0𝑔𝑖=𝑔𝜑(𝑚)/2𝜑(𝑚)/2−1∏𝑖=1𝑔𝑖𝑔𝜑(𝑚)−𝑖≡𝑔𝜑(𝑚)/2(mod𝑚).∏1≤k<m, k⟂mk≡∏i=0φ(m)−1gi=gφ(m)/2∏i=1φ(m)/2−1gigφ(m)−i≡gφ(m)/2(modm).

    Because 𝑔𝜑(𝑚)/2mod𝑚gφ(m)/2modm is the unique element not equal to 1mod𝑚1modm whose multiplicative inverse is itself, it equals −1mod𝑚−1modm. This shows that the remainder equals −1−1 in this case.

    For cases where primitive roots do not exist modulo 𝑚m, proving the remainder equals 11. For this, first perform prime factorization 𝑚 =𝑝𝑒11𝑝𝑒22⋯𝑝𝑒𝑠𝑠m=p1e1p2e2⋯pses, then use the Chinese Remainder Theorem. We only need to prove:

    ∏1≤𝑘<𝑚, 𝑘⟂𝑚𝑘≡1(mod𝑝𝑒𝑗𝑗)∏1≤k<m, k⟂mk≡1(modpjej)

    holds for all factors 𝑝𝑒𝑗𝑗pjej. The Chinese Remainder Theorem shows that each possible remainder combination (𝑟1,𝑟2,⋯,𝑟𝑠)(r1,r2,⋯,rs), where 1 ≤𝑟𝑗 <𝑝𝑒𝑗𝑗1≤rj<pjej and 𝑝𝑗 ⟂𝑟𝑗pj⟂rj, uniquely corresponds to a 1 ≤𝑘 <𝑚1≤k<m with 𝑘 ⟂𝑚k⟂m such that 𝑘 ≡𝑟𝑗(mod𝑝𝑒𝑗𝑗)k≡rj(modpjej). Therefore, for some remainder 𝑟𝑗rj, there are exactly 𝜑(𝑚)/𝜑(𝑝𝑒𝑗𝑗)φ(m)/φ(pjej) values of 𝑘k such that 𝑘 ≡𝑟𝑗(mod𝑝𝑒𝑗𝑗)k≡rj(modpjej). Using this, we can group the product:

    ∏1≤𝑘<𝑚, 𝑘⟂𝑚𝑘≡⎛⎜ ⎜ ⎜ ⎜⎝∏1≤𝑟𝑗<𝑝𝑒𝑗𝑗, 𝑟𝑗⟂𝑝𝑗𝑟𝑗⎞⎟ ⎟ ⎟ ⎟⎠𝜑(𝑚)/𝜑(𝑝𝑒𝑗𝑗)(mod𝑝𝑒𝑗𝑗).∏1≤k<m, k⟂mk≡(∏1≤rj<pjej, rj⟂pjrj)φ(m)/φ(pjej)(modpjej).

    Here, the exponent 𝜑(𝑚)/𝜑(𝑝𝑒𝑗𝑗) =𝜑(𝑚/𝑝𝑒𝑗𝑗)φ(m)/φ(pjej)=φ(m/pjej) must be an odd number. For this to be odd, it is necessarily required that 𝑚/𝑝𝑒𝑗𝑗 =1,2m/pjej=1,2, because Euler's function 𝜑(𝑛)φ(n) is even for all 𝑛 ≥3n≥3. If 𝑝𝑗pj is an odd prime, because primitive roots do not exist modulo 𝑚m, it necessarily follows that 𝑚/𝑝𝑒𝑗𝑗 ≠1,2m/pjej≠1,2; if 𝑝𝑒𝑗𝑗 =2,4pjej=2,4, because primitive roots do not exist modulo 𝑚m, it necessarily follows that 𝑚/𝑝𝑒𝑗𝑗m/pjej contains some odd prime factor, hence greater than 22: in both cases, the exponent 𝜑(𝑚)/𝜑(𝑝𝑒𝑗𝑗)φ(m)/φ(pjej) is even. And the term in brackets has been proven to be congruent to −1−1 modulo 𝑝𝑒𝑗𝑗pjej. Therefore, this power is necessarily congruent to 11 modulo 𝑝𝑒𝑗𝑗pjej. The only remaining case is 𝑝𝑗 =2pj=2 and 𝑒𝑗 >2ej>2. For this case, it can be directly proven that:

    ∏1≤𝑟𝑗<2𝑒𝑗, 𝑟𝑗⟂2𝑟𝑗≡1(mod2𝑒𝑗).∏1≤rj<2ej, rj⟂2rj≡1(mod2ej).

    Following the proof idea above, all odd numbers 𝑟𝑗rj with 1 ≤𝑟𝑗 <2𝑒𝑗1≤rj<2ej can be paired and canceled, and those that cannot be paired must satisfy the equation 𝑥2 ≡1(mod2𝑒𝑗)x2≡1(mod2ej). This equation means 2𝑒𝑗 ∣(𝑥 −1)(𝑥 +1)2ej∣(x−1)(x+1). Let 𝑥 =2𝑦 +1x=2y+1, which necessarily leads to 2𝑒𝑗−2 ∣𝑦(𝑦 +1)2ej−2∣y(y+1).     // Calculate (n!)_p mod p.
int factmod(int n, int p) {
  // Pretreatment.
  std::vector<int> f(p);
  f[0] = 1;
  for (int i = 1; i < p; ++i) {
    f[i] = (long long)f[i - 1] * i % p;
  }
  // Recursion.
  int res = 1;
  while (n > 1) {
    if ((n / p) & 1) res = p - res;
    res = (long long)res * f[n % p] % p;
    n /= p;
  }
  return res;
}

int multiplicity_factorial(int n, int p) {
  int count = 0;
  do {
    n /= p;
    count += n;
  } while (n);

}

    Kummer's Theorem

    The result of a binomial coefficient modulo a number often forms a fractal structure. For example, the Sierpinski triangle can be obtained through binomial coefficients modulo 22.

    If analyzed carefully, whether 𝑝p divides a binomial coefficient is related to whether borrowing is needed when subtracting the upper and lower indices in base 𝑝p. This gives Kummer's theorem.

    Kummer's Theorem

    The exponent of prime 𝑝p in the binomial coefficient (𝑚𝑛)(mn) is exactly the number of times borrowing is needed when subtracting 𝑛n from 𝑚m in base 𝑝p, i.e.:

    𝑛𝑢𝑝((𝑚𝑛))=𝑆𝑝(𝑛)+𝑆𝑝(𝑚−𝑛)−𝑆𝑝(𝑚)𝑝−1.nup((mn))=Sp(n)+Sp(m−n)−Sp(m)p−1.

    In particular, the exponent of 22 in the binomial coefficient is 𝜈2((𝑚𝑛)) =𝑆2(𝑛) +𝑆2(𝑚 −𝑛) −𝑆2(𝑚)ν2((mn))=S2(n)+S2(m−n)−S2(m).

    Proof

    First prove the expression below. For this, using Legendre's formula:

    𝑛𝑢𝑝((𝑚𝑛))=𝜈𝑝(𝑚!)−𝑛𝑢𝑝(𝑛!)−𝑛𝑢𝑝((𝑚−𝑛)!)=𝑠𝑢𝑚∞𝑖=1(⌊𝑚𝑝𝑖⌋−⌊𝑛𝑝𝑖⌋−⌊𝑚−𝑛𝑝𝑖⌋)=𝑆𝑝(𝑛)+𝑆𝑝(𝑚−𝑛)−𝑆𝑝(𝑚)𝑝−1.nup((mn))=νp(m!)−nup(n!)−nup((m−n)!)=sumi=1∞(⌊mpi⌋−⌊npi⌋−⌊m−npi⌋)=Sp(n)+Sp(m−n)−Sp(m)p−1.

    This expression can be understood as the number of times borrowing is needed when subtracting 𝑛n from 𝑚m in base 𝑝p. Because if there is a case where subtracting is insufficient and borrowing is needed at the 𝑖i-th digit (the lowest digit index is 11), then in the result of subtraction, the digit before the 𝑖i-th digit ⌊𝑚−𝑛𝑝𝑖⌋⌊m−npi⌋ is actually the digit before the 𝑖i-th digit in 𝑚m ⌊𝑚𝑝𝑖⌋⌊mpi⌋ minus one (i.e., the borrowed one), minus the digit before the 𝑖i-th digit in 𝑛n ⌊𝑛𝑝𝑖⌋⌊npi⌋. So the difference:

    ⌊𝑚𝑝𝑖⌋−⌊𝑛𝑝𝑖⌋−⌊𝑚−𝑛𝑝𝑖⌋=1⌊mpi⌋−⌊npi⌋−⌊m−npi⌋=1

    if and only if a borrowing occurs once; otherwise, the difference is 00. Therefore, the summation in the above expression can be understood as the number of times borrowing occurs. This gives the literal statement of Kummer's theorem.
