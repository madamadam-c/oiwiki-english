    Quadratic Residues

    Introduction

    Quadratic residues can be considered as discussing the feasibility of taking square roots modulo 𝑚m. For higher-power roots, see 𝑘k-th residues.

    Definition

    Quadratic Residue

    Let 𝑎a be an integer and 𝑝p satisfy (𝑎,𝑝) =1(a,p)=1. If there exists an integer 𝑥x such that

    𝑥2≡𝑎(mod𝑝),x2≡a(modp),

    then 𝑎a is called a quadratic residue modulo 𝑝p; otherwise, 𝑎a is called a quadratic nonresidue modulo 𝑝p. In the following, when the modulus 𝑝p is clear from context, we may simply write quadratic (non)residue.

    Euler's Criterion

    When the modulus is an odd prime, we have the following theorem:

    Euler's Criterion

    For an odd prime 𝑝p and an integer 𝑎a satisfying (𝑎,𝑝) =1(a,p)=1, we have

    𝑎𝑝−12≡{1(mod𝑝),(∃𝑥∈ℤ),  𝑎≡𝑥2(mod𝑝),−1(mod𝑝),otherwise.ap−12≡{1(modp),(∃x∈Z),  a≡x2(modp),−1(modp),otherwise.

    That is, for the above 𝑝p and 𝑎a,

    1. 𝑎a is a quadratic residue modulo 𝑝p if and only if 𝑎𝑝−12 ≡1(mod𝑝)ap−12≡1(modp).
    2. 𝑎a is a quadratic nonresidue modulo 𝑝p if and only if 𝑎𝑝−12 ≡ −1(mod𝑝)ap−12≡−1(modp).
    Proof

    First, by Fermat's Little Theorem, we have 𝑎𝑝−1 ≡1(mod𝑝)ap−1≡1(modp), hence

    (𝑎𝑝−12+1)(𝑎𝑝−12−1)≡0(mod𝑝),(ap−12+1)(ap−12−1)≡0(modp),

    so for any 𝑎a with (𝑎,𝑝) =1(a,p)=1, we have 𝑎(𝑝−1)/2 ≡ ±1(mod𝑝)a(p−1)/2≡±1(modp).

    Additionally, since 𝑝p is an odd prime, we have:

    𝑥𝑝−1−𝑎𝑝−12=(𝑥2)𝑝−12−𝑎𝑝−12=(𝑥2−𝑎)𝑃(𝑥),xp−1−ap−12=(x2)p−12−ap−12=(x2−a)P(x),

    where 𝑃(𝑥)P(x) is some polynomial with integer coefficients. Then:

    𝑥𝑝−𝑥=𝑥(𝑥𝑝−1−𝑎𝑝−12)+𝑥(𝑎𝑝−12−1)=(𝑥2−𝑎)𝑥𝑃(𝑥)+(𝑎𝑝−12−1)𝑥.xp−x=x(xp−1−ap−12)+x(ap−12−1)=(x2−a)xP(x)+(ap−12−1)x.

    By Theorem 5 of congruence equations, 𝑎a is a quadratic residue modulo 𝑝p if and only if 𝑎(𝑝−1)/2 ≡1(mod𝑝)a(p−1)/2≡1(modp). Therefore, 𝑎a is a quadratic nonresidue modulo 𝑝p if and only if 𝑎(𝑝−1)/2 ≡ −1(mod𝑝)a(p−1)/2≡−1(modp).

    Based on Euler's Criterion, we can obtain the following corollary:

    Number of Quadratic Residues

    For an odd prime 𝑝p, there are exactly 𝑝−12p−12 quadratic residues and 𝑝−12p−12 quadratic nonresidues modulo 𝑝p.

    Proof

    By Euler's Criterion, consider 𝑎𝑝−12 ≡1(mod𝑝)ap−12≡1(modp).

    Note that 𝑝−12 ∣(𝑝 −1)p−12∣(p−1). By Theorem 6 of congruence equations, the equation 𝑎𝑝−12 ≡1(mod𝑝)ap−12≡1(modp) has 𝑝−12p−12 solutions. Therefore, there are exactly 𝑝−12p−12 quadratic residues and 𝑝−12p−12 quadratic nonresidues modulo 𝑝p.

    (𝑝𝑞)(𝑞𝑝)=(−1)𝑝−12𝑞−12.(pq)(qp)=(−1)p−12q−12.

long long p, v;  // Modulus and the value of r^2 - a, respectively

struct Poly {
  long long a, b;

  Poly(long long _a = 0, long long _b = 0) : a(_a), b(_b) {}
};

Poly operator*(const Poly& x, const Poly& y) {
  // Overloaded multiplication; see the explanation above for the operation properties
  return Poly((x.a * y.a + v * (x.b * y.b % p)) % p,
              (x.a * y.b + x.b * y.a) % p);
}

// Fast exponentiation of polynomials, used to compute the answer
Poly modpow(Poly a, long long b) {
  Poly res(1, 0);
  while (b) {
    if (b & 1) res = res * a;
    a = a * a;
    b >>= 1;
  }
  return res;
}

// Ordinary fast exponentiation, used to test quadratic non-residues
long long modpow(long long a, long long b) {
  long long res = 1;
  while (b) {
    if (b & 1) res = res * a % p;
    a = a * a % p;
    b >>= 1;
  }
  return res;
}

// Used to generate random numbers
std::mt19937 rng(std::random_device{}());

long long cipolla(long long a, long long _p) {
  p = _p;
  if (a == 0)
    return 0;  // Special case for 0
  else if (modpow(a, (p - 1) / 2) == p - 1)
    return -1;  // Quadratic non-residue detected, so there is no solution
  else {
    // Randomize r so that r^2 - a is a quadratic non-residue
    long long r;
    for (r = rng() % p;; r = rng() % p) {
      if (modpow((r * r - a + p) % p, (p - 1) / 2) == p - 1) break;
    }
    v = (r * r - a + p) % p;
    return modpow(Poly(r, 1), (p + 1) / 2).a;  // Compute the result from the conclusion formula
  }
}
