    Powerful Number Sieve

    Definition

    Powerful Number (hereinafter PN) sieve is similar to the Dujiao sieve, or rather an extension of it, and can be used to compute prefix sums of some multiplicative functions.

    Requirements:

    • There exists a function 𝑔g such that:
      • 𝑔g is a multiplicative function.
      • 𝑔g has a prefix sum that is easy to compute.
      • For a prime 𝑝p, 𝑔(𝑝) =𝑓(𝑝)g(p)=f(p).

    Assume we need to compute the prefix sum 𝐹(𝑛) =∑𝑛𝑖=1𝑓(𝑖)F(n)=∑i=1nf(i) of a multiplicative function 𝑓f.

    Powerful Numbers

    Definition: For a positive integer 𝑛n, let its prime factorization be 𝑛 =∏𝑚𝑖=1𝑝𝑒𝑖𝑖n=∏i=1mpiei. 𝑛n is a PN if and only if ∀1 ≤𝑖 ≤𝑚,𝑒𝑖 >1∀1≤i≤m,ei>1.

    Property 1: All PNs can be expressed in the form 𝑎2𝑏3a2b3.

    Proof: If 𝑒𝑖ei is even, combine 𝑝𝑒𝑖𝑖piei into 𝑎2a2; if 𝑒𝑖ei is odd, first combine 𝑝3𝑖pi3 into 𝑏3b3, then combine 𝑝𝑒𝑖−3𝑖piei−3 into 𝑎2a2.

    Property 2: The number of PNs not exceeding 𝑛n is at most 𝑂(√𝑛)O(n).

    Proof: Consider enumerating 𝑎a, then consider the number of 𝑏b satisfying the condition. The number of PNs is approximately

    ∫√𝑛13√𝑛𝑥2d𝑥=𝑂(√𝑛)∫1nnx23dx=O(n)

    So how do we find all PNs not exceeding 𝑛n? Use a linear sieve to find all primes within √𝑛n, then perform a DFS to search the exponents of each prime. Since the number of PNs not exceeding 𝑛n is at most 𝑂(√𝑛)O(n), we search at most 𝑂(√𝑛)O(n) times.

    PN Sieve

    First, construct a multiplicative function 𝑔g whose prefix sum is easy to compute, satisfying 𝑔(𝑝) =𝑓(𝑝)g(p)=f(p) for primes 𝑝p. Let 𝐺(𝑛) =∑𝑛𝑖=1𝑔(𝑖)G(n)=∑i=1ng(i).

    Process

    1. Construct 𝑔g
    2. Construct a method for fast computation of 𝐺G
    3. Compute ℎ(𝑝𝑐)h(pc)
    4. Search for PNs and accumulate the answer during the process
    5. Obtain the result

    For step 3, we can compute directly from the formula, use enumeration for precomputation and lookup tables, or derive on the fly when encountered during the search.

    Properties

    Let's analyze using the second method for computing ℎ(𝑝𝑐)h(pc). The analysis can be divided into two parts: computing ℎ(𝑝𝑐)h(pc) and searching.

    For the first part, since the number of primes within 𝑂(√𝑛)O(n) is 𝑂(√𝑛log⁡𝑛)O(nlog⁡n), each prime 𝑝p has at most log⁡𝑛log⁡n exponents, and computing ℎ(𝑝𝑐)h(pc) requires a loop of (𝑐 −1)(c−1) times. Therefore, the time complexity of the first part is 𝑂(√𝑛log⁡𝑛⋅log⁡𝑛⋅log⁡𝑛) =𝑂(√𝑛log⁡𝑛)O(nlog⁡n⋅log⁡n⋅log⁡n)=O(nlog⁡n), and this is a loose upper bound. Depending on the problem, different optimizations can be added to reduce the time complexity of the first part.

    For the search part, since the number of PNs not exceeding 𝑛n is at most 𝑂(√𝑛)O(n), we search at most 𝑂(√𝑛)O(n) times. For each PN, the time complexity varies depending on the method for computing 𝐺G. For example, if the time complexity of computing 𝐺(⌊𝑛𝑑⌋)G(⌊nd⌋) is 𝑂(1)O(1), then the complexity of the second part is 𝑂(√𝑛)O(n).

    Specifically, if the Dujiao sieve is used to compute 𝐺(⌊𝑛𝑑⌋)G(⌊nd⌋), the time complexity of the second part is that of the Dujiao sieve, namely 𝑂(𝑛23)O(n23). Because if 𝐺(𝑛)G(n) is computed once in advance, and larger values are stored using a linear sieve optimization and data structures supporting fast random access (such as std::map and std::unordered_map in C++), then the 𝐺(⌊𝑛𝑑⌋)G(⌊nd⌋) used in the Dujiao sieve are either recorded by the linear sieve or stored in std::map. This can be directly verified by program.

    For space complexity, the bottleneck is storing ℎ(𝑝𝑐)h(pc). If a two-dimensional array 𝑎a is used, where 𝑎𝑖,𝑗ai,j represents the value of ℎ(𝑝𝑗𝑖)h(pij), the space complexity is 𝑂(√𝑛log⁡𝑛⋅log⁡𝑛) =𝑂(√𝑛)O(nlog⁡n⋅log⁡n)=O(n).

constexpr int MOD = 1e9 + 7;

template <typename T>
int mint(T x) {
  x %= MOD;
  if (x < 0) x += MOD;
  return x;
}

int add(int x, int y) { return x + y >= MOD ? x + y - MOD : x + y; }

int mul(int x, int y) { return (long long)1 * x * y % MOD; }

int sub(int x, int y) {
  return x < y ? x - y + MOD : x - y;  // Avoid negative values
}

int qp(int x, int y) {
  int r = 1;
  for (; y; y >>= 1) {
    if (y & 1) r = mul(r, x);
    x = mul(x, x);
  }
  return r;
}

int inv(int x) { return qp(x, MOD - 2); }

constexpr int N = 2e6 + 5;
constexpr int M = 35;

long long global_n;

int h[N][M];
bool vis_h[N][M];

int ans;

bool isp[N];

void sieve(int n) {
  pcnt = 0;
  for (int i = 2; i <= n; ++i) isp[i] = true;  // Prime marker array
  phi[1] = 1;
  for (int i = 2; i <= n; ++i) {
    if (isp[i]) {
      ++pcnt;
      prime[pcnt] = i;
      phi[i] = i - 1;
    }
    for (int j = 1; j <= pcnt; ++j) {  // Sieve out composites
      long long nxt = (long long)1 * i * prime[j];
      if (nxt > n) break;
      isp[nxt] = false;
      if (i % prime[j] == 0) {  // Case where i is composite
        phi[nxt] = phi[i] * prime[j];
        break;
      }
      phi[nxt] = phi[i] * phi[prime[j]];
    }
  }

  for (int i = 1; i <= n; ++i) g[i] = mul(i, phi[i]);

  sg[0] = 0;
  for (int i = 1; i <= n; ++i) sg[i] = add(sg[i - 1], g[i]);  // Prefix sum of g
}

int inv2, inv6;

void init() {
  sieve(N - 1);
  for (int i = 1; i <= pcnt; ++i) h[i][0] = 1, h[i][1] = 0;
  for (int i = 1; i <= pcnt; ++i) vis_h[i][0] = vis_h[i][1] = true;
  inv2 = inv(2);
  inv6 = inv(6);
}

int S1(long long n) { return mul(mul(mint(n), mint(n + 1)), inv2); }

int S2(long long n) {
  return mul(mul(mint(n), mul(mint(n + 1), mint(n * 2 + 1))), inv6);
}

map<long long, int> mp_g;

int G(long long n) {
  if (n < N) return sg[n];
  if (mp_g.count(n)) return mp_g[n];

  int ret = S2(n);
  for (long long i = 2, j; i <= n; i = j + 1) {
    j = n / (n / i);
    ret = sub(ret, mul(sub(S1(j), S1(i - 1)), G(n / i)));
  }
  mp_g[n] = ret;
  return ret;
}

void dfs(long long d, int hd, int pid) {
  ans = add(ans, mul(hd, G(global_n / d)));

  for (int i = pid; i <= pcnt; ++i) {
    if (i > 1 && d > global_n / prime[i] / prime[i]) break;  // Pruning

    int c = 2;
    for (long long x = d * prime[i] * prime[i]; x <= global_n;
         x *= prime[i], ++c) {  // Compute f and g functions
      if (!vis_h[i][c]) {
        int f = qp(prime[i], c);
        f = mul(f, sub(f, 1));
        int g = mul(prime[i], prime[i] - 1);
        int t = mul(prime[i], prime[i]);

        for (int j = 1; j <= c; ++j) {
          f = sub(f, mul(g, h[i][c - j]));
          g = mul(g, t);
        }
        h[i][c] = f;
        vis_h[i][c] = true;
      }

      if (h[i][c]) dfs(x, mul(hd, h[i][c]), i + 1);
    }
  }
}

int solve(long long n) {
  global_n = n;
  ans = 0;
  dfs(1, 1, 1);
  return ans;
}
