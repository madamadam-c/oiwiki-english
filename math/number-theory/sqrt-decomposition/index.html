    Number-theoretic Block Decomposition

    Divisor block (also known as integer division block or floor division block) can quickly compute sums of the form

    𝑛∑𝑖=1𝑓(𝑖)𝑔(⌊𝑛𝑖⌋)∑i=1nf(i)g(⌊ni⌋)

    If ∑𝑟𝑖=𝑙𝑓(𝑖)∑i=lrf(i) can be computed in 𝑂(1)O(1) time or the prefix sums of 𝑓f are already precomputed, then divisor block can compute the above sum in 𝑂(√𝑛)O(n) time.

    Divisor block is often used in conjunction with techniques like Möbius inversion.

    Idea

    First, this article illustrates the idea of divisor block through a simple example. Suppose we need to count the number of integer points under the hyperbola shown in the figure:

    This is equivalent to computing the sum:

    11∑𝑖=1⌊11𝑖⌋.∑i=111⌊11i⌋.

    This is a special case of the previously shown sum when 𝑓(𝑘) =1f(k)=1 and 𝑔(𝑘) =𝑘g(k)=k.

    The simplest approach is to calculate each column one by one and sum them, but this requires calculating the number of integer points in each column for 𝑖 =1,2,⋯,11i=1,2,⋯,11. Observing the figure, we can see that these columns can be divided into 5 blocks, and within each block, the column height is consistent, forming a rectangular point pattern. Therefore, as long as we know the width of these blocks, we can quickly complete the count by calculating the size of these rectangular blocks.

    This is the basic idea of divisor block.

    Properties

    This section discusses several conclusions about the blocks of integer points under the hyperbola 𝑦 =𝑛𝑥y=nx. Specifically, we need to divide the integers between 11 and 𝑛n into several blocks based on the value of ⌊𝑛𝑖⌋⌊ni⌋. Let

    𝐷(𝑛)={⌊𝑛𝑖⌋:1≤𝑖≤𝑛, 𝑖∈𝐍+}.D(n)={⌊ni⌋:1≤i≤n, i∈N+}.

    This is the set of all possible values of ⌊𝑛𝑖⌋⌊ni⌋.

    First, there are only 𝑂(√𝑛)O(n) different values. Therefore, the number of blocks obtained by divisor block is only 𝑂(√𝑛)O(n).

    Property 1

    |𝐷(𝑛)| ≤2√𝑛|D(n)|≤2n.

    Proof

    Consider two cases:

    • When 𝑖 ≤√𝑛i≤n, there are at most √𝑛n possible values for 𝑖i, so there are also at most √𝑛n possible values for ⌊𝑛𝑖⌋⌊ni⌋.
    • When 𝑖 >√𝑛i>n, ⌊𝑛𝑖⌋ ≤𝑛𝑖 <√𝑛⌊ni⌋≤ni<n, which also has at most √𝑛n possible values.

    Therefore, the total number of possible values |𝐷(𝑛)| ≤2√𝑛|D(n)|≤2n.

    Through more detailed analysis, the set 𝐷(𝑛)D(n) and its size can actually be precisely described.

    Property 2

    Let 𝑠 =⌊√𝑛⌋s=⌊n⌋. The elements of set 𝐷(𝑛)D(n) in ascending order are:

    1<2<⋯<𝑠−1<𝑠≤⌊𝑛𝑠⌋<⌊𝑛𝑠−1⌋<⋯<⌊𝑛2⌋<⌊𝑛1⌋=𝑛.1<2<⋯<s−1<s≤⌊ns⌋<⌊ns−1⌋<⋯<⌊n2⌋<⌊n1⌋=n.

    Moreover, |𝐷(𝑛)| =⌊√4𝑛+1⌋ −1|D(n)|=⌊4n+1⌋−1.

    Proof

    First, for 1 ≤𝑖 ≤𝑠1≤i≤s, we can prove that ⌊𝑛⌊𝑛/𝑖⌋⌋ =𝑖⌊n⌊n/i⌋⌋=i. Let 𝑑 =⌊𝑛𝑖⌋d=⌊ni⌋, and we need to prove ⌊𝑛𝑑⌋ =𝑖⌊nd⌋=i. Written as an inequality, this is equivalent to knowing 𝑑 ≤𝑛𝑖 <𝑑 +1d≤ni<d+1, and we need to prove 𝑖 ≤𝑛𝑑 <𝑖 +1i≤nd<i+1. The known condition can be written as 𝑖 ≤𝑛𝑑 <𝑖 +𝑖𝑑i≤nd<i+id, so we only need to prove 𝑖𝑑 ≤1id≤1, i.e., 𝑖 ≤𝑑 =⌊𝑛𝑖⌋i≤d=⌊ni⌋. This is equivalent to 𝑖 ≤𝑛𝑖i≤ni, which holds for all 1 ≤𝑖 ≤𝑠 ≤√𝑛1≤i≤s≤n.

    This result actually shows that the mapping 𝑖 ↦⌊𝑛𝑖⌋i↦⌊ni⌋ forms a bijection between the set {𝑖 :1 ≤𝑖 ≤𝑠}{i:1≤i≤s} and the set {⌊𝑛𝑖⌋:1≤𝑖≤𝑠}{⌊ni⌋:1≤i≤s}. Since 𝑖i values are distinct, ⌊𝑛𝑖⌋⌊ni⌋ values are also distinct. The only element that could possibly be the same in the two sets is 𝑠s and ⌊𝑛𝑠⌋⌊ns⌋. Therefore, |𝐷(𝑛)| =2𝑠 −[𝑠=⌊𝑛/𝑠⌋]|D(n)|=2s−[s=⌊n/s⌋].

    To obtain the final expression for |𝐷(𝑛)||D(n)|, we need to examine when 𝑠 =⌊𝑛𝑠⌋s=⌊ns⌋ holds.

    • When 𝑠 =⌊𝑛𝑠⌋s=⌊ns⌋, we always have 𝑠 ≤𝑛𝑠 <𝑠 +1s≤ns<s+1, i.e., 𝑠2 ≤𝑛 <𝑠2 +𝑠s2≤n<s2+s. Then, 4𝑠2 +1 ≤4𝑛 +1 <4𝑠2 +4𝑠 +1 =(2𝑠 +1)24s2+1≤4n+1<4s2+4s+1=(2s+1)2. Also, since 4𝑛 +14n+1 is always odd, the left side can be equivalently relaxed to 4𝑠24s2. So this condition is equivalent to 2𝑠 ≤√4𝑛+1 <2𝑠 +12s≤4n+1<2s+1, i.e., ⌊√4𝑛+1⌋ =2𝑠⌊4n+1⌋=2s.
    • When 𝑠 <⌊𝑛𝑠⌋s<⌊ns⌋, we always have 𝑠 +1 ≤𝑛𝑠s+1≤ns, i.e., 𝑠2 +𝑠 ≤𝑛s2+s≤n. And since 𝑛 <(𝑠 +1)2n<(s+1)2, we have 𝑠2 +𝑠 ≤𝑛 <(𝑠 +1)2s2+s≤n<(s+1)2. This is equivalent to (2𝑠 +1)2 ≤4𝑛 +1 <4(𝑠 +1)2 +1(2s+1)2≤4n+1<4(s+1)2+1. Using again that 4𝑛 +14n+1 is odd, the right side can be equivalently tightened to 4(𝑠 +1)24(s+1)2. So this condition is equivalent to 2𝑠 +1 ≤√4𝑛+1 <2𝑠 +22s+1≤4n+1<2s+2, i.e., ⌊√4𝑛+1⌋ =2𝑠 +1⌊4n+1⌋=2s+1.

    Summarizing these two cases, we get |𝐷(𝑛)| =⌊√4𝑛+1⌋ −1|D(n)|=⌊4n+1⌋−1.

    Then, the left and right endpoints of a single block are easy to determine.

    Property 3

    For 𝑑 ∈𝐷(𝑛)d∈D(n), the range of all integers 𝑖i satisfying ⌊𝑛𝑖⌋ =𝑑⌊ni⌋=d is:

    ⌊𝑛𝑑+1⌋+1≤𝑖≤⌊𝑛𝑑⌋.⌊nd+1⌋+1≤i≤⌊nd⌋.
    Proof

    Since ⌊𝑛𝑖⌋ =𝑑⌊ni⌋=d is equivalent to the inequality:

    𝑑≤𝑛𝑖<𝑑+1.d≤ni<d+1.

    This is further equivalent to:

    𝑛𝑑+1<𝑖≤𝑛𝑑.nd+1<i≤nd.

    Using the fact that 𝑖 ∈𝐍+i∈N+, taking the floor of this inequality gives:

    ⌊𝑛𝑑+1⌋+1≤𝑖≤⌊𝑛𝑑⌋.⌊nd+1⌋+1≤i≤⌊nd⌋.

    This property also reflects the symmetry of the graph: the set of right endpoints of each block (the green points in the figure) is exactly 𝐷(𝑛)D(n). This is easy to understand because the entire graph is symmetric about the line 𝑦 =𝑥y=x.

    In addition to these properties, the set 𝐷(𝑛)D(n) also has good recursive properties:

    Property 4

    For 𝑚 ∈𝐷(𝑛)m∈D(n), we have 𝐷(𝑚) ⊆𝐷(𝑛)D(m)⊆D(n).

    Proof

    Let 𝑚 =⌊𝑛𝑘⌋m=⌊nk⌋. Then, since for all 𝑖 ∈𝐍+i∈N+, we have:

    ⌊𝑚𝑖⌋=⌊⌊𝑛/𝑘⌋𝑖⌋=⌊𝑛𝑘𝑖⌋∈𝐷(𝑛),⌊mi⌋=⌊⌊n/k⌋i⌋=⌊nki⌋∈D(n),

    so 𝐷(𝑚) ⊆𝐷(𝑛)D(m)⊆D(n). The second equality uses the property of the floor function for nested fractions.

    As mentioned earlier, 𝐷(𝑛)D(n) is both the set of values of Missing or unrecognized delimiter for \leftMissing or unrecognized delimiter for \left within each block and the set of right endpoints of blocks. This means that if we recursively apply divisor block (i.e., the function's value at 𝑛n depends on its values at 𝑚 ∈𝐷(𝑛) ∖{𝑛}m∈D(n)∖{n}), then the set of values and right endpoints involved in the entire computation are actually all in 𝐷(𝑛)D(n). A typical example is the Du Jiao Sieve.

    Process

    Using the conclusions described in the previous section, we obtain the specific process of divisor block.

    To compute the value of the sum

    𝑛∑𝑖=1𝑓(𝑖)𝑔(⌊𝑛𝑖⌋)∑i=1nf(i)g(⌊ni⌋)

    we can divide the indices 𝑖 =1,2,⋯,𝑛i=1,2,⋯,n into blocks based on the value of ⌊𝑛𝑖⌋⌊ni⌋. Since indices with the same value of ⌊𝑛𝑖⌋⌊ni⌋ form a continuous integer interval [𝑙,𝑟][l,r], the value of the sum for this block is:

    (𝑟∑𝑖=𝑙𝑓(𝑖))⋅𝑔(⌊𝑛𝑙⌋).(∑i=lrf(i))⋅g(⌊nl⌋).

    To quickly compute this sum, we usually need to be able to quickly compute the sum of 𝑓f on the left side. Sometimes, the expression of this sum is known and can be computed in 𝑂(1)O(1) time; sometimes, we can precompute its prefix sums, still allowing 𝑂(1)O(1) time for a single query.

    When sequentially calculating the left and right endpoints of each block, the left endpoint 𝑙l of the current block equals the right endpoint of the previous block plus 1, and the right endpoint of the current block equals ⌊𝑛⌊𝑛/𝑙⌋⌋⌊n⌊n/l⌋⌋. From this, we get the following pseudocode:

    Ceiling Division Block

    Divisor block can be used to compute sums involving ceiling division:

    Note that the upper limit of the summation has changed, and there is a separate term when 𝑖 =𝑛i=n.

    Multi-dimensional Divisor Block

    Divisor block can also handle sums with more than one division expression:

    𝑛∑𝑖=1𝑓(𝑖)𝑔(⌊𝑛1𝑖⌋,⌊𝑛2𝑖⌋,⋯,⌊𝑛𝑚𝑖⌋).∑i=1nf(i)g(⌊n1i⌋,⌊n2i⌋,⋯,⌊nmi⌋).

    Divisor block can be used to compute sums with arbitrary exponent division expressions:

    Property

    #include <iostream>

long long H(int n) {
  long long res = 0;  // Store the result
  int l = 1, r;       // Left and right endpoints of the block
  while (l <= n) {
    r = n / (n / l);  // Compute the right endpoint of the current block
    // Add this block's contribution to the result. Multiply by 1LL to avoid overflow
    res += 1LL * (r - l + 1) * (n / l);
    l = r + 1;  // Move the left endpoint to the next block
  }
  return res;
}

  int t, n;
  std::cin >> t;
  while (t--) {
    std::cin >> n;
    std::cout << H(n) << '\n';
  }
  return 0;
}
