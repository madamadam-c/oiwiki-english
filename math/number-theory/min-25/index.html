    Min_25 Sieve

    Definition

    In terms of its methodology, this sieve is also known as the "Extended Eratosthenes Sieve".

    It is called "Min_25 Sieve" because it was invented and first used by Min_25.

    Properties

    It can solve prefix sum problems for a class of multiplicative functions in 𝑂(𝑛34log⁡𝑛)O(n34log⁡n) or Θ(𝑛1−𝜖)Θ(n1−ϵ) time complexity.

    Requirements: 𝑓(𝑝)f(p) is a sum of completely multiplicative functions that can be quickly evaluated for 𝑝p (e.g., polynomials); 𝑓(𝑝𝑐)f(pc) can be quickly evaluated.

    Notations

    • Unless otherwise specified, in this section all variables denoted by 𝑝p take values in the set of all primes.
    • 𝑥/𝑦 :=⌊𝑥𝑦⌋x/y:=⌊xy⌋
    • isprime⁡(𝑛) :=[|{𝑑 :𝑑 ∣𝑛}| =2]isprime⁡(n):=[|{d:d∣n}|=2], i.e., its value is 11 when 𝑛n is prime, and 00 otherwise.
    • 𝑝𝑘pk: the 𝑘k-th smallest prime (e.g., 𝑝1 =2,𝑝2 =3p1=2,p2=3). Special case: let 𝑝0 =1p0=1.
    • lpf⁡(𝑛) :=[1 <𝑛]min{𝑝 :𝑝 ∣𝑛} +[1 =𝑛]lpf⁡(n):=[1<n]min{p:p∣n}+[1=n], i.e., the smallest prime factor of 𝑛n. Special case: when 𝑛 =1n=1, its value is 11.
    • 𝐹prime(𝑛) :=∑2≤𝑝≤𝑛𝑓(𝑝)Fprime(n):=∑2≤p≤nf(p)
    • 𝐹𝑘(𝑛) :=∑𝑛𝑖=2[𝑝𝑘 ≤lpf⁡(𝑖)]𝑓(𝑖)Fk(n):=∑i=2n[pk≤lpf⁡(i)]f(i)

    Explanation

    Observing the definition of 𝐹𝑘(𝑛)Fk(n), we find that the answer is 𝐹1(𝑛) +𝑓(1) =𝐹1(𝑛) +1F1(n)+f(1)=F1(n)+1.

    Consider how to compute 𝐹𝑘(𝑛)Fk(n). By enumerating the smallest prime factor and its exponent for each 𝑖i, we obtain the recurrence:

    𝐹𝑘(𝑛)=𝑛∑𝑖=2[𝑝𝑘≤lpf⁡(𝑖)]𝑓(𝑖)=∑𝑘≤𝑖𝑝2𝑖≤𝑛∑𝑐≥1𝑝𝑐𝑖≤𝑛𝑓(𝑝𝑐𝑖)([𝑐>1]+𝐹𝑖+1(𝑛/𝑝𝑐𝑖))+∑𝑘≤𝑖𝑝𝑖≤𝑛𝑓(𝑝𝑖)=∑𝑘≤𝑖𝑝2𝑖≤𝑛∑𝑐≥1𝑝𝑐+1𝑖≤𝑛(𝑓(𝑝𝑐𝑖)𝐹𝑖+1(𝑛/𝑝𝑐𝑖)+𝑓(𝑝𝑐+1𝑖))+𝐹prime(𝑛)−𝐹prime(𝑝𝑘−1)Fk(n)=∑i=2n[pk≤lpf⁡(i)]f(i)=∑k≤ipi2≤n∑c≥1pic≤nf(pic)([c>1]+Fi+1(n/pic))+∑k≤ipi≤nf(pi)=∑k≤ipi2≤n∑c≥1pic+1≤n(f(pic)Fi+1(n/pic)+f(pic+1))+Fprime(n)−Fprime(pk−1)

    The last step is based on the fact: for 𝑐c satisfying 𝑝𝑐𝑖 ≤𝑛 <𝑝𝑐+1𝑖pic≤n<pic+1, we have 𝑝𝑐+1𝑖 >𝑛 ⟺ 𝑛/𝑝𝑐𝑖 <𝑝𝑖 <𝑝𝑖+1pic+1>n⟺n/pic<pi<pi+1, hence 𝐹𝑖+1(𝑛/𝑝𝑐𝑖) =0Fi+1(n/pic)=0.

    Its boundary condition is 𝐹𝑘(𝑛) =0Fk(n)=0 when 𝑝𝑘 >𝑛pk>n.

    Assuming we have already computed all 𝐹prime(𝑛)Fprime(n), there are two ways to compute all 𝐹𝑘(𝑛)Fk(n):

    1. Compute directly according to the recurrence.
    2. Enumerate 𝑝p from large to small; since transitions only contribute when 𝑝2 <𝑛p2<n, we can optimize using suffix sums according to the recurrence.

    Now consider how to compute 𝐹prime(𝑛)Fprime(n).

    Observing the process of computing 𝐹𝑘(𝑛)Fk(n), it is easy to see that 𝐹primeFprime only has useful values at 𝑂(√𝑛)O(n) points: 1,2,…,⌊√𝑛⌋,𝑛/√𝑛,…,𝑛/2,𝑛1,2,…,⌊n⌋,n/n,…,n/2,n.

    Generally, 𝑓(𝑝)f(p) is a low-degree polynomial in 𝑝p, which can be expressed as 𝑓(𝑝) =∑𝑎𝑖𝑝𝑐𝑖f(p)=∑aipci.

    For each 𝑝𝑐𝑖pci, its contribution to 𝐹prime(𝑛)Fprime(n) is 𝑎𝑖∑2≤𝑝≤𝑛𝑝𝑐𝑖ai∑2≤p≤npci.

    Considering the contributions of each 𝑝𝑐𝑖pci separately, the problem reduces to: given 𝑛,𝑠,𝑔(𝑝) =𝑝𝑠n,s,g(p)=ps, compute ∑𝑝≤𝑚𝑔(𝑝)∑p≤mg(p) for all 𝑚 =𝑛/𝑖m=n/i.

    Note

    𝑔(𝑝) =𝑝𝑠g(p)=ps is a completely multiplicative function!

    Thus, let 𝐺𝑘(𝑛) :=∑𝑛𝑖=2[𝑝𝑘<lpf⁡(𝑖)∨isprime⁡(𝑖)]𝑔(𝑖)Gk(n):=∑i=2n[pk<lpf⁡(i)∨isprime⁡(i)]g(i), i.e., the sum of 𝑔g values of numbers remaining after the 𝑘k-th round of the Eratosthenes sieve.

    For a composite number 𝑥 ≤𝑛x≤n, we must have lpf⁡(𝑥) ≤√𝑥 ≤√𝑛lpf⁡(x)≤x≤n. Let 𝑝ℓ(𝑛)pℓ(n) be the largest prime not exceeding √𝑛n, then ∑2≤𝑝≤𝑛𝑔(𝑝) =𝐺ℓ(𝑛)(𝑛)∑2≤p≤ng(p)=Gℓ(n)(n), i.e., after ℓℓ rounds of the Eratosthenes sieve, the remaining numbers are all primes.

    Consider the boundary value of 𝐺G. Obviously, 𝐺0(𝑛) =∑𝑛𝑖=2𝑔(𝑖)G0(n)=∑i=2ng(i). (Remember? We specially defined 𝑝0 =1p0=1)

    For the transition, considering the process of the Eratosthenes sieve, we analyze the contributions of each part:

    1. For the part where 𝑛 <𝑝2𝑘n<pk2, the 𝐺G value remains unchanged, i.e., 𝐺𝑘(𝑛) =𝐺𝑘−1(𝑛)Gk(n)=Gk−1(n).
    2. For the part where 𝑝2𝑘 ≤𝑛pk2≤n, the numbers being sieved must have prime factor 𝑝𝑘pk, i.e., −𝑔(𝑝𝑘)𝐺𝑘−1(𝑛/𝑝𝑘)−g(pk)Gk−1(n/pk).
    3. For the second part, since 𝑝2𝑘 ≤𝑛 ⟺ 𝑝𝑘 ≤𝑛/𝑝𝑘pk2≤n⟺pk≤n/pk, numbers satisfying lpf⁡(𝑖) <𝑝𝑘lpf⁡(i)<pk are subtracted extra. This part should be added back, i.e., 𝑔(𝑝𝑘)𝐺𝑘−1(𝑝𝑘−1)g(pk)Gk−1(pk−1).

    Then we have:

    𝐺𝑘(𝑛)=𝐺𝑘−1(𝑛)−[𝑝2𝑘≤𝑛]𝑔(𝑝𝑘)(𝐺𝑘−1(𝑛/𝑝𝑘)−𝐺𝑘−1(𝑝𝑘−1))Gk(n)=Gk−1(n)−[pk2≤n]g(pk)(Gk−1(n/pk)−Gk−1(pk−1))

    Complexity Analysis

    For the computation of 𝐹𝑘(𝑛)Fk(n), the time complexity of the first method is proven to be 𝑂(𝑛1−𝜖)O(n1−ϵ) (see Zhu Zhenting's training paper Some Summation Problems for Special Number-Theoretic Functions Section 2.3);

    For the second method, its essence is the second part of the Min_25 sieve, which is also mentioned in Ren Zhizhou's paper Several Methods for Summing Multiplicative Functions (Section 6.5.4), and its time complexity is proven to be 𝑂(𝑛34log⁡𝑛)O(n34log⁡n).

    For the computation of 𝐹prime(𝑛)Fprime(n), its implementation is actually the same as the first part of the Min_25 sieve.

    For each 𝑚 =𝑛/𝑖m=n/i, transitions only contribute when enumerating 𝑝𝑘pk satisfying 𝑝2𝑘 ≤𝑚pk2≤m. The time complexity can be estimated as:

    𝑇(𝑛)=∑𝑖2≤𝑛𝑂(𝜋(√𝑖))+∑𝑖2≤𝑛𝑂(𝜋(√𝑛𝑖))=∑𝑖2≤𝑛𝑂(√𝑖ln⁡√𝑖)+∑𝑖2≤𝑛𝑂(√𝑛𝑖ln⁡√𝑛𝑖)=𝑂(∫√𝑛1√𝑛𝑥log⁡√𝑛𝑥d𝑥)=𝑂(𝑛34log⁡𝑛)T(n)=∑i2≤nO(π(i))+∑i2≤nO(π(ni))=∑i2≤nO(iln⁡i)+∑i2≤nO(niln⁡ni)=O(∫1nnxlog⁡nxdx)=O(n34log⁡n)

    For space complexity, we can see that both 𝐹𝑘Fk and 𝐹primeFprime only have valid values at 𝑛/𝑖n/i, with 𝑂(√𝑛)O(n) points in total. Recording only the valid values can reduce space complexity to 𝑂(√𝑛)O(n).

    First, we can obtain all valid values through one number-theoretic block division, and record them in an array lislis of size 𝑂(√𝑛)O(n). For a valid value 𝑣v, let id(𝑣)id(v) be its index in lislis. It is easy to see that for all valid values 𝑣v, id(𝑣) ≤√𝑛id(v)≤n.

    Then we separately consider valid values ≤√𝑛≤n and >√𝑛>n: for valid values 𝑣 ≤√𝑛v≤n, we use an array lele to record id(𝑣)id(v), i.e., le𝑣 =id(𝑣)lev=id(v); for valid values 𝑣 >√𝑛v>n, we use an array gege to record id(𝑣)id(v). Since 𝑣v is too large, we use 𝑣′ =𝑛/𝑣 <√𝑛v′=n/v<n to record id(𝑣)id(v), i.e., ge𝑣′ =id(𝑣)gev′=id(v).

    This way, we can use two arrays of size 𝑂(√𝑛)O(n) to record all idid values for valid values and query them in 𝑂(1)O(1). When computing 𝐹𝑘Fk or 𝐹primeFprime, using the idid of valid values instead of the valid values themselves as indices reduces space complexity to 𝑂(√𝑛)O(n).

#include <cmath>
#include <iostream>

constexpr int MAXS = 200000;  // 2sqrt(n)
constexpr int mod = 1000000007;

template <typename x_t, typename y_t>
void inc(x_t &x, const y_t &y) {
  x += y;
  (mod <= x) && (x -= mod);
}

template <typename x_t, typename y_t>
void dec(x_t &x, const y_t &y) {
  x -= y;
  (x < 0) && (x += mod);
}

template <typename x_t, typename y_t>
int sum(const x_t &x, const y_t &y) {
  return x + y < mod ? x + y : (x + y - mod);
}

template <typename x_t, typename y_t>
int sub(const x_t &x, const y_t &y) {
  return x < y ? x - y + mod : (x - y);
}

template <typename _Tp>
int div2(const _Tp &x) {
  return ((x & 1) ? x + mod : x) >> 1;
}

// The above are all for avoiding negative values and applying the modulus
template <typename _Tp>
long long sqrll(const _Tp &x) {  // Square function
  return (long long)x * x;
}

int pri[MAXS / 7], lpf[MAXS + 1], spri[MAXS + 1], pcnt;

void sieve(const int &n) {
  for (int i = 2; i <= n; ++i) {
    if (lpf[i] == 0) {  // Record primes
      lpf[i] = ++pcnt;
      pri[lpf[i]] = i;
      spri[pcnt] = sum(spri[pcnt - 1], i);  // Prefix sum
    }
    for (int j = 1, v; j <= lpf[i] && (v = i * pri[j]) <= n; ++j) lpf[v] = j;
  }
}

long long global_n;
int lim;
int le[MAXS + 1],  // x <= \sqrt{n}
    ge[MAXS + 1];  // x > \sqrt{n}
#define idx(v) (v <= lim ? le[v] : ge[global_n / v])

int G[MAXS + 1][2], Fprime[MAXS + 1];
long long lis[MAXS + 1];
int cnt;

void init(const long long &n) {
  for (long long i = 1, j, v; i <= n; i = n / j + 1) {
    j = n / i;
    v = j % mod;
    lis[++cnt] = j;
    (j <= lim ? le[j] : ge[global_n / j]) = cnt;
    G[cnt][0] = sub(v, 1ll);
    G[cnt][1] = div2((long long)(v + 2ll) * (v - 1ll) % mod);
  }
}

void calcFprime() {
  for (int k = 1; k <= pcnt; ++k) {
    const int p = pri[k];
    const long long sqrp = sqrll(p);
    for (int i = 1; lis[i] >= sqrp; ++i) {
      const long long v = lis[i] / p;
      const int id = idx(v);
      dec(G[i][0], sub(G[id][0], k - 1));
      dec(G[i][1], (long long)p * sub(G[id][1], spri[k - 1]) % mod);
    }
  }
  /* F_prime = G_1 - G_0 */
  for (int i = 1; i <= cnt; ++i) Fprime[i] = sub(G[i][1], G[i][0]);
}

int f_p(const int &p, const int &c) {
  /* f(p^{c}) = p xor c */
  return p ^ c;
}

int F(const int &k, const long long &n) {
  if (n < pri[k] || n <= 1) return 0;
  const int id = idx(n);
  long long ans = Fprime[id] - (spri[k - 1] - (k - 1));
  if (k == 1) ans += 2;
  for (int i = k; i <= pcnt && sqrll(pri[i]) <= n; ++i) {
    long long pw = pri[i], pw2 = sqrll(pw);
    for (int c = 1; pw2 <= n; ++c, pw = pw2, pw2 *= pri[i])
      ans +=
          ((long long)f_p(pri[i], c) * F(i + 1, n / pw) + f_p(pri[i], c + 1)) %
          mod;
  }
  return ans % mod;
}

  cin >> global_n;
  lim = sqrt(global_n);  // Upper limit

  sieve(lim + 1000);  // Preprocess
  init(global_n);
  calcFprime();
  cout << (F(1, global_n) + 1ll + mod) % mod << '\n';

  return 0;
}
