    Dirichlet Convolution

    This article introduces Dirichlet convolution and Dirichlet generating functions.

    Dirichlet Convolution

    The Dirichlet convolution of arithmetic functions 𝑓(𝑛)f(n) and 𝑔(𝑛)g(n), denoted 𝑓 ∗𝑔f∗g, is defined as the arithmetic function:

    (𝑓∗𝑔)(𝑛)=∑𝑘∣𝑛𝑓(𝑘)𝑔(𝑛𝑘)=∑𝑘ℓ=𝑛𝑓(𝑘)𝑔(ℓ).(f∗g)(n)=∑k∣nf(k)g(nk)=∑kℓ=nf(k)g(ℓ).

    Dirichlet convolution is an important operation on arithmetic functions. Many properties of arithmetic functions are discovered through this operation.

    Examples

    1. The identity function 𝜀ε is the Dirichlet convolution of the Möbius function 𝜇μ and the constant function 11:

      𝜀=𝜇∗1⟺𝜀(𝑛)=∑𝑑∣𝑛𝜇(𝑑).ε=μ∗1⟺ε(n)=∑d∣nμ(d).

    2. The divisorCount function 𝜏τ is the Dirichlet convolution of the constant function 11 with itself:

      𝜏=1∗1⟺𝜏(𝑛)=∑𝑑∣𝑛1.τ=1∗1⟺τ(n)=∑d∣n1.

    3. The sum-of-divisors function 𝜎σ is the Dirichlet convolution of the identity function idid and the constant function 11:

      𝜎=id∗1⟺𝜎(𝑛)=∑𝑑∣𝑛𝑑.σ=id∗1⟺σ(n)=∑d∣nd.

    4. Euler's totient function 𝜑φ is the Dirichlet convolution of the identity function idid and the Möbius function 𝜇μ:

      𝜑=id∗𝜇⟺𝜑(𝑛)=∑𝑑∣𝑛𝑑⋅𝜇(𝑛𝑑).φ=id∗μ⟺φ(n)=∑d∣nd⋅μ(nd).

    Möbius Inversion uses 𝜀 =𝜇 ∗1ε=μ∗1 to transform arithmetic function identities.

    Properties

    Dirichlet convolution has a series of algebraic properties.

    Theorem

    Let 𝑓,𝑔,ℎf,g,h all be arithmetic functions. Then:

    1. Commutativity: 𝑓 ∗𝑔 =𝑔 ∗𝑓f∗g=g∗f.
    2. Associativity: (𝑓 ∗𝑔) ∗ℎ =𝑓 ∗(𝑔 ∗ℎ)(f∗g)∗h=f∗(g∗h).
    3. Distributivity: (𝑓 +𝑔) ∗ℎ =𝑓 ∗ℎ +𝑔 ∗ℎ(f+g)∗h=f∗h+g∗h.
    4. Identity: 𝑓 ∗𝜀 =𝜀 ∗𝑓 =𝑓f∗ε=ε∗f=f, where 𝜀(𝑛) =[𝑛 =1]ε(n)=[n=1] is the convolution identity, and [ ⋅][⋅] is the Iverson bracket.

    5. Inverse: If and only if 𝑓(1) ≠0f(1)≠0, there exists 𝑔g such that 𝑓 ∗𝑔 =𝑔 ∗𝑓 =𝜀f∗g=g∗f=ε, and 𝑔g is called the Dirichlet inverse of 𝑓f, denoted 𝑓−1f−1. Moreover, the inverse 𝑔g satisfies the recurrence formula:

      𝑔(𝑛)=𝜀(𝑛)−∑𝑘ℓ=𝑛, 𝑘≠1𝑓(𝑘)𝑔(ℓ)𝑓(1).g(n)=ε(n)−∑kℓ=n, k≠1f(k)g(ℓ)f(1).
    Proof

    To verify commutativity, direct computation shows:

    (𝑓∗𝑔)(𝑛)=∑𝑘ℓ=𝑛𝑓(𝑘)𝑔(ℓ)=(𝑔∗𝑓)(𝑛).(f∗g)(n)=∑kℓ=nf(k)g(ℓ)=(g∗f)(n).

    To verify associativity, direct computation shows:

    ((𝑓∗𝑔)∗ℎ)(𝑛)=∑𝑘ℓ𝑚=𝑛𝑓(𝑘)𝑔(ℓ)ℎ(𝑚)=(𝑓∗(𝑔∗ℎ))(𝑛).((f∗g)∗h)(n)=∑kℓm=nf(k)g(ℓ)h(m)=(f∗(g∗h))(n).

    To verify distributivity, direct computation shows:

    ((𝑓+𝑔)∗ℎ)(𝑛)=∑𝑘ℓ=𝑛(𝑓(𝑘)+𝑔(𝑘))ℎ(ℓ)=∑𝑘ℓ=𝑛𝑓(𝑘)ℎ(ℓ)+∑𝑘ℓ=𝑛𝑔(𝑘)ℎ(ℓ)=(𝑓∗ℎ+𝑔∗ℎ)(𝑛).((f+g)∗h)(n)=∑kℓ=n(f(k)+g(k))h(ℓ)=∑kℓ=nf(k)h(ℓ)+∑kℓ=ng(k)h(ℓ)=(f∗h+g∗h)(n).

    To verify 𝜀(𝑛)ε(n) is the identity, direct computation shows:

    (𝑓∗𝜀)(𝑛)=∑𝑘ℓ=𝑛𝑓(𝑘)𝜀(ℓ)=𝑓(𝑛).(f∗ε)(n)=∑kℓ=nf(k)ε(ℓ)=f(n).

    The second equality is because 𝜀(ℓ)ε(ℓ) only takes non-zero value when ℓ =1ℓ=1, i.e., 𝑘 =𝑛k=n.

    Finally, we need to prove that 𝑓−1f−1 exists if and only if 𝑓(1) ≠0f(1)≠0. For any 𝑓f, suppose there exists 𝑔g such that 𝑓 ∗𝑔 =𝜀f∗g=ε. This means:

    (𝑓∗𝑔)(𝑛)=∑𝑘ℓ=𝑛𝑓(𝑘)𝑔(ℓ)=𝜀(𝑛).(f∗g)(n)=∑kℓ=nf(k)g(ℓ)=ε(n).

    This actually gives a series of equations for the values of 𝑔(𝑛)g(n), from which 𝑔(𝑛)g(n) can be directly solved. In particular, when 𝑛 =1n=1, the equation becomes 𝑓(1)𝑔(1) =1f(1)g(1)=1, so for 𝑔g to exist, we require 𝑓(1) ≠0f(1)≠0. And as long as 𝑓(1) ≠0f(1)≠0, we can directly solve:

    𝑔(𝑛)=𝜀(𝑛)−∑𝑘ℓ=𝑛, 𝑘≠1𝑓(𝑘)𝑔(ℓ)𝑓(1).g(n)=ε(n)−∑kℓ=n, k≠1f(k)g(ℓ)f(1).

    It can be used to recursively compute 𝑔(𝑛)g(n). Therefore, the inverse 𝑔g exists if and only if 𝑓(1) ≠0f(1)≠0.

    In abstract algebraic terms, these algebraic properties show that all arithmetic functions form a commutative ring under (pointwise) addition and Dirichlet convolution, and its invertible elements are exactly those functions that take non-zero values at 𝑛 =1n=1. This ring is called the Dirichlet ring.

    Multiplicative functions are a special type of arithmetic function. They are closed under Dirichlet convolution and Dirichlet inverse.

    Theorem

    If 𝑓,𝑔f,g are multiplicative functions, then 𝑓 ∗𝑔f∗g is also a multiplicative function. Moreover, the inverse 𝑓−1f−1 always exists and is also a multiplicative function.

    Proof

    For the first point, let ℎ =𝑓 ∗𝑔h=f∗g. For direct verification, for any 𝑛1 ⟂𝑛2n1⟂n2:

    ℎ(𝑛1)ℎ(𝑛2)=(∑𝑘1ℓ1=𝑛1𝑓(𝑘1)𝑔(ℓ1))(∑𝑘2ℓ2=𝑛2𝑓(𝑘2)𝑔(ℓ2))=∑𝑘1ℓ1=𝑛1, 𝑘2ℓ2=𝑛2𝑓(𝑘1)𝑓(𝑘2)𝑔(ℓ1)𝑔(ℓ2)=∑𝑘ℓ=𝑛1𝑛2𝑓(𝑘)𝑔(ℓ)=ℎ(𝑛1𝑛2).h(n1)h(n2)=(∑k1ℓ1=n1f(k1)g(ℓ1))(∑k2ℓ2=n2f(k2)g(ℓ2))=∑k1ℓ1=n1, k2ℓ2=n2f(k1)f(k2)g(ℓ1)g(ℓ2)=∑kℓ=n1n2f(k)g(ℓ)=h(n1n2).

    Here, the logic of changing the order of summation in the third equality is: when 𝑘k ranges over the divisors of 𝑛1𝑛2n1n2, the prime factors of 𝑘k can be divided into two categories according to whether they are prime factors of 𝑛1n1 or 𝑛2n2. Multiplying the prime factors in each category (counting repetitions) gives 𝑘1k1 and 𝑘2k2, which respectively range over the divisors of 𝑛1n1 and 𝑛2n2; conversely, from the divisors 𝑘1k1 and 𝑘2k2 of 𝑛1n1 and 𝑛2n2, we can always get the divisor 𝑘 =𝑘1𝑘2k=k1k2 of 𝑛1𝑛2n1n2.

    For the second point, let 𝑔 =𝑓−1g=f−1, considering using mathematical induction. First, 𝑔(1) =1/𝑓(1) =1g(1)=1/f(1)=1. At this time, the recurrence formula for the inverse can be written as:

    𝑔(𝑛)=𝜀(𝑛)−∑𝑘ℓ=𝑛, 𝑘≠1𝑓(𝑘)𝑔(ℓ).g(n)=ε(n)−∑kℓ=n, k≠1f(k)g(ℓ).

    So, for 𝑛1 ⟂𝑛2n1⟂n2 and 𝑛1𝑛2 >1n1n2>1:

    𝑔(𝑛1𝑛2)=−∑𝑘ℓ=𝑛1𝑛2, 𝑘≠1𝑓(𝑘)𝑔(ℓ)=−∑𝑘1ℓ1=𝑛1, 𝑘2ℓ2=𝑛2, 𝑘1𝑘2≠1𝑓(𝑘1)𝑓(𝑘2)𝑔(ℓ1)𝑔(ℓ2)=𝑓(1)𝑓(1)𝑔(𝑛1)𝑔(𝑛2)−∑𝑘1ℓ1=𝑛1, 𝑘2ℓ2=𝑛2𝑓(𝑘1)𝑓(𝑘2)𝑔(ℓ1)𝑔(ℓ2)=𝑔(𝑛1)𝑔(𝑛2)−(∑𝑘1ℓ1=𝑛1𝑓(𝑘1)𝑔(ℓ1))(∑𝑘2ℓ2=𝑛2𝑓(𝑘2)𝑔(ℓ2))=𝑔(𝑛1)𝑔(𝑛2)−𝜀(𝑛1)𝜀(𝑛2)=𝑔(𝑛1)𝑔(𝑛2).g(n1n2)=−∑kℓ=n1n2, k≠1f(k)g(ℓ)=−∑k1ℓ1=n1, k2ℓ2=n2, k1k2≠1f(k1)f(k2)g(ℓ1)g(ℓ2)=f(1)f(1)g(n1)g(n2)−∑k1ℓ1=n1, k2ℓ2=n2f(k1)f(k2)g(ℓ1)g(ℓ2)=g(n1)g(n2)−(∑k1ℓ1=n1f(k1)g(ℓ1))(∑k2ℓ2=n2f(k2)g(ℓ2))=g(n1)g(n2)−ε(n1)ε(n2)=g(n1)g(n2).

    Even more special are completely multiplicative functions.

    Theorem

    1. Distributivity: (𝛼𝑓) ∗(𝛼𝑔) =𝛼 ⋅(𝑓 ∗𝑔)(αf)∗(αg)=α⋅(f∗g).

    Dirichlet Generating Functions

    Closely related to Dirichlet convolution are Dirichlet generating functions.

    An arithmetic function 𝑓(𝑛)f(n) — that is, the sequence {𝑓(𝑛)}{f(n)} — corresponds to the Dirichlet generating function (Dirichlet series generating function, DGF), which is defined as a formal Dirichlet series:

    𝐹(𝑠)=∞∑𝑛=1𝑓(𝑛)𝑛𝑠.F(s)=∑n=1∞f(n)ns.

    The 𝑠s in the series is a formal variable. In common Dirichlet generating functions, 𝑠s can often be considered a complex variable, and the analytical properties of Dirichlet series can be discussed, but this goes beyond the scope of competitive programming.

    The product of Dirichlet generating functions corresponds to the Dirichlet convolution of the corresponding arithmetic functions:

    Theorem

    For arithmetic functions 𝑓,𝑔f,g and their Dirichlet generating functions 𝐹,𝐺F,G, the generating function of their Dirichlet convolution 𝑓 ∗𝑔f∗g equals 𝐹 ⋅𝐺F⋅G.

    Proof

    Direct verification:

    𝐹(𝑠)𝐺(𝑠)=(∞∑𝑘=1𝑓(𝑘)𝑘𝑠)(∞∑ℓ=1𝑔(ℓ)ℓ𝑠)=∞∑𝑘=1∞∑ℓ=1𝑓(𝑘)𝑔(ℓ)(𝑘ℓ)𝑠=∞∑𝑛=1∑𝑘ℓ=𝑛𝑓(𝑘)𝑔(ℓ)𝑛𝑠=∞∑𝑛=1(𝑓∗𝑔)(𝑛)𝑛𝑠.F(s)G(s)=(∑k=1∞f(k)ks)(∑ℓ=1∞g(ℓ)ℓs)=∑k=1∞∑ℓ=1∞f(k)g(ℓ)(kℓ)s=∑n=1∞∑kℓ=nf(k)g(ℓ)ns=∑n=1∞(f∗g)(n)ns.

    Using the correspondence between Dirichlet convolution and the product of Dirichlet generating functions, we can understand the properties of Dirichlet convolution from the perspective of Dirichlet generating functions. Since the multiplication of formal Dirichlet series satisfies commutativity, associativity, and distributivity over addition, the Dirichlet convolution of arithmetic functions satisfies the same algebraic properties.

    Euler Product

    The special nature of multiplicative functions is also reflected in Dirichlet generating functions. Since integers have the Fundamental Theorem of Arithmetic, the generating function 𝐹(𝑠)F(s) of a multiplicative function 𝑓(𝑛)f(n) can be written as:

    𝐹(𝑠)=∞∑𝑛=1𝑓(𝑛)𝑛𝑠=∞∑𝑛=1∏𝑝∈𝐏𝑓(𝑝𝑒)𝑝𝑒𝑠=∏𝑝∈𝐏∞∑𝑒=0𝑓(𝑝𝑒)𝑝𝑒𝑠=∏𝑝∈𝐏(1+𝑓(𝑝)𝑝𝑠+𝑓(𝑝2)𝑝2𝑠+𝑓(𝑝3)𝑝3𝑠+⋯).F(s)=∑n=1∞f(n)ns=∑n=1∞∏p∈Pf(pe)pes=∏p∈P∑e=0∞f(pe)pes=∏p∈P(1+f(p)ps+f(p2)p2s+f(p3)p3s+⋯).

    This means that 𝐹(𝑠)F(s) can be decomposed into the product of several 𝐹𝑝(𝑠)Fp(s), and each 𝐹𝑝(𝑠)Fp(s) corresponds to an arithmetic function that only takes non-zero values at powers of 𝑝p. This infinite product is also called the Euler product. If both 𝐹(𝑠)F(s) and 𝐺(𝑠)G(s) can be decomposed in a similar form, then their product is also; mapping this to arithmetic functions, the Dirichlet convolution of multiplicative functions is still a multiplicative function.

    Furthermore, if 𝑓(𝑛)f(n) is also a completely multiplicative function, then 𝑓(𝑝𝑒) =𝑓(𝑝)𝑒f(pe)=f(p)e, and the formula can be further simplified:

    𝐹(𝑠)=∏𝑝∈𝐏∞∑𝑒=0𝑓(𝑝)𝑒𝑝𝑒𝑠=∏𝑝∈𝐏(1−𝑓(𝑝)𝑝𝑠)−1.F(s)=∏p∈P∑e=0∞f(p)epes=∏p∈P(1−f(p)ps)−1.

    Unlike multiplicative functions, the Dirichlet generating function of completely multiplicative functions is not closed under multiplication, so the Dirichlet convolution and Dirichlet inverse of completely multiplicative functions may not be completely multiplicative functions, but they are certainly multiplicative functions.

    Computation of Dirichlet Convolution

    This section discusses the computation of Dirichlet convolution, that is, given the sequences {𝑓(𝑘)}𝑛𝑘=1{f(k)}k=1n and {𝑔(𝑘)}𝑛𝑘=1{g(k)}k=1n, solve for the first several terms {ℎ(𝑘)}𝑛𝑘=1{h(k)}k=1n of the Dirichlet convolution ℎ =𝑓 ∗𝑔h=f∗g. Depending on the properties of the functions involved, the complexity of the algorithm varies.

    General Case

    ℎ(𝑛)=∑𝑘ℓ=𝑛𝑓(𝑘)𝑔(ℓ).h(n)=∑kℓ=nf(k)g(ℓ).

    // Compute the Dirichlet convolution h = f * g.
auto dirichlet_convolute(const std::vector<int>& f, const std::vector<int>& g) {
  int n = f.size() - 1;
  std::vector<int> h(n + 1);
  for (int k = 1; k <= n; ++k) {
    for (int d = 1; k * d <= n; ++d) {
      h[k * d] += f[k] * g[d];
    }
  }
  return h;
}

    Case of Convolution with Multiplicative Functions

    If 𝑔g is a multiplicative function, we can use the Euler product to accelerate the computation of Dirichlet convolution. Computing ℎh is equivalent to computing the coefficients of its Dirichlet generating function 𝐻H. Since:

    𝐻(𝑠)=𝐹(𝑠)𝐺(𝑠)=𝐹(𝑠)∏𝑝∈𝐏𝐺𝑝(𝑠).H(s)=F(s)G(s)=F(s)∏p∈PGp(s).

    𝐺𝑝(𝑠)=∑𝑝𝑘≤𝑛𝑓(𝑝𝑘)𝑝𝑘𝑠=1+𝑓(𝑝)𝑝𝑠+𝑓(𝑝2)𝑝2𝑠+⋯.Gp(s)=∑pk≤nf(pk)pks=1+f(p)ps+f(p2)p2s+⋯.

    // Compute the Dirichlet convolution h = f * g.
// Assume that g is multiplicative.
auto dirichlet_convolute(const std::vector<int>& f, const std::vector<int>& g) {
  int n = f.size() - 1;
  std::vector<int> h(f);
  std::vector<bool> vis(n + 1);
  for (int i = 2; i <= n; ++i) {
    if (vis[i]) continue;
    // Reverse the order for in-place computation.
    for (int k = n / i * i; k; k -= i) {
      vis[k] = true;
      int d = k;
      while (true) {
        d /= i;
        h[k] += h[d] * g[k / d];
        if (d % i) break;
      }
    }
  }
  return h;
}

    // Compute the Dirichlet convolution h = f * g.
// Assume that h is multiplicative.
auto dirichlet_convolute(const std::vector<int>& f, const std::vector<int>& g) {
  int n = f.size() - 1;
  std::vector<int> h(n + 1), primes, rem(n + 1), lpf(n + 1);
  std::vector<bool> vis(n + 1);
  h[1] = 1;
  for (int x = 2; x <= n; ++x) {
    if (!vis[x]) {
      primes.push_back(x);
      rem[x] = 1;
      lpf[x] = x;
    }
    for (int p : primes) {
      if (x * p > n) break;
      vis[x * p] = true;
      rem[x * p] = x % p ? x : rem[x];
      lpf[x * p] = p;
      if (x % p == 0) break;
    }
    if (rem[x] == 1) {  // prime powers.
      for (int k = x; k; k /= lpf[x]) {
        h[x] += f[k] * g[x / k];
      }
    } else {  // other cases.
      h[x] = h[rem[x]] * h[x / rem[x]];
    }
  }
  return h;
}
