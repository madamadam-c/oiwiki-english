    Stern-Brocot Tree and Farey Sequence

    Introduction

    This article introduces data structures for storing reduced fractions and other related concepts. They are closely related to continued fractions, can be used to solve a series of number theory problems in competitive programming, and may appear as the hidden background of certain problems.

    Stern-Brocot Tree

    The Stern-Brocot tree is an elegant structure for maintaining fractions, containing all distinct positive rational numbers. This structure was independently discovered by Moritz Stern in 1858 and Achille Brocot in 1861.

    Construction

    Layer-by-Layer Construction

    The Stern-Brocot tree can be obtained in the process of iteratively constructing the 𝑘k-th order Stern-Brocot sequence. The 00-th order Stern-Brocot sequence consists of two simple fractions:

    01, 10.01, 10.

    Here, 1010 is not technically a rational number; it can be understood as representing ∞∞ in lowest terms.

    In the 𝑘k-th order Stern-Brocot sequence, between two adjacent fractions 𝑎𝑏ab and 𝑐𝑑cd, we insert their mediant1 𝑎+𝑐𝑏+𝑑a+cb+d to obtain the (𝑘 +1)(k+1)-th order Stern-Brocot sequence. Although the definition of mediant itself allows for fraction reduction, in the construction of the Stern-Brocot tree, we only need to directly add the numerators and denominators without worrying about reduction. In this way, we can iteratively construct Stern-Brocot sequences of all orders. The results of the first few iterations are:

    01,11,1001,12,11,21,1001,13,12,23,11,32,21,31,1001,11,1001,12,11,21,1001,13,12,23,11,32,21,31,10

    Connecting the newly added fractions at each iteration into a tree structure gives the Stern-Brocot tree, as shown in the following figure:

    The 𝑘k-th order Stern-Brocot sequence, excluding the left and right endpoints, is the inorder traversal of the Stern-Brocot tree at depth 𝑘 −1k−1.

    Triple Construction

    Another equivalent construction method uses the triple

    (01,11,10)(01,11,10)

    as the root node, and at each node

    (𝑎𝑏,𝑝𝑞,𝑐𝑑)(ab,pq,cd)

    we add respectively

    (𝑎𝑏,𝑎+𝑝𝑏+𝑞,𝑝𝑞), (𝑝𝑞,𝑝+𝑐𝑞+𝑑,𝑐𝑑)(ab,a+pb+q,pq), (pq,p+cq+d,cd)

    as the left and right child nodes, which constructs the entire Stern-Brocot tree. In the triple stored at each node of the Stern-Brocot tree, the actual stored fraction is the middle fraction 𝑝𝑞pq of the triple, while the left and right fractions 𝑎𝑏ab and 𝑐𝑑cd are fractions that appeared earlier. Moreover, considering the first construction method, the fraction 𝑝𝑞pq is obtained precisely by inserting the mediant of 𝑎𝑏ab and 𝑐𝑑cd.

    Matrix Representation and Stern-Brocot Number System

    The triple construction implies that each node on the Stern-Brocot tree corresponds to a matrix

    𝑆=(𝑏𝑑𝑎𝑐).S=(bdac).

    The root node of the Stern-Brocot tree is the identity matrix 𝐼I, and moving to the left child and right child corresponds to multiplying the current matrix on the right by

    𝐿=(1101), 𝑅=(1011)L=(1101), R=(1011)

    respectively. The fraction actually corresponding to each node is 𝑓(𝑆) =𝑎+𝑐𝑏+𝑑f(S)=a+cb+d. Each node's matrix 𝑆S can be written as a product of a series of matrices 𝐿L and 𝑅R, which can also be understood as a string of 𝐿L and 𝑅R representing the path from the root node to it. Representing all positive rational numbers uniquely as such a string can be considered as obtaining a representation of positive rational numbers, hence it is also called the Stern-Brocot number system.

void build(int n, int a = 0, int b = 1, int c = 1, int d = 0, int level = 1) {
  if (level > n) return;  // Only first n layers.
  int x = a + c, y = b + d;
  build(n, a, b, x, y, level + 1);

}

    Properties

    Now we discuss the properties of the Stern-Brocot tree. In short, the Stern-Brocot tree is a binary search tree containing all positive reduced rational fractions. It is also a heap of numerators and denominators, and a Cartesian tree of the pairs formed by denominator and numerator. If we consider the interval formed by the endpoints in the triple construction, the Stern-Brocot tree can also be viewed as a segment tree on [0,∞][0,∞]. These statements can be derived from the following three basic properties:

    Monotonicity

    In the above construction, the fractions at each level are monotonically increasing. This can be proved by induction. Because if 𝑎𝑏 <𝑐𝑑ab<cd, then we must have

    𝑎𝑏<𝑎+𝑐𝑏+𝑑<𝑐𝑑.ab<a+cb+d<cd.

    This can be obtained by clearing denominators in the inequality. The base case is 01 <1001<10, and monotonicity clearly holds.

    Reduced Form

    In the above construction, each fraction is in lowest terms. This also requires inductive proof. In each level of the construction, adjacent fractions 𝑎𝑏ab and 𝑐𝑑cd satisfy

    𝑏𝑐−𝑎𝑑=det⁡(𝑏𝑑𝑎𝑐)=1.bc−ad=det⁡(bdac)=1.

    At the root, this is the identity matrix, which clearly holds. When moving downward, the determinant of the matrices 𝐿L and 𝑅R multiplied are both 11. By properties of determinants, the following also holds at the next level:

    det⁡(𝑏𝑏+𝑑𝑎𝑎+𝑐)=det⁡(𝑏+𝑑𝑑𝑎+𝑐𝑐)=1.det⁡(bb+daa+c)=det⁡(b+dda+cc)=1.

    This is also obvious for the base case 0101 and 1010. Thus, by Bézout's identity, the numerator and denominator of each fraction must be coprime, i.e., all fractions are in lowest terms.

    Completeness

    Finally, we need to show that the Stern-Brocot tree includes all positive reduced fractions. Because the first two properties already show that the Stern-Brocot tree is a binary search tree, and any positive reduced fraction 𝑝𝑞pq must lie between 0101 and 1010. According to the search method on a binary search tree, the only possibility that the binary search tree does not contain 𝑝𝑞pq is that the search process runs infinitely. This is impossible.

    Assume we now know

    𝑎𝑏<𝑝𝑞<𝑐𝑑.ab<pq<cd.

    Then we must have

    𝑏𝑝−𝑎𝑞≥1, 𝑐𝑞−𝑑𝑝≥1.bp−aq≥1, cq−dp≥1.

    Multiplying the two inequalities by (𝑐 +𝑑)(c+d) and (𝑎 +𝑏)(a+b) respectively, we get

    (𝑐+𝑑)(𝑏𝑝−𝑎𝑞)+(𝑎+𝑏)(𝑐𝑞−𝑑𝑝)≥𝑎+𝑏+𝑐+𝑑.(c+d)(bp−aq)+(a+b)(cq−dp)≥a+b+c+d.

    Using the previously established equation 𝑏𝑐 −𝑎𝑑 =1bc−ad=1, we obtain

    𝑝+𝑞≥𝑎+𝑏+𝑐+𝑑.p+q≥a+b+c+d.

    Each time the search goes one level deeper, the right side strictly increases while the left side remains unchanged, so the search must terminate in a finite number of steps.

    Finding a Fraction

    In practical applications of the Stern-Brocot tree, we often need to query the position of a given fraction in the Stern-Brocot tree.

    Naive Algorithm

    Since the Stern-Brocot tree is a binary search tree, we can determine the path from the root to the given fraction by comparing the current fraction with the target fraction. Represent moving to the left child as 𝐿L and moving to the right child as 𝑅R. Each path corresponds to a string of 𝐿L and 𝑅R, which is exactly the representation of the rational number in the Stern-Brocot number system mentioned above. The process of finding the path to a rational number is equivalent to obtaining its representation in the Stern-Brocot number system.

    The implementation of the naive fraction finding algorithm is as follows:

std::string find(int x, int y, int a = 0, int b = 1, int c = 1, int d = 0) {
  int m = a + c, n = b + d;
  if (x == m && y == n) return "";
  if (x * n < y * m) {
    return 'L' + find(x, y, a, b, m, n);
  } else {
    return 'R' + find(x, y, m, n, c, d);
  }
}

def find(x, y, a=0, b=1, c=1, d=0):
    m = a + c
    n = b + d

    The complexity of the algorithm is 𝑂(𝑝 +𝑞)O(p+q), so it is not practical in competitive programming.

    In the Stern-Brocot number system, each positive irrational number corresponds to a unique infinite-length string. The same algorithm can be used to construct this string. Each prefix of this infinite string corresponds to a reduced rational fraction. Arranging these reduced fractions in a sequence, the denominators in the sequence are strictly increasing, and the limit of the sequence is the irrational number. Therefore, the Stern-Brocot tree can be used to find rational approximations of any accuracy for a given irrational number. However, it should be noted that the difference between this rational sequence and the irrational number is not strictly decreasing. For the rigorous theory of rational approximation, refer to the section on Diophantine approximation on the continued fractions page. When using the Stern-Brocot tree to find the best approximation of a real number with denominators not exceeding a certain range, one should compare the distances of the left and right interval endpoints to the real number.

    Fast Algorithm

    The naive fraction finding algorithm is not efficient, but with simple optimization, we can obtain a fast search algorithm with 𝑂(log⁡(𝑝+𝑞))O(log⁡(p+q)) complexity. The key to optimization is to process consecutive 𝐿L and 𝑅R operations together.

    If the fraction 𝑝𝑞pq to be found lies between 𝑎𝑏ab and 𝑐𝑑cd, then when moving to the right 𝑡t times consecutively, the right boundary stays still while the left node moves to 𝑎+𝑡𝑐𝑏+𝑡𝑑a+tcb+td. Conversely, when moving to the left 𝑡t times consecutively, the left boundary stays still while the right node moves to 𝑡𝑎+𝑐𝑡𝑏+𝑑ta+ctb+d. Therefore, we can directly determine the number of moves to the right and left by 𝑎+𝑡𝑐𝑏+𝑡𝑑 <𝑝𝑞a+tcb+td<pq or 𝑝𝑞 <𝑡𝑎+𝑐𝑡𝑏+𝑑pq<ta+ctb+d.     Algorithm Based on Continued Fractions

    For the case where the fraction is known, we can use continued fractions to give a simpler algorithm. Assume the first group of moves is to the right; if not, set the number of first right moves to zero. Alternating between moving right and left, we arrange the positions of each group of moves as follows:

    𝑝0𝑞0, 𝑝1𝑞1, 𝑝2𝑞2, ⋯, 𝑝𝑛−2𝑞𝑛−2, 𝑝𝑛−1𝑞𝑛−1, 𝑝𝑛𝑞𝑛.p0q0, p1q1, p2q2, ⋯, pn−2qn−2, pn−1qn−1, pnqn.

    Here, the even-numbered groups of moves are to the right, thus recording the position of the left endpoint; the odd-numbered groups of moves are to the left, thus recording the position of the right endpoint. Add two more endpoints in front of this sequence:

    𝑝−2𝑞−2=01, 𝑝−1𝑞−1=10.p−2q−2=01, p−1q−1=10.

    Let the number of moves in the 𝑘k-th group be 𝑡𝑘tk. Then, based on the relationship between the number of moves and the endpoint position obtained above, we have

    𝑝𝑘𝑞𝑘=𝑡𝑘𝑝𝑘−1+𝑝𝑘−2𝑡𝑘𝑞𝑘−1+𝑞𝑘−2.pkqk=tkpk−1+pk−2tkqk−1+qk−2.

    According to the recurrence relation of continued fractions, the endpoints

    𝑝𝑘𝑞𝑘=[𝑡0,𝑡1,⋯,𝑡𝑘].pkqk=[t0,t1,⋯,tk].

    The final continued fraction is

    𝑝𝑞=𝑝𝑘+𝑝𝑘−1𝑞𝑘+𝑞𝑘−1=[𝑡0,𝑡1,⋯,𝑡𝑛−1,𝑡𝑛,1].pq=pk+pk−1qk+qk−1=[t0,t1,⋯,tn−1,tn,1].

    Therefore, in the continued fraction representation of the target fraction, excluding the final 1, the preceding terms encode the path from the root to the current node on the Stern-Brocot tree. Among them, the even terms (starting from index 0) are edges to right child nodes, and odd terms are edges to left child nodes.

    The continued fraction representation of a rational number can be obtained by the Euclidean algorithm. Therefore, the complexity of the fraction finding algorithm based on continued fraction representation is 𝑂(log⁡min{𝑝,𝑞})O(log⁡min{p,q}).

    Calkin-Wilf Tree

    Another simpler structure for storing positive rational fractions is the Calkin-Wilf tree. It is usually shown as follows:

    The root node of the tree is 1111. Then, for a fraction 𝑝𝑞pq at a node, its left and right children are 𝑝𝑝+𝑞pp+q and 𝑝+𝑞𝑞p+qq respectively. Similar to the Stern-Brocot tree, every fraction in it is in lowest terms, and each positive reduced fraction appears exactly once.

    Relationship with Continued Fractions

    Unlike the Stern-Brocot tree, the Calkin-Wilf tree is not a binary search tree, so it cannot be used for binary search of rational numbers.

    In the Calkin-Wilf tree, when 𝑝 >𝑞p>q, the parent node of fraction 𝑝𝑞pq is 𝑝−𝑞𝑞p−qq; when 𝑝 <𝑞p<q, it is 𝑝𝑞−𝑝pq−p. For the first case, starting from 𝑝𝑞pq, it is the right child of its parent node, and can move up through the right side of the parent node until the numerator is no longer greater than the denominator. At this point, the fraction stored at the node is 𝑝mod𝑞𝑞pmodqq, and the number of moves in this group is ⌊𝑝𝑞⌋⌊pq⌋. For the second case, it is the left child of its parent node, and can move up through the left side of the parent node until the denominator is no greater than the numerator. At this point, the fraction stored at the node is 𝑝𝑞mod𝑝pqmodp, and the number of moves in this group is ⌊𝑞𝑝⌋⌊qp⌋.

    Using the language of continued fractions, let the current node store the remainder 𝑠𝑘sk of some continued fraction. Then moving up ⌊𝑠𝑘⌋⌊sk⌋ times along the right side of the parent node reaches the fraction 1𝑠𝑘+11sk+1, followed by moving ⌊𝑠𝑘+1⌋⌊sk+1⌋ times along the left side to reach 𝑠𝑘+2sk+2. Therefore, starting from node 𝑠0 =𝑝𝑞s0=pq and moving up to the root 1111, the path is encoded by the continued fraction [𝑡0,𝑡1,⋯,𝑡𝑛,1][t0,t1,⋯,tn,1]: excluding the final 1, the even terms (starting from index 0) represent the number of moves along the right side of the parent node, and the odd terms represent the number of moves along the left side.

    For the node storing fraction 𝑝𝑞 =[𝑡0,𝑡1,⋯,𝑡𝑛,1]pq=[t0,t1,⋯,tn,1], its parent node has the following representation:

    1. When 𝑡0 >0t0>0, its parent node is 𝑝−𝑞𝑞 =[𝑡0 −1,𝑡1,⋯,𝑡𝑛,1]p−qq=[t0−1,t1,⋯,tn,1].
    2. When 𝑡0 =0t0=0 and 𝑡1 >1t1>1, its parent node is 𝑝𝑞−𝑝 =[0,𝑡1 −1,𝑡2,⋯,𝑡𝑛,1]pq−p=[0,t1−1,t2,⋯,tn,1].
    3. When 𝑡0 =0t0=0 and 𝑡1 =1t1=1, its parent node is 𝑝𝑞−𝑝 =[𝑡2,𝑡3,⋯,𝑡𝑛,1]pq−p=[t2,t3,⋯,tn,1].

    Conversely, its child nodes are 𝑝+𝑞𝑞 =[𝑡0 +1,𝑡1,⋯,𝑡𝑛,1]p+qq=[t0+1,t1,⋯,tn,1] and 𝑝𝑝+𝑞 =[0,1,𝑡0,𝑡1,⋯,𝑡𝑛,1]pp+q=[0,1,t0,t1,⋯,tn,1]. For the continued fraction representation of the second child node, when 𝑡0 =0t0=0, it should be understood as [0,1 +𝑡1,⋯,𝑡𝑛,1][0,1+t1,⋯,tn,1].

    Relationship with Stern-Brocot Tree

    Similarly, establishing a connection with continued fractions, the nodes along the path in the Stern-Brocot tree exhibit a recursive relationship of convergent fractions, while the nodes along the path in the Calkin-Wilf tree exhibit a recursive relationship of remainders. The continued fraction representation of the same fraction is fixed, so the encoding of its path from the node to the root on the Calkin-Wilf tree is exactly the same as the encoding of the path from the root to the node on the Stern-Brocot tree. However, because the direction of the path is reversed, although the Stern-Brocot tree and Calkin-Wilf tree store the same fractions at the same level, their positions are different.

    If we perform breadth-first search on both trees and number the nodes sequentially, with the root node numbered as 11, then for a node numbered 𝑣v, its left and right children are 2𝑣2v and 2𝑣 +12v+1 respectively. From the binary representation of the number, excluding the leading 11, each 11 from high to low represents moving to a right child, and each 00 represents moving to a left child. On the Calkin-Wilf tree, the rational number represented by continued fraction [𝑡0,𝑡1,⋯,𝑡𝑛,1][t0,t1,⋯,tn,1] is at the node numbered

    1⋯0⋯0⏟𝑡31⋯1⏟𝑡20⋯0⏟𝑡11⋯1⏟𝑡0.1⋯0⋯0⏟t31⋯1⏟t20⋯0⏟t11⋯1⏟t0.

    Correspondingly, on the Stern-Brocot tree, the rational number represented by continued fraction [𝑡0,𝑡1,⋯,𝑡𝑛,1][t0,t1,⋯,tn,1] is at the node numbered

    11⋯1⏟𝑡00⋯0⏟𝑡11⋯1⏟𝑡20⋯0⏟𝑡3⋯.11⋯1⏟t00⋯0⏟t11⋯1⏟t20⋯0⏟t3⋯.

    Removing the initial 11, the remaining binary digits form the number of vertices at the same level from left to right (starting from 00). This derivation shows that the arrangement of fractions at the same level in the Stern-Brocot tree and Calkin-Wilf tree are bit-reversal permutations of each other.

    This is why nodes on the Stern-Brocot tree are sometimes numbered according to their corresponding Calkin-Wilf tree node numbers, as shown in the following figure:

    This numbering can be constructed recursively: the root node is numbered 11. Each time we move to a left child, we replace the leading 11 of the number with 1010, and when moving to a right child, we replace the leading 11 with 1111. Reading this number from right to left gives the path from the root to that node.

    Stern's Diatomic Sequence

    Arranging all fractions in the Calkin-Wilf tree according to the breadth-first search numbering, or arranging all fractions in the Stern-Brocot tree according to the numbering shown in the figure above, we obtain the following sequence:

    11, 12, 21, 13, 32, 23, 31, 14, 43, 35, 52,⋯.11, 12, 21, 13, 32, 23, 31, 14, 43, 35, 52,⋯.

    Using the construction process of the Calkin-Wilf tree, it can be proved that in this sequence, for any two adjacent fractions, the denominator of the first equals the numerator of the second. Extracting the numerators gives the Stern's diatomic sequence (Stern diatomic sequence, OEIS A002487), also called the Stern-Brocot sequence. The sequence numbering starts from 11, with the 0th term specified as 00.

    Let 𝑎𝑛an be the 𝑛n-th number in the Stern's diatomic sequence. Then it satisfies the following recurrence:

    𝑎2𝑛=𝑎𝑛,𝑎2𝑛+1=𝑎𝑛+𝑎𝑛+1.a2n=an,a2n+1=an+an+1.

    The recurrence starts with 𝑎0 =0a0=0 and 𝑎1 =1a1=1. To find the value of 𝑎𝑛an in the Stern's diatomic sequence, directly using the recurrence gives 𝑂(log2⁡𝑛)O(log2⁡n) complexity, which is not good. A better approach is to treat it as the numerator of the fraction numbered 𝑛n on the Calkin-Wilf tree, and use the continued fraction based recurrence relationship described above to solve it with 𝑂(log⁡𝑛)O(log⁡n) complexity.

    Farey Sequence

    The Farey sequence has extremely similar characteristics to the Stern-Brocot tree. Denote the 𝑛n-th order Farey sequence (Farey sequence of order 𝑛n) as 𝐹𝑛Fn. It represents the sequence of all reduced fractions with denominator not exceeding 𝑛n in the interval [0,1][0,1], arranged in increasing order:

    𝐹1={01,11}𝐹2={01,12,11}𝐹3={01,13,12,23,11}𝐹4={01,14,13,12,23,34,11}𝐹5={01,15,14,13,25,12,35,23,34,45,11}F1={01,11}F2={01,12,11}F3={01,13,12,23,11}F4={01,14,13,12,23,34,11}F5={01,15,14,13,25,12,35,23,34,45,11}

    By the definition of the Farey sequence, it naturally satisfies monotonicity, reduced form, and completeness. As shown in the figure, the fractions newly added to 𝐹𝑘Fk compared to 𝐹𝑘−1Fk−1 are always the mediants of adjacent fractions in 𝐹𝑘−1Fk−1.

    The algorithm for constructing the Stern-Brocot tree above can also be used to construct the Farey sequence. Since the Stern-Brocot tree contains all reduced fractions, we can obtain code for constructing the Farey sequence by simply modifying the boundary condition to the restriction on denominators. The 𝑛n-th order Farey sequence 𝐹𝑛Fn can be viewed as a subsequence of the (𝑛 −1)(n−1)-th order Stern-Brocot sequence.

    Sequence Length and Fraction Finding

    The length of the Farey sequence can be found recursively. Compared to 𝐹𝑛−1Fn−1, the additional fractions in 𝐹𝑛Fn all have denominator 𝑛n, and the numerator does not exceed 𝑛n and is coprime with 𝑛n. Therefore:

    |𝐹𝑛|=|𝐹𝑛−1|+𝜑(𝑛)=1+𝑛∑𝑘=1𝜑(𝑘).|Fn|=|Fn−1|+φ(n)=1+∑k=1nφ(k).

    More commonly than directly finding the sequence length is finding the index of a fraction 𝑟 =𝑝𝑞r=pq in the sequence 𝐹𝑘Fk. This is equivalent to computing

    1+𝑛∑𝑘=1⌊𝑟𝑘⌋∑𝑖=1[𝑖⟂𝑘]=1+𝑛∑𝑑=1𝜇(𝑑)⌊𝑛/𝑑⌋∑𝑗=1⌊𝑟𝑗⌋.1+∑k=1n∑i=1⌊rk⌋[i⟂k]=1+∑d=1nμ(d)∑j=1⌊n/d⌋⌊rj⌋.

    To obtain the right-hand side, we used Möbius inversion. Combining linear sieve and enumerating factors can achieve 𝑂(𝑛)O(n) preprocessing and 𝑂(𝑛log⁡𝑛)O(nlog⁡n) queries. Combining the Du Jiao sieve with the generalized Euclidean algorithm can achieve 𝑂(𝑛2/3)O(n2/3) preprocessing and 𝑂(√𝑛log⁡𝑛)O(nlog⁡n) queries.

    Conversely, to find the fraction given an index, we can perform binary search on real numbers in [0,1][0,1], or perform binary search on the Stern-Brocot tree. The former may be limited by floating-point precision, with 𝑂(log⁡𝑉)O(log⁡V) queries where 𝑉V is the precision range. The latter is not limited by floating-point precision, but requires 𝑂(log2⁡𝑛)O(log2⁡n) queries.

    Farey Neighbors

    If fractions 𝑎𝑏ab and 𝑐𝑑cd are adjacent in some Farey sequence, they are called Farey neighbors (Farey neighbors), also known as a Farey pair (Farey pair).

    Let 𝑎𝑏 <𝑐𝑑ab<cd. From the construction process of the Farey sequence, the fraction added later among two adjacent fractions must be the mediant of the other fraction and its previous neighbor. Therefore, Farey neighbors are also adjacent in some order of the Stern-Brocot sequence. According to the property proved in Reduced form, we must also have

    𝑏𝑐−𝑎𝑑=1.bc−ad=1.

    Conversely, this is also a sufficient condition for two reduced proper fractions to become Farey neighbors. We now explain this. Let 𝑎𝑏ab be the fraction with the larger denominator among the two. Then both fractions appear in 𝐹𝑏Fb. Let 𝑒𝑓ef be the fraction to the right of 𝑎𝑏ab in 𝐹𝑏Fb. According to the necessity we have shown, 𝑏𝑒 −𝑎𝑓 =1be−af=1. However, the linear congruence equation 𝑏𝑥 −𝑎𝑦 =1bx−ay=1 has only one positive integer solution with 𝑦 ≤𝑏y≤b. Therefore, (𝑒,𝑓) =(𝑐,𝑑)(e,f)=(c,d).

    In fact, because the next reduced fraction that will appear between them is 𝑎+𝑐𝑏+𝑑a+cb+d, both 𝑎𝑏ab and 𝑐𝑑cd are adjacent in the Farey sequences from order max{𝑏,𝑑}max{b,d} to order (𝑏 +𝑑 −1)(b+d−1).

    Recurrence Relation

    The Farey sequence has a simple recurrence relation, which can be used to sequentially find all fractions of the 𝑛n-th order Farey sequence from left to right.

    First, the analysis above points out that in 𝐹𝑛Fn, the newly added term 𝑝𝑛pn is always the mediant of the left and right adjacent fractions. In fact, this relationship holds for all fractions in 𝐹𝑛Fn (except the endpoints). Let 𝑎𝑏 <𝑝𝑞 <𝑐𝑑ab<pq<cd. According to the necessary and sufficient condition for Farey neighbors, we always have

    𝑏𝑝−𝑎𝑞=1=𝑐𝑞−𝑑𝑝⟺𝑝𝑞=𝑎+𝑐𝑏+𝑑.bp−aq=1=cq−dp⟺pq=a+cb+d.

    However, for the general case, the fraction 𝑎+𝑐𝑏+𝑑a+cb+d may need reduction.

    Using this observation, we can construct the following recurrence relation. Let 𝑎𝑏ab and 𝑝𝑞pq be known. We want to find the value of the third fraction 𝑐𝑑cd. At this point, there exists 𝑘k such that

    𝑎+𝑐=𝑘𝑝, 𝑏+𝑑=𝑘𝑞a+c=kp, b+d=kq

    holds. Because the difference

    𝑘𝑝−𝑎𝑘𝑞−𝑏−𝑝𝑞=𝑏𝑝−𝑎𝑞𝑞(𝑘𝑞−𝑏)=1𝑞(𝑘𝑞−𝑏)kp−akq−b−pq=bp−aqq(kq−b)=1q(kq−b)

    decreases as 𝑘k increases, and the fraction closest to 𝑝𝑞pq should be the one with the smallest difference among all fractions satisfying 𝑘𝑞 −𝑑 ≤𝑛kq−d≤n. Thus we must have

    𝑘=⌊𝑛+𝑏𝑞⌋.k=⌊n+bq⌋.

    It can be verified that the fraction obtained in this way is indeed in 𝐹𝑛Fn. Therefore, the numerators and denominators of fractions in 𝐹𝑛Fn satisfy the recurrence relation:

    𝑝𝑘=⌊𝑛+𝑞𝑘−2𝑞𝑘−1⌋𝑝𝑘−1−𝑝𝑘−2,𝑞𝑘=⌊𝑛+𝑞𝑘−2𝑞𝑘−1⌋𝑞𝑘−1−𝑞𝑘−2.pk=⌊n+qk−2qk−1⌋pk−1−pk−2,qk=⌊n+qk−2qk−1⌋qk−1−qk−2.

    The recurrence starts with (𝑝0,𝑞0) =(0,1)(p0,q0)=(0,1) and (𝑝1,𝑞1) =(1,𝑛)(p1,q1)=(1,n).
