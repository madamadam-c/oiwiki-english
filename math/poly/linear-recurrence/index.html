    Constant-coefficient Homogeneous Linear Recurrences

    Introduction

    Constant-coefficient homogeneous linear recurrence sequences (also called C-finite or C-recursive sequences) are a common type of fundamental recurrence sequences.

    For a sequence (𝑎𝑗)𝑗≥0(aj)j≥0 and its recurrence relation

    𝑎𝑛=𝑑∑𝑗=1𝑐𝑗𝑎𝑛−𝑗,(𝑛≥𝑑)an=∑j=1dcjan−j,(n≥d)

    where not all 𝑐𝑗cj are zero, our goal is to compute 𝑎𝑘ak given the initial values 𝑎0,…,𝑎𝑑−1a0,…,ad−1 and the coefficients 𝑐1,…,𝑐𝑑c1,…,cd from the recurrence relation. If 𝑘 ≫𝑑k≫d, we want a faster algorithm.

    Here (𝑎𝑗)𝑗≥0(aj)j≥0 is called a 𝑑d-order constant-coefficient homogeneous linear recurrence sequence.

    Represented as Rational Functions

    For the sequence (𝑎𝑗)𝑗≥0(aj)j≥0 above, there always exists a rational function

    Bostan–Mori Algorithm

    Computing a Single Term

    Our goal remains: given the polynomials 𝑃(𝑥),𝑄(𝑥)P(x),Q(x) above, compute [𝑥𝑘]𝑃(𝑥)𝑄(𝑥)[xk]P(x)Q(x).

    The Bostan–Mori algorithm is based on Graeffe iteration. For the polynomials 𝑃(𝑥),𝑄(𝑥)P(x),Q(x) above, we have

    𝑃(𝑥)𝑄(𝑥)=𝑃(𝑥)𝑄(−𝑥)𝑄(𝑥)𝑄(−𝑥)=𝑈0(𝑥2)+𝑥𝑈1(𝑥2)𝑉(𝑥2)P(x)Q(x)=P(x)Q(−x)Q(x)Q(−x)=U0(x2)+xU1(x2)V(x2)

    Since the denominator 𝑉(𝑥2)V(x2) is an even function, the subproblem only needs to consider one side

    [𝑥𝑘]𝑃(𝑥)𝑄(𝑥)=[𝑥⌊𝑘/2⌋]𝑈𝑘mod2(𝑥)𝑉(𝑥)[xk]P(x)Q(x)=[x⌊k/2⌋]Ukmod2(x)V(x)

    We pay the cost of two polynomial multiplications to reduce the problem to at least half its original size, and when 𝑘 =0k=0, we clearly have [𝑥0]𝑃(𝑥)𝑄(𝑥) =𝑃(0)𝑄(0)[x0]P(x)Q(x)=P(0)Q(0), with the same time complexity.

    Computing Several Consecutive Terms

    The goal is: given the polynomials 𝑃(𝑥),𝑄(𝑥)P(x),Q(x) above, compute [𝑥[𝐿,𝑅)]𝑃(𝑥)𝑄(𝑥)[x[L,R)]P(x)Q(x). In the following computation, we only need to consider coefficients that "affect" the answer—this is the key to the Bostan–Mori algorithm.

    Assume deg⁡𝑃 <deg⁡𝑄deg⁡P<deg⁡Q, otherwise we can perform one division to return to this case.

    We first consider the simpler problem:

    [𝑥[𝐿,𝑅)]1𝑄(𝑥)=[𝑥[𝐿,𝑅)]1𝑄(𝑥)𝑄(−𝑥)⋅𝑄(−𝑥)[x[L,R)]1Q(x)=[x[L,R)]1Q(x)Q(−x)⋅Q(−x)
