    Polynomial Shift and Consecutive-point Value Shift

    Polynomial Shift

    Polynomial shift is a simple case of polynomial composition transformation. Given the coefficients of 𝑓(𝑥) =∑𝑛𝑖=0𝑓𝑖𝑥𝑖f(x)=∑i=0nfixi and a constant 𝑐c, find the coefficients of 𝑓(𝑥 +𝑐)f(x+c), i.e., 𝑓(𝑥) ↦𝑓(𝑥 +𝑐)f(x)↦f(x+c).

    Divide-and-Conquer Method

    Let:

    𝑓(𝑥)=𝑓0(𝑥)+𝑥⌊𝑛/2⌋𝑓1(𝑥)f(x)=f0(x)+x⌊n/2⌋f1(x)

    Then:

    𝑓(𝑥+𝑐)=𝑓0(𝑥+𝑐)+(𝑥+𝑐)⌊𝑛/2⌋𝑓1(𝑥+𝑐)f(x+c)=f0(x+c)+(x+c)⌊n/2⌋f1(x+c)

    The coefficients of (𝑥 +𝑐)⌊𝑛/2⌋(x+c)⌊n/2⌋ are binomial coefficients, so:

    𝑇(𝑛)=2𝑇(𝑛/2)+𝑂(𝑛log⁡𝑛)=𝑂(𝑛log2⁡𝑛)T(n)=2T(n/2)+O(nlog⁡n)=O(nlog2⁡n)

    Where 𝑂(𝑛log⁡𝑛)O(nlog⁡n) is the time for polynomial multiplication.

    Then:

    𝑓(𝑥+𝑐)=𝑓(𝑐)+𝑓′(𝑐)1!𝑥+𝑓″(𝑐)2!𝑥2+⋯+𝑓(𝑛)(𝑐)𝑛!𝑥𝑛f(x+c)=f(c)+f′(c)1!x+f″(c)2!x2+⋯+f(n)(c)n!xn

    Continuous Point Value Shift

    Problem LOJ 166 Lagrange Interpolation 2

    Given the consecutive point values 𝑓(0),𝑓(1),…,𝑓(𝑛)f(0),f(1),…,f(n) of a polynomial 𝑓f with degree ≤𝑛≤n, compute 𝑓(𝑐),𝑓(𝑐 +1),…,𝑓(𝑐 +𝑛)f(c),f(c+1),…,f(c+n) modulo 998244353998244353, where 1 ≤𝑛 ≤105,𝑛 <𝑚 ≤1081≤n≤105,n<m≤108.

    Lagrange Interpolation Formula Method

    Consider the Lagrange Interpolation Formula:

    𝑓(𝑥)=∑0≤𝑖≤𝑛𝑓(𝑖)∏0≤𝑗≤𝑛∧𝑗≠𝑖𝑥−𝑗𝑖−𝑗=∑0≤𝑖≤𝑛𝑓(𝑖)𝑥!(𝑥−𝑛−1)!(𝑥−𝑖)(−1)𝑛−𝑖𝑖!(𝑛−𝑖)!=𝑥!(𝑥−𝑛−1)!∑0≤𝑖≤𝑛𝑓(𝑖)(𝑥−𝑖)(−1)𝑛−𝑖𝑖!(𝑛−𝑖)!f(x)=∑0≤i≤nf(i)∏0≤j≤n∧j≠ix−ji−j=∑0≤i≤nf(i)x!(x−n−1)!(x−i)(−1)n−ii!(n−i)!=x!(x−n−1)!∑0≤i≤nf(i)(x−i)(−1)n−ii!(n−i)!

    The above is in convolution form but cannot guarantee 𝑥 −𝑖 ≠0x−i≠0 in the denominator. So below we only consider the case 𝑐 >𝑛c>n; other cases (like avoiding zeros in denominators when coefficients are under modulo prime) can be discussed case by case. Let:

    𝐴0(𝑥)=∑0≤𝑖≤𝑛𝑓(𝑖)(−1)𝑛−𝑖𝑖!(𝑛−𝑖)!𝑥𝑖𝐵0(𝑥)=∑𝑖≥01𝑐−𝑛+𝑖𝑥𝑖A0(x)=∑0≤i≤nf(i)(−1)n−ii!(n−i)!xiB0(x)=∑i≥01c−n+ixi

    Then for 𝑡 ≥0t≥0:

    [𝑥𝑛+𝑡](𝐴0(𝑥)𝐵0(𝑥))=𝑛+𝑡∑𝑖=0([𝑥𝑖]𝐴0(𝑥))([𝑥𝑛+𝑡−𝑖]𝐵0(𝑥))=𝑛∑𝑖=0𝑓(𝑖)(−1)𝑛−𝑖𝑖!(𝑛−𝑖)!1𝑐+𝑡−𝑖=(𝑐+𝑡−𝑛−1)!(𝑐+𝑡)!𝑓(𝑐+𝑡)[xn+t](A0(x)B0(x))=∑i=0n+t([xi]A0(x))([xn+t−i]B0(x))=∑i=0nf(i)(−1)n−ii!(n−i)!1c+t−i=(c+t−n−1)!(c+t)!f(c+t)

    In implementation, taking the required part of 𝐵0(𝑥)B0(x) by truncation can compute more point values, and cyclic convolution can be used.

    With a slight modification to the problem, if for some 𝑑d we are given point values 𝑓(𝑑),𝑓(𝑑 +𝑘),…,𝑓(𝑑 +𝑛𝑘)f(d),f(d+k),…,f(d+nk), we can compute 𝑓(𝑐 +𝑑),𝑓(𝑐 +𝑑 +𝑘),…,𝑓(𝑐 +𝑑 +𝑛𝑘)f(c+d),f(c+d+k),…,f(c+d+nk). This can be viewed as shifting the point values of 𝑔(𝑥) =𝑓(𝑑 +𝑘𝑥)g(x)=f(d+kx) from 𝑔(0),𝑔(1),…,𝑔(𝑛)g(0),g(1),…,g(n) to 𝑔(𝑐/𝑘),𝑔(𝑐/𝑘 +1),…,𝑔(𝑐/𝑘 +𝑛)g(c/k),g(c/k+1),…,g(c/k+n).

    The Lagrange interpolation formula also provides a linear-time method for computing a single point value by maintaining some prefix and suffix products.

    Unsigned Stirling Numbers of the First Kind on the Same Row

    Problem P5408 Stirling Numbers of the First Kind Row

    Find [𝑛0],[𝑛1],…,[𝑛𝑛][n0],[n1],…,[nn] modulo prime 167772161167772161, where 1 ≤𝑛 <2621441≤n<262144.

    Consider:

    𝑥――𝑛=𝑛∑𝑖=0[𝑛𝑖]𝑥𝑖,𝑛≥0xn―=∑i=0n[ni]xi,n≥0
