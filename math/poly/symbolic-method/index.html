    Symbolic Method

    The symbolic method is a technique for quickly converting combinatorial objects into generating functions. We will consider specific operations defined on sets and derive the corresponding operations on generating functions.

    We call a combinatorial class (or simply class) (A,| ⋅|)(A,|⋅|), where AA is the set of combinatorial objects, and the function | ⋅||⋅| maps each combinatorial object to a non-negative integer, generally called the size function. Note that this non-negative integer cannot be infinite. For example, for strings with alphabet {0,1}{0,1}, we can set the length of the string as its size function; for trees or graphs, we can set the number of nodes as the size function. Note that this is not absolute—some specific nodes may have size function set to 00, etc.

    This article is a simplification based on Chapter 1 of Analytic Combinatorics.

    Unlabeled System

    In the unlabeled system, we use ordinary generating functions (OGF). For a set AA, its corresponding OGF is denoted as

    𝐴(𝑧)=∑𝛼∈A𝑧|𝛼|=∑𝑛≥0𝑎𝑛𝑧𝑛A(z)=∑α∈Az|α|=∑n≥0anzn

    We agree to use the same group of letters to represent the generating function of the same class, for example, using 𝑎𝑛an to denote [𝑧𝑛]𝐴(𝑧)[zn]A(z), i.e., the coefficient of 𝑧𝑛zn in 𝐴(𝑧)A(z), and using A𝑛An to denote the set of objects in AA with size function 𝑛n (so 𝑎𝑛 =card⁡(A𝑛)an=card⁡(An) where cardcard is cardinality).

    This article will not discuss admissibility; readers can refer to the literature for content.

    Next, we introduce two special combinatorial classes and objects:

    • Let 𝜖ϵ be a neutral object and E ={𝜖}E={ϵ} be a neutral class. The neutral object has size 00, and the OGF of the neutral class is 𝐸(𝑧) =1E(z)=1.
    • Let ∘∘ or ∙∙ be an atom object and Z∘ ={ ∘}Z∘={∘} or Z∙ ={ ∙}Z∙={∙} (or simply ZZ) be an atom class. The atom object has size 11, and the OGF of the atom class is 𝑍(𝑧) =𝑧Z(z)=z.

    For two combinatorial classes AA and BB, we denote combinatorial isomorphism as A =BA=B or A ≅BA≅B, but we only use the latter notation when the isomorphism is non-trivial.

    We have

    A≅E×A≅A×EA≅E×A≅A×E

    where ×× is a binary operation representing the Cartesian product of sets.

    Set (Disjoint) Union Construction

    For the union of classes AA and BB, we denote

    A+B=(E1×A)+(E2×B)A+B=(E1×A)+(E2×B)

    This definition avoids violating the requirement of disjoint sets in set theory. We can imagine coloring the objects in AA red and the objects in BB blue.

    The corresponding OGF is

    𝐴(𝑧)+𝐵(𝑧)A(z)+B(z)

    Consider

    𝐴(𝑧)+𝐵(𝑧)=∑𝛼∈A𝑧|𝛼|+∑𝛽∈B𝑧|𝛽|=∑𝑛≥0(𝑎𝑛+𝑏𝑛)𝑧𝑛A(z)+B(z)=∑α∈Az|α|+∑β∈Bz|β|=∑n≥0(an+bn)zn

    Corresponding to addition of formal power series.

    Set Cartesian Product Construction

    For the Cartesian product of classes AA and BB, we denote

    A×B={(𝛼,𝛽)∣𝛼∈A,𝛽∈B}A×B={(α,β)∣α∈A,β∈B}

    The corresponding OGF is

    𝐴(𝑧)⋅𝐵(𝑧)A(z)⋅B(z)

    We define the size of (𝛼,𝛽)(α,β) as the sum of the sizes of its components. Then we also have

    𝛾=(𝛼1,𝛼2,…,𝛼𝑛)⟹|𝛾|=|𝛼1|+|𝛼2|+⋯+|𝛼𝑛|γ=(α1,α2,…,αn)⟹|γ|=|α1|+|α2|+⋯+|αn|

    So

    𝐴(𝑧)⋅𝐵(𝑧)=(∑𝛼∈A𝑧|𝛼|)(∑𝛽∈B𝑧|𝛽|)=∑(𝛼,𝛽)∈(A×B)𝑧|𝛼|+|𝛽|=∑𝑛≥0∑𝑖+𝑗=𝑛𝑎𝑖𝑏𝑗𝑧𝑛A(z)⋅B(z)=(∑α∈Az|α|)(∑β∈Bz|β|)=∑(α,β)∈(A×B)z|α|+|β|=∑n≥0∑i+j=naibjzn

    Corresponding to multiplication of formal power series.

    Set Sequence Construction

    The Sequence construction generates all possible combinations.

    Example SEQ⁡({𝑎})={𝜖}+{𝑎}+{(𝑎,𝑎)}+{(𝑎,𝑎,𝑎)}+⋯SEQ⁡({𝑎,𝑏})={𝜖}+{𝑎,𝑏}+{(𝑎,𝑏)}+{(𝑏,𝑎)}+{(𝑎,𝑎)}+{(𝑏,𝑏)}+{(𝑎,𝑏,𝑎)}+{(𝑎,𝑏,𝑏)}+{(𝑎,𝑎,𝑏)}+{(𝑏,𝑏,𝑎)}+{(𝑏,𝑎,𝑏)}+{(𝑏,𝑏,𝑏)}+{(𝑎,𝑎,𝑎)}+{(𝑏,𝑎,𝑎)}+⋯SEQ⁡({a})={ϵ}+{a}+{(a,a)}+{(a,a,a)}+⋯SEQ⁡({a,b})={ϵ}+{a,b}+{(a,b)}+{(b,a)}+{(a,a)}+{(b,b)}+{(a,b,a)}+{(a,b,b)}+{(a,a,b)}+{(b,b,a)}+{(b,a,b)}+{(b,b,b)}+{(a,a,a)}+{(b,a,a)}+⋯

    We can see that elements with different orders of components like {(𝑎,𝑏)},{(𝑏,𝑎)}{(a,b)},{(b,a)} are generated. The Sequence construction generates ordered combinations.

    We define

    SEQ⁡(A)=E+A+(A×A)+(A×A×A)+⋯SEQ⁡(A)=E+A+(A×A)+(A×A×A)+⋯

    And require A0 =∅A0=∅, i.e., there are no objects of size 00 in AA.

    The corresponding OGF is

    𝑄(𝐴(𝑧))=1+𝐴(𝑧)+𝐴(𝑧)2+𝐴(𝑧)3+⋯=11−𝐴(𝑧)Q(A(z))=1+A(z)+A(z)2+A(z)3+⋯=11−A(z)

    Where 𝑄Q is Pólya's quasi-inversion.

    Example: Ordered Rooted Tree

    We can use the Sequence construction to define ordered rooted trees, i.e., rooted trees where the order among children is significant. Let this combinatorial class be TT. A tree consists of a root node and a Sequence of trees:

    T={∙}×SEQ⁡(T)T={∙}×SEQ⁡(T)

    The corresponding OGF is

    𝑇(𝑧)=𝑧1−𝑇(𝑧)T(z)=z1−T(z)

    The first few coefficients are 0 1 1 2 5 14 42 132 429 1430 4862 16796. Ignoring the constant term, this is OEIS A000108.

    Set Multiset Construction

    The Multiset construction generates all possible combinations but does not distinguish the order among elements in a component.

    Example MSET⁡({𝑎})={𝜖}+{𝑎}+{(𝑎,𝑎)}+{(𝑎,𝑎,𝑎)}+⋯MSET⁡({𝑎,𝑏})={𝜖}+{𝑎}+{(𝑎,𝑎)}+{(𝑎,𝑎,𝑎)}+⋯+{𝑏}+{(𝑎,𝑏)}+{(𝑎,𝑎,𝑏)}+⋯+{(𝑏,𝑏)}+{(𝑎,𝑏,𝑏)}+{(𝑎,𝑎,𝑏,𝑏)}+⋯+⋯MSET⁡({a})={ϵ}+{a}+{(a,a)}+{(a,a,a)}+⋯MSET⁡({a,b})={ϵ}+{a}+{(a,a)}+{(a,a,a)}+⋯+{b}+{(a,b)}+{(a,a,b)}+⋯+{(b,b)}+{(a,b,b)}+{(a,a,b,b)}+⋯+⋯

    Note that {(𝑏,𝑎)},{(𝑎,𝑏,𝑎)}{(b,a)},{(a,b,a)} appear in SEQ⁡({𝑎,𝑏})SEQ⁡({a,b}) but not in MSET⁡({𝑎,𝑏})MSET⁡({a,b}). We can consider that Multiset generates unordered combinations.

    We define its recursive formula as

    MSET⁡({𝛼0,𝛼1,…,𝛼𝑛})=MSET⁡({𝛼0,𝛼1,…,𝛼𝑛−1})×SEQ⁡({𝛼𝑛})MSET⁡({α0,α1,…,αn})=MSET⁡({α0,α1,…,αn−1})×SEQ⁡({αn})

    That is

    MSET⁡(A)=∏𝛼∈ASEQ⁡({𝛼})MSET⁡(A)=∏α∈ASEQ⁡({α})

    And require A0 =∅A0=∅. Alternatively, we can give the equivalent

    MSET⁡(A)=SEQ⁡(A)/𝐑MSET⁡(A)=SEQ⁡(A)/R

    Where 𝐑R is an equivalence relation. We say (𝛼1,…,𝛼𝑛)𝐑(𝛽1,…,𝛽𝑛)(α1,…,αn)R(β1,…,βn) if and only if there exists a permutation 𝜎σ such that 𝛽𝑗 =𝛼𝜎(𝑗)βj=ασ(j) for all 𝑗j.

    The corresponding OGF is

    Exp⁡(𝐴(𝑧))=∏𝛼∈A(1−𝑧|𝛼|)−1=∏𝑛≥1(1−𝑧𝑛)−𝑎𝑛Exp⁡(A(z))=∏α∈A(1−z|α|)−1=∏n≥1(1−zn)−an

    Note that

    ln⁡(1+𝑧)=𝑧1−𝑧22+𝑧33−⋯=∑𝑛≥1(−1)𝑛−1𝑧𝑛𝑛ln⁡(1+z)=z1−z22+z33−⋯=∑n≥1(−1)n−1znn

    And 𝐴(𝑧) =exp⁡(ln⁡(𝐴(𝑧)))A(z)=exp⁡(ln⁡(A(z))), so

    Exp⁡(𝐴(𝑧))=exp⁡(∑𝑛≥1−𝑎𝑛⋅ln⁡(1−𝑧𝑛))=exp⁡(∑𝑛≥1−𝑎𝑛⋅∑𝑚≥1−𝑧𝑛𝑚𝑚)=exp⁡(𝐴(𝑧)1+𝐴(𝑧2)2+𝐴(𝑧3)3+⋯)Exp⁡(A(z))=exp⁡(∑n≥1−an⋅ln⁡(1−zn))=exp⁡(∑n≥1−an⋅∑m≥1−znmm)=exp⁡(A(z)1+A(z2)2+A(z3)3+⋯)

    Here, ExpExp is Pólya's exponentiation operator, also known as the Euler transform.
