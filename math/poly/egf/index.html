    Exponential Generating Functions

    The exponential generating function (EGF) of a sequence 𝑎a is defined as a formal power series:

    ˆ𝐹(𝑥)=∑𝑛𝑎𝑛𝑥𝑛𝑛!F^(x)=∑nanxnn!

    Basic Operations

    The addition and subtraction of exponential generating functions are the same as those of ordinary generating functions—adding corresponding coefficients.

    Consider multiplication of exponential generating functions. For two sequences 𝑎,𝑏a,b, with their exponential generating functions ˆ𝐹(𝑥),ˆ𝐺(𝑥)F^(x),G^(x):

    ˆ𝐹(𝑥)ˆ𝐺(𝑥)=∑𝑖≥0𝑎𝑖𝑥𝑖𝑖!∑𝑗≥0𝑏𝑗𝑥𝑗𝑗!=∑𝑛≥0𝑥𝑛𝑛∑𝑖=0𝑎𝑖𝑏𝑛−𝑖1𝑖!(𝑛−𝑖)!=∑𝑛≥0𝑥𝑛𝑛!𝑛∑𝑖=0(𝑛𝑖)𝑎𝑖𝑏𝑛−𝑖F^(x)G^(x)=∑i≥0aixii!∑j≥0bjxjj!=∑n≥0xn∑i=0naibn−i1i!(n−i)!=∑n≥0xnn!∑i=0n(ni)aibn−i

    Therefore, ˆ𝐹(𝑥)ˆ𝐺(𝑥)F^(x)G^(x) is the exponential generating function of the sequence:

    ⟨𝑛∑𝑖=0(𝑛𝑖)𝑎𝑖𝑏𝑛−𝑖⟩⟨∑i=0n(ni)aibn−i⟩

    Closed Form

    We also consider the closed form of exponential generating functions.

    The exponential generating function of the sequence ⟨1,1,1,⋯⟩⟨1,1,1,⋯⟩ is:

    ˆ𝐹(𝑥)=∑𝑛≥0𝑥𝑛𝑛!=e𝑥F^(x)=∑n≥0xnn!=ex

    Because expanding e𝑥ex at 𝑥 =0x=0 gives its infinite series form.

    Similarly, the exponential generating function of the geometric progression ⟨1,𝑝,𝑝2,⋯⟩⟨1,p,p2,⋯⟩ is:

    ˆ𝐹(𝑥)=∑𝑛≥0𝑝𝑛𝑥𝑛𝑛!=e𝑝𝑥F^(x)=∑n≥0pnxnn!=epx

    Exponential Generating Function vs Ordinary Generating Function

    How to understand exponential generating functions? We define the exponential generating function of sequence 𝑎a as:

    𝐹(𝑥)=∑𝑛≥0𝑎𝑛𝑥𝑛𝑛!F(x)=∑n≥0anxnn!

    But 𝐹(𝑥)F(x) is actually the ordinary generating function of the sequence ⟨𝑎𝑛𝑛!⟩⟨ann!⟩.

    These two understandings are both fine. In other words, different generating functions are just different ways of understanding the problem.

    Combinatorial Meaning of Polynomial exp in EGF

    If you haven't studied polynomial exp yet, skip here first. This is a meaning that arises from understanding exp, and in a sense can deepen the understanding of EGF.

    In EGF, 𝑓𝑛(𝑥)fn(x)'s 𝑓f is by default an EGF. So we first consider the product of any two EGFs:

    ˆ𝐻(𝑥)=ˆ𝐹(𝑥)ˆ𝐺(𝑥)=∑𝑛≥0[𝑛∑𝑖=0(𝑛𝑖)𝑓𝑖𝑔𝑛−𝑖]𝑥𝑛𝑛!H^(x)=F^(x)G^(x)=∑n≥0[∑i=0n(ni)fign−i]xnn!

    The [𝑥𝑘]ˆ𝐻(𝑥)[xk]H^(x) obtained from multiplying two EGFs is actually a convolution. And [𝑥𝑘]ˆ𝐻(𝑥)[xk]H^(x) obtained from multiplying multiple EGFs is actually the sum of coefficients for each case where we select one term 𝑥𝑎𝑖xai from each EGF such that ∑𝑖𝑎𝑖 =𝑘∑iai=k.

    From the perspective of sets, this is the number of ways to partition 𝑛n labeled elements into 𝑘 >0k>0 labeled sets.

    If 𝑘 =0k=0, the coefficient is obviously the product of constants of each term in the original EGF. However, some requirements in polynomial exp cause 𝑓(𝑥)f(x)'s constant term to be 00. The specific reason is explained below.

    In the definition of multinomial coefficients (specifically refer to the combinatorial meaning of multinomial coefficients in combinatorics), sets are ordered by default. But in exp⁡(𝑓(𝑥))exp⁡(f(x)), 𝑓𝑘(𝑥)fk(x), the EGF obtained from multiplying 𝑘k copies of 𝑓(𝑥)f(x) is the same, while set partitions are clearly unordered. So its coefficient should be multiplied by 1𝑘!1k!.

    Let 𝐹𝑘(𝑛)Fk(n) be the number of ways to partition 𝑛n labeled elements into 𝑘k non-empty unordered sets (non-empty because of expexp), and 𝑓𝑖fi be the number of ways for a specific combinatorial structure on a finite set of 𝑖i elements (it is the original EGF, counting schemes for the set elements, depending only on the size of the set). Then 𝐹𝑘(𝑛)Fk(n):

    𝐹𝑘(𝑛)=𝑛!𝑘!∑∑𝑘𝑖𝑎𝑖=𝑛𝑘∏𝑗=1𝑓𝑎𝑗𝑎𝑗!Fk(n)=n!k!∑∑ikai=n∏j=1kfajaj!

    Let the EGF of 𝑓𝑛fn be ˆ𝐹(𝑥)F^(x), i.e.:

    ˆ𝐹(𝑥)=∑𝑛≥0𝑓𝑛𝑥𝑛𝑛!F^(x)=∑n≥0fnxnn!

    Let the EGF of 𝐹𝑘(𝑛)Fk(n) be 𝐺𝑘(𝑥)Gk(x), then:

    𝐺𝑘(𝑥)=∑𝑛≥0𝐹𝑘(𝑛)𝑥𝑛𝑛!=∑𝑛≥0𝑥𝑛1𝑘!∑∑𝑘𝑖𝑎𝑖=𝑛𝑘∏𝑗=1𝑓𝑎𝑗𝑎𝑗!=1𝑘!∑𝑛≥0∑∑𝑘𝑖𝑎𝑖=𝑛𝑘∏𝑗=1𝑓𝑎𝑗𝑥𝑎𝑗𝑎𝑗!=1𝑘!ˆ𝐹𝑘(𝑥)Gk(x)=∑n≥0Fk(n)xnn!=∑n≥0xn1k!∑∑ikai=n∏j=1kfajaj!=1k!∑n≥0∑∑ikai=n∏j=1kfajxajaj!=1k!F^k(x)

    For all 𝑘 ≥0k≥0:

    ∑𝑘≥0𝐺𝑘(𝑥)=∑𝑘≥0ˆ𝐹𝑘(𝑥)𝑘!=exp⁡ˆ𝐹(𝑥)∑k≥0Gk(x)=∑k≥0F^k(x)k!=exp⁡F^(x)

    The above is a direct combinatorial formula understanding. We can also prove the relationship between exp⁡(𝑓(𝑥))exp⁡(f(x)) and 𝑓(𝑥)f(x) from the perspective of recurrence.

    Similarly, let 𝐹𝑘(𝑛)Fk(n) be the number of ways to partition 𝑛n labeled elements into 𝑘k non-empty sets (unlabeled), 𝑔𝑖gi be the number of schemes for a set of 𝑖i elements (same meaning as 𝑓𝑖fi above), and let 𝐺(𝑥)G(x) be the EGF of {𝑔𝑖}{gi}, 𝐻𝑘(𝑥)Hk(x) be the EGF of {𝐹𝑘(𝑛)}{Fk(n)}.

    Among 𝑛n elements, selecting 𝑖i elements as a separately partitioned set has 𝑔𝑖gi schemes, and the remaining 𝑛 −𝑖n−i elements form 𝑘 −1k−1 sets with 𝐹𝑘−1(𝑛 −𝑖)Fk−1(n−i) schemes. But in the final partition scheme, each set in a scheme will be enumerated as a separately partitioned set, so it's counted 𝑘k times, thus we need to divide by 𝑘k.

    𝐻𝑘(𝑥)=∑𝑛≥0𝑥𝑛𝑛!𝐹𝑘(𝑛)=∑𝑛≥0𝑥𝑛𝑛!𝑛−𝑘+1∑𝑖=1(𝑛𝑖)𝐹𝑘−1(𝑛−𝑖)×𝑔𝑖×1𝑘=1𝑘∑𝑛≥0𝑥𝑛𝑛!𝑛∑𝑖=0(𝑛𝑖)𝐹𝑘−1(𝑛−𝑖)×𝑔𝑖=1𝑘⋅𝐻𝑘−1(𝑥)𝐺(𝑥)Hk(x)=∑n≥0xnn!Fk(n)=∑n≥0xnn!∑i=1n−k+1(ni)Fk−1(n−i)×gi×1k=1k∑n≥0xnn!∑i=0n(ni)Fk−1(n−i)×gi=1k⋅Hk−1(x)G(x)

    The upper bound comes from non-empty set partition: 𝑛 −(𝑘 −1) ≥𝑖n−(k−1)≥i (the first 𝑘 −1k−1 sets each have at least one element). But if we exceed the enumeration upper bound and involve 𝐹𝑘−1(𝑛 −𝑖)Fk−1(n−i), setting it to 0 has no effect.

    After getting the recurrence formula, it can be recursively expanded, with the boundary being 𝑘 =1k=1 where 𝐻1(𝑥) =𝐺(𝑥)H1(x)=G(x).

    𝐻𝑘(𝑥)=1𝑘⋅𝐻𝑘−1(𝑥)𝐺(𝑥)=1𝑘⋅1𝑘−1⋅𝐻𝑘−2(𝑥)𝐺2(𝑥)=⋯=1𝑘⋅1𝑘−1⋯12⋅𝐻1(𝑥)𝐺𝑘−1(𝑥)=1𝑘!𝐺𝑘(𝑥)Hk(x)=1k⋅Hk−1(x)G(x)=1k⋅1k−1⋅Hk−2(x)G2(x)=⋯=1k⋅1k−1⋯12⋅H1(x)Gk−1(x)=1k!Gk(x)

    Similarly:

    ∑𝑘≥0𝐻𝑘(𝑥)=∑𝑘≥0𝐺𝑘(𝑥)𝑘!=exp⁡𝐺(𝑥)∑k≥0Hk(x)=∑k≥0Gk(x)k!=exp⁡G(x)

    Obviously, defining as non-empty set partition (𝑔0 =0g0=0) is consistent with its meaning. If it includes the empty set (𝑔0 =1g0=1), then in [𝑥𝑛]𝐺𝑘[xn]Gk there will be contributions from [𝑥𝑛]𝐺𝑦,𝑦 >𝑘[xn]Gy,y>k (selecting the constant term in at least one 𝐺G), causing double counting, and we can't get the desired result.

    From the perspective of recurrence, the product of multiple EGFs can also be seen as a knapsack-like combination (the process of merging two counting objects).

    Summarizing the meaning of polynomial exp: the number of cases in the generating set family of sets composed of labeled elements, or the total number of schemes for partitioning into any number of non-empty subsets.

    Permutations and Circular Permutations

    The exponential generating function for the number of permutations of length 𝑛n is:

    ˆ𝑃(𝑥)=∑𝑛≥0𝑛!𝑥𝑛𝑛!=∑𝑛≥0𝑥𝑛=11−𝑥P^(x)=∑n≥0n!xnn!=∑n≥0xn=11−x

    The definition of circular permutation is the number of ways to arrange 1,2,⋯,𝑛1,2,⋯,n in a ring. That is, schemes after rotation are equivalent (but reflection is not equivalent).
