    Polynomial Newton Iteration

    Description

    Given a polynomial 𝐺(𝑥,𝑦)G(x,y), we know that the polynomial 𝑓(𝑥)f(x) satisfies:

    𝐺(𝑥,𝑓(𝑥))≡0(mod𝑥𝑛)G(x,f(x))≡0(modxn)

    And there exists a value 𝑓1f1 such that 𝐺(𝑥,𝑦)G(x,y) satisfies:

    • 𝐺(0,𝑓1) =0G(0,f1)=0;
    • 𝜕𝐺𝜕𝑦(0,𝑓1) ≠0∂G∂y(0,f1)≠0.

    Find 𝑓(𝑥)f(x) modulo 𝑥𝑛xn.

    Newton's Method

    Consider doubling.

    First, when 𝑛 =1n=1, the solution to [𝑥0]𝐺(𝑥,𝑓(𝑥)) =0[x0]G(x,f(x))=0 needs to be solved separately—𝑓1f1 in the assumption is such a solution.

    Assume we have obtained the solution 𝑓⌈𝑛2⌉(𝑥)f⌈n2⌉(x) modulo 𝑥⌈𝑛2⌉x⌈n2⌉, and we want to find the solution 𝑓(𝑥) =𝑓𝑛(𝑥)f(x)=fn(x) modulo 𝑥𝑛xn.

    Expand 𝐺(𝑥,𝑓(𝑥))G(x,f(x)) around 𝑓(𝑥) =𝑓⌈𝑛2⌉(𝑥)f(x)=f⌈n2⌉(x) using Taylor expansion:

    +∞∑𝑖=0𝜕𝑖𝐺𝜕𝑦𝑖(𝑥,𝑓⌈𝑛2⌉(𝑥))𝑖!(𝑓(𝑥)−𝑓⌈𝑛2⌉(𝑥))𝑖≡0(mod𝑥𝑛)∑i=0+∞∂iG∂yi(x,f⌈n2⌉(x))i!(f(x)−f⌈n2⌉(x))i≡0(modxn)

    Since the lowest non-zero term of 𝑓(𝑥) −𝑓⌈𝑛2⌉(𝑥)f(x)−f⌈n2⌉(x) has degree at least ⌈𝑛2⌉⌈n2⌉, we have:

    ∀2⩽𝑖:(𝑓(𝑥)−𝑓⌈𝑛2⌉(𝑥))𝑖≡0(mod𝑥𝑛)∀2⩽i:(f(x)−f⌈n2⌉(x))i≡0(modxn)

    Thus:

    +∞∑𝑖=0𝜕𝑖𝐺𝜕𝑦𝑖(𝑥,𝑓⌈𝑛2⌉(𝑥))𝑖!(𝑓(𝑥)−𝑓⌈𝑛2⌉(𝑥))𝑖≡𝐺(𝑥,𝑓⌈𝑛2⌉(𝑥))+𝜕𝐺𝜕𝑦(𝑥,𝑓⌈𝑛2⌉(𝑥))[𝑓(𝑥)−𝑓⌈𝑛2⌉(𝑥)]≡0(mod𝑥𝑛)∑i=0+∞∂iG∂yi(x,f⌈n2⌉(x))i!(f(x)−f⌈n2⌉(x))i≡G(x,f⌈n2⌉(x))+∂G∂y(x,f⌈n2⌉(x))[f(x)−f⌈n2⌉(x)]≡0(modxn)𝑓𝑛(𝑥)≡𝑓⌈𝑛2⌉(𝑥)−𝐺(𝑥,𝑓⌈𝑛2⌉(𝑥))𝜕𝐺𝜕𝑦(𝑥,𝑓⌈𝑛2⌉(𝑥))(mod𝑥𝑛)fn(x)≡f⌈n2⌉(x)−G(x,f⌈n2⌉(x))∂G∂y(x,f⌈n2⌉(x))(modxn)

    Or:

    𝑓2𝑛(𝑥)≡𝑓𝑛(𝑥)−𝐺(𝑥,𝑓𝑛(𝑥))𝜕𝐺𝜕𝑦(𝑥,𝑓𝑛(𝑥))(mod𝑥2𝑛)f2n(x)≡fn(x)−G(x,fn(x))∂G∂y(x,fn(x))(modx2n)

    Example Problems

    Polynomial Inverse

    Let the given function be ℎ(𝑥)h(x):

    𝐺(𝑥,𝑦)=1𝑦−ℎ(𝑥)G(x,y)=1y−h(x)

    Applying Newton's Method:

    𝑓2𝑛(𝑥)≡𝑓𝑛(𝑥)−1/𝑓𝑛(𝑥)−ℎ(𝑥)−1/𝑓2𝑛(𝑥)(mod𝑥2𝑛)≡2𝑓𝑛(𝑥)−𝑓2𝑛(𝑥)ℎ(𝑥)(mod𝑥2𝑛)f2n(x)≡fn(x)−1/fn(x)−h(x)−1/fn2(x)(modx2n)≡2fn(x)−fn2(x)h(x)(modx2n)

    Time complexity:

    𝑇(𝑛)=𝑇(𝑛2)+𝑂(𝑛log⁡𝑛)=𝑂(𝑛log⁡𝑛)T(n)=T(n2)+O(nlog⁡n)=O(nlog⁡n)

    Polynomial Square Root

    Let the given function be ℎ(𝑥)h(x):

    𝐺(𝑥,𝑦)=𝑦2−ℎ(𝑥)≡0G(x,y)=y2−h(x)≡0

    Applying Newton's Method:

    𝑓2𝑛(𝑥)≡𝑓𝑛(𝑥)−𝑓2𝑛(𝑥)−ℎ(𝑥)2𝑓𝑛(𝑥)(mod𝑥2𝑛)≡𝑓2𝑛(𝑥)+ℎ(𝑥)2𝑓𝑛(𝑥)(mod𝑥2𝑛)f2n(x)≡fn(x)−fn2(x)−h(x)2fn(x)(modx2n)≡fn2(x)+h(x)2fn(x)(modx2n)

    Time complexity:

    𝑇(𝑛)=𝑇(𝑛2)+𝑂(𝑛log⁡𝑛)=𝑂(𝑛log⁡𝑛)T(n)=T(n2)+O(nlog⁡n)=O(nlog⁡n)

    Polynomial Exponential Function

    Let the given function be ℎ(𝑥)h(x):

    𝐺(𝑥,𝑦)=ln⁡𝑦−ℎ(𝑥)G(x,y)=ln⁡y−h(x)

    Applying Newton's Method:

    𝑓2𝑛(𝑥)≡𝑓𝑛(𝑥)−ln⁡𝑓𝑛(𝑥)−ℎ(𝑥)1/𝑓𝑛(𝑥)(mod𝑥2𝑛)≡𝑓𝑛(𝑥)(1−ln⁡𝑓𝑛(𝑥)+ℎ(𝑥))(mod𝑥2𝑛)f2n(x)≡fn(x)−ln⁡fn(x)−h(x)1/fn(x)(modx2n)≡fn(x)(1−ln⁡fn(x)+h(x))(modx2n)

    Time complexity:

    𝑇(𝑛)=𝑇(𝑛2)+𝑂(𝑛log⁡𝑛)=𝑂(𝑛log⁡𝑛)T(n)=T(n2)+O(nlog⁡n)=O(nlog⁡n)

    Manual Calculation Demonstration

    For better understanding, let's demonstrate the algorithm flow with some examples.

    Square Root of Complex Polynomial Mod Polynomial

    Assume ℎh is a complex polynomial not divisible by 𝑥x (has a constant term), find its square root modulo 𝑥𝑛xn.

    We have the equation:

    𝐺(𝑓(𝑥))=𝑓2(𝑥)−ℎ(𝑥)≡0(mod𝑥𝑛)G(f(x))=f2(x)−h(x)≡0(modxn)

    Expand 𝐺G using Taylor. Note that this is expansion with respect to 𝑓f, so the derivatives are all partial derivatives with respect to 𝑓f, and 𝑥x is treated as a constant here.

    𝐺(𝑓(𝑥))=+∞∑𝑖=0𝐺(𝑖)(𝑓0(𝑥))𝑖!(𝑓(𝑥)−𝑓0(𝑥))𝑖=𝐺(𝑓0(𝑥))+2𝑓0(𝑥)(𝑓(𝑥)−𝑓0(𝑥))+(𝑓(𝑥)−𝑓0(𝑥))2G(f(x))=∑i=0+∞G(i)(f0(x))i!(f(x)−f0(x))i=G(f0(x))+2f0(x)(f(x)−f0(x))+(f(x)−f0(x))2

    Use doubling for calculation. Assume the intermediate results in doubling are 𝑓0(𝑥),𝑓1(𝑥),…,𝑓𝑗(𝑥)f0(x),f1(x),…,fj(x), or more precisely, 𝑓𝑗(𝑥)fj(x) is a complex polynomial satisfying 𝐺(𝑓𝑗(𝑥)) ≡0(mod𝑥2𝑗)G(fj(x))≡0(modx2j), and for uniqueness it also satisfies:

    • The degree of 𝑓𝑗(𝑥)fj(x) does not exceed 𝑥2𝑗x2j;
    • 𝑓𝑗+𝑘(𝑥) −𝑓𝑗(𝑥) ≡0(mod𝑥2𝑗)fj+k(x)−fj(x)≡0(modx2j) for all 𝑘k.

    Substituting 𝑓𝑗+1(𝑥)fj+1(x) and 𝑓𝑗(𝑥)fj(x) into the above formula:

    𝐺(𝑓𝑗+1(𝑥))=𝐺(𝑓𝑗(𝑥))+2𝑓𝑗(𝑓𝑗+1(𝑥)−𝑓𝑗(𝑥))+(𝑓𝑗+1(𝑥)−𝑓𝑗(𝑥))2≡0(mod𝑥2𝑗+1)G(fj+1(x))=G(fj(x))+2fj(fj+1(x)−fj(x))+(fj+1(x)−fj(x))2≡0(modx2j+1)

    Obviously, 𝑓𝑗+1(𝑥) −𝑓𝑗(𝑥)fj+1(x)−fj(x) must be a multiple of 𝑥2𝑗x2j. Thus we get:

    𝑓𝑗+1(𝑥)≡𝑓𝑗(𝑥)−𝑓2𝑗(𝑥)−ℎ(𝑥)2𝑓𝑗(𝑥)≡𝑓𝑗(𝑥)2+ℎ(𝑥)2𝑓𝑗(𝑥)(mod𝑥2𝑗+1)fj+1(x)≡fj(x)−fj2(x)−h(x)2fj(x)≡fj(x)2+h(x)2fj(x)(modx2j+1)
