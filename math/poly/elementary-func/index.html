    This page contains common elementary function operations on polynomials. Specifically, this page includes:

    1. Polynomial inverse
    2. Polynomial square root
    3. Polynomial division
    4. Polynomial modulo
    5. Polynomial exponential function
    6. Polynomial logarithmic function
    7. Polynomial trigonometric functions
    8. Polynomial inverse trigonometric functions
    Elementary Functions and Non-Elementary Functions

    The definition of elementary functions is as follows1:

    If there exists a mapping 𝑢 →𝜕𝑢u→∂u in a field 𝐹F satisfying:

    1. 𝜕(𝑢 +𝑣) =𝜕𝑢 +𝜕𝑣∂(u+v)=∂u+∂v
    2. 𝜕(𝑢𝑣) =𝑢𝜕𝑣 +𝑣𝜕𝑢∂(uv)=u∂v+v∂u

    Then this field is called a differential field.

    If a function 𝑢u on a differential field 𝐹F satisfies any of the following conditions, it is called an elementary function:

    1. 𝑢u is an algebraic function on 𝐹F.
    2. 𝑢u is an exponential function on 𝐹F, i.e., there exists 𝑎 ∈𝐹a∈F such that 𝜕𝑢 =𝑢𝜕𝑎∂u=u∂a.
    3. 𝑢u is a logarithmic function on 𝐹F, i.e., there exists 𝑎 ∈𝐹a∈F such that 𝜕𝑢 =𝜕𝑎𝑎∂u=∂aa.

    The following are common elementary functions:

    1. Algebraic function: function 𝑓(𝑥)f(x) where there exists a finite polynomial 𝑃P such that 𝑃(𝑓(𝑥)) =0P(f(x))=0, e.g., 2𝑥 +12x+1,√𝑥x,(1 +𝑥2)−1(1+x2)−1,|𝑥||x|.
    2. Exponential function
    3. Logarithmic function
    4. Trigonometric functions
    5. Inverse trigonometric functions
    6. Hyperbolic functions
    7. Inverse hyperbolic functions

    8. Compositions of the above functions, e.g.:

      etan⁡𝑥1+𝑥2sin⁡(√1+ln2⁡𝑥)etan⁡x1+x2sin⁡(1+ln2⁡x) −iln⁡(𝑥+i√1−𝑥2)−iln⁡(x+i1−x2)

    The following are common non-elementary functions:

    1. Error function:

      erf⁡(𝑥):=2√𝜋∫𝑥0exp⁡(−𝑡2)d𝑡erf⁡(x):=2π∫0xexp⁡(−t2)dt

    Polynomial Inverse

    Given a polynomial 𝑓(𝑥)f(x), find 𝑓−1(𝑥)f−1(x).

    Solution

    Doubling Method

    First, it is easy to know:

    [𝑥0]𝑓−1(𝑥)=([𝑥0]𝑓(𝑥))−1[x0]f−1(x)=([x0]f(x))−1

    Assume we have already found the inverse 𝑓−10(𝑥)f0−1(x) of 𝑓(𝑥)f(x) modulo 𝑥⌈𝑛2⌉x⌈n2⌉. We have:

    𝑓(𝑥)𝑓−10(𝑥)≡1(mod𝑥⌈𝑛2⌉)𝑓(𝑥)𝑓−1(𝑥)≡1(mod𝑥⌈𝑛2⌉)𝑓−1(𝑥)−𝑓−10(𝑥)≡0(mod𝑥⌈𝑛2⌉)f(x)f0−1(x)≡1(modx⌈n2⌉)f(x)f−1(x)≡1(modx⌈n2⌉)f−1(x)−f0−1(x)≡0(modx⌈n2⌉)

    Squaring both sides:

    𝑓−2(𝑥)−2𝑓−1(𝑥)𝑓−10(𝑥)+𝑓−20(𝑥)≡0(mod𝑥𝑛)f−2(x)−2f−1(x)f0−1(x)+f0−2(x)≡0(modxn)

    Multiplying both sides by 𝑓(𝑥)f(x) and rearranging:

    𝑓−1(𝑥)≡𝑓−10(𝑥)(2−𝑓(𝑥)𝑓−10(𝑥))(mod𝑥𝑛)f−1(x)≡f0−1(x)(2−f(x)f0−1(x))(modxn)

    Compute recursively.

    Time Complexity:

    𝑇(𝑛)=𝑇(𝑛2)+𝑂(𝑛log⁡𝑛)=𝑂(𝑛log⁡𝑛)T(n)=T(n2)+O(nlog⁡n)=O(nlog⁡n)

    Newton's Method

    See Newton's Method.

    Graeffe's Method

    To find 𝑓−1(𝑥)mod𝑥2𝑛f−1(x)modx2n, consider:

    𝑓−1(𝑥)mod𝑥2𝑛=𝑓(−𝑥)(𝑓(𝑥)𝑓(−𝑥))−1mod𝑥2𝑛=𝑓(−𝑥)𝑔−1(𝑥2)mod𝑥2𝑛f−1(x)modx2n=f(−x)(f(x)f(−x))−1modx2n=f(−x)g−1(x2)modx2n

    We only need to find 𝑔−1(𝑥)mod𝑥𝑛g−1(x)modxn to restore 𝑔−1(𝑥2)mod𝑥2𝑛g−1(x2)modx2n because 𝑓(𝑥)𝑓( −𝑥)f(x)f(−x) is an even function. Time complexity is the same.

    constexpr int MAXN = 262144;
constexpr int mod = 998244353;

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void polyinv(const poly &h, const int n, poly &f) {
  /* f = 1 / h = f_0 (2 - f_0 h) */
  static poly_t inv_t;
  std::fill(f, f + n + n, 0);
  f[0] = fpow(h[0], mod - 2);
  for (int t = 2; t <= n; t <<= 1) {
    const int t2 = t << 1;
    std::copy(h, h + t, inv_t);
    std::fill(inv_t + t, inv_t + t2, 0);

    DFT(f, t2);
    DFT(inv_t, t2);
    for (int i = 0; i != t2; ++i)
      f[i] = (i64)f[i] * sub(2, (i64)f[i] * inv_t[i] % mod) % mod;
    IDFT(f, t2);

    std::fill(f + t, f + t2, 0);
  }
}

    Polynomial Square Root

    Given polynomial 𝑔(𝑥)g(x), find 𝑓(𝑥)f(x) such that:

    𝑓2(𝑥)≡𝑔(𝑥)(mod𝑥𝑛)f2(x)≡g(x)(modxn)

    Solution

    Doubling Method

    First, discuss the case where [𝑥0]𝑔(𝑥)[x0]g(x) is not 00.

    We know:

    [𝑥0]𝑓(𝑥)=√[𝑥0]𝑔(𝑥)[x0]f(x)=[x0]g(x)

    If [𝑥0]𝑔(𝑥)[x0]g(x) has no square root, then polynomial 𝑔(𝑥)g(x) has no square root.

    [𝑥0]𝑔(𝑥)[x0]g(x) may have multiple square roots; choosing different roots yields different 𝑓(𝑥)f(x).

    Assume we have already found the square root 𝑓0(𝑥)f0(x) of 𝑔(𝑥)g(x) modulo 𝑥⌈𝑛2⌉x⌈n2⌉:

    𝑓20(𝑥)≡𝑔(𝑥)(mod𝑥⌈𝑛2⌉)𝑓20(𝑥)−𝑔(𝑥)≡0(mod𝑥⌈𝑛2⌉)(𝑓20(𝑥)−𝑔(𝑥))2≡0(mod𝑥𝑛)(𝑓20(𝑥)+𝑔(𝑥))2≡4𝑓20(𝑥)𝑔(𝑥)(mod𝑥𝑛)(𝑓20(𝑥)+𝑔(𝑥)2𝑓0(𝑥))2≡𝑔(𝑥)(mod𝑥𝑛)𝑓20(𝑥)+𝑔(𝑥)2𝑓0(𝑥)≡𝑓(𝑥)(mod𝑥𝑛)2−1𝑓0(𝑥)+2−1𝑓−10(𝑥)𝑔(𝑥)≡𝑓(𝑥)(mod𝑥𝑛)f02(x)≡g(x)(modx⌈n2⌉)f02(x)−g(x)≡0(modx⌈n2⌉)(f02(x)−g(x))2≡0(modxn)(f02(x)+g(x))2≡4f02(x)g(x)(modxn)(f02(x)+g(x)2f0(x))2≡g(x)(modxn)f02(x)+g(x)2f0(x)≡f(x)(modxn)2−1f0(x)+2−1f0−1(x)g(x)≡f(x)(modxn)

    Compute by doubling.

    Time Complexity:

    𝑇(𝑛)=𝑇(𝑛2)+𝑂(𝑛log⁡𝑛)=𝑂(𝑛log⁡𝑛)T(n)=T(n2)+O(nlog⁡n)=O(nlog⁡n)

    There is also a method with smaller constant: while maintaining 𝑓(𝑥)f(x) by doubling, also maintain 𝑓−1(𝑥)f−1(x) instead of computing the inverse every time.

    When [𝑥0]𝑔(𝑥) ≠1[x0]g(x)≠1, quadratic residues may be needed to compute [𝑥0]𝑓(𝑥)[x0]f(x).

    The above method requires knowing the inverse of 𝑓0(𝑥)f0(x), so the constant term cannot be 00.

    If [𝑥0]𝑔(𝑥) =0[x0]g(x)=0, decompose 𝑔(𝑥)g(x) as 𝑥𝑘ℎ(𝑥)xkh(x), where [𝑥0]ℎ(𝑥) ≠0[x0]h(x)≠0.

    • If 𝑘k is odd, then 𝑔(𝑥)g(x) has no square root.
    • If 𝑘k is even, find the square root √ℎ(𝑥)h(x) of ℎ(𝑥)h(x), then get 𝑓(𝑥) ≡𝑥𝑘/2√ℎ(𝑥)(mod𝑥𝑛)f(x)≡xk/2h(x)(modxn).

using namespace std;

constexpr int MAXN = 1 << 20, mod = 998244353;

int a[MAXN], b[MAXN], g[MAXN], gg[MAXN];

int qpow(int x, int y) {  // Fast exponentiation
  int ans = 1;

  while (y) {
    if (y & 1) {
      ans = (long long)1 * ans * x % mod;
    }
    x = (long long)1 * x * x % mod;
    y >>= 1;
  }
  return ans;
}

int inv2 = qpow(2, mod - 2);  // Inverse

void change(int *f, int len) {
  for (int i = 1, j = len / 2; i < len - 1; i++) {
    if (i < j) {
      swap(f[i], f[j]);
    }

    int k = len / 2;
    while (j >= k) {
      j -= k;
      k /= 2;
    }
    if (j < k) {
      j += k;
    }
  }
}

void NTT(int *f, int len, int type) {  // NTT
  change(f, len);

  for (int q = 2; q <= len; q <<= 1) {
    int nxt = qpow(3, (mod - 1) / q);
    for (int i = 0; i < len; i += q) {
      int w = 1;

      for (int k = i; k < i + (q >> 1); k++) {
        int x = f[k];
        int y = (long long)1 * w * f[k + (q / 2)] % mod;

        f[k] = (x + y) % mod;
        f[k + (q / 2)] = (x - y + mod) % mod;
        w = (long long)1 * w * nxt % mod;
      }
    }
  }

  if (type == -1) {
    reverse(f + 1, f + len);
    int iv = qpow(len, mod - 2);

    for (int i = 0; i < len; i++) {
      f[i] = (long long)1 * f[i] * iv % mod;
    }
  }
}

void inv(int deg, int *f, int *h) {  // Compute inverse
  if (deg == 1) {
    h[0] = qpow(f[0], mod - 2);
    return;
  }

  inv((deg + 1) >> 1, f, h);

  int len = 1;
  while (len < deg * 2) {  // Doubling
    len *= 2;
  }

  copy(f, f + deg, gg);
  fill(gg + deg, gg + len, 0);

  NTT(gg, len, 1);
  NTT(h, len, 1);
  for (int i = 0; i < len; i++) {
    h[i] = (long long)1 * (2 - (long long)1 * gg[i] * h[i] % mod + mod) % mod *
           h[i] % mod;
  }

  NTT(h, len, -1);
  fill(h + deg, h + len, 0);
}

int n, t[MAXN];

// deg: degree
// f: array to take the square root of
// h: answer array
void sqrt(int deg, int *f, int *h) {
  if (deg == 1) {
    h[0] = 1;
    return;
  }

  sqrt((deg + 1) >> 1, f, h);

  int len = 1;
  while (len < deg * 2) {  // Doubling
    len *= 2;
  }
  fill(g, g + len, 0);
  inv(deg, h, g);
  copy(f, f + deg, t);
  fill(t + deg, t + len, 0);
  NTT(t, len, 1);
  NTT(g, len, 1);
  NTT(h, len, 1);

  for (int i = 0; i < len; i++) {
    h[i] = (long long)1 * inv2 *
           ((long long)1 * h[i] % mod + (long long)1 * g[i] * t[i] % mod) % mod;
  }
  NTT(h, len, -1);
  fill(h + deg, h + len, 0);
}

int main() {
  cin >> n;

  for (int i = 0; i < n; i++) {
    cin >> a[i];
  }
  sqrt(n, a, b);

  for (int i = 0; i < n; i++) {
    cout << b[i] << ' ';
  }

  return 0;
}

    Polynomial Division & Modulo

    Given polynomials 𝑓(𝑥),𝑔(𝑥)f(x),g(x), find the quotient 𝑄(𝑥)Q(x) and remainder 𝑅(𝑥)R(x) when 𝑔(𝑥)g(x) divides 𝑓(𝑥)f(x).

    Solution

    Find that if we can eliminate the effect of 𝑅(𝑥)R(x), we can directly solve it using Polynomial Inverse.

    Consider the transformation:

    𝑓𝑅(𝑥)=𝑥deg⁡𝑓𝑓(1𝑥)fR(x)=xdeg⁡ff(1x)

    Observe that this is reversing the coefficients of 𝑓(𝑥)f(x).

    Let 𝑛 =deg⁡𝑓,𝑚 =deg⁡𝑔n=deg⁡f,m=deg⁡g.

    Replace 𝑥x with 1𝑥1x in 𝑓(𝑥) =𝑄(𝑥)𝑔(𝑥) +𝑅(𝑥)f(x)=Q(x)g(x)+R(x) and multiply both sides by 𝑥𝑛xn:

    𝑥𝑛𝑓(1𝑥)=𝑥𝑛−𝑚𝑄(1𝑥)𝑥𝑚𝑔(1𝑥)+𝑥𝑛−𝑚+1𝑥𝑚−1𝑅(1𝑥)𝑓𝑅(𝑥)=𝑄𝑅(𝑥)𝑔𝑅(𝑥)+𝑥𝑛−𝑚+1𝑅𝑅(𝑥)xnf(1x)=xn−mQ(1x)xmg(1x)+xn−m+1xm−1R(1x)fR(x)=QR(x)gR(x)+xn−m+1RR(x)

    Note that the coefficients of 𝑅𝑅(𝑥)RR(x) in the above equation are of degree 𝑥𝑛−𝑚+1xn−m+1, so we can eliminate the effect of 𝑅𝑅(𝑥)RR(x) by taking modulo 𝑥𝑛−𝑚+1xn−m+1.

    Since 𝑄𝑅(𝑥)QR(x) has degree (𝑛 −𝑚) <(𝑛 −𝑚 +1)(n−m)<(n−m+1), 𝑄𝑅(𝑥)QR(x) is not affected.

    Thus:

    𝑓𝑅(𝑥)≡𝑄𝑅(𝑥)𝑔𝑅(𝑥)(mod𝑥𝑛−𝑚+1)fR(x)≡QR(x)gR(x)(modxn−m+1)

    Use polynomial inverse to find 𝑄(𝑥)Q(x), then substitute back to get 𝑅(𝑥)R(x).

    Time Complexity: 𝑂(𝑛log⁡𝑛)O(nlog⁡n).

    Polynomial Logarithmic Function & Exponential Function

    Solution

    Ordinary Method

    First, for polynomial 𝑓(𝑥)f(x), if ln⁡𝑓(𝑥)ln⁡f(x) exists, by its definition, it must satisfy:

    [𝑥0]𝑓(𝑥)=1[x0]f(x)=1

    Differentiate ln⁡𝑓(𝑥)ln⁡f(x) and integrate:

    dln⁡𝑓(𝑥)d𝑥≡𝑓′(𝑥)𝑓(𝑥)(mod𝑥𝑛)ln⁡𝑓(𝑥)≡∫dln⁡𝑓(𝑥)≡∫𝑓′(𝑥)𝑓(𝑥)d𝑥(mod𝑥𝑛)dln⁡f(x)dx≡f′(x)f(x)(modxn)ln⁡f(x)≡∫dln⁡f(x)≡∫f′(x)f(x)dx(modxn)

    Polynomial differentiation and integration take 𝑂(𝑛)O(n) time, and inverse takes 𝑂(𝑛log⁡𝑛)O(nlog⁡n) time. So polynomial logarithm takes 𝑂(𝑛log⁡𝑛)O(nlog⁡n) time.

    First, for polynomial 𝑓(𝑥)f(x), if exp⁡𝑓(𝑥)exp⁡f(x) exists, it must satisfy:

    [𝑥0]𝑓(𝑥)=0[x0]f(x)=0

    Otherwise, the constant term of exp⁡𝑓(𝑥)exp⁡f(x) does not converge.

    Differentiate exp⁡𝑓(𝑥)exp⁡f(x):

    dexp⁡𝑓(𝑥)d𝑥≡exp⁡𝑓(𝑥)𝑓′(𝑥)(mod𝑥𝑛)dexp⁡f(x)dx≡exp⁡f(x)f′(x)(modxn)

constexpr int mod = 998244353;

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void derivative(const poly &h, const int n, poly &f) {
  for (int i = 1; i != n; ++i) f[i - 1] = (i64)h[i] * i % mod;
  f[n - 1] = 0;
}

void integrate(const poly &h, const int n, poly &f) {
  for (int i = n - 1; i; --i) f[i] = (i64)h[i - 1] * inv[i] % mod;
  f[0] = 0; /* C */
}

void polyln(const poly &h, const int n, poly &f) {
  /* f = ln h = ∫ h' / h dx */
  assert(h[0] == 1);
  static poly_t ln_t;
  const int t = n << 1;

  derivative(h, n, ln_t);
  std::fill(ln_t + n, ln_t + t, 0);
  polyinv(h, n, f);

  DFT(ln_t, t);
  DFT(f, t);
  for (int i = 0; i != t; ++i) ln_t[i] = (i64)ln_t[i] * f[i] % mod;
  IDFT(ln_t, t);

  integrate(ln_t, n, f);
}

void polyexp(const poly &h, const int n, poly &f) {
  /* f = exp(h) = f_0 (1 - ln f_0 + h) */
  assert(h[0] == 0);
  static poly_t exp_t;
  std::fill(f, f + n + n, 0);
  f[0] = 1;
  for (int t = 2; t <= n; t <<= 1) {
    const int t2 = t << 1;

    polyln(f, t, exp_t);
    exp_t[0] = sub(pls(h[0], 1), exp_t[0]);
    for (int i = 1; i != t; ++i) exp_t[i] = sub(h[i], exp_t[i]);
    std::fill(exp_t + t, exp_t + t2, 0);

    DFT(f, t2);
    DFT(exp_t, t2);
    for (int i = 0; i != t2; ++i) f[i] = (i64)f[i] * exp_t[i] % mod;
    IDFT(f, t2);

    std::fill(f + t, f + t2, 0);
  }
}

void polytri(const poly &h, const int n, poly &sin_t, poly &cos_t) {
  /* sin(f) = (exp(i * f) - exp(- i * f)) / 2i */
  /* cos(f) = (exp(i * f) + exp(- i * f)) / 2 */
  /* tan(f) = sin(f) / cos(f) */
  assert(h[0] == 0);
  static poly_t tri1_t, tri2_t;

  for (int i = 0; i != n; ++i) tri2_t[i] = (i64)h[i] * imgunit % mod;
  polyexp(tri2_t, n, tri1_t);
  polyinv(tri1_t, n, tri2_t);

  if (sin_t != nullptr) {
    const int invi = fpow(pls(imgunit, imgunit), mod - 2);
    for (int i = 0; i != n; ++i)
      sin_t[i] = (i64)(tri1_t[i] - tri2_t[i] + mod) * invi % mod;
  }
  if (cos_t != nullptr) {
    for (int i = 0; i != n; ++i) cos_t[i] = div2(pls(tri1_t[i], tri2_t[i]));
  }
}

using i64 = long long;
using poly_t = int[MAXN];
using poly = int *const;

void derivative(const poly &h, const int n, poly &f) {
  for (int i = 1; i != n; ++i) f[i - 1] = (i64)h[i] * i % mod;
  f[n - 1] = 0;
}

void integrate(const poly &h, const int n, poly &f) {
  for (int i = n - 1; i; --i) f[i] = (i64)h[i - 1] * inv[i] % mod;
  f[0] = 0; /* C */
}

void polyarcsin(const poly &h, const int n, poly &f) {
  /* arcsin(f) = ∫ f' / sqrt(1 - f^2) dx  */
  static poly_t arcsin_t;
  const int t = n << 1;
  std::copy(h, h + n, arcsin_t);
  std::fill(arcsin_t + n, arcsin_t + t, 0);

  DFT(arcsin_t, t);
  for (int i = 0; i != t; ++i) arcsin_t[i] = sqr(arcsin_t[i]);
  IDFT(arcsin_t, t);

  arcsin_t[0] = sub(1, arcsin_t[0]);
  for (int i = 1; i != n; ++i)
    arcsin_t[i] = arcsin_t[i] ? mod - arcsin_t[i] : 0;

  polysqrt(arcsin_t, n, f);
  polyinv(f, n, arcsin_t);
  derivative(h, n, f);

  DFT(f, t);
  DFT(arcsin_t, t);
  for (int i = 0; i != t; ++i) arcsin_t[i] = (i64)f[i] * arcsin_t[i] % mod;
  IDFT(arcsin_t, t);

  integrate(arcsin_t, n, f);
}

void polyarccos(const poly &h, const int n, poly &f) {
  /* arccos(f) = - ∫ f' / sqrt(1 - f^2) dx  */
  polyarcsin(h, n, f);
  for (int i = 0; i != n; ++i) f[i] = f[i] ? mod - f[i] : 0;
}

void polyarctan(const poly &h, const int n, poly &f) {
  /* arctan(f) = ∫ f' / (1 + f^2) dx  */
  static poly_t arctan_t;
  const int t = n << 1;
  std::copy(h, h + n, arctan_t);
  std::fill(arctan_t + n, arctan_t + t, 0);

  DFT(arctan_t, t);
  for (int i = 0; i != t; ++i) arctan_t[i] = sqr(arctan_t[i]);
  IDFT(arctan_t, t);

  inc(arctan_t[0], 1);
  std::fill(arctan_t + n, arctan_t + t, 0);

  polyinv(arctan_t, n, f);
  derivative(h, n, arctan_t);

  DFT(f, t);
  DFT(arctan_t, t);
  for (int i = 0; i != t; ++i) arctan_t[i] = (i64)f[i] * arctan_t[i] % mod;
  IDFT(arctan_t, t);

  integrate(arctan_t, n, f);
}
