    Interpolation

    Introduction

    Interpolation is a method for calculating new data points within a certain range based on known, discrete data points. Interpolation methods are commonly used in function fitting.

    For example, for data points:

    𝑥x00112233445566
    𝑓(𝑥)f(x)000.84150.84150.90930.90930.14110.1411−0.7568−0.7568−0.9589−0.9589−0.2794−0.2794

    Here 𝑓(𝑥)f(x) is unknown. Interpolation methods can estimate unknown data points by fitting 𝑓(𝑥)f(x) in a certain form.

    For example, we can fit 𝑓(𝑥)f(x) with a piecewise linear function:

    This interpolation method is called linear interpolation.

    We can also fit 𝑓(𝑥)f(x) with a polynomial:

    This interpolation method is called polynomial interpolation.

    The general form of polynomial interpolation is as follows:

    Polynomial Interpolation

    Given known 𝑛 +1n+1 points (𝑥0,𝑦0),(𝑥1,𝑦1),…,(𝑥𝑛,𝑦𝑛)(x0,y0),(x1,y1),…,(xn,yn), find a polynomial 𝑓(𝑥) =∑𝑛𝑖=0𝑎𝑖𝑥𝑖f(x)=∑i=0naixi such that

    𝑓(𝑥𝑖)=𝑦𝑖,∀𝑖=0,1,…,𝑛f(xi)=yi,∀i=0,1,…,n

    is satisfied.

    Below we introduce two methods in polynomial interpolation: Lagrange interpolation and Newton interpolation. It is easy to prove that these two methods yield the same result.

    Lagrange Interpolation

    Since we need to construct a function 𝑓(𝑥)f(x) passing through points 𝑃1(𝑥1,𝑦1),𝑃2(𝑥2,𝑦2),⋯,𝑃𝑛(𝑥𝑛,𝑦𝑛)P1(x1,y1),P2(x2,y2),⋯,Pn(xn,yn). First, let the projection of the 𝑖i-th point on the x-axis be 𝑃′𝑖(𝑥𝑖,0)Pi′(xi,0).

    Consider constructing 𝑛n functions 𝑓1(𝑥),𝑓2(𝑥),⋯,𝑓𝑛(𝑥)f1(x),f2(x),⋯,fn(x) such that for the 𝑖i-th function 𝑓𝑖(𝑥)fi(x), its graph passes through {𝑃′𝑗(𝑥𝑗,0),(𝑗≠𝑖)𝑃𝑖(𝑥𝑖,𝑦𝑖){Pj′(xj,0),(j≠i)Pi(xi,yi). Then we know that the function we seek is 𝑓(𝑥) =𝑛∑𝑖=1𝑓𝑖(𝑥)f(x)=∑i=1nfi(x).

    We can set 𝑓𝑖(𝑥) =𝑎 ⋅∏𝑗≠𝑖(𝑥 −𝑥𝑗)fi(x)=a⋅∏j≠i(x−xj). Substituting point 𝑃𝑖(𝑥𝑖,𝑦𝑖)Pi(xi,yi) gives 𝑎 =𝑦𝑖∏𝑗≠𝑖(𝑥𝑖−𝑥𝑗)a=yi∏j≠i(xi−xj). Therefore:

    𝑓𝑖(𝑥)=𝑦𝑖⋅∏𝑗≠𝑖(𝑥−𝑥𝑗)∏𝑗≠𝑖(𝑥𝑖−𝑥𝑗)=𝑦𝑖⋅∏𝑗≠𝑖𝑥−𝑥𝑗𝑥𝑖−𝑥𝑗fi(x)=yi⋅∏j≠i(x−xj)∏j≠i(xi−xj)=yi⋅∏j≠ix−xjxi−xj

    Thus, the form of Lagrange interpolation is:

    𝑓(𝑥)=𝑛∑𝑖=1𝑦𝑖⋅∏𝑗≠𝑖𝑥−𝑥𝑗𝑥𝑖−𝑥𝑗f(x)=∑i=1nyi⋅∏j≠ix−xjxi−xj

    The naive implementation has time complexity 𝑂(𝑛2)O(n2), which can be optimized to 𝑂(𝑛log2⁡𝑛)O(nlog2⁡n), see Fast Polynomial Interpolation.

    Solution

    In this problem, we only need to compute 𝑓(𝑘)f(k), so we can directly substitute 𝑘k into the above formula during calculation. Sometimes we need to perform more complex operations like multiple evaluations; in those cases we need to find all coefficients of 𝑓f. The code provides an implementation for finding the coefficients.

    𝑓(𝑘)=𝑛∑𝑖=1𝑦𝑖∏𝑗≠𝑖𝑘−𝑥𝑗𝑥𝑖−𝑥𝑗f(k)=∑i=1nyi∏j≠ik−xjxi−xj

    In this problem, we also need to compute modular inverses. If we compute the numerators and denominators separately first, then multiply the numerator by the modular inverse of the denominator and add to the final answer, the bottleneck will not be in computing inverses, and the time complexity is 𝑂(𝑛2)O(n2).

    Since we are computing under a fixed modulus 998244353998244353, we can consider the time complexity of computing modular inverses to be constant time here.

    #include <iostream>
#include <vector>

constexpr int MOD = 998244353;
using LL = long long;

int inv(int k) {
  int res = 1;
  for (int e = MOD - 2; e; e /= 2) {
    if (e & 1) res = (LL)res * k % MOD;
    k = (LL)k * k % MOD;
  }
  return res;
}

// Returns f satisfying f(x_i) = y_i
// Excluding the time for modular inverses, this is clearly O(n^2)
std::vector<int> lagrange_interpolation(const std::vector<int> &x,
                                        const std::vector<int> &y) {
  const int n = x.size();
  std::vector<int> M(n + 1), px(n, 1), f(n);
  M[0] = 1;
  // Compute M(x) = prod_(i=0..n-1)(x - x_i)
  for (int i = 0; i < n; ++i) {
    for (int j = i; j >= 0; --j) {
      M[j + 1] = (M[j] + M[j + 1]) % MOD;
      M[j] = (LL)M[j] * (MOD - x[i]) % MOD;
    }
  }
  // Compute px_i = prod_(j=0..n-1, j!=i) (x_i - x_j)
  for (int i = 0; i < n; ++i) {
    for (int j = 0; j < n; ++j)
      if (i != j) {
        px[i] = (LL)px[i] * (x[i] - x[j] + MOD) % MOD;
      }
  }
  // Combine f(x) = sum_(i=0..n-1)(y_i / px_i)(M(x) / (x - x_i))
  for (int i = 0; i < n; ++i) {
    LL t = (LL)y[i] * inv(px[i]) % MOD, k = M[n];
    for (int j = n - 1; j >= 0; --j) {
      f[j] = (f[j] + k * t) % MOD;
      k = (M[j] + k * x[i]) % MOD;
    }
  }
  return f;
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  int n, k;
  std::cin >> n >> k;
  std::vector<int> x(n), y(n);
  for (int i = 0; i < n; ++i) std::cin >> x[i] >> y[i];
  const auto f = lagrange_interpolation(x, y);
  int v = 0;
  for (int i = n - 1; i >= 0; --i) v = ((LL)v * k + f[i]) % MOD;
  std::cout << v << '\n';
  return 0;
}

    Lagrange Interpolation with Consecutive Integer x-coordinates

    If the x-coordinates of the known points are consecutive integers, we can achieve 𝑂(𝑛)O(n) interpolation.

    Let the polynomial we want be 𝑓(𝑥)f(x). We know 𝑓(1),⋯,𝑓(𝑛 +1)f(1),⋯,f(n+1) (1 ≤𝑖 ≤𝑛 +11≤i≤n+1). Substituting into the interpolation formula above:

    𝑓(𝑥)=𝑛+1∑𝑖=1𝑦𝑖∏𝑗≠𝑖𝑥−𝑥𝑗𝑥𝑖−𝑥𝑗=𝑛+1∑𝑖=1𝑦𝑖∏𝑗≠𝑖𝑥−𝑗𝑖−𝑗f(x)=∑i=1n+1yi∏j≠ix−xjxi−xj=∑i=1n+1yi∏j≠ix−ji−j

    The product can be considered separately for numerator and denominator. The numerator is:

    𝑛+1∏𝑗=1(𝑥−𝑗)𝑥−𝑖∏j=1n+1(x−j)x−i

    The denominator product 𝑖 −𝑗i−j can be split into two factorials:

    (−1)𝑛+1−𝑖⋅(𝑖−1)!⋅(𝑛+1−𝑖)!(−1)n+1−i⋅(i−1)!⋅(n+1−i)!

    Thus the interpolation formula for x-coordinates 1,⋯,𝑛 +11,⋯,n+1:

    𝑓(𝑥)=𝑛+1∑𝑖=1(−1)𝑛+1−𝑖𝑦𝑖⋅𝑛+1∏𝑗=1(𝑥−𝑗)(𝑖−1)!(𝑛+1−𝑖)!(𝑥−𝑖)f(x)=∑i=1n+1(−1)n+1−iyi⋅∏j=1n+1(x−j)(i−1)!(n+1−i)!(x−i)

    Precompute prefix and suffix products of (𝑥 −𝑖)(x−i) and factorial inverses, then substitute into this formula, achieving 𝑂(𝑛)O(n) complexity.

    Example Problem CF622F The Sum of the k-th Powers

    Given 𝑛,𝑘n,k, compute 𝑛∑𝑖=1𝑖𝑘∑i=1nik modulo 109 +7109+7.

    Solution

#include <iostream>
using namespace std;
constexpr int N = 1e6 + 5, mod = 1e9 + 7;

int n, k, tab[N], p[N], pcnt, f[N], pre[N], suf[N], fac[N], inv[N], ans;

int qpow(int x, int y) {
  int ans = 1;
  for (; y; y >>= 1, x = 1LL * x * x % mod)
    if (y & 1) ans = 1LL * ans * x % mod;
  return ans;
}

void sieve(int lim) {
  f[1] = 1;
  for (int i = 2; i <= lim; i++) {
    if (!tab[i]) {
      p[++pcnt] = i;
      f[i] = qpow(i, k);
    }
    for (int j = 1; j <= pcnt && 1LL * i * p[j] <= lim; j++) {
      tab[i * p[j]] = 1;
      f[i * p[j]] = 1LL * f[i] * f[p[j]] % mod;
      if (!(i % p[j])) break;
    }
  }
  for (int i = 2; i <= lim; i++) f[i] = (f[i - 1] + f[i]) % mod;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> n >> k;
  sieve(k + 2);
  if (n <= k + 2) return cout << f[n], 0;
  pre[0] = suf[k + 3] = 1;
  for (int i = 1; i <= k + 2; i++) pre[i] = 1LL * pre[i - 1] * (n - i) % mod;
  for (int i = k + 2; i >= 1; i--) suf[i] = 1LL * suf[i + 1] * (n - i) % mod;
  fac[0] = inv[0] = fac[1] = inv[1] = 1;
  for (int i = 2; i <= k + 2; i++) {
    fac[i] = 1LL * fac[i - 1] * i % mod;
    inv[i] = 1LL * (mod - mod / i) * inv[mod % i] % mod;
  }
  for (int i = 2; i <= k + 2; i++) inv[i] = 1LL * inv[i - 1] * inv[i] % mod;
  for (int i = 1; i <= k + 2; i++) {
    int P = 1LL * pre[i - 1] * suf[i + 1] % mod;
    int Q = 1LL * inv[i - 1] * inv[k + 2 - i] % mod;
    int mul = ((k + 2 - i) & 1) ? -1 : 1;
    ans = (ans + 1LL * (Q * mul + mod) % mod * P % mod * f[i] % mod) % mod;
  }
  cout << ans << '\n';
  return 0;
}

    #include <cstdint>
#include <iostream>
#include <vector>
using namespace std;

constexpr uint32_t MOD = 998244353;

struct mint {
  uint32_t v_;

  mint() : v_(0) {}

  mint(int64_t v) {
    int64_t x = v % (int64_t)MOD;
    v_ = (uint32_t)(x + (x < 0 ? MOD : 0));
  }

  friend mint inv(mint const &x) {
    int64_t a = x.v_, b = MOD;
    if ((a %= b) == 0) return 0;
    int64_t s = b, m0 = 0;
    for (int64_t q = 0, _ = 0, m1 = 1; a;) {
      _ = s - a * (q = s / a);
      s = a;
      a = _;
      _ = m0 - m1 * q;
      m0 = m1;
      m1 = _;
    }
    return m0;
  }

  mint &operator+=(mint const &r) {
    if ((v_ += r.v_) >= MOD) v_ -= MOD;
    return *this;
  }

  mint &operator-=(mint const &r) {
    if ((v_ -= r.v_) >= MOD) v_ += MOD;
    return *this;
  }

  mint &operator*=(mint const &r) {
    v_ = (uint32_t)((uint64_t)v_ * r.v_ % MOD);
    return *this;
  }

  mint &operator/=(mint const &r) { return *this = *this * inv(r); }

  friend mint operator+(mint l, mint const &r) { return l += r; }

  friend mint operator-(mint l, mint const &r) { return l -= r; }

  friend mint operator*(mint l, mint const &r) { return l *= r; }

  friend mint operator/(mint l, mint const &r) { return l /= r; }
};

template <class T>
struct NewtonInterp {
  // {(x_0,y_0),...,(x_{n-1},y_{n-1})}
  vector<pair<T, T>> p;
  // dy[r][l] = [y_l,...,y_r]
  vector<vector<T>> dy;
  // (x-x_0)...(x-x_{n-1})
  vector<T> base;
  // [y_0]+...+[y_0,y_1,...,y_n](x-x_0)...(x-x_{n-1})
  vector<T> poly;

  void insert(T const &x, T const &y) {
    p.emplace_back(x, y);
    size_t n = p.size();
    if (n == 1) {
      base.push_back(1);
    } else {
      size_t m = base.size();
      base.push_back(0);
      for (size_t i = m; i; --i) base[i] = base[i - 1];
      base[0] = 0;
      for (size_t i = 0; i < m; ++i)
        base[i] = base[i] - p[n - 2].first * base[i + 1];
    }
    dy.emplace_back(p.size());
    dy[n - 1][n - 1] = y;
    if (n > 1) {
      for (size_t i = n - 2; ~i; --i)
        dy[n - 1][i] =
            (dy[n - 2][i] - dy[n - 1][i + 1]) / (p[i].first - p[n - 1].first);
    }
    poly.push_back(0);
    for (size_t i = 0; i < n; ++i) poly[i] = poly[i] + dy[n - 1][0] * base[i];
  }

  T eval(T const &x) {
    T ans{};
    for (auto it = poly.rbegin(); it != poly.rend(); ++it) ans = ans * x + *it;
    return ans;
  }
};

int main() {
  NewtonInterp<mint> ip;
  int n, k;
  cin >> n >> k;
  for (int i = 1, x, y; i <= n; ++i) {
    cin >> x >> y;
    ip.insert(x, y);
  }
  cout << ip.eval(k).v_;
  return 0;
}
