    Probability Inequalities

    In algorithm competitions, randomized algorithms are sometimes used. The correctness and time/space complexity of these algorithms typically rely on the premise that "certain random events occur with very small probability." For example, the complexity of quicksort depends on the event that "the selected pivot element is almost the smallest or largest element" occurring rarely.

    This article will briefly introduce some tools for analyzing randomized algorithms and provide several simple application examples.

    Union Bound

    Let 𝐴1,⋯,𝐴𝑚A1,⋯,Am be random events, then

    𝑃{𝑚⋃𝑖=1𝐴𝑖}≤𝑚∑𝑖=1𝑃{𝐴𝑖}P{⋃i=1mAi}≤∑i=1mP{Ai}

    That is: the probability that at least one of a set of events occurs does not exceed the sum of the probabilities of each event occurring.

    In fact, this conclusion can be slightly strengthened:

    • The probability that at least one of a set of events occurs is at least the sum of the probabilities of each event, minus the sum of the probabilities of each pair occurring simultaneously.
    • The probability that at least one of a set of events occurs is at most the sum of the probabilities of each event, minus the sum of the probabilities of each pair occurring simultaneously, plus the sum of the probabilities of each triple occurring simultaneously.
    • ……

    As the number of layers increases, the alternating upper and lower bounds become tighter. This series of conclusions is formally similar to the inclusion-exclusion principle, and the proof process is similar to that of inclusion-exclusion, so it is omitted here.

    Markov's Inequality

    Let 𝑋X be a non-negative random variable, then for any positive real number 𝑎a,

    𝑃{𝑋≥𝑎}≤𝐸𝑋𝑎P{X≥a}≤EXa

    In fact, since Markov's inequality itself does not use any information about the distribution of the random variable beyond its expectation, the bound obtained by directly applying this inequality is usually quite loose.

    Proof

    Let 𝐼I be the indicator function of the event 𝑋 ≥𝑎X≥a, then

    𝐼≤𝑋𝑎I≤Xa

    Consequently,

    𝑃{𝑋≥𝑎}=𝐸𝐼≤𝐸[𝑋𝑎]=𝐸𝑋𝑎P{X≥a}=EI≤E[Xa]=EXa

    Chebyshev's Inequality

    Let 𝑋X be a random variable, then for any 𝑎 >0a>0,

    𝑃{|𝑋−𝐸𝑋|≥𝑎}≤𝐷𝑋𝑎2P{|X−EX|≥a}≤DXa2

    In particular, when 𝑎a takes the value 𝑘𝜎kσ,

    𝑃{|𝑋−𝐸𝑋|≥𝑘𝜎}≤1𝑘2P{|X−EX|≥kσ}≤1k2

    where 𝜎σ is the standard deviation of 𝑋X.

    Proof

    From the given, we have

    𝑃{|𝑋−𝐸𝑋|≥𝑎}=𝑃{(𝑋−𝐸𝑋)2≥𝑎2}P{|X−EX|≥a}=P{(X−EX)2≥a2}

    Noting that (𝑋 −𝐸𝑋)2(X−EX)2 is non-negative, by Markov's inequality,

    𝑃{(𝑋−𝐸𝑋)2≥𝑎2}≤𝐸(𝑋−𝐸𝑋)2𝑎2=𝐷𝑋𝑎2P{(X−EX)2≥a2}≤E(X−EX)2a2=DXa2

    Chernoff Bound

    A general Chernoff bound can be derived by directly applying Markov's inequality to the random variable e𝑡𝑋etX:

    Let 𝑋X be a random variable, then for any 𝑡 >0t>0,

    𝑃{𝑋≥𝑎}=𝑃{e𝑡𝑋>e𝑡𝑎}≤𝐸e𝑡𝑋e𝑡𝑎P{X≥a}=P{etX>eta}≤EetXeta

    Similarly, when 𝑡 <0t<0,

    𝑃{𝑋≤𝑎}=𝑃{e𝑡𝑋>e𝑡𝑎}≤𝐸e𝑡𝑋e𝑡𝑎P{X≤a}=P{etX>eta}≤EetXeta

    Chernoff Bound for Sum of Poisson Trials

    The random variables involved in algorithm competitions are usually not so "general." We can describe them using Poisson trials in probability theory.

    A Poisson trial refers to a random experiment with only two possible outcomes.

    The outcome of a single Poisson trial can be described by a random variable 𝑋X taking values 00 or 11, with probability distribution

    𝑃{𝑋=𝑖}={𝑝𝑖,𝑖=11−𝑝1,𝑖=0P{X=i}={pi,i=11−p1,i=0

    For Poisson trials, we have the following conclusion:

    For 𝑛n independent Poisson trials 𝑋1,𝑋2,⋯,𝑋𝑛X1,X2,⋯,Xn, let 𝑋 =∑𝑛𝑖=1𝑋𝑖X=∑i=1nXi and 𝜇 =𝐸𝑋μ=EX, then for any 0 <𝜖 <10<ϵ<1,

    𝑃{|𝑋−𝜇|≥𝜖𝜇}≤2exp⁡(−13𝜇𝜖2)P{|X−μ|≥ϵμ}≤2exp⁡(−13μϵ2)

    Hoeffding's Inequality

    If 𝑋1,⋯,𝑋𝑛X1,⋯,Xn are independent real random variables and 𝑋𝑖 ∈[𝑎𝑖,𝑏𝑖]Xi∈[ai,bi], and the random variable 𝑋 =𝑛∑𝑖=1𝑋𝑖X=∑i=1nXi, then

    𝑃{|𝑋−𝐸𝑋|≥𝜖}≤2exp⁡⎛⎜ ⎜ ⎜ ⎜ ⎜ ⎜⎝−2𝜖2𝑛∑𝑖=1(𝑏𝑖−𝑎𝑖)2⎞⎟ ⎟ ⎟ ⎟ ⎟ ⎟⎠P{|X−EX|≥ϵ}≤2exp⁡(−2ϵ2∑i=1n(bi−ai)2)

    Both Chernoff bounds and Hoeffding's inequality bound the degree to which a random variable deviates from its expected value. The proofs of these two inequalities are relatively lengthy; interested readers may refer to the relevant chapters in the book "Probability and Computing."

    Empirically, if 𝐸𝑋EX is not too close to 𝑎1 +⋯ +𝑎𝑛a1+⋯+an, the bound given by this inequality is usually relatively tight; if it is very close (for example, in UOJ #72 New Approach), the bound is usually quite loose. In such cases, using Chernoff bounds is a better choice.

    Application Examples

    Example: Estimating Pi by Random Points

    Consider the following algorithm to estimate the exact value of 𝜋π:

    Generate 𝑛n random points in the square region [ −1,1]2[−1,1]2. Let 𝑚m be the number of points falling inside the unit disk 𝑥2 +𝑦2 ≤1x2+y2≤1. Then 4𝑚𝑛4mn can be taken as an approximation of 𝜋π.

    Question: If we want to ensure that the above algorithm returns a result with relative error no more than 𝜖ϵ with probability at least (1 −𝛿)(1−δ), how should 𝑛n be chosen?

    Solution

    Let 𝑋𝑖Xi denote the event "the i-th randomly generated point is inside the unit disk." Then the total number of points inside the disk 𝑋 =∑𝑛𝑖=1𝑋𝑖X=∑i=1nXi. We need to find an appropriate 𝑛n such that

    𝑃{∣4𝑋𝑛−𝜋∣≥𝜖𝜋}≤𝛿P{|4Xn−π|≥ϵπ}≤δ

    The above is equivalent to

    𝑃{∣𝑋−𝜋4𝑛∣≥𝜖⋅𝜋4𝑛}≤𝛿P{|X−π4n|≥ϵ⋅π4n}≤δ

    According to Chernoff bounds, we just need to set

    2exp⁡(−13𝜖2⋅𝜋4𝑛)≤𝛿2exp⁡(−13ϵ2⋅π4n)≤δ

    From this, we can solve for

    𝑛≥12𝜋𝜖−2ln⁡2𝛿n≥12πϵ−2ln⁡2δ

    That is, when 𝑛 =Ω(𝜖−2ln⁡1𝛿)n=Ω(ϵ−2ln⁡1δ), the required accuracy can be achieved.

    Example: Prize Drawing Problem

    A box contains 𝑛n balls, of which exactly 𝑘k balls correspond to grand prizes. You will perform several independent, equally probable random draws, with each ball being returned to the box after drawing. How many times must you draw to ensure with probability at least (1 −𝜖)(1−ϵ) that every prize ball has been drawn at least once?

    Solution

    If there is only one prize ball, then drawing 𝑀 =𝑛log⁡𝜖−1M=nlog⁡ϵ−1 times is sufficient to guarantee it, because the probability of missing all 𝑀M times is

    (1−1𝑛)𝑛log⁡𝜖−1≤𝑒log⁡𝜖=𝜖(1−1n)nlog⁡ϵ−1≤elog⁡ϵ=ϵ

    Now with 𝑘 >1k>1 prize balls, according to the Union Bound, we just need to ensure that the probability of missing each prize ball is no more than 𝜖𝑘ϵk. So the answer is 𝑛log⁡𝑘𝜖nlog⁡kϵ.

    Example: Randomly Selecting Half the Elements

    Give an algorithm to select an equally probable random subset of size 𝑛2n2 from 𝑛n elements, with 𝑛n guaranteed to be even. The only random source you can use is a fair coin, and try to minimize the number of coin flips (not necessarily optimal).

    Solution

    First, consider this algorithm:

    • By flipping 𝑛n coins, we can select an equally probable random subset from all subsets.
    • Repeat this process until the selected subset has exactly 𝑛2n2 elements.
      • Note that subsets of size 𝑛2n2 constitute at least 1𝑛1n of all subsets, so the expected number of repetitions is ≤𝑛≤n.

    This algorithm requires an expected 𝑛2n2 coin flips.

    Another algorithm:

    • We can implement random 𝑛n-to-1 selection by flipping an expected 2⌈log2⁡𝑛⌉2⌈log2⁡n⌉ coins.
      • Specific method: randomly generate a ⌈log2⁡𝑛⌉⌈log2⁡n⌉-bit binary number; if it is greater than or equal to 𝑛n, regenerate; otherwise, select the element with the corresponding index (index starting from 0) and end the process.
    • Then select one element from all elements, then select one from the remaining elements, and so on, until 𝑛2n2 elements are selected.

    This algorithm requires an expected 𝑛⌈log2⁡𝑛⌉n⌈log2⁡n⌉ coin flips.

    Combining the two algorithms:

    • First, use the first algorithm to obtain a random subset.
    • If the subset size is less than 𝑛2n2, use the second algorithm to continuously add elements until the size reaches 𝑛2n2.
    • If the subset size exceeds 𝑛2n2, use the second algorithm to continuously remove elements until the size is reduced to 𝑛2n2.

    Now analyze the number of operations needed for steps 2 and 3 (i.e., the number of additions/removals of elements):

    • Let indicator variable 𝑋𝑖Xi denote whether element 𝑖i is selected into the initial subset, and let 𝑋 :=𝑋1 +⋯ +𝑋𝑛X:=X1+⋯+Xn denote the subset size. The number of operations needed in steps 2 and 3 equals ∣𝑋 −E[𝑋]∣|X−E[X]|. Taking 𝑡 =𝑐 ⋅√𝑛t=c⋅n (where 𝑐c is any constant) in Hoeffding's inequality gives Pr[∣𝑋 −E[𝑋]∣ ≥𝑡] ≤2e−𝑐2Pr[|X−E[X]|≥t]≤2e−c2. That is, by allowing a Θ(√𝑛)Θ(n)-level deviation, we can achieve any desired constant-level failure probability.

    So far we have shown that this algorithm can with high probability guarantee the number of coin flips is within 𝑛 +Θ(√𝑛log⁡𝑛)n+Θ(nlog⁡n).

    • Here 𝑛n comes from the coin flips needed to obtain the initial subset; Θ(√𝑛log⁡𝑛)Θ(nlog⁡n) is the total overhead for Θ(√𝑛)Θ(n) additions/removals.
    Expected Complexity Calculation

    Let's analyze from another perspective, trying to calculate the expected number of coin flips for this algorithm.

    Use Hoeffding's inequality to find an upper bound on the expected number of operations in steps 2 and 3:
