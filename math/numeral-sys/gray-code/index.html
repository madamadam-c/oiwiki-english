    Gray Code

    Gray code is a binary numeral system in which any two consecutive numbers differ in only one binary digit. For example, the Gray code sequence for 3-bit binary numbers is:

    000,001,011,010,110,111,101,100000,001,011,010,110,111,101,100

    Note that the sequence indices are zero-based, meaning 𝐺(0) =000G(0)=000 and 𝐺(4) =110G(4)=110.

    Gray code was proposed by Frank Gray of Bell Labs in the 1940s and was patented in 1953.

    Constructing Gray Code (Transformation)

    There are many methods for constructing Gray code. We will first introduce manual construction methods, then provide the implementation code along with a correctness proof.

    Manual Construction

    𝑘k-bit Gray code can be constructed using the following method. Starting from the all-zero Gray code, follow this strategy:

    1. Flip the least significant bit to get the next Gray code (e.g., 000 →001000→001).
    2. Flip the bit to the left of the rightmost 11 to get the next Gray code (e.g., 001 →011001→011).

    Alternating between these two strategies for 2𝑘−12k−1 iterations yields the complete 𝑘k-bit Gray code sequence.

    Mirror Construction

    𝑘k-bit Gray code can be quickly obtained from (𝑘 −1)(k−1)-bit Gray code by reflecting it vertically and prefixing the reflected part with new bits, as shown in the diagram:

    Correctness Proof

    We will now prove that in the Gray code sequence generated by the formula above, any two consecutive Gray codes differ in exactly one binary digit.

    Consider the difference between 𝑛n and 𝑛 +1n+1. Adding 11 to 𝑛n turns all consecutive 11s at the end of 𝑛n into 00s (flipping them), and turns the lowest 00 into 11. We can represent the binary digits of 𝑛n and 𝑛 +1n+1 as follows:

    (𝑛)2=⋯011⋯11⏟𝑘 ones(𝑛+1)2=⋯100⋯00⏟𝑘 zeros(n)2=⋯011⋯11⏟k ones(n+1)2=⋯100⋯00⏟k zeros

    When computing 𝑔(𝑛)g(n) and 𝑔(𝑛 +1)g(n+1), the last 𝑘k bits both become 100⋯00⏟𝑘 bits100⋯00⏟k bits, while the (𝑘 +1)(k+1)-th bit differs because 𝑛n and 𝑛 +1n+1 are identical except for the last 𝑘 +1k+1 bits. Thus the (𝑘 +1)(k+1)-th bit either XORs with 11 in both cases or XORs with 00 in both cases. In either scenario, the (𝑘 +1)(k+1)-th bit is different. The bits beyond the last 𝑘 +1k+1 perform the same XOR operation and therefore remain identical.

    Q.E.D.

    Practical Applications

    Gray code has several useful and sometimes unexpected applications:

    • The 𝑘k-bit Gray code sequence can serve as a Hamiltonian cycle on the vertices of a 𝑘k-dimensional hypercube (a square in 2D, a unit vector in 1D), where each bit of the Gray code represents a coordinate along one dimension.

    • Gray code is used to minimize signal transmission errors in digital-to-analog converters (such as sensors) because only one bit changes at a time.

    • Gray code can be used to solve the Tower of Hanoi problem.

      Let the number of disks be 𝑛n. We start from the 𝑛n-bit all-zero Gray code 𝐺(0)G(0) and move to the next Gray code in sequence (𝐺(𝑖)G(i) moves to 𝐺(𝑖 +1)G(i+1)). The 𝑖i-th binary digit of the current Gray code represents the 𝑖i-th disk from smallest to largest.

      Since only one binary digit changes per step, when the 𝑖i-th digit changes, we move the 𝑖i-th disk. During disk movement, except for the smallest disk, any other disk has only one placement option when moving. When moving the smallest disk, we always have two placement options. Our strategy is as follows:

      If 𝑛n is odd, the disk movement path is 𝑓 →𝑡 →𝑟 →𝑓 →𝑡 →𝑟 →⋯f→t→r→f→t→r→⋯, where 𝑓f is the starting peg, 𝑡t is the final peg where all disks are stacked, and 𝑟r is the auxiliary peg.

      If 𝑛n is even: 𝑓 →𝑟 →𝑡 →𝑓 →𝑟 →𝑡 →⋯f→r→t→f→r→t→⋯.

    • Gray code is also used in genetic algorithm theory.
