    Linear Basis

    Recall the concept of basis vectors in solid geometry from high school mathematics. We can find a set of basis vectors 𝒊i, 𝒋j, 𝒌k in three-dimensional Euclidean space, after which any vector in space can be expressed by these basis vectors. In other words, we can describe an infinite three-dimensional space using finite basis vectors, which demonstrates the importance of basis vectors.

    Three-dimensional Euclidean space is a special vector space. The basis vectors of three-dimensional Euclidean space are generalized to linear bases in vector spaces.

    In OI, applications of linear bases generally involve only two types of vector spaces: the 𝑛n-dimensional real vector space 𝐑𝑛Rn and the 𝑛n-dimensional Boolean field vector space 𝐙𝑛2Z2n. We will introduce these in detail in the Applications section. If you are not familiar with linear algebra, it is recommended to start reading from the applications section.

    The following will introduce linear bases from the perspective of general vector spaces and present common properties of linear bases.

    Prerequisites: Vector space.

    A linear basis is a basis of a vector space and an important tool for studying vector spaces.

    Definition

    A maximal linearly independent set of a vector space 𝑉V is called a set of Hamel bases or linear bases, or simply bases.

    The basis of the vector space {𝜃}{θ} is defined as the empty set.

    It can be proven that any vector space has a linear basis1. We define the dimension of a vector space 𝑉V as the number of elements (or cardinality) in its linear basis, denoted as dim⁡𝑉dim⁡V.

    Properties

    1. For a finite-dimensional vector space 𝑉V, let its dimension be 𝑛n, then:

      1. Any 𝑛 +1n+1 vectors in 𝑉V are linearly dependent.

      2. Any 𝑛n linearly independent vectors in 𝑉V form a basis of 𝑉V.

      3. If any vector in 𝑉V can be linearly expressed by the vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an, then it is a basis of 𝑉V.

        Proof

        Take any basis 𝑏1,𝑏2,…,𝑏𝑛b1,b2,…,bn in 𝑉V. From the given conditions, the vector set 𝑏1,𝑏2,…,𝑏𝑛b1,b2,…,bn can be linearly expressed by 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an, hence

        𝑛=rank⁡{𝑏1,𝑏2,…,𝑏𝑛}≤rank⁡{𝑎1,𝑎2,…,𝑎𝑛}≤𝑛n=rank⁡{b1,b2,…,bn}≤rank⁡{a1,a2,…,an}≤n

        Therefore rank⁡{𝑎1,𝑎2,…,𝑎𝑛} =𝑛rank⁡{a1,a2,…,an}=n

      4. Any linearly independent vector set 𝑎1,𝑎2,…,𝑎𝑚a1,a2,…,am in 𝑉V can be extended to a basis of 𝑉V by inserting some vectors.

    2. (Subspace dimension formula) Let 𝑉1,𝑉2V1,V2 be finite-dimensional vector spaces over ℙP, and 𝑉1 +𝑉2V1+V2 and 𝑉1 ∩𝑉2V1∩V2 are also finite-dimensional, then dim⁡𝑉1 +dim⁡𝑉2 =dim⁡(𝑉1 +𝑉2) +dim⁡(𝑉1 ∩𝑉2)dim⁡V1+dim⁡V2=dim⁡(V1+V2)+dim⁡(V1∩V2)

      Proof

      Let dim⁡𝑉1 =𝑛1dim⁡V1=n1,dim⁡𝑉2 =𝑛2dim⁡V2=n2,dim⁡(𝑉1 ∩𝑉2) =𝑚dim⁡(V1∩V2)=m.

      Take a basis 𝑎1,𝑎2,…,𝑎𝑚a1,a2,…,am of 𝑉1 ∩𝑉2V1∩V2 and extend it to bases of 𝑉1V1 and 𝑉2V2 respectively: 𝑎1,𝑎2,…,𝑎𝑚,𝑏1,𝑏2,…,𝑏𝑛1−𝑚a1,a2,…,am,b1,b2,…,bn1−m and 𝑎1,𝑎2,…,𝑎𝑚,𝑐1,𝑐2,…,𝑐𝑛2−𝑚a1,a2,…,am,c1,c2,…,cn2−m.

      Next, we only need to prove that the vector set 𝑎1,𝑎2,…,𝑎𝑚,𝑏1,𝑏2,…,𝑏𝑛1−𝑚,𝑐1,𝑐2,…,𝑐𝑛2−𝑚a1,a2,…,am,b1,b2,…,bn1−m,c1,c2,…,cn2−m is linearly independent.

      Let ∑𝑚𝑖=1𝑟𝑖𝑎𝑖 +∑𝑛1−𝑚𝑖=1𝑠𝑖𝑏𝑖 +∑𝑛2−𝑚𝑖=1𝑡𝑖𝑐𝑖 =𝜃∑i=1mriai+∑i=1n1−msibi+∑i=1n2−mtici=θ.

      Then ∑𝑛2−𝑚𝑖=1𝑡𝑖𝑐𝑖 = −∑𝑚𝑖=1𝑟𝑖𝑎𝑖 −∑𝑛1−𝑚𝑖=1𝑠𝑖𝑏𝑖∑i=1n2−mtici=−∑i=1mriai−∑i=1n1−msibi.

      Note that the left side is in 𝑉2V2 and the right side is in 𝑉1V1, so both sides are in 𝑉1 ∩𝑉2V1∩V2. Therefore ∑𝑛2−𝑚𝑖=1𝑡𝑖𝑐𝑖 =∑𝑚𝑖=1𝑘𝑖𝑎𝑖∑i=1n2−mtici=∑i=1mkiai

      Hence 𝑡1 =𝑡2 =⋯ =𝑡𝑛2−𝑚 =𝑘1 =𝑘2 =⋯ =𝑘𝑚 =0t1=t2=⋯=tn2−m=k1=k2=⋯=km=0, and then 𝑟1 =𝑟2 =⋯ =𝑟𝑚 =𝑠1 =𝑠2 =⋯ =𝑠𝑛1−𝑚 =𝑡1 =𝑡2 =⋯ =𝑡𝑛2−𝑚 =0r1=r2=⋯=rm=s1=s2=⋯=sn1−m=t1=t2=⋯=tn2−m=0

    3. Let 𝑉1,𝑉2V1,V2 be finite-dimensional vector spaces over ℙP, and 𝑉1 +𝑉2V1+V2 and 𝑉1 ∩𝑉2V1∩V2 are also finite-dimensional. Then the following are equivalent:

      1. 𝑉1 +𝑉2 =𝑉1 ⊕𝑉2V1+V2=V1⊕V2.

      2. dim⁡𝑉1 +dim⁡𝑉2 =dim⁡(𝑉1 +𝑉2)dim⁡V1+dim⁡V2=dim⁡(V1+V2).

      3. If 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is a basis of 𝑉1V1, 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm is a basis of 𝑉2V2, then 𝑎1,𝑎2,…,𝑎𝑛,𝑏1,𝑏2,…,𝑏𝑚a1,a2,…,an,b1,b2,…,bm is a basis of 𝑉1 +𝑉2V1+V2.

      Note

      Properties 1 and 3 can be extended to infinite-dimensional vector spaces

    Orthogonal Bases and Orthonormal Bases

    If a basis 𝐵B of a vector space 𝑉V satisfies ∀𝑏,𝑏′ ∈𝐵, (𝑏,𝑏′) ≠0 ⟺ 𝑏 =𝑏′∀b,b′∈B, (b,b′)≠0⟺b=b′ (i.e., pairwise orthogonal), then this basis is called an orthogonal basis.

    If an orthogonal basis 𝐵B of a vector space 𝑉V also satisfies ∀𝑏 ∈𝐵, |𝑏| =√(𝑏,𝑏) =1∀b∈B, |b|=(b,b)=1, then this basis is called an orthonormal basis.

    Any basis of a finite-dimensional vector space 𝑉V can be transformed into an orthogonal basis through Gram-Schmidt orthogonalization.

    Applications

    Based on the previous content, we can use linear bases to:

    1. Find the rank of a given vector set.

    2. For a given vector set, find a maximal linearly independent set (or a basis of the vector space it spans).

    3. Insert some vectors into a given vector set, and find a maximal linearly independent set in the resulting vector set (or a basis of the vector space it spans).

    4. For a maximal linearly independent set (or basis) found, determine whether a certain vector can be linearly expressed by it.

    5. For a maximal linearly independent set (or basis) found, find special elements (such as maximum, minimum, etc.) in the vector space it spans.

    In OI, we generally refer to the linear basis in the 𝑛n-dimensional real vector space 𝐑𝑛Rn as the real linear basis, and the linear basis in the 𝑛n-dimensional Boolean field vector space 𝐙𝑛2Z2n as the XOR linear basis.

    Tip

    In 𝐙2Z2, addition is XOR and multiplication is AND. It can be proven that 𝐙2Z2 is a field.

    It can be proven that the algebraic system (𝐙𝑛2, +, ⋅,𝐙2)(Z2n,+,⋅,Z2) is a vector space, where:

    (𝑎1,…,𝑎𝑛)+(𝑏1,…,𝑏𝑛):=(𝑎1+𝑏1,…,𝑎𝑛+𝑏𝑛),(a1,…,an)+(b1,…,bn):=(a1+b1,…,an+bn), 𝑘⋅(𝑎1,…,𝑎𝑛):=(𝑘𝑎1,…,𝑘𝑎𝑛).k⋅(a1,…,an):=(ka1,…,kan).

    That is, addition is XOR and scalar multiplication is AND.

    Taking the XOR linear basis as an example, we can construct an XOR linear basis 𝐵 ={𝑏1,…,𝑏𝑛}B={b1,…,bn} from a given set of Boolean sequences 𝑋 ={𝑥1,…,𝑥𝑚}X={x1,…,xm}. This basis has the following properties:

    1. The XOR sum of any non-empty subset of 𝐵B is not 00.

    2. For any element 𝑥x in 𝑋X, there exist some elements in 𝐵B whose XOR sum is 𝑥x.

    3. For any set 𝐵′B′ satisfying the above two properties, the number of elements in 𝐵′B′ is not less than the number of elements in 𝐵B.

    We can use the XOR linear basis to:

    1. Determine whether a number can be expressed as the XOR sum of a subset of a given number set.

    2. Find the number of ways to express a number as the XOR sum of a subset of a given number set.

    3. Find the maximum/minimum/𝑘k-th largest/𝑘k-th smallest XOR sum of a subset of a given number set.

    4. Find the rank of a number in the XOR sums of a subset of a given number set.

    Construction Methods

    Since there is no essential difference between XOR linear bases and real linear bases, we will use XOR linear bases as an example. The code for real linear bases only requires minor modifications.

    Greedy Method

    For each number 𝑝p in the original set, convert to binary and scan from high to low. For bit 𝑥x that is 11, if 𝑎𝑥ax does not exist, then set 𝑎𝑥 ←𝑝ax←p and end the scan. If it exists, set 𝑝 ←𝑝 xor 𝑎𝑥p←p xor ax.

    To query the maximum XOR of any elements in the original set, scan the linear basis from high to low. If XORing with the current 𝑎𝑥ax makes the answer larger, XOR the answer with 𝑎𝑥ax.

    Why does this work? Because scanning from high to low, if we are at bit 𝑖i, it means we can ensure bit 𝑖i of the answer is 11, and there will be no opportunity to change bit 𝑖i later.

    To query the minimum XOR of any elements in the original set, simply take the smallest element in the linear basis set.

    To query whether a number can be XORed out, similar to insertion. If the final inserted number 𝑝p becomes 00 through XOR, then it can be XORed out.

      if (deg(a[i], col)) {
        std::swap(a[row], a[i]);
        break;

    if (!deg(a[row], col)) continue;
    for (int i = 1; i <= n; ++i) {
      if (i == row) continue;
      if (deg(a[i], col)) {
        a[i] ^= a[row];
      }
    }
    ++row;
  }
  ull ans = 0;
  for (int i = 1; i < row; ++i) {
    ans ^= a[i];
  }
  cout << ans << '\n';
  return 0;
}

    Properties

    The linear basis constructed by the greedy method has the following properties:

    • The linear basis has no subset whose XOR sum is 00.

    • The highest bits of the numbers in the linear basis are all different.

    The linear basis constructed by the Gaussian elimination method satisfies the following properties:

    • The matrix after Gaussian elimination is a row-reduced echelon matrix.

      This property includes the two properties satisfied by the linear basis constructed by the greedy method.

      If you don't understand the correctness of this property, you can refer to Gaussian elimination.

    Time Complexity

    Let the vector length be 𝑛n and total count be 𝑚m. The time complexity is 𝑂(𝑛𝑚)O(nm). The constant for Gaussian elimination is slightly larger.

    For real linear bases, the time complexity is 𝑂(𝑛2𝑚)O(n2m).

    Merging Linear Bases

    Merging linear bases can be done by brute force: insert one linear basis into another. The time complexity of a single merge is 𝑂(𝑛2)O(n2) for XOR linear bases or 𝑂(𝑛3)O(n3) for real linear bases.

    Intersection of Linear Bases

    Strictly speaking, the intersection of linear bases is finding a linear basis of the intersection of the two vector spaces spanned by them. This section introduces two algorithms. Both algorithms have time complexity 𝑂(𝑛2)O(n2) for XOR linear bases or 𝑂(𝑛3)O(n3) for real linear bases.

    Naive Algorithm

    Let the linear bases to intersect be 𝛼α and 𝛽β. The algorithm for intersecting linear bases is just a modification of the brute-force merge algorithm (using XOR linear bases as an example):

    • Try to insert each vector 𝛽𝑗βj from linear basis 𝛽β into 𝛼α using the greedy method, and initialize the intersection linear basis 𝛾γ as the empty set.

    • During insertion, record the contribution of elements from linear basis 𝛽β in the vector being inserted. Specifically, maintain a new vector 𝑏b, initialized as 𝛽𝑗βj. Moreover, if the vector being inserted is XORed with the vector at the 𝑥x-th position of the linear basis, then contribution 𝑏b should also be XORed with the recorded contribution 𝑏𝑥bx at position 𝑥x.

    • If insertion succeeds and vector 𝛽′𝑗βj′ is inserted at the 𝑥x-th position of the linear basis, change the recorded 𝑏𝑥bx at position 𝑥x to the contribution 𝑏b from linear basis 𝛽β obtained during the process of getting 𝛽′𝑗βj′.

    • If insertion fails, insert the recorded contribution 𝑏b of linear basis 𝛽β into 𝛾γ.

    The linear basis 𝛾γ obtained this way is the desired intersection. Of course, this algorithm also finds the union of linear bases.

    Explanation of the algorithm

    Let the merged linear basis be {𝛼1,⋯,𝛼𝑚,𝛽′𝑗1,⋯,𝛽′𝑗ℓ}{α1,⋯,αm,βj1′,⋯,βjℓ′}, where 𝛽′𝑗𝑘βjk′ is the vector obtained from inserting 𝛽𝑗𝑘βjk. Then {𝛼1,⋯,𝛼𝑚,𝛽𝑗1,⋯,𝛽𝑗ℓ}{α1,⋯,αm,βj1,⋯,βjℓ} is also a merged linear basis. Let 𝛽+β+ be the set {𝛽𝑗1,⋯,𝛽𝑗ℓ}{βj1,⋯,βjℓ}, then the merged basis can be written as 𝛼 ∪𝛽+α∪β+. Moreover, every vector 𝑐c in the sum space can be uniquely represented as

    𝑐=𝑎⊕𝑏c=a⊕b

    where 𝑎 ∈span⁡𝛼a∈span⁡α and 𝑏 ∈span⁡𝛽+b∈span⁡β+. The 𝑏b in this decomposition is what the algorithm attempts to record as "the contribution of elements in linear basis 𝛽β". Strictly speaking, it is only the contribution of vectors that were successfully inserted from 𝛽β.

    For successful insertions, the finally recorded 𝑏b is the 𝑏b term in this decomposition. Let 𝛽𝑗 ∈𝛽+βj∈β+. Initially, 𝛽𝑗 =0 ⊕𝛽𝑗βj=0⊕βj is already the correct decomposition of 𝛽𝑗βj on basis 𝛼 ∪𝛽+α∪β+. When updating 𝛽′𝑗 =𝑎 ⊕𝑏βj′=a⊕b to 𝛽′𝑗 ⊕𝑐𝑥βj′⊕cx, because 𝛽′𝑗 ⊕𝑐𝑥 =(𝑎 ⊕𝑎𝑥) ⊕(𝑏 ⊕𝑏𝑥)βj′⊕cx=(a⊕ax)⊕(b⊕bx), we only need to update 𝑏b to 𝑏 ⊕𝑏𝑥b⊕bx to ensure the decomposition remains correct. Therefore, by induction, when finally inserting 𝛽′𝑗βj′ into the merged linear basis, the recorded contribution 𝑏b is the 𝑏b term in the above decomposition.

    For failed insertions, the variable to be finally inserted becomes 00, and the contribution 𝑏b at this time should be inserted into 𝛾γ. At this point, repeating the above argument still ensures that during the insertion process we always have 𝛽′𝑗 =𝑎 ⊕𝑏βj′=a⊕b, and 𝑎 ∈span⁡𝛼a∈span⁡α, but 𝑏b is no longer in span⁡𝛽+span⁡β+. This is because initially 𝛽𝑗 =0 ⊕𝛽𝑗βj=0⊕βj has 𝛽𝑗 ∉𝛽+βj∉β+. In addition, the terms XORed during contribution updates all belong to span⁡𝛽+span⁡β+. So in fact, 𝑏 ⊕𝛽𝑗 ∈span⁡𝛽+b⊕βj∈span⁡β+.

    So why does inserting these 𝑏b's from failed insertions into 𝛾γ give a linear basis of the intersection space? First, insertion of 𝛽𝑗βj fails, so finally we get 0 =𝑎 ⊕𝑏0=a⊕b, where 𝑎 ∈span⁡𝛼a∈span⁡α and 𝑏 ∈span⁡(𝛽+ ∪{𝛽𝑗}) ⊆span⁡𝛽b∈span⁡(β+∪{βj})⊆span⁡β. Therefore, 𝑏 =𝑎b=a must be in the intersection space span⁡𝛼 ∩span⁡𝛽span⁡α∩span⁡β. Conversely, let 𝑐c be any element in the intersection space. Since 𝑐 ∈span⁡𝛽c∈span⁡β, 𝑐c can be expressed as a linear combination (XOR sum) of elements in 𝛽β:

    𝑐=⨁𝛽𝑗∈𝛽𝜆𝑗𝛽𝑗,c=⨁βj∈βλjβj,

    where 𝜆𝑗 ∈{0,1}λj∈{0,1}. For each 𝛽𝑗 ∉𝛽+βj∉β+, denote the contribution inserted into 𝛾γ as 𝑏𝑗bj. Then

    𝑐⊕⨁𝛽𝑗∉𝛽+𝜆𝑗𝑏𝑗=⨁𝛽𝑗∈𝛽+𝜆𝑗𝛽𝑗+⨁𝛽𝑗∉𝛽+𝜆𝑗(𝛽𝑗⊕𝑏𝑗),c⊕⨁βj∉β+λjbj=⨁βj∈β+λjβj+⨁βj∉β+λj(βj⊕bj),

    Note that both 𝑏𝑗bj and 𝑐c are in the intersection space, so the left side must also be in the intersection space. Hence the left side can be written as a linear combination of elements in 𝛼α. Meanwhile, on the right side, all terms either have 𝛽𝑗 ∈𝛽+βj∈β+ or have 𝛽𝑗 ∉𝛽+βj∉β+ and 𝛽𝑗 ⊕𝑏𝑗 ∈𝛽+βj⊕bj∈β+. So the right side is actually a linear combination of elements in 𝛽+β+. But since 𝛼 ∪𝛽+α∪β+ is linearly independent, all coefficients are 00. That is, 𝑐 =⨁𝛽𝑗∉𝛽+𝜆𝑗𝑏𝑗 ∈span⁡{𝑏1,⋯,𝑏𝑗}c=⨁βj∉β+λjbj∈span⁡{b1,⋯,bj}. This shows that these contributions 𝑏b from failed insertions together span the intersection space.

    According to this explanation, the purpose of maintaining contribution 𝑏b in the process is actually to maintain the decomposition 𝑎 ⊕𝑏a⊕b. Moreover, when finally inserting contributions into 𝛾γ, we always have 𝑎 =𝑏a=b. So regardless of maintaining contributions of elements in 𝛼α or 𝛽β (i.e., maintaining 𝑎a or 𝑏b), the result is correct. If we want to maintain the contribution of elements in linear basis 𝛼α, we only need to modify the initial values of the corresponding contributions: each vector 𝛼𝑖αi in 𝛼α initially has contribution 𝛼𝑖αi, and each inserted 𝛽𝑗βj initially has contribution 00.

    #include <array>
#include <iostream>

class LinearBasis {
  static constexpr int K = 30;
  std::array<int, K> a;

  // Size of basis.
  int size() const {
    int res = 0;
    for (auto x : a) {
      if (x) {
        ++res;
      }
    }
    return res;
  }

 public:
  LinearBasis() : a{} {}

  // Insert vector x.
  void insert(int x) {
    for (int k = K - 1; ~k && x; --k) {
      if ((x >> k) & 1) {
        if (!a[k]) {
          a[k] = x;
        }
        x ^= a[k];
      }
    }
  }

  // Return a basis for *THIS intersecting RHS.
  LinearBasis intersect(const LinearBasis& rhs) const {
    LinearBasis res;
    std::array<int, K> c = a, b_parts = {};
    for (int i = K - 1; ~i; --i) {
      int x = rhs.a[i], b_part = x;
      for (int k = i; ~k && x; --k) {
        if ((x >> k) & 1) {
          if (!c[k]) {
            c[k] = x;
            b_parts[k] = b_part;
          }
          x ^= c[k];
          b_part ^= b_parts[k];
        }
      }
      res.insert(b_part);
    }
    return res;
  }

  // Output.
  void print() const {
    std::cout << size();
    for (auto x : a) {
      if (x) {
        std::cout << ' ' << x;
      }
    }
    std::cout << '\n';
  }
};

int main() {
  int t;
  std::cin >> t;
  for (; t; --t) {
    LinearBasis a, b;
    int n;
    std::cin >> n;
    for (; n; --n) {
      int x;
      std::cin >> x;
      a.insert(x);
    }
    int m;
    std::cin >> m;
    for (; m; --m) {
      int x;
      std::cin >> x;
      b.insert(x);
    }
    a.intersect(b).print();
  }
  return 0;
}

    Zassenhaus Algorithm

    Another equivalent approach is the Zassenhaus algorithm, which can also calculate both the union and intersection of two linear bases simultaneously. The complexity is exactly the same as above.

    The specific steps are:

    • Initialize a linear basis 𝛾γ with vector length 2𝑛2n as empty, where vectors are written in the form (𝑎,𝑏)(a,b), and both 𝑎a and 𝑏b have length 𝑛n.

    • Insert elements of 𝛼α into 𝛾γ in the form (𝛼𝑖,𝛼𝑖)(αi,αi).

    • Insert elements of 𝛽β into 𝛾γ in the form (𝛽𝑗,0)(βj,0).

    • Among all non-zero elements (𝑐𝑘,𝑑𝑘)(ck,dk) in the resulting linear basis 𝛾γ, the collection of 𝑐𝑘ck from vectors where 𝑐𝑘 ≠0ck≠0 forms a basis of the union of 𝛼α and 𝛽β, and the collection of 𝑑𝑘dk from vectors where 𝑐𝑘 =0ck=0 forms a basis of the intersection of 𝛼α and 𝛽β.

    The method for constructing linear bases in the algorithm can be the greedy method or Gaussian elimination method, as long as the linear basis in 𝛾γ forms a row echelon matrix.

    Comparing the elimination steps in the Zassenhaus algorithm with the naive algorithm above, it is easy to find that the greedy-based Zassenhaus algorithm is equivalent to the naive algorithm that maintains contributions of 𝛼α elements. If instead we first insert all (𝛼𝑖,0)(αi,0), then insert all (𝛽𝑗,𝛽𝑗)(βj,βj), then the greedy-based Zassenhaus algorithm is equivalent to the naive algorithm that maintains contributions of 𝛽β elements. Based on the equivalence of elimination steps, the correctness of the Zassenhaus algorithm also holds.

    Additionally, we can provide an independent and more general algebraic proof:

    Correctness proof

    Let 𝑉V be a vector space with subspaces 𝑈 =span⁡𝛼U=span⁡α and 𝑊 =span⁡𝛽W=span⁡β. The algorithm itself is equivalent to finding a basis 𝛾γ of

    𝐻=span⁡({(𝛼𝑖,𝛼𝑖):𝛼𝑖∈𝛼}∪{(𝛽𝑗,0):𝛽𝑗∈𝛽})H=span⁡({(αi,αi):αi∈α}∪{(βj,0):βj∈β})

    by reducing to row echelon form. At the end of the algorithm, elements (𝑐𝑘,𝑑𝑘)(ck,dk) in 𝛾γ need to be divided into two categories according to whether 𝑐𝑘 ≠0ck≠0. So consider the projection mapping 𝜋 :𝐻 →𝑉π:H→V with 𝜋(𝑎,𝑏) =𝑎π(a,b)=a. Then 𝜋(𝐻) =𝑈 +𝑊π(H)=U+W and it is easy to verify

    ker⁡𝜋=𝐻∩({0}×𝑉)={0}×(𝑈∩𝑊).ker⁡π=H∩({0}×V)={0}×(U∩W).

    According to theorems on linear mappings, dim⁡𝐻 =dim⁡𝜋(𝐻) +dim⁡ker⁡𝜋 =dim⁡(𝑈 +𝑊) +dim⁡(𝑈 ∩𝑊)dim⁡H=dim⁡π(H)+dim⁡ker⁡π=dim⁡(U+W)+dim⁡(U∩W).

    The first few columns of a row echelon matrix are still a row echelon matrix, so the number of rows where 𝑐𝑘 ≠0ck≠0 exactly equals the row rank of 𝛼 ∪𝛽α∪β, which is dim⁡(𝑈 +𝑊)dim⁡(U+W). Moreover, the set of 𝑐𝑘ck from these rows forms a basis of 𝑈 +𝑊U+W. The remaining non-zero rows exactly number dim⁡(𝑈 ∩𝑊)dim⁡(U∩W), and all satisfy 𝑐𝑘 =0ck=0. For 𝑑𝑘dk in these rows, since (0,𝑑𝑘) ∈ker⁡𝜋(0,dk)∈ker⁡π, we have 𝑑𝑘 ∈𝑈 ∩𝑊dk∈U∩W. Moreover, (0,𝑑𝑘)(0,dk) as a row in a row echelon matrix must be linearly independent, which shows these 𝑑𝑘dk are all linearly independent. Together, these 𝑑𝑘dk form a linearly independent set of size dim⁡(𝑈 ∩𝑊)dim⁡(U∩W) in the intersection space 𝑈 ∩𝑊U∩W, so they must also be a basis of this space.

    Extension: Prefix Linear Basis

    This section only discusses the case of XOR linear bases, and assumes a single vector can be stored in 𝑂(1)O(1) space, with single operation complexity always 𝑂(1)O(1).

    For cases requiring multiple queries of maximum XOR in intervals, one common approach is to use Cat tree combined with linear basis, with time complexity 𝑂(𝑛𝑚log⁡𝑚 +𝑛2𝑞)O(nmlog⁡m+n2q), where 𝑛n is vector length, 𝑚m is sequence length, 𝑞q is number of queries. Another viable approach is to use prefix linear bases (or timestamp linear bases), which can reduce complexity to 𝑂(𝑛(𝑚 +𝑞))O(n(m+q)).

    A prefix linear basis maintains the linear basis of all suffixes for each prefix of the sequence, allowing us to query the linear basis of each interval. Note that the linear bases of all suffixes [𝑗,𝑖][j,i] of a prefix [1,𝑖][1,i] are mutually contained: the linear basis of [𝑗,𝑖][j,i] always contains the linear basis of [𝑗 +1,𝑖][j+1,i]. Therefore, among these suffix linear bases, there are at most 𝑛n different types, and they can always be obtained by progressively adding new vectors to an empty set to get all these suffix linear bases from [𝑖,𝑖][i,i] to [1,𝑖][1,i]. Therefore, using this monotonicity, for each added vector 𝑣v, we just need to mark its maximum index 𝑡t, and we can store all suffix linear bases in 𝑂(𝑛)O(n) space. Moreover, when querying the linear basis corresponding to interval [𝑗,𝑖][j,i], we only need to keep vectors with timestamp 𝑡 ≥𝑗t≥j in the prefix linear basis at position 𝑖i.

    We can call the timestamp 𝑡t of each vector 𝑣v its timestamp. A vector 𝑣v in the linear basis can always be expressed as the XOR sum of some elements in the original sequence, for example 𝑣𝑖1 ⊕𝑣𝑖2 ⊕⋯ ⊕𝑣𝑖𝑘vi1⊕vi2⊕⋯⊕vik. Among all such possible representations, the maximum value of the minimum index is 𝑡t, that is,

    𝑡(𝑣)=max{𝑗:∃𝑖1,⋯,𝑖𝑘∈[𝑗,𝑖] s.t. 𝑣=𝑣𝑖1⊕𝑣𝑖2⊕⋯⊕𝑣𝑖𝑘}.t(v)=max{j:∃i1,⋯,ik∈[j,i] s.t. v=vi1⊕vi2⊕⋯⊕vik}.

    This expression is just a formal way of writing the previous paragraph's description. What it gives us is that to maintain the timestamp of each vector 𝑣v in the linear basis, we just need to greedily select vectors as new as possible to replace old ones.

    Based on the greedy method mentioned above for constructing linear bases, the prefix linear basis makes the following adjustments during construction:

    • Save a timestamp 𝑡𝑥tx for each retained vector 𝑎𝑥ax in the linear basis, initially all set to 00.

    • When adding the 𝑖i-th vector 𝑣v from the sequence, still scan from high to low, but also record the current time 𝑖i.

    • If bit 𝑥x of 𝑣v is 11, compare the timestamp 𝑡𝑥tx of the existing vector 𝑎𝑥ax in the linear basis with the current time 𝑖i:

      • If 𝑖 >𝑡𝑥i>tx, that is, the vector to be added is newer, set 𝑎𝑥ax to 𝑣v, update the timestamp to 𝑖i, and continue the addition process with the result 𝑎𝑥 ⊕𝑣ax⊕v of XORing the old 𝑎𝑥ax with 𝑣v using the recorded time 𝑡𝑥tx.
      • If 𝑖 <𝑡𝑥i<tx, that is, the vector to be added is older, do not update 𝑎𝑥ax and 𝑡𝑥tx, just XOR 𝑣v with 𝑎𝑥ax and continue the addition.

    In other words, if the current bit can be represented by a newer vector, directly use the newer vector; otherwise, keep the original vector. When updating the vector at position 𝑥x, we cannot store the XOR result 𝑎𝑥 ⊕𝑣ax⊕v at position 𝑥x, because the timestamp of the XOR result 𝑎𝑥 ⊕𝑣ax⊕v is min{𝑡(𝑎𝑥) =𝑡(𝑣)} =𝑡(𝑎𝑥)min{t(ax)=t(v)}=t(ax), which is less than the timestamp 𝑡(𝑣)t(v) of the vector 𝑣v to be added. For the same reason, the Gaussian elimination method for constructing linear bases may destroy the timestamp property when updating upward during the process, so it is no longer suitable for constructing prefix linear bases.

    #include <algorithm>
#include <array>
#include <iostream>
#include <numeric>
#include <vector>

class LinearBasis {
  static constexpr int K = 20;
  std::array<int, K> a, t;

 public:
  LinearBasis() : a{}, t{} {}

  // Insert vector x at time i.
  void insert(int x, int i) {
    for (int k = K - 1; ~k && x; --k) {
      if (((x >> k) & 1)) {
        if (i > t[k]) {
          std::swap(a[k], x);
          std::swap(t[k], i);
        }
        x ^= a[k];
      }
    }
  }

  // Find max xor of subsets of elements from time i till now.
  int query(int i) const {
    int res = 0;
    for (int k = K - 1; ~k; --k) {
      if (t[k] >= i && (res ^ a[k]) > res) {
        res ^= a[k];
      }
    }
    return res;
  }
};

int main() {
  int n;
  std::cin >> n;
  std::vector<int> c(n + 1);
  for (int i = 1; i <= n; ++i) std::cin >> c[i];
  int q;
  std::cin >> q;
  std::vector<std::array<int, 2>> qu(q);
  for (auto& v : qu) std::cin >> v[0] >> v[1];
  std::vector<int> ids(q);
  std::iota(ids.begin(), ids.end(), 0);
  std::sort(ids.begin(), ids.end(),
            [&](int l, int r) -> bool { return qu[l][1] < qu[r][1]; });
  LinearBasis lb;
  std::vector<int> res(q);
  for (int i = 1, j = 0; i <= n; ++i) {
    lb.insert(c[i], i);
    for (; j < q && qu[ids[j]][1] == i; ++j) {
      res[ids[j]] = lb.query(qu[ids[j]][0]);
    }
  }
  for (int x : res) std::cout << x << '\n';
  return 0;
}

If the properties of the linear basis obtained from Gaussian elimination are needed, they can be handled separately during queries.
