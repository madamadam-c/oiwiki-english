    Characteristic Polynomial

    This section studies only square matrices, as linear transformations corresponding to a matrix 𝐴A map 𝑛n vectors to 𝑛n vectors.

    In practical problems, we often consider repeated transformations. If we only describe that "the linear transformation corresponding to matrix 𝐴A maps the identity matrix 𝐼I to 𝐴A", it becomes abstract. The best approach is to find "fixed points", i.e., parts that remain unchanged under the transformation.

    However, in practice, the linear transformation corresponding to matrix 𝐴A may have no fixed points, so we settle for finding parts that are collinear or undergo simple deformations.

    Eigenvalues and Eigenvectors

    Under the linear transformation corresponding to matrix 𝐴A, some vectors do not change direction, only scale.

    Let 𝑉V be a vector space over 𝐹F, and 𝑇T be a linear transformation on 𝑉V. If there exists 𝜆λ in 𝐹F and a non-zero vector 𝜉ξ in 𝑉V such that:

    𝑇𝜉=𝜆𝜉Tξ=λξ

    then 𝜆λ is called an eigenvalue of 𝑇T, and 𝜉ξ is called an eigenvector of 𝑇T belonging to eigenvalue 𝜆λ.

    Eigenvectors lie on the same line; under linear transformations, they maintain their direction (being compressed to zero is also considered as not changing direction). Eigenvectors are not unique; any vector collinear with an eigenvector is also an eigenvector. However, the zero vector is not an eigenvector. Vectors with direction are naturally non-zero. The eigenvalue of an eigenvector is the factor by which it is scaled.

    In applications, for eigenvectors with the same eigenvalue, we typically select a basis as their representative set.

    Let 𝛼1,𝛼2,⋯,𝛼𝑛α1,α2,⋯,αn be a basis of 𝑉V, and 𝑇T have matrix 𝐴A with respect to this basis, i.e.:

    𝑇(𝛼1,𝛼2,⋯,𝛼𝑛)=(𝛼1,𝛼2,⋯,𝛼𝑛)𝐴T(α1,α2,⋯,αn)=(α1,α2,⋯,αn)A

    Let 𝜆0λ0 be an eigenvalue of 𝑇T, and 𝜉ξ be an eigenvector of 𝑇T belonging to 𝜆0λ0. Let a non-zero vector 𝑋X satisfy:

    𝜉=(𝛼1,𝛼2,⋯,𝛼𝑛)𝑋ξ=(α1,α2,⋯,αn)X

    Then we have:

    𝑇𝜉=𝜆0𝜉Tξ=λ0ξ𝑇(𝛼1,𝛼2,⋯,𝛼𝑛)𝑋=𝜆0(𝛼1,𝛼2,⋯,𝛼𝑛)𝑋T(α1,α2,⋯,αn)X=λ0(α1,α2,⋯,αn)X(𝛼1,𝛼2,⋯,𝛼𝑛)𝐴𝑋=𝜆0(𝛼1,𝛼2,⋯,𝛼𝑛)𝑋(α1,α2,⋯,αn)AX=λ0(α1,α2,⋯,αn)X𝐴𝑋=𝜆0𝑋AX=λ0X(𝐴−𝜆0𝐼)𝑋=0(A−λ0I)X=0

    Therefore, the corresponding determinant is also 00.

    Characteristic Polynomial

    Consider an 𝑛 ×𝑛n×n matrix 𝐴A, where 𝑛 ≥0 ∧𝑛 ∈ℤn≥0∧n∈Z. Let 𝜆λ be a parameter. The matrix 𝜆𝐼 −𝐴λI−A is called the characteristic matrix of 𝐴A.

    The determinant of the characteristic matrix is called the characteristic polynomial of 𝐴A. When expanded, it is an 𝑛n-degree polynomial with roots equal to the eigenvalues of 𝐴A, denoted 𝑝𝐴(𝜆)pA(λ):

    𝑝𝐴(𝜆)=det⁡(𝜆𝐼𝑛−𝐴)=∣ ∣ ∣ ∣ ∣𝜆−𝑎11−𝑎12⋯−𝑎1𝑛−𝑎21𝜆−𝑎22⋯−𝑎2𝑛⋮⋮⋮−𝑎𝑛1−𝑎𝑛2⋯𝜆−𝑎𝑛𝑛∣ ∣ ∣ ∣ ∣pA(λ)=det⁡(λIn−A)=|λ−a11−a12⋯−a1n−a21λ−a22⋯−a2n⋮⋮⋮−an1−an2⋯λ−ann|

    where 𝐼𝑛In is an 𝑛 ×𝑛n×n identity matrix. Some sources define 𝑝𝐴(𝜆) =det⁡(𝐴−𝜆𝐼𝑛)pA(λ)=det⁡(A−λIn), which differs from our definition by a sign ( −1)𝑛(−1)n, but using this definition ensures 𝑝𝐴(𝜆)pA(λ) is always monic, whereas the other definition is monic only when 𝑛n is even. Note that the determinant of a 0 ×00×0 matrix is 11, which is well-defined.

    The non-zero solution vectors 𝑋X of (𝜆0𝐼 −𝐴)𝑋 =0(λ0I−A)X=0 are called eigenvectors of 𝐴A belonging to 𝜆0λ0.

    The linear transformation 𝑇T has eigenvalue 𝜆0λ0 if and only if matrix 𝐴A has eigenvalue 𝜆0λ0.

    The linear transformation 𝑇T has eigenvector 𝜉ξ if and only if matrix 𝐴A has eigenvector 𝑋X, where:

    𝜉=(𝛼1,⋯,𝛼𝑛)𝑋ξ=(α1,⋯,αn)X

    By the fundamental theorem of algebra, the characteristic polynomial can be factored as:

    𝑓(𝜆)=|𝜆𝐼−𝐴|=(𝜆−𝜆1)𝑑1⋯(𝜆−𝜆𝑚)𝑑𝑚f(λ)=|λI−A|=(λ−λ1)d1⋯(λ−λm)dm

    𝑑𝑖di is called the algebraic multiplicity of eigenvalue 𝜆𝑖λi. The sum of all algebraic multiplicities equals the dimension of the space 𝑛n.

    Finding All Eigenvalues and Eigenvectors of a Matrix

    Follow these steps:

    • Compute the determinant |𝜆𝐼 −𝐴||λI−A|.
    • Find all roots of the polynomial 𝑓(𝜆) =|𝜆𝐼 −𝐴|f(λ)=|λI−A| in the field 𝐹F, i.e., the eigenvalues of 𝐴A.
    • For each eigenvalue 𝜆λ of 𝐴A, solve the homogeneous linear system (𝜆𝐼 −𝐴)𝑋 =0(λI−A)X=0, and find a fundamental set of solutions 𝑋1,⋯,𝑋𝑡X1,⋯,Xt. Then all eigenvectors of 𝐴A belonging to 𝜆λ are:
    𝑘1𝑋1+𝑘2𝑋2+⋯+𝑘𝑡𝑋𝑡k1X1+k2X2+⋯+ktXt

    where not all 𝑘𝑖ki are zero.

    • The eigenvectors of linear transformation 𝑇T belonging to 𝜆λ are:
    𝜉𝑖=(𝛼1,⋯,𝛼𝑛)𝑋𝑖ξi=(α1,⋯,αn)Xi

    Therefore, all eigenvectors belonging to 𝜆λ are:

    𝑘1𝜉1+𝑘2𝜉2+⋯+𝑘𝑡𝜉𝑡k1ξ1+k2ξ2+⋯+ktξt

    where not all 𝑘𝑖ki are zero.

    The existence of eigenvalues and eigenvectors depends on the field of 𝑉V.

    Similar Transformations

    Introduction

    If an 𝑛 ×𝑛n×n matrix 𝐴A is an upper triangular matrix, such as:

    𝐴=⎡⎢ ⎢ ⎢ ⎢⎣𝑎1,1𝑎1,2⋯𝑎1,𝑛𝑎2,2⋯𝑎2,𝑛⋱⋮𝑎𝑛,𝑛⎤⎥ ⎥ ⎥ ⎥⎦A=[a1,1a1,2⋯a1,na2,2⋯a2,n⋱⋮an,n]

    Then

    𝑝𝐴(𝑥)=det⁡(𝑥𝐼𝑛−𝐴)=⎡⎢ ⎢ ⎢ ⎢⎣𝑥−𝑎1,1−𝑎1,2⋯−𝑎1,𝑛𝑥−𝑎2,2⋯−𝑎2,𝑛⋱⋮𝑥−𝑎𝑛,𝑛⎤⎥ ⎥ ⎥ ⎥⎦=𝑛∏𝑖=1(𝑥−𝑎𝑖,𝑖)pA(x)=det⁡(xIn−A)=[x−a1,1−a1,2⋯−a1,nx−a2,2⋯−a2,n⋱⋮x−an,n]=∏i=1n(x−ai,i)

    which can be easily obtained. Lower triangular matrices are similar. However, if 𝐴A is not one of these two types, we need to use similarity transformations to make the matrix easier for finding the characteristic polynomial.

    Definition

    For 𝑛 ×𝑛n×n matrices 𝐴A and 𝐵B, if there exists an invertible 𝑛 ×𝑛n×n matrix 𝑃P such that:

    𝐵=𝑃−1𝐴𝑃B=P−1AP

    then matrices 𝐴A and 𝐵B are similar. The transformation 𝐴 ↦𝑃−1𝐴𝑃A↦P−1AP is called a similarity transformation. Also, 𝐴A and 𝑃−1𝐴𝑃P−1AP have the same characteristic polynomial.

    Consider:

    det⁡(𝑥𝐼𝑛−𝑃−1𝐴𝑃)=det⁡(𝑥𝑃−1𝐼𝑛𝑃−𝑃−1𝐴𝑃)=det⁡(𝑃−1𝑥𝐼𝑛𝑃−𝑃−1𝐴𝑃)=det⁡(𝑃−1)⋅det⁡(𝑃)⋅det⁡(𝑥𝐼𝑛−𝐴)=det⁡(𝑥𝐼𝑛−𝐴)=𝑝𝐴(𝑥)det⁡(xIn−P−1AP)=det⁡(xP−1InP−P−1AP)=det⁡(P−1xInP−P−1AP)=det⁡(P−1)⋅det⁡(P)⋅det⁡(xIn−A)=det⁡(xIn−A)=pA(x)

    The proof is complete. Similarly for 𝐴 ↦𝑃𝐴𝑃−1A↦PAP−1. Also, 𝑝𝐴(0) =( −1)𝑛 ⋅det⁡(𝐴)pA(0)=(−1)n⋅det⁡(A), because 𝑝𝐴(0) =det⁡(−1⋅𝐼𝑛𝐴) =det⁡(−1⋅𝐼𝑛) ⋅det⁡(𝐴)pA(0)=det⁡(−1⋅InA)=det⁡(−1⋅In)⋅det⁡(A), hence det⁡(𝐴) =det⁡(𝑃−1𝐴𝑃)det⁡(A)=det⁡(P−1AP).

    Theorem: Similar matrices have the same characteristic polynomial and eigenvalues, but not conversely.

    This theorem states that the characteristic polynomial of the matrix of a linear transformation is independent of the choice of basis, and is directly determined by the linear transformation itself. Hence, it can be called the characteristic polynomial of the linear transformation.

    The characteristic polynomial 𝑓(𝜆) =|𝜆𝐼 −𝐴|f(λ)=|λI−A| of matrix 𝐴A is monic. By Vieta's formulas, the coefficient of the (𝑛 −1)(n−1)-th degree term is:

    −(𝜆1+⋯+𝜆𝑛)=−(𝑎11+⋯+𝑎𝑛𝑛)=−𝑡𝑟𝐴−(λ1+⋯+λn)=−(a11+⋯+ann)=−trA

    where 𝑡𝑟𝐴trA is called the trace of 𝐴A, the sum of elements on the main diagonal.

    By Vieta's formulas, the constant term of the characteristic polynomial is:

    (−1)𝑛|𝐴|=(−1)𝑛(𝜆1⋯𝜆𝑛)(−1)n|A|=(−1)n(λ1⋯λn)

    Theorem: Similar matrices have the same trace.

    Commutation Formula

    Theorem: Regardless of whether matrices 𝐴A and 𝐵B are square or not, as long as multiplication is possible, the trace of 𝐴𝐵AB equals the trace of 𝐵𝐴BA.

    One proof is direct expansion, which completes the proof. Another proof uses the commutation formula.

    Theorem: Let 𝐴A be an 𝑚 ×𝑛m×n matrix, and 𝐵B be an 𝑛 ×𝑚n×m matrix. Then:

    𝜆𝑛|𝜆𝐼𝑚−𝐴𝐵|=𝜆𝑚|𝜆𝐼𝑛−𝐵𝐴|λn|λIm−AB|=λm|λIn−BA|

    This formula shows that 𝐴𝐵AB and 𝐵𝐴BA have the same non-zero eigenvalues.

    Schur's Lemma

    Any 𝑛 ×𝑛n×n matrix 𝐴A is similar to an upper triangular matrix. That is, there exists a full-rank matrix 𝑃P such that 𝑃−1𝐴𝑃P−1AP is an upper triangular matrix, with its main diagonal elements being all eigenvalues of 𝐴A.

    Corollary: Let the 𝑛n eigenvalues of 𝐴A be 𝜆1,⋯,𝜆𝑛λ1,⋯,λn, and 𝜙(𝑥)ϕ(x) be any polynomial. Then the 𝑛n eigenvalues of the matrix polynomial 𝜙(𝐴)ϕ(A) are:

    𝜙(𝜆1),⋯,𝜙(𝜆𝑛)ϕ(λ1),⋯,ϕ(λn)

    In particular, the eigenvalues of 𝑘𝐴kA are 𝑘𝜆1,⋯,𝑘𝜆𝑛kλ1,⋯,kλn, and the eigenvalues of 𝐴𝑚Am are 𝜆1𝑚,⋯,𝜆𝑛𝑚λ1m,⋯,λnm.

    Similarity Transformations Using Gaussian Elimination

    For an 𝑛 ×𝑛n×n matrix 𝐵B, Gaussian elimination can be applied, with basic operations being elementary row operations.

    Performing these operations on a matrix (left multiplication by elementary matrices) followed by right multiplication by their inverses is a similarity transformation. Left multiplication corresponds to row operations; similarly, right multiplication corresponds to column operations.

    If a matrix can be transformed into an upper or lower triangular form via similarity transformations, then its characteristic polynomial can be easily obtained. However, if we apply the transformation 𝐴 ↦𝑇𝑖𝑗(𝑘)𝐴𝑇𝑖𝑗( −𝑘)A↦Tij(k)ATij(−k) to elements on the subdiagonal, after eliminating element at row 𝑖i, column 𝑗j of 𝐴A using 𝐴 ↦𝑇𝑖𝑗(𝑘)𝐴A↦Tij(k)A, right multiplying by 𝑇𝑖𝑗( −𝑘)Tij(−k) will add −𝑘−k times column 𝑖i to column 𝑗j, which may cause previously zeroed elements to become non-zero. This may prevent the matrix from being transformed into upper or lower triangular form.

    Later, we will show that after applying transformations to elements on the subdiagonal, the resulting matrix can still easily yield the characteristic polynomial.

    Cayley–Hamilton Theorem

    For any 𝑛 ×𝑛n×n matrix 𝐴A, with characteristic polynomial 𝑓(𝜆) =|𝜆𝐼 −𝐴|f(λ)=|λI−A|, we have 𝑓(𝐴) =0f(A)=0.

    For a linear transformation 𝑇T, there is a parallel result: if 𝑓(𝜆)f(λ) is the characteristic polynomial of 𝑇T, then 𝑓(𝑇)f(T) is the zero transformation.

    By this theorem, for any matrix 𝐴A, there exists a polynomial that annihilates it.

    Minimal Polynomial

    Let 𝑉V be an 𝑛n-dimensional vector space. Since the matrix corresponding to a linear transformation has 𝑛2n2 elements, all linear transformations form an 𝑛2n2-dimensional vector space.

    For a specific linear transformation 𝑇T, from the 0-th application to the 𝑛n-th application, there are 𝑛2 +1n2+1 linear transformations. Their corresponding matrices are necessarily linearly dependent. Thus, there exists a non-zero polynomial 𝑓f such that 𝑓(𝑇)f(T) is the zero transformation. We say transformation 𝑇T satisfies polynomial 𝑓f. Among all polynomials 𝑓f that 𝑇T satisfies, there exists one of minimum degree.

    The monic polynomial of minimum degree that annihilates matrix 𝐴A is called the minimal polynomial of 𝐴A, denoted 𝑚𝐴(𝜆)mA(λ).

    By the Euclidean algorithm for polynomials, the minimal polynomial is unique and divides any polynomial that annihilates 𝐴A. In particular, the minimal polynomial divides the characteristic polynomial.

    Theorem: (not counting multiplicities) the characteristic polynomial 𝑓(𝜆)f(λ) and minimal polynomial 𝑚𝐴(𝜆)mA(λ) of matrix 𝐴A have the same roots.

    Theorem: Eigenvectors of matrix 𝐴A belonging to distinct eigenvalues are linearly independent.

using Matrix = std::vector<std::vector<int>>;
using i64 = int64_t;

Matrix to_upper_Hessenberg(const Matrix &M, int mod) {
  Matrix H(M);
  int n = H.size();
  for (int i = 0; i < n; ++i) {
    for (int j = 0; j < n; ++j) {
      if ((H[i][j] %= mod) < 0) H[i][j] += mod;
    }
  }
  for (int i = 0; i < n - 1; ++i) {
    int pivot = i + 1;
    for (; pivot < n; ++pivot) {
      if (H[pivot][i] != 0) break;
    }
    if (pivot == n) continue;
    if (pivot != i + 1) {
      for (int j = i; j < n; ++j) std::swap(H[i + 1][j], H[pivot][j]);
      for (int j = 0; j < n; ++j) std::swap(H[j][i + 1], H[j][pivot]);
    }
    for (int j = i + 2; j < n; ++j) {
      for (;;) {
        if (H[j][i] == 0) break;
        if (H[i + 1][i] == 0) {
          for (int k = i; k < n; ++k) std::swap(H[i + 1][k], H[j][k]);
          for (int k = 0; k < n; ++k) std::swap(H[k][i + 1], H[k][j]);
          break;
        }
        if (H[j][i] >= H[i + 1][i]) {
          int q = H[j][i] / H[i + 1][i], mq = mod - q;
          for (int k = i; k < n; ++k)
            H[j][k] = (H[j][k] + i64(mq) * H[i + 1][k]) % mod;
          for (int k = 0; k < n; ++k)
            H[k][i + 1] = (H[k][i + 1] + i64(q) * H[k][j]) % mod;
        } else {
          int q = H[i + 1][i] / H[j][i], mq = mod - q;
          for (int k = i; k < n; ++k)
            H[i + 1][k] = (H[i + 1][k] + i64(mq) * H[j][k]) % mod;
          for (int k = 0; k < n; ++k)
            H[k][j] = (H[k][j] + i64(q) * H[k][i + 1]) % mod;
        }
      }
    }
  }
  return H;
}

std::vector<int> get_charpoly(const Matrix &M, int mod) {
  Matrix H(to_upper_Hessenberg(M, mod));
  int n = H.size();
  std::vector<std::vector<int>> p(n + 1);
  p[0] = {1 % mod};
  for (int i = 1; i <= n; ++i) {
    const std::vector<int> &pi_1 = p[i - 1];
    std::vector<int> &pi = p[i];
    pi.resize(i + 1, 0);
    int v = mod - H[i - 1][i - 1];
    if (v == mod) v -= mod;
    for (int j = 0; j < i; ++j) {
      pi[j] = (pi[j] + i64(v) * pi_1[j]) % mod;
      if ((pi[j + 1] += pi_1[j]) >= mod) pi[j + 1] -= mod;
    }
    int t = 1;
    for (int j = 1; j < i; ++j) {
      t = i64(t) * H[i - j][i - j - 1] % mod;
      int prod = i64(t) * H[i - j - 1][i - 1] % mod;
      if (prod == 0) continue;
      prod = mod - prod;
      for (int k = 0; k <= i - j - 1; ++k)
        pi[k] = (pi[k] + i64(prod) * p[i - j - 1][k]) % mod;
    }
  }
  return p[n];
}

bool verify(const Matrix &M, const std::vector<int> &charpoly, int mod) {
  if (mod == 1) return true;
  int n = M.size();
  std::vector<int> randvec(n), sum(n, 0);
  std::mt19937 gen(std::random_device{}());
  std::uniform_int_distribution<int> dis(1, mod - 1);
  for (int i = 0; i < n; ++i) randvec[i] = dis(gen);
  for (int i = 0; i <= n; ++i) {
    int v = charpoly[i];
    for (int j = 0; j < n; ++j) sum[j] = (sum[j] + i64(v) * randvec[j]) % mod;
    std::vector<int> prod(n, 0);
    for (int j = 0; j < n; ++j) {
      for (int k = 0; k < n; ++k) {
        prod[j] = (prod[j] + i64(M[j][k]) * randvec[k]) % mod;
      }
    }
    randvec.swap(prod);
  }
  for (int i = 0; i < n; ++i)
    if (sum[i] != 0) return false;
  return true;
}
