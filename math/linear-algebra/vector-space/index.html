    Vector Spaces

    A vector space is a generalization of 𝑑d-dimensional Euclidean space (0 ≤𝑑 ≤30≤d≤3), and related concepts can be found in Relationship between Euclidean space and vector space.

    Prerequisites: Abelian groups, fields.

    Informally, a set closed under an operation, satisfying associativity, identity, and inverses forms a group. If it also satisfies commutativity, it forms an Abelian group.

    If a set is closed under the four arithmetic operations, it forms a field. See Basic concepts of abstract algebra for details.

    Definition

    A vector space (or linear space) is a fundamental concept and important object of study in linear algebra. A vector space is an algebraic structure (𝑉, +, ⋅,ℙ)(V,+,⋅,P) consisting of a set of vectors 𝑉V, a field ℙP, addition ++, and scalar multiplication (scalar product).

    Specifically, let (𝑉, +)(V,+) be an Abelian group, and ℙP be a field.

    Define an algebraic operation between elements of ℙP and elements of 𝑉V, called scalar multiplication: ⋅ :ℙ ×𝑉 ↦𝑉⋅:P×V↦V, denoted 𝑝 ⋅𝑣p⋅v or 𝑝𝑣pv, where 𝑝p is in field ℙP and 𝑣v is in Abelian group 𝑉V. This operation must be closed; the result is always meaningful and remains in group 𝑉V.

    And satisfy the following conditions:

    1. Scalar multiplication distributes over vector addition: For 𝐮,𝐯 ∈𝑉,𝑎 ∈ℙu,v∈V,a∈P, 𝑎(𝐮 +𝐯) =𝑎𝐮 +𝑎𝐯a(u+v)=au+av
    2. Scalar multiplication distributes over scalar addition: For 𝑎,𝑏 ∈ℙ,𝐮 ∈𝑉a,b∈P,u∈V, (𝑎 +𝑏)𝐮 =𝑎𝐮 +𝑏𝐮(a+b)u=au+bu
    3. Scalar multiplication is associative (consistent with field multiplication): For 𝑎,𝑏 ∈ℙ,𝐮 ∈𝑉a,b∈P,u∈V, 𝑎(𝑏𝐮) =(𝑎𝑏)𝐮a(bu)=(ab)u
    4. Scalar multiplication identity: Let 1 ∈ℙ1∈P be the multiplicative identity of ℙP. Then for 𝑢 ∈𝑉u∈V, 1𝐮 =𝐮1u=u

    Then the algebraic system (𝑉, +, ⋅,ℙ)(V,+,⋅,P) is called a vector space over ℙP, ℙP is called the base field of the vector space, elements of 𝑉V are called vectors, and elements of ℙP are called scalars. When ℙP is the real number field, it is called a real vector space. When ℙP is the complex number field, it is called a complex vector space.

    Whether it's a sequence of numbers, an arrow, or something else, as long as it satisfies the above axioms, it can be considered a vector, and the theory of linear algebra can be applied.

    The zero element of the additive group is called the zero vector, denoted 𝟎0 or 𝜃θ.

    The original addition and subtraction of vectors in the Abelian group, combined with the newly defined scalar multiplication, are collectively called linear operations.

    Note

    For convenience in the following discussion:

    1. Elements of 𝑉V are not bolded.
    2. The algebraic system (𝑉, +, ⋅,ℙ)(V,+,⋅,P) satisfying the vector space definition is also called a vector space.

    Please distinguish between these.

    Intuitive Understanding

    Not strictly speaking, scalar multiplication corresponds to a kind of "scaling", elements of base field ℙP represent the "ratio" of scaling, and vector addition corresponds to "superposition". At the same time, elements of ℙP also represent the "range of coordinates" for vectors.

    Conditions 1-4 describe the relationship between "scaling" and "superposition". This can be understood by considering arrows in the plane.

    Basic Properties

    Note

    The following properties can be found in group theory, etc.

    For a vector space (𝑉, +, ⋅,ℙ)(V,+,⋅,P):

    1. 𝜃θ is unique
    2. ∀𝛼 ∈𝑉∀α∈V, −𝛼−α is unique
    3. ∃0 ∈ℙ∃0∈P, ∀𝛼 ∈𝑉∀α∈V, 0𝛼 =𝜃0α=θ
    4. ∀𝑘 ∈ℙ∀k∈P, 𝑘𝜃 =𝜃kθ=θ
    5. ( −1)𝛼 = −𝛼, ∀𝛼 ∈𝑉(−1)α=−α, ∀α∈V
    6. No zero divisors: ∀𝛼 ∈𝑉,𝑘 ∈ℙ∀α∈V,k∈P, 𝑘𝛼 =𝜃 ⟹ 𝑘 =0 ∨𝛼 =𝜃kα=θ⟹k=0∨α=θ

    7. Cancellation law for addition: ∀𝛼,𝛽,𝛾 ∈𝑉∀α,β,γ∈V, 𝛼 +𝛽 =𝛼 +𝛾 ⟹ 𝛽 =𝛾α+β=α+γ⟹β=γ

      In fact, the cancellation law is a property of Abelian groups.

    Examples

    1. ℙ𝑛Pn forms a vector space over field ℙP with addition and scalar multiplication. For example, ℙP can be ℝR, ℂC, ℕ𝑝Np (where 𝑝p is prime), etc.
    2. The 𝑛 ×𝑚n×m matrices over field ℙP, denoted ℙ𝑛×𝑚Pn×m, form a vector space over ℙP with matrix addition and scalar multiplication.
    3. The ring of single-variable polynomials over field ℙP, denoted ℙ[𝑥]P[x], forms a vector space over ℙP with polynomial addition and scalar multiplication.
    4. The set of all continuous functions on interval [𝑎,𝑏][a,b] (denoted 𝐶[𝑎,𝑏]C[a,b]) forms a vector space over the codomain field with "function addition" and "scalar multiplication of functions".

    Related Concepts

    Linear Dependence, Linear Independence

    For a vector space (𝑉, +, ⋅,ℙ)(V,+,⋅,P):

    1. Vectors 𝑎1,𝑎2,…,𝑎𝑛 ∈𝑉a1,a2,…,an∈V are called a vector set.
    2. For 𝑘1,𝑘2,…,𝑘𝑛 ∈ℙk1,k2,…,kn∈P, ∑𝑛𝑖=1𝑘𝑖𝑎𝑖∑i=1nkiai is called a linear combination of the vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an.
    3. If vector 𝛽 ∈𝑉β∈V can be expressed as a linear combination of vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an, then 𝛽β is said to be linearly represented by vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an.
    4. For 𝑘1,𝑘2,…,𝑘𝑛 ∈ℙk1,k2,…,kn∈P, if the vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an satisfies ∑𝑛𝑖=1𝑘𝑖𝑎𝑖 =𝜃 ⟺ 𝑘𝑖 =0,𝑖 =1,2,…,𝑛∑i=1nkiai=θ⟺ki=0,i=1,2,…,n, then the vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is linearly independent; otherwise, the vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is linearly dependent.

    The zero vector is linearly dependent with any vector.

    Linear representation or linear dependence can be written in matrix multiplication form:

    𝛽=𝑘1𝑎1+𝑘2𝑎2+⋯+𝑘𝑟𝑎𝑟=(𝑎1,𝑎2,⋯,𝑎𝑟)⎛⎜ ⎜ ⎜ ⎜ ⎜ ⎜⎝𝑘1𝑘2⋮𝑘𝑟⎞⎟ ⎟ ⎟ ⎟ ⎟ ⎟⎠β=k1a1+k2a2+⋯+krar=(a1,a2,⋯,ar)(k1k2⋮kr)

    By convention, vectors 𝑎a are placed side by side on the left; scalars 𝑘k are placed vertically on the right, forming a "column vector".

    Note: The "column vector" formed by scalars here is just a convenient formal notation, not belonging to space 𝑉V, and fundamentally differs from the vectors on the left. If the left-side vectors happen to be column vectors, arranging them side by side formally constitutes a "matrix", and the above product is exactly the common form of "matrix times column vector".

    As noted below, linear representation is equivalent to the vector 𝛽β lying in the image space of the matrix (𝑎1,𝑎2⋯,𝑎𝑟)(a1,a2⋯,ar).

    According to the definition below, the zero vector always lies in the image space. From the perspective of linear transformations, linear dependence is equivalent to multiple vectors being mapped to the zero vector after transformation, while linear independence is equivalent to only the zero vector itself being mapped to the zero vector.

    Properties

    For a vector space (𝑉, +, ⋅,ℙ)(V,+,⋅,P):

    1. If a subset of a vector set is linearly dependent, then the vector set is linearly dependent. If a vector set is linearly independent, then any non-empty subset is linearly independent. Brief summary: "Large independent, small independent"; "Small dependent, large dependent".
    2. A vector set containing 𝜃θ is linearly dependent.
    3. A vector set is linearly dependent if and only if some vector in the set can be linearly expressed by the other vectors.
    4. If vector 𝛽β can be linearly expressed by vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an, then the expression is unique if and only if the vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is linearly independent.
    5. If vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is linearly independent, then vector 𝛽β can be linearly expressed by vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an if and only if vector set 𝑎1,𝑎2,…,𝑎𝑛,𝛽a1,a2,…,an,β is linearly dependent.

    Maximal Linearly Independent Set, Rank

    Linear dependence can be understood as "redundancy", indicating that some vectors in the set can be expressed by others and can be deleted. After deleting them, what remains is a maximal linearly independent set.

    For a vector space (𝑉, +, ⋅,ℙ)(V,+,⋅,P):

    1. For vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm, let {𝑎1,𝑎2,…,𝑎𝑛} ⊆{𝑏1,𝑏2,…,𝑏𝑚}{a1,a2,…,an}⊆{b1,b2,…,bm}, if:

      • Vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is linearly independent.
      • ∀𝛽 ∈{𝑏1,𝑏2,…,𝑏𝑚} ∖{𝑎1,𝑎2,…,𝑎𝑛}∀β∈{b1,b2,…,bm}∖{a1,a2,…,an}, vector set 𝑎1,𝑎2,…,𝑎𝑛,𝛽a1,a2,…,an,β is linearly dependent.

      Then vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is called a maximal linearly independent set of vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm. Similarly, maximal linearly independent sets of vector space 𝑉V can be defined.

      By convention, the maximal linearly independent set of vector set 𝜃,𝜃,…,𝜃θ,θ,…,θ is the empty set. Thus, the vector set corresponding to an all-zero matrix has no maximal linearly independent set.

      The method of deleting vectors from a set is not unique, so maximal linearly independent sets are not unique. Conventionally, delete from left to right.

      Conveniently, by deleting in order, the vectors left over are exactly the columns corresponding to the positions of 11's in the row-reduced echelon matrix from the "row perspective" view of Gaussian elimination.

      The size of a maximal linearly independent set of vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm is called the rank of the vector set, denoted rank⁡{𝑏1,𝑏2,…,𝑏𝑚}rank⁡{b1,b2,…,bm}, with rank⁡{𝜃,𝜃,…,𝜃} =0rank⁡{θ,θ,…,θ}=0.

      Thus, the definition of rank for vector sets is completely consistent with the definition of rank for matrices.

    2. If vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an can linearly express all vectors in vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm, then vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm is said to be linearly expressed by vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an.

    3. If vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an can be linearly expressed by vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm, and vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm can be linearly expressed by vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an, then the two vector sets are called equivalent, denoted {𝑎1,𝑎2,…,𝑎𝑛} ≅{𝑏1,𝑏2,…,𝑏𝑚}{a1,a2,…,an}≅{b1,b2,…,bm}.

      Equivalence of vector sets means the same spanned space. Vector sets with the same spanned space are equivalent; vector sets with different spanned spaces are not equivalent.

      Vector set equivalence is stronger than matrix equivalence. It not only requires the same rank but also the exact same space. Therefore, when two matrices are placed side by side, the rank must not change.

      Matrix equivalence only requires the same rank. Therefore, matrix equivalence indicates that the first matrix (or space) can be transformed to the second matrix (or space) by an invertible transformation.

    Properties

    For a vector space (𝑉, +, ⋅,ℙ)(V,+,⋅,P):

    1. If vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an can be linearly expressed by vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm.

      • If 𝑛 >𝑚n>m, then vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is linearly dependent.
      • If vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an is linearly independent, then 𝑛 ≤𝑚n≤m.

    2. Equivalent linearly independent vector sets have the same size.

      Any maximal linearly independent set of a vector set has the same size.

    3. A vector set is linearly independent if and only if its rank equals its size.

    4. If vector set 𝑎1,𝑎2,…,𝑎𝑛a1,a2,…,an can be linearly expressed by vector set 𝑏1,𝑏2,…,𝑏𝑚b1,b2,…,bm, then rank⁡{𝑎1,𝑎2,…,𝑎𝑛} ≤rank⁡{𝑏1,𝑏2,…,𝑏𝑚}rank⁡{a1,a2,…,an}≤rank⁡{b1,b2,…,bm}.

    5. Equivalent vector sets have the same rank.

    Isomorphism

    1. 𝜎(𝑢 +𝑣) =𝜎(𝑢) +𝜎(𝑣)σ(u+v)=σ(u)+σ(v)
    2. 𝜎(𝑘𝑢) =𝑘𝜎(𝑢)σ(ku)=kσ(u)

    Then 𝜎σ is called an isomorphism from 𝑉V to 𝑉′V′, and 𝑉V and 𝑉′V′ are said to be isomorphic, denoted 𝑉 ≅𝑉′V≅V′.

    Applications

    From this section, we mainly discuss the "column perspective" on linear systems.

    Matrix 𝐴A itself is also composed of column vectors. By treating 𝐴A as a vector set, and 𝑥x as unknown coefficients, we ask whether this set of column vectors in 𝐴A can be combined with unknowns to form column vector 𝑏b. Here, column vector 𝑥x is completely unknown.

    The equation 𝐴𝑥 =𝑏Ax=b can be reorganized as:

    𝛼1𝑥1+𝛼2𝑥2+⋯+𝛼𝑛𝑥𝑛=𝑏α1x1+α2x2+⋯+αnxn=b

    Here, matrix 𝐴A on the left of the matrix multiplication can be seen as a vector set, i.e., a group of column vectors. This set of column vectors, as a basis, spans a space. We explore whether column vector 𝑏b lies in this space.

    Solving Linear Systems from the Column Perspective

    Rank is the number of vectors in a maximal linearly independent set, representing "constraints". The remaining vectors give the degrees of freedom, allowing redundant vectors in other directions.

    If we denote 𝑛n as the number of columns of matrix 𝐴A (the number of column vectors), and 𝑟(𝐴)r(A) as the rank of matrix 𝐴A, then the degrees of freedom 𝑆S is:

    𝑆=𝑛−𝑟(𝐴)S=n−r(A)

    The set of all solutions to the system also forms a vector set. The degrees of freedom 𝑆S is the rank of the solution vector set of 𝐴𝑥 =0Ax=0, i.e., the dimension of the kernel space below.

    Equivalent Systems

    The common solutions of two systems are defined as the intersection of their two solution sets.

    Two systems are equivalent if their solution sets are equal. Systems with equal solution sets are equivalent; systems with different solution sets are not equivalent.

    System equivalence is stronger than matrix equivalence. Not only must the ranks be equal, but when the two matrices are placed vertically, the rank must still not change.

    This contrasts with vector set equivalence, where vector set equivalence requires matrices placed horizontally with unchanged rank. Therefore, the following relationship holds:

    Matrix equivalence does not necessarily imply corresponding vector set equivalence or system equivalence, but if vector set equivalence or system equivalence holds, then corresponding matrix equivalence (same rank) must hold.

    If the vector set corresponding to a matrix is equivalent, then transposing the matrix makes the corresponding systems equivalent, and vice versa.

    Kernel Space and Image Space of a Matrix

    The kernel space and image space here are described from the perspective of vector spaces.

    For a matrix 𝐴A, let 𝑊W be the set of all solutions 𝑥x to the equation 𝐴𝑥 =0Ax=0. Then 𝑊W is a vector space. The scalar field of 𝑊W is the same as the field containing elements of 𝐴A.

    𝑊W is called the kernel space (or null space) of matrix 𝐴A, denoted 𝑁(𝐴)N(A).

    The kernel space 𝑁(𝐴)N(A) of matrix 𝐴A is the solution space of equation 𝐴𝑥 =0Ax=0. According to the definition of basis below, the fundamental solution set of this equation is a basis of the kernel space.

    If matrix 𝐴A is invertible, then its kernel space 𝑁(𝐴)N(A) contains only the zero vector.

    For matrix 𝐴A, its 𝑛n columns are vectors 𝛼α. The space spanned by the 𝑛n column vectors 𝛼α is called the image space (or column space) of 𝐴A, denoted:

    𝑅(𝐴)=span⁡{𝛼1,𝛼2,⋯,𝛼𝑛}R(A)=span⁡{α1,α2,⋯,αn}

    According to the definition of dimension below, the dimension of the image space equals the rank of matrix 𝐴A.

    From the definition, for every element 𝑦y in image space 𝑅(𝐴)R(A), there exists a representation:

    𝑦=𝑘1𝛼1+𝑘2𝛼2+⋯+𝑘𝑛𝛼𝑛=(𝛼1,𝛼2,⋯,𝛼𝑛)⎛⎜ ⎜ ⎜ ⎜ ⎜ ⎜⎝𝑘1𝑘2⋮𝑘𝑛⎞⎟ ⎟ ⎟ ⎟ ⎟ ⎟⎠=𝐴⎛⎜ ⎜ ⎜ ⎜ ⎜ ⎜⎝𝑘1𝑘2⋮𝑘𝑛⎞⎟ ⎟ ⎟ ⎟ ⎟ ⎟⎠y=k1α1+k2α2+⋯+knαn=(α1,α2,⋯,αn)(k1k2⋮kn)=A(k1k2⋮kn)

    Therefore, image space 𝑅(𝐴)R(A) is the range of 𝐴𝑥Ax for any vector 𝑥x.

    Similarly, the row space of 𝐴A can be defined as the range of 𝐴𝑇AT, denoted 𝑅(𝐴𝑇)R(AT).

    Since the row rank equals the column rank, the dimension of the row space also equals the rank of the matrix. Thus, transposition changes the image space but not its dimension.

    Here we can establish correspondences with the preceding discussion:

    Vector set equivalence is equivalent to the image spaces 𝑅(𝐴)R(A) of the corresponding matrices being the same.

    System equivalence is equivalent to the row spaces 𝑅(𝐴𝑇)R(AT) of the corresponding matrices being the same.
